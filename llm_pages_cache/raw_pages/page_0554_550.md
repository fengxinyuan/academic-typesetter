## 15.8 马尔可夫链  

非负矩阵出现在多种物理问题中。下面我们简要介绍一个概率论中的问题，该问题运用了本章此前所建立的部分定理。

为简化起见，我们考虑一个物理系统，其状态（或状况、或位置）可用 $ n $ 种互斥且穷尽的方式加以描述。我们用 $ \mathbf{$s _ { 1 } , s _ { 2 } $, \ldots , s$ _ { n }$} $ 表示这些状态。我们假定可在时刻 $ \mathbf{$t _ { 0 } < t _ { 1 } < t _ { 2 } $< \cdots } $ 对该系统进行观测，并记录系统在每一时刻所处的状态。我们进一步假定：对每个 $ i = 1,2,\dots,n $ 和每个时刻 $ t_k $，存在一个**绝对概率** $ \mathbf{$p _ { i } ( t _ { r } )$} $，即系统在时刻 $ \mathbf{$t _ { r }$} $ 处于状态 $ \mathbf{$s _ { i }$} $ 的概率，其中 $ k = 0,1,2,\dots $ 且 $ i = 1,2,\dots,n $。由于系统在时刻 $ \mathbf{$t _ { r }$} $ 必处于 $ n $ 个状态之一，故有  

$$

$$}
