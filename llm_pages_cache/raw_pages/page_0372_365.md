习题 5．设 $A \in \mathbb { C } ^ { n \times n }$，$\lambda _ { A }$ 表示 $A ^ { * } A$ 的谱半径。若 $\big \| \bigstar \bigstar \bigstar$ 表示谱范数，则证明 $\| A \| _ { s } = \lambda _ { A } ^ { 1 / 2 }$。（换言之，$\left. A \right. _ { s }$ 恰好等于 $A$ 的最大奇异值。）

**解**：矩阵 $A ^ { * } A$ 是半正定埃尔米特矩阵，因此其特征值均为非负实数。于是 $\lambda _ { A }$ 实际上是 $A ^ { * } A$ 的一个特征值。

$( 1 \leq i \leq n - 1 )$



设  \pmb { x } _ { 1 } , \  $\pmb { x }$ _ { 2 } $, \ldots , \ \pmb { x }$ _ { n }  是矩阵  A ^ { * } A  的一组标准正交特征向量，其对应的特征值为 $0 \leq \lambda$ _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n } 。注意 $\lambda$ _ { 1 } $= \lambda$ _ { n } ，且若 $\begin{array} { r } { { \pmb x } = \sum$ _ { i = 1 } ^ { n } $\alpha$ _ { i } { $\pmb x }$ _ { i } } $\end{array}$ ，则 $\begin{array} { r } { A ^ { * } A { \bf x } = \sum$ _ { i = 1 } ^ { n } $\alpha$ _ { i } $\lambda$ _ { i } $\pmb { x }$ _ { i } } $\end{array}$ 。令 $\Vert \big \Vert \big \Vert \big \Vert$ _ { $\mathrm { ~ E ~ } }$ 表示 $ \mathbb{C}^n $ 上的欧几里得向量范数。于是有  

$$

\| A { \pmb x } \| _ { \mathrm { E } } ^ { 2 } = ( A { \pmb x } , A { \pmb x } ) = ( { \pmb x } , A ^ { * } A { \pmb x } ) = \sum _ { i = 1 } ^ { n } | \alpha _ { i } | ^ { 2 } \lambda _ { i } .
$$
  

对满足  \pmb { x } $\in \mathbb { C } ^ { n }$ 的向量 $ x $，即 $\sum$ _ { i = 1 } ^ { n } $\vert \alpha$ _ { i } $\vert ^ { 2 } = 1$ ，上述表达式不超过 $\lambda$ _ { n } ，且当 $\alpha$ _ { 1 } $= \alpha$ _ { 2 } $= \cdot \cdot \cdot = \alpha$ _ { n - 1 } = 0  且 $\mathfrak { X }$ _ { n } = 1  时取等号。因此  

$$

\left\| A \right\| _ { \mathrm { s } } = \operatorname* { m a x } _ { \left\| \mathbf { x } \right\| _ { \mathrm { E } } = 1 } \left\| A \mathbf { x } \right\| _ { \mathrm { E } } = \lambda _ { n } ^ { 1 / 2 } = \lambda _ { A } ^ { 1 / 2 } .
$$
