## 5.3 埃尔米特矩阵、斜埃尔米特矩阵与定矩阵

埃尔米特矩阵的结构与性质尤为简洁而优美。由于此类矩阵在实际应用中频繁出现，深入理解它们至关重要。特别地，若矩阵 A 满足 $A ^ { * } = A$，则称 A 为埃尔米特矩阵。因此，根据定理 5.2.3 可知，任一埃尔米特矩阵均为正规矩阵，从而具备前一节所确立的所有正规矩阵的性质。

## 定理 1．埃尔米特矩阵的谱是实数集。

**证明．** 埃尔米特矩阵 H 是正规矩阵，故由式 (5.2.1) 可知，$H = U D U ^ { * }$，其中 U 是酉矩阵，D 是由 H 的特征值构成的对角矩阵。但 $H ^ { * } = H$ 意味着 $U \overleftrightarrow { D } U ^ { * } = U D U ^ { * }$，从而推出 $\begin{array} { r } { \overrightarrow { D } = D ; } \end{array}$，由此即得结论。

进一步地，还可断言：一个正规矩阵 A 具有实谱，是 A 为埃尔米特矩阵的充分必要条件。

**定理 2．** 一个正规矩阵 A 是埃尔米特矩阵，当且仅当其谱位于实轴上。

**证明．** 设 $A ^ { * } A = A A ^ { * }$，且假设 $\sigma ( A ) \subset ( - \infty , \infty )$。由于 $A = U D U ^ { \star }$ 且 $A ^ { * } = U D ^ { * } U ^ { * } = U D U ^ { * }$，故有 $A = A ^ { * }$，从而 A 是埃尔米特矩阵。

本定理的第二部分即为定理 1。

因此，埃尔米特矩阵——且仅埃尔米特矩阵——具有标准正交特征向量基（orthonormal eigenbasis）以及实谱（real spectrum）。埃尔米特矩阵的另一重要刻画则由其定义及定理 5.1.1 推出。

习题 1．证明：一个 $ n \times n $ 矩阵 $ A $ 是埃尔米特矩阵，当且仅当对所有 $\mathbf { x } , \mathbf { y } \in { \mathcal { F } } ^ { n } , \ \mathbf { \partial } \bigcirc$ ，均有 $ (Ax, y) \; $\mathbf { \ x { $\equiv } } = ( \mathbf { x } , A \mathbf { y }$ ) 。

我们知道，对任意方阵而言，属于互异特征值的特征向量必线性无关（命题 4.10.4）。若该矩阵是埃尔米特矩阵，则它也是正规矩阵；而根据正规变换的定义，它必存在一组标准正交特征向量基。
