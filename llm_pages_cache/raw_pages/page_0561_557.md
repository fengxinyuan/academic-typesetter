# 分析学中的一些定理与概念

本附录中，我们不加证明地讨论若干分析学中的重要定理；这些定理在本书正文部分被多次使用。我们以足够一般化的框架陈述这些结果，以满足本书应用之需；尽管它们在更一般的背景下同样可以轻易证明。首先，我们需要一些定义。

回顾可知，在 $\mathbb { C } ^ { n }$ 中，任意向量范数均可作为向量大小（或距离）的度量（参见第 10.2 节）。给定 $\mathbb { C } ^ { n }$ 上的一个向量范数 $\parallel \parallel$ 及一个实数 $\varepsilon > 0 _ { ; }$，我们定义点 $\ b { x _ { 0 } } \in \mathbb { C } ^ { n }$ 的一个邻域 $\mathcal { N } _ { \varepsilon } ( \mathbf { x } _ { 0 } )$ 为：所有满足 $\| \pmb { x } - \pmb { x _ { 0 } } \| < \varepsilon$ 的向量 x（在此语境下亦称为点）所构成的集合（即以 $\pmb { x } _ { 0 }$ 为中心、半径为 ε 的球体的内部；参见第 10.2 节）。若 $\mathbb { C } ^ { n } ,$ 中的一点集为 $\mathcal { S }$，则称点 x 是 $\mathcal { S }$ 的一个极限点，当且仅当 x 的每个邻域均包含某个点 $\pmb { y } \in \mathcal { S }$，使得 ${ \pmb y } \neq { \pmb x } .$。若集合 $\mathcal { S }$ 可表示为若干邻域的并集，则称其为开集；若 $\mathcal { S }$ 的每一个极限点都属于 S，则称其为闭集。集合 $\mathcal { S }$ 称为有界集，若存在实数 $K \geq 0$ 及某个 $\boldsymbol { \mathbf { \mathit { x } } } \in \mathbb { C } ^ { n }$，使得对所有 $\pmb { y } \in \mathcal { S } .$ 均有 $\| { \boldsymbol { y } } - { \boldsymbol { x } } \| < K$ 成立。
