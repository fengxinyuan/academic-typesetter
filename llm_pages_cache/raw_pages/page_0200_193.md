注意式 (7) 和式 (9) 中矩阵 $U$ 与 $V$ 的结构：将 $U$（相应地，$V$）的各列视作来自 $ \text{${ $\mathcal { F } } ^ { m } } $（相应地，$ \text{${ $\mathcal { F } } ^ { n }$ )$} $）的向量，则它们分别构成 $ \text{$A A ^ { * }$} $ 在 $ \text{${ $\mathcal { F } } ^ { m } } $ 中（相应地，$ \text{$A ^ { * } A$} $ 在 $ \text{${ $\mathcal { F } } ^ { n }$ )$} $ 中）的一组标准正交特征向量基。因此，矩阵 $A$ 的奇异值分解可通过求解矩阵 $ \text{$A A ^ { * }$} $ 与 $ \text{$A ^ { * } A$} $ 的特征值—特征向量问题而获得。

例 4．考虑习题 5.4.2 中定义的矩阵 $A$；其奇异值为 $ \text{$s _ { 1 } $= \sqrt { 2 } } $ 与 $ \text{$s _ { 2 } = 1$} $。为求 $A$ 的一个奇异值分解，我们计算 $ \text{$A ^ { * } A$} $ 与 $ \text{$A A ^ { * }$} $，并分别为这两个矩阵构造标准正交特征向量基。在 $ \text{$\mathcal { F } ^ { 2 }$} $ 中可取标准基作为 $ \text{$A ^ { * } A$} $ 的基；而对 $ \text{$A A ^ { * }$} $，则可取向量组 $ \text{$\{ [ { $\boldsymbol { \alpha } } \quad { \boldsymbol { 0 } } \quad \alpha ] ^ { \mathrm { { T } } } , [ { \boldsymbol { 0 } } \quad { \boldsymbol { 1 } } \quad { \boldsymbol { 0 } } ] ^ { \mathrm { { T } } } , [ { \boldsymbol { \alpha } } \quad { \boldsymbol { 0 } } \quad - \alpha ] ^ { \mathrm { { T } } } \} } $，其中 $ \text{$\alpha  $= 1 / \sqrt { 2 } , } $。于是

$$
A = { \left[ \begin{array} { l l } { 1 } & { 0 } \\ { 0 } & { 1 } \\ { 1 } & { 0 } \end{array} \right] } = { \left[ \begin{array} { l l l } { \alpha } & { 0 } & { \alpha } \\ { 0 } & { 1 } & { 0 } \\ { \alpha } & { 0 } & { - \alpha } \end{array} \right] } { \left[ \begin{array} { l l } { { \sqrt { 2 } } } & { 0 } \\ { 0 } & { 1 } \\ { 0 } & { 0 } \end{array} \right] } { \left[ \begin{array} { l l } { 1 } & { 0 } \\ { 0 } & { 1 } \end{array} \right] }
$$

即为 $A$ 的一个奇异值分解。

关系式 (7) 引出了两个 $m \times n$ 矩阵 $ A $ 与 $ B $ 的**酉等价**（unitary equivalence）这一普遍概念。我们称 $ A $ 与 $ B $ 是酉等价的，若存在酉矩阵 $ U $ 与 $ V $，使得  
$$
$A = U B V ^ { * }$.
$$  
显然，酉等价是一种等价关系；而定理 2 可被理解为断言：在每一酉等价类中，均存在一个关于酉等价的规范形（即矩阵 $ D $）。接下来的结果是预期之中的。

**命题 2.** 两个 $ m \times n $ 矩阵酉等价，当且仅当它们具有相同的奇异值。

**证明.** 假设矩阵 $ A $ 与 $\pmb { { \cal B } } \in \mathcal { F } ^ { m }  ^ { \star , }$ 的奇异值重合。对每个矩阵分别写出形如 (7) 的奇异值分解（取相同的 $ D $），则酉等价性立即可得。

反之，设 $ A $ 与 $ B $ 酉等价，并设  D _ { 1 }  与  D _ { 2 }  分别为 $ A $ 与 $ B $ 在其奇异值分解中出现的奇异值矩阵。不失一般性，可假设  D _ { 1 }  与  D _ { 2 }  对角线上的奇异值按非减顺序排列。容易验证：$ A $ 与 $ B $ 的酉等价性蕴含  D _ { 1 }  与  D _ { 2 }  亦酉等价：  
$$
$\ b { D _ { 2 } } = \ b { U _ { 1 } D _ { 1 } } \ b { V _ { 1 } ^ { * } }$.
$$  
将上述关系式视为  D _ { 2 }  的奇异值分解，并注意到此类表示中中间因子  D _ { 1 }  是唯一确定的，即可推出  
$$
$D _ { 1 } = D _ { 2 }$.
$$

**推论 1.** 两个 $m \times n$ 矩阵 $ A $ 与 $ B $ 酉等价，当且仅当矩阵  A ^ { * } A  与  B ^ { * } B  相似。
