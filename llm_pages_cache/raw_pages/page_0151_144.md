例 7．设  T  $\in \mathcal { L } ( \mathcal { F } ^ { 2 }$ )  定义如下：

$$

T { \sqrt { \left( { \frac { x _ { 1 } } { x _ { 2 } } } \right) } } = { \left[ \begin{array} { l l } { x _ { 1 } + x _ { 2 } } \\ { \qquad x _ { 2 } } \end{array} \right] } .
$$


显然，子空间 $\begin{array} { r l } { \mathcal { S } _ { 0 } \triangleq \operatorname { s p a n } \{ [ 1 } & { { } 0 ] ^ { \mathrm { T } } \} = \{ [ \alpha \quad 0 ] ^ { \mathrm { T } } : \alpha \in \mathcal { F } \} } \end{array}$ 是 $T$-不变的：$\begin{array} { r l } { T ( [ \alpha } & { { } 0 ] ^ { \mathsf { T } } ) = [ \alpha \quad 0 ] ^ { \mathsf { T } } \in \mathcal { S } _ { 0 } } \end{array}$。然而，子空间 $\tilde { \mathcal { S } } \triangleq \operatorname { s p a n } \{ [ 0 \quad 1 ] ^ { \mathbf { T } } \}$ 是 $\mathcal { S } _ { \mathbf { 0 } }$ 的一个直和补子空间，但它并非 $T$-不变的：$\begin{array} { r l } { T ( [ 0 } & { { } 1 ] ^ { \boldsymbol { \mathsf { T } } } ) = } \end{array} \begin{array} { r l } { [ 1 } & { { } 1 ] ^ { \boldsymbol { \mathsf { T } } } \notin \tilde { \mathcal { S } } . } \end{array}$。注意到 $\mathcal { S } _ { \mathfrak { d } }$ 是 $\mathcal { F } ^ { 2 }$ 中唯一的非平凡 $T$-不变子空间，因此我们推出：无法将 $\mathcal { F } ^ { 2 }$ 分解为若干 $T$-不变子空间的直和。□

若向量空间 $\mathcal { S }$ 可分解为 $k$ 个子空间 $\mathcal { S } _ { i } ,$ 的直和，且这些子空间均是 $T$-不变的，则对每个 $\mathbf { x } \in { \mathcal { S } } ,$，我们可写出：

$$
T ( \pmb { x } ) = \sum _ { i = 1 } ^ { k } { \frac { \ d } { \ d t } } T _ { i } ( \pmb { x } _ { i } ) ,\tag{3}
$$

其中，对每个 $ i $，有 $\begin{array} { r } { \mathbf { \Delta x } = \sum _ { i = 1 } ^ { k } x _ { i } \left( x _ { i } \in \mathcal { S } _ { i } , i = 1 , 2 , . . . , k \right) } \end{array}$ 和 $T _ { i } = \left. T \right. _ { \mathcal { S } _ { i } }$。（参见习题 2 后面的注记。）注意，当 $k = 2 \mathrm { E q }$ 时，式 (3) 与式 (1) 的差异在于：我们现在可将 $T _ { i }$ 解释为属于 ${ \mathcal { L } } ( { \mathcal { S } } _ { i } )$，其中 $ i = 1 $ 和 $ 2 $。在牢记式 (3) 的前提下，我们给出如下定义。

设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，且设 $\begin{array} { r } { \mathcal { S } = \sum _ { i = 1 } ^ { k } \dot { \mathcal { S } } _ { i } } \end{array}$，其中每个 $\mathcal { S } _ { i }$ 是 $ T $-不变子空间。则称线性变换 $_ T$ 为变换 $T _ { i } = T | _ { \mathcal { S } _ { i } } \left( i = 1 , 2 , \ldots , k \right)$ 的直和，并记作  

$$
T = \sum _ { i = 1 } ^ { k } { } ^ { \cdot } T _ { i } \triangleq T _ { 1 } + T _ { 2 } + \cdots + T _ { k } .\tag{4}
$$  

需注意，式 (4) 现在蕴含对每个 $\pmb { x } \in \mathcal { S } ,$，式 (3) 成立；反之亦然。表示式 (4) 的重要意义在于：它使得我们将对变换 $T$ 的研究归约为对其“部分” $T _ { i }$（分别作用于更小的子空间上）的研究。这正是下一节分析 $T .$ 的矩阵表示类时所采用的基本策略。
