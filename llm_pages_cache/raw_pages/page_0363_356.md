范数可在一线性空间上以极为多样的方式定义，从而导出具有不同几何形状的单位球。然而，所有单位球共有的一个性质是凸性。（关于凸性的普遍讨论，参见附录 2。）

**定理 1.** 赋范线性空间中的单位球是一个凸集。

**证明.** 设 $\mathcal { S } , \Vert \mathbf { \Sigma } \Vert$ 是一个赋范线性空间，其单位球为 $ B $。若 $ x, y \in B $，则对任意 $ \lambda \in [0,1] $，向量 $ \lambda x + (1-\lambda)y $ 属于连接 $ x $ 与 $ y $ 的线段。我们只需证明 $ \|\lambda x + (1-\lambda)y\| \leq 1 $。但由范数的第二条与第三条公理可立即得到  

$$
\| z \| \leq t \| x \| + ( 1 - t ) \| y \| ,
$$  

又因 $ \|x\| \leq 1 $ 且 $ \|y\| \leq 1 $，故有 $ \lambda\|x\| + (1-\lambda)\|y\| \leq \lambda \cdot 1 + (1-\lambda) \cdot 1 = 1 $，从而 $ \|\lambda x + (1-\lambda)y\| \leq 1 $，即 $ \lambda x + (1-\lambda)y \in B $。

**习题 2.** 证明：赋范线性空间中任意一个球都是凸集。

赋范线性空间中一种基本的开集是邻域，它简单地定义为一个球的内部。更严格地说，若 $\mathcal { S } , \parallel \mathbf { \Sigma } \parallel$ 是一个赋范线性空间，则以 $\scriptstyle { \pmb { x } } _ { 0 }$ 为中心、半径为 $r$ 的邻域是指如下集合：  

$$
N ( \pmb { x } _ { 0 } , r ) = \{ \pmb { x } \in \mathcal { S } ; \lVert \pmb { x } - \pmb { x } _ { 0 } \rVert < r \} .\tag{1}
$$

$x , y \in B , t \in [ 0 , 1 ] z = t { \pmb x } + ( 1 - t ) { \pmb y } z \in B . \| { \boldsymbol { \mathbf { x } } } \| \leq 1 \| \mathbf { y } \| \leq 1 \| z \| \leq 1 z \in B .$



邻域在分析学中经常十分有用。例如，若 $\mathcal { S } , \parallel \mathbf { \Sigma } \parallel$ 与 $\mathcal { R } , \parallel \mathbf { \epsilon } \parallel _ { 2 }$ 是两个赋范线性空间，且 $f$ 是定义在 $\mathcal { S }$ 上、取值于 ${ \mathcal R } ,$ 的函数，则 $f$ 在点 $\pmb { x } _ { 0 } \in \mathcal { S }$ 处连续，是指：对任意给定的 $\varepsilon > 0$，存在一个依赖于 $\delta ,$ 的 $\delta > 0 _ { : }$，使得当 ${ \pmb x } \in N ( { \pmb x } _ { 0 } , \delta )$ 时，有 $f ( { \pmb x } ) \in N ( f ( { \pmb x } _ { 0 } )$，ε）。注意，$N ( \pmb { x } _ { 0 } , \delta )$ 是由范数 $\parallel \parallel _ { 1 }$ 所定义的 $\mathcal { S }$ 中的一个邻域，而 $N ( f ( \pmb { x } _ { 0 } ) , \pmb { \varepsilon } )$ 是由范数 $\Vert \bigstar \bigstar \bigstar | | _ { 2 }$ 所定义的 $\mathcal { R }$ 中的一个邻域。

分析学的一个基本概念是收敛性；我们在第9.8节中已讨论过 $\mathbb { C } ^ { n }$ 与 $\mathbb { R } ^ { n }$ 中序列与级数的收敛性。对于一般的有限维线性空间 ${ \mathcal { S } } ,$，前述方法可加以推广：首先在 ${ \mathcal { S } } .$ 中引入一组基，记为 $\left\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \right\}$。若 $\{ \pmb { x } _ { k } \} _ { k = 1 } ^ { \infty }$ 是 $\mathcal { S }$ 中的一个序列，则该序列的每一项均可表示为

$$
{ \bf x } _ { k } = \sum _ { j = 1 } ^ { n } \mathrm { ~ } \alpha _ { j } ^ { ( k ) } b _ { j } , \mathrm { ~ } k = 1 , 2 , \ldots ,\tag{2}
$$

且称该序列**按坐标收敛**于元素 $\begin{array} { r } { \mathbf { x } _ { 0 } = \sum _ { j = 1 } ^ { n } \alpha _ { j } ^ { ( 0 ) } \pmb { b } _ { j } } \end{array}$，若对由令 $j = 1 , 2 , \dots , n .$ 所得的 $n$ 个标量序列中的每一个，均有 ${ \alpha } _ { j } ^ { ( k ) }  { \alpha } _ { j } ^ { ( 0 ) }$ 当 $k \to \infty$ 时成立。因此，第 9.8 节中所讨论的向量序列之收敛，即为线性空间 $\mathbb { C } ^ { n }$ 关于其标准基的按坐标收敛。
