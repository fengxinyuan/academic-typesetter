定理 2．设 $( U , T , V )$ 是 L(λ) 的一个标准三元组。则微分方程 (14.4.1) 在任意给定向量 $\mathbf { x } _ { 0 } , \mathbf { x } _ { 1 } , \ldots , \mathbf { x } _ { l - 1 } \in \mathbb { C } ^ { n } ,$ 下满足如下初始条件：  

$$
\begin{array} { r } { { \pmb x } ^ { ( j ) } ( 0 ) = { \pmb x } _ { j } , \qquad j = 0 , 1 , \ldots , l - 1 , } \end{array}\tag{7}
$$  

的解存在且唯一。该解由公式 (6) 给出，其中  

$$
\boldsymbol { z } = [ V \quad T V \quad \cdots \quad T ^ { l - 1 } . V ] S _ { L } \left[ \begin{array} { c } { \boldsymbol { x } _ { 0 } } \\ { \vdots } \\ { \boldsymbol { x } _ { l - 1 } } \end{array} \right] ,\tag{8}
$$  

而 $S _ { L }$ 是 $L ( \lambda )$ 的对称化子（symmetrizer）。

**证明**．我们首先验证：由公式 (6) 和 (8) 所定义的函数 $\mathbf { \boldsymbol { x } } ( t )$ 确实满足初始条件 (7)。对公式 (6) 求导可得  

$$
\left[ \begin{array} { c } { { \pmb x } ( 0 ) } \\ { { \pmb x } ^ { ( 1 ) } ( 0 ) } \\ { \vdots } \\ { { \pmb x } ^ { ( l - 1 ) } ( 0 ) } \end{array} \right] = \left[ \begin{array} { c } { { U } } \\ { { U T } } \\ { \vdots } \\ { { U T } ^ { l - 1 } } \end{array} \right] z = Q z ,\tag{9}
$$

采用式 (14.2.13) 的记号。但定理 14.2.5 的结论蕴含着 $Q R S _ { L } = I ,$；因此，将式 (8) 中的 $ z $ 代入式 (9)，可知如此定义的 $ x(t) $ 满足初始条件。

最后，由于 $ Q $ 可逆，由式 (9) 即可推出 $ z $ 的唯一性。
