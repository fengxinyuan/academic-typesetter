应当注意，一个集合在某种加法与标量乘法运算下可以构成一个线性空间，但在另一组运算（即使定义在同一数域上）下却未必构成线性空间。例如，集合 $\mathbb { R } _ { 2 }$ 在如下定义的运算下**不构成**实数域 $\mathbb{R}$ 上的线性空间：  

$$
\begin{array} { c } { { ( a _ { 1 } , a _ { 2 } ) + ( b _ { 1 } , b _ { 2 } ) = ( a _ { 1 } + b _ { 1 } - 1 , a _ { 2 } + b _ { 2 } ) , } } \\ { { { } } } \\ { { \alpha ( a _ { 1 } , a _ { 2 } ) = ( \alpha a _ { 1 } , \alpha a _ { 2 } ) } } \end{array}
$$  

其中 $$( a _ { 1 } , a _ { 2 } ) , ( b _ { 1 } , b _ { 2 } ) \in \mathbb { R } _ { 2 }$$ 为任意元素，$$\alpha \in \mathbb { R }$$ 为任意标量。  

为避免此类混淆，我们始终假定：对 $n$ 元组集合与矩阵集合所施行的运算，均如第 1 章所定义。  

最后还需指出：三元组 $$( a _ { 1 } , a _ { 2 } , a _ { 3 } ) _ { \mathrm { { ; } } }$$，曾被称作以原点为起点、以直角坐标为 $$\mathbf { P }$$ 的点 $$( a _ { 1 } , a _ { 2 } , a _ { 3 } )$$ 为终点的向量（这一观点在定义三元组上的运算时尤为有效），亦可视为三维空间中的一个“点”。类似地，$n$ 元组 $$( a _ { 1 } , a _ { 2 } , \ldots , a _ { n } )$$ $$( a _ { i } \in \mathcal { F } , i = 1 , 2 , . . . , n )$$ 亦可称为“$n$ 维”线性空间 $$\mathcal { F } _ { \pmb { \mathscr { n } } }$$ 中的一个“点”。

## 3.2 子空间

设  \mathcal { S }  表示域 $\mathcal { F }$ 上的一个线性空间，并考虑 $\mathcal { S }$ 中的一个元素子集 $\mathcal { S }$ _ { $\mathfrak { d } }$ 。加法与标量乘法运算对 $\mathcal { S }$ 中所有元素均有定义，特别地，对属于 $\mathcal { S }$ _ { $\mathfrak { d } }$ 的那些元素亦有定义。这些运算作用于 $\mathcal { S }$ _ { $\mathfrak { d } }$ 的元素所得结果仍为 $\mathcal { S }$ 的元素。然而，有可能这两个运算是关于 $\mathcal { S }$ _ { $\mathfrak { d } } ^ { \mathrm { ~ \because ~ } }$ 封闭的，即：当对 $\mathcal { S }$ _ { $\mathfrak { d } }$ 中任意元素施行上述两种运算时，所得结果仍属于 $\mathscr { S }$ _ { $\mathfrak { d } }$ 。此时，我们称 $\mathscr { S }$ _ { $\mathfrak { d } }$ 是 $\mathscr { s }  $ 的一个子空间。
