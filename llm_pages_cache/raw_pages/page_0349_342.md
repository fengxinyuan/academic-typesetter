系统理论背景下的概念。设  A  $\in \mathbb { C } ^ { n \times n }$ 与 $B \in \mathbb { C } ^ { n \times m }  $，并考虑如下带初值条件的微分方程：

$$

{ \dot { \mathbf { x } } } ( t ) = A { \mathbf { x } } ( t ) + B u ( t ) , \qquad { \mathbf { x } } ( 0 ) = { \mathbf { x } } _ { 0 } .\tag{4}
$$


相容性要求对每个 $ t $ 均有  \ b { x } $( t ) \in \mathbb { C } ^ { n }$ 且 $\pmb { u } ( t ) \in \mathbb { C } ^ { m }$ 。我们采取如下观点： $\pmb { u } ( t$ )是一个向量函数，称为**控制函数**（control），可用于引导或调控相应初值问题的解  { $\boldsymbol x } ( t$ )，以实现某种目标。我们所考虑的目标是：通过适当选取控制，使得解  { $\boldsymbol x } ( t$ )在某个时刻 $ t $ 之后，函数 $\pmb { x } ( t$ )达到 $\mathbb { C } ^ { n } .  $ 中某个预先指定的向量值。

为使上述思想严格化，我们首先定义一类**容许控制函数**（admissible control functions） \pmb { u } ( t ) 。我们将  { $\mathcal { U } }$ _ { m }  定义为所有定义在区域 $t \geq 0 ,$ 上、取值于 $\mathbb { C } ^ { m } .$ 且分段连续的函数所构成的线性空间；并假定 $\pmb { u } ( t ) \in \mathcal { U }$ _ { m } 。于是，由式 (9.10.10) 可知，当选定控制函数 $\pmb { u } ( t ) \in \mathcal { U }$ _ { m }  后，该初值问题的解可显式地表为

$$

x ( t ; x _ { 0 } , u ) = e ^ { A t } x _ { 0 } + \int _ { 0 } ^ { t } e ^ { ( t - s ) A } B u ( s ) d s .\tag{5}
$$


左侧所采用的复杂记号旨在强调解 $ x $ 对控制函数 $ u $、初值 $\pmb { x }$ _ { 0 }  以及自变量 $ t $ 的依赖关系。

一个向量 $\boldsymbol { y } \in \mathbb { C } ^ { n }$ 称为可从初始向量 $\mathbf { \boldsymbol { x } } _ { 0 }$ 到达，若存在某个 $\pmb { u } ( t ) \in \mathcal { U } _ { m }$，使得对某个正时间 $ t $ 有 $\mathbf { x } ( t ; \mathbf { x } _ { 0 } , { \pmb u } ) = \mathbf { y }$。在相同条件下，我们也可以说：$ y $ 可在时间 $ t $ 内从 $\mathbf { \delta x } _ { 0 }$ 到达。

方程组 (4) 称为可控的（此处“可控性”针对的是系统本身，而非矩阵对的可控性），若 $ \mathbb{R}^n $ 中任意向量均可从 $ \mathbb{R}^n $ 中任一其他向量到达。我们下一个主要目标是证明：系统 (4) 可控当且仅当矩阵对 $ (A, B) $ 可控；而该结论将直接由接下来的定理推出。

首先回顾：矩阵对 $ (A, B) $ 的可控子空间（我们将记作 $\mathcal { C } _ { A , B }$）由下式给出：

$$
\mathcal { C } _ { A , B } = \sum _ { r = 0 } ^ { n - 1 } \operatorname { I m } ( A ^ { r } B ) .\tag{6}
$$

（参见定理 5.13.1 的推论 1(d)。）

定理 2．向量 $z \in \mathbb { C } ^ { n }$ 可在时间 $ t $ 内从 $\pmb { y } \in \mathbb { C } ^ { n }$ 到达，当且仅当

$$
{ \boldsymbol { z } } \mathbin { - } e ^ { A t } \mathbf { y } \in \mathcal { C } _ { A , B } .
$$

该定理的证明将借助另一引理展开；该引理给出了矩阵对 $( A , B )$ 的可控子空间的一个有用刻画。
