定理 3．设 $T \in { \mathcal { L } } ( { \mathcal { S } } _ { 1 } { \mathcal { S } } _ { 2 } )$，且 dim $\mathcal { S } _ { 1 } = n ,$ = dim $\mathcal { S } _ { 2 } = m .$。则下列命题等价：  
(a) T 是可逆的；

(b) $\ker $T = \{ $\pmb { \theta } \}$ $$，$\operatorname{rank} $T = m = n$$

(c) $T$ 在 $$\mathcal { S } _ { 1 }$$ 与 $$\mathcal { S } _ { 2 }$$ 之间定义了一个同构。

(d) $T$ 的任一矩阵表示均为 $n \times n$ 非奇异矩阵。

利用定理 4.5.5，我们可推出以下三条推论。

**推论 1**．设 $$T \in { \mathcal { L } } ( { \mathcal { S } } _ { 1 } , { \mathcal { S } } _ { 2 } )$$ 是左可逆的，则 $T$ 可逆当且仅当 $\dim $\mathcal { S } _ { 1 } $= \dim \mathcal { S }$ _ { 2 }$$。特别地，作用在 $$\mathcal { S }$$ 上的左可逆变换必为可逆变换，且在 $$\mathcal { S }$$ 上定义了一个单射（即一一映射）到其自身的线性映射。

**推论 2**．设 $$T  $\in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } )$$ 是右可逆的，则 $$T$$ 可逆当且仅当 $\operatorname{def} $T = 0$$。特别地，作用在 $$\mathcal { S }$$ 上的右可逆变换必为可逆变换，且在 $$\mathcal { S }$$ 上定义了一个单射到其自身的线性映射。

**推论 3**．任一可逆变换的矩阵表示均为可逆矩阵。

考虑一个可逆变换 $$T \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$$。由定义，存在变换 $$T _ { 1 } , T _ { 2 } \in \mathcal { L } ( \mathcal { S } _ { 2 } , \mathcal { S } _ { 1 } )$$，使得等式 (1) 与 (2) 同时成立。此时，下列等式  

$$
T _ { 1 } = T _ { 1 } I _ { 2 } = T _ { 1 } ( T T _ { 2 } ) = ( T _ { 1 } T ) T _ { 2 } = I _ { 1 } T _ { 2 } = T _ { 2 }
$$  

表明：$T$ 的左逆与右逆重合。因此，存在一个变换 $$T ^ { \prime 1 } \in \mathcal { L } ( \mathcal { S } _ { 2 } , \mathcal { S } _ { 1 } )$$，满足如下条件：  

$$
T ^ { - 1 } T = I _ { 1 } \qquad \mathrm { a n d } \qquad T T ^ { - 1 } = I _ { 2 } .\tag{3}
$$

变换 $T ^ { - 1 }$ 称为 $T$ 的逆变换，且易见其唯一性。将式 (4.2.4) 与式 (3) 比较可知：若 $A$ 是可逆变换 $T \in { \mathcal { L } } ( { \mathcal { S } } _ { 1 } , { \mathcal { S } } _ { 2 } )$ 关于基 $( \mathcal { E } , \mathcal { G } )$ 的一个表示，则 $A ^ { - 1 }$ 即为 $T ^ { - 1 }$ 关于基 $( \mathcal { G } , \mathcal { E } )$ 的表示。特别地，若 $ T $、$T ^ { - 1 } \in { \mathcal { L } } ( { \mathcal { S } } )$，则它们关于 $ \mathcal{V} $ 中某一固定基的表示分别为 $ A $ 与 $\overset { \cdot } { A } ^ { - 1 }$。

注意，定理 3 的第 (d) 条断言：一个变换 $ T $ 可逆当且仅当对任一表示矩阵 $A \in \mathcal { A } _ { T }$，均有 $ \det\,\text{$A  $\neq 0 } \ne 0 $。当 $T$ 作用于空间 ${ \mathcal { S } } ,$ 上时，由习题 4.4.1(b) 可知，它的所有表示矩阵具有相同的行列式。在此情形下，自然可将变换 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 的行列式（记作 $ \det\,\text{$T ,$} $）定义为它的任一表示矩阵 $\mathcal { A } _ { T } ^ { 0 }$ 的行列式。因此我们得出结论：变换 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 可逆当且仅当 $ \det\,\text{$T  $\neq 0 . } \ne 0 $。该结论对矩阵的情形已在第 2.6 节中建立。
