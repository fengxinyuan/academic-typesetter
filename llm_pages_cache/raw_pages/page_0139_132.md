习题 4．证明：若 $( i _ { 1 } , i _ { 2 } , \ldots , i _ { n } )$ 是 $( 1 , 2 , \ldots , n )$ 的一个排列，则对任意 $\pmb { A } = [ a _ { s j } ] _ { s , j = 1 } ^ { n }$，有  

$$
[ a _ { i _ { k } i _ { m } } ] _ { k , m = 1 } ^ { n } \approx [ a _ { s j } ] _ { s , j = 1 } ^ { n }
$$  

提示：注意矩阵 $\pmb { \mathcal { A } } = [ a _ { i _ { k } i _ { m } } ] _ { k , m = 1 } ^ { n }$ 是由 A 先对列作相应置换、再对行作相同置换而得到的。由此可推出：存在一个置换矩阵 P，使得 $\pmb { \tilde { A } } = \pmb { P } \pmb { A } \pmb { P } ^ { - 1 }$。□  

习题 4 引出了如下问题：确定作用于矩阵元素上的哪些运算能将其变为一个相似矩阵。回顾可知，任一非奇异矩阵均可表为初等矩阵之积（参见习题 2.7.7），因此我们将式 (4.3.8) 中的矩阵 P 写成形式 $P = E _ { k } E _ { k - 1 } \cdot \cdot \cdot E _ { 1 }$。于是，将 B 变换为相似矩阵 A 的过程，便可理解为一系列初等矩阵相继作用的结果：

$$
A = E _ { k } ( E _ { k - 1 } \cdot \cdot \cdot ( E _ { 2 } ( E _ { 1 } B E _ { 1 } ^ { - 1 } ) E _ { 2 } ^ { - 1 } ) \cdot \cdot \cdot E _ { k - 1 } ^ { - 1 } ) E _ { k } ^ { - 1 } .
$$  

对于任一初等矩阵 $ E $，运算  E B E ^ { - 1 }  的结果可依据该初等矩阵的类型（参见第 2.7 节）用行变换与列变换简洁地加以描述。以下习题即由此方式建立。

**习题 5.** 证明：一个矩阵被变换为与其相似的矩阵，当且仅当施行如下类型的初等运算：

(a) 将第 $ i $ 列（行）与第 $ j $ 列（行）互换，随后将第 $ i $ 行（列）与第 $ j $ 行（列）互换；

(b) 将第 $ j $ 列（行）乘以非零标量 $ \alpha $，紧接着将第 $ j $ 行（列）乘以 $1 / \alpha ;  $；

(c) 将第 $ j $ 列（行）乘以  { $\pmb { \alpha } } ,$ 后加到第 $ i $ 列（行）上，同时将第 $ i $ 列（行）乘以 $- \alpha ,$ 后加到第 $ j $ 列（行）上。 □  

注意到习题 5 中所述运算不改变矩阵的迹，故可完成下一习题。

**习题 6.** 验证：若  { $\cal A } \approx { \cal B } ,$ ，则 $ \operatorname{tr} A = \operatorname{tr} B $。 □  

需指出的是，我们迄今为相似矩阵等价类所找到的共同不变量（秩、行列式、迹）尚不足以完全刻画该等价类。
