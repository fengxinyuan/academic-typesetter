由此，我们证明了如下命题。

命题 1．系统 $\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \}$ 中线性无关元素的个数，等于其（矩阵）表示关于某一固定基的列空间的维数。

换言之，若 € 表示系统 $\left\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \right\}$ 关于某组基的一个矩阵表示 A $\boldsymbol { \mathcal { C } } _ { A }$ 的列空间，则

$$
\dim ( { \mathrm { s p a n } } \{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \} ) = \dim { \mathcal { C } } _ { A } = \dim ( { \mathrm { I m ~ } } A ) .\tag{5}
$$  

该结果的意义在于：确定任意有限维空间中一组元素所张成的线性包（即线性生成子空间）的维数这一问题，被归约为求一个矩阵的列空间的维数。

还需注意，公式 (5) 对于该系统关于空间 $\mathcal { S }$ 的任一基底的表示均成立。因此，该系统的所有表示所对应的矩阵，其列空间维数均相同。

下一个命题断言了一个引人注目的等式：矩阵 $ A $ 的列空间 $ \mathcal{C} $ 的维数与其秩（按第 2.8 节中基于 $\mathcal { C } _ { A }$ 行列式理论所定义的秩）相等。

**定理 1.** 对任意矩阵 $ A $，  

$$
\dim \mathcal { C } _ { A } = \operatorname { r a n k } A .
$$  

**证明.** 我们需证：列空间的维数等于 $A \in \mathcal { F } ^ { m \times n }$ 的最高阶非零子式（minor）的阶数（参见定理 2.8.1）。

为方便起见，不妨设该最高阶非零子式恰为 $ A $ 左上角 $ r \times r $ 子矩阵的行列式。（否则，通过对 $ A $ 的行与列作适当重排，可得到一个等价矩阵，其左上角 $ r \times r $ 子矩阵即为该非零子式所在位置；而行、列重排不改变矩阵的秩。）设该子矩阵的阶数为 $ r $。考虑 $( r + 1 ) \times ( r + 1 )$ 子矩阵。

$$
\tilde { A } = \left[ \begin{array} { c c c c c } { a _ { 1 1 } } & { \cdots } & { a _ { 1 r } } & { | } & { a _ { 1 s } } \\ { a _ { 2 1 } } & { a _ { 2 r } } & { | } & { a _ { 2 s } } \\ { \vdots } & { } & { \vdots } & { | } & { \vdots } \\ { a _ { r 1 } } & { \cdots } & { a _ { r r } } & { | } & { a _ { r s } } \\ { \scriptstyle \longmapsto \cdots \cdots \cdots \cdots \cdots \cdots } & { | } & { \scriptscriptstyle { 1 } } \\ { a _ { k 1 } } & { \cdots } & { a _ { k r } } & { | } & { a _ { k s } } \end{array} \right]
$$  

并注意到：对所有可能的 $ k $ 与 $ s $ 的取值，均有 $ \det\,\text{$\tilde { A } = 0$} $。
