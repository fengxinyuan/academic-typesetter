**习题 3.** 设 $ \mathbf{$A  $\in \mathcal { F } ^ { m \times n } } $。证明齐次方程 $ \mathbf{$A  $\pmb { x } = \pmb { \theta } } $ 的全部解构成 $ \mathbf{${ $\mathcal { F } } ^ { n } } $ 的一个子空间。 □  

所有满足 $ \mathbf{$A  $\mathbf { x } = \pmb \theta } $ 的向量 $ \mathbf{x} $ 构成的集合称为矩阵 $ A $ 的**零空间**（null space）或**核**（kernel），记作 $ \mathbf{$N ( A )$} $ 或 $ \operatorname{Ker} A $。注意：习题 3 实质上即断言 $ \operatorname{Ker} A $ 是一个子空间。

**解**：向量 $ \mathbf{$[ { $\pmb x }$ _ { 1 } $\quad { \pmb x }$ _ { 2 } $\quad { \pmb x }$ _ { 3 } ] ^ { $\pmb { \Gamma } } } $ 属于 $ \operatorname{Ker} A $ 当且仅当  

$ \mathbf{___SAFE_MATH_SLOT_1___} $

或者，等价地，  

$$
\begin{array} { r l r } & { } & { x _ { 1 } - x _ { 2 } \qquad = 0 , } \\ & { } & { x _ { 1 } + x _ { 2 } + x _ { 3 } = 0 . } \end{array}
$$  

因此，$x _ { 1 } = x _ { 2 } , x _ { 3 } = - 2 x _ { 2 }$，且 Ker A 中的每个向量均具有如下形式：  

$$
\left[ \begin{array} { r } { \alpha } \\ { \alpha } \\ { - 2 \alpha } \end{array} \right] = \alpha \left[ \begin{array} { r } { 1 } \\ { 1 } \\ { - 2 } \end{array} \right]
$$  

其中 α 为某个实数。正如例 1(a) 所示，这是 ℝ³ 的一个子空间。$\mathbb { R } ^ { 3 }$  

几何上，ℝ³ 中的一个向量 x 属于矩阵 $\mathbb { R } ^ { 3 }$ 的核（即 Ker $\pmb { A } = [ a _ { i j } ] _ { i , j = 1 } ^ { m , 3 }$），当且仅当 x 与 A 的所有行向量正交。因此，对 $i = 1 , 2 , \dots , m ,$，向量 x 必须垂直于 $[ { a _ { i } } _ { 1 } \quad { a _ { i } } _ { 2 } \quad { a _ { i } } _ { 3 } ]$。若 $m = 2 ,$，如前一例所示，则任意 x ∈ Ker A 都必须同时正交于向量 $[ 1 ~ - 1 ~ 0 ]$ 和 $[ 1 \quad 1 \quad 1 ] _ { }$；换言之，x 必须正交于由这两个向量张成且过原点的平面。由此显然可见，Ker A 表示一条过原点的直线，且该直线正交于上述平面。

$$
