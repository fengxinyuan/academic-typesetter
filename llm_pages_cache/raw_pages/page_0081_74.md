在该定义中，我们使用了“域”（field）这一概念。域的严格定义属于我们将回避的问题。对于不熟悉该概念的读者，只需理解：本书中凡引入一般域  \mathcal { F }  之处，均可将其替换为 $ \mathbb{R} $（实数集）或 $ \mathbb{C} $（复数集）。

在给出线性空间的具体例子之前，我们先引入一些记号约定。设 $ \mathbb{F} $ 为一个数域，则所有元素取自 $ \mathbb{F} $ 的 $ m \times n $ 矩阵构成的集合记为 $m \times n$ 。特别地， $\mathbb { R } ^ { m \times n } （$ 相应地， $\mathbb { C } ^ { m \times n } )$ ）表示所有实数（相应地，复数） $m \times n$ 矩阵的集合。利用这一记号， $\mathcal { F } ^ { 1 \times n } （$ 相应地， { $\mathcal { F } } ^ { m \times 1 } )$ ）分别表示所有长度为 $ n $ 的行矩阵（相应地，长度为 $ m $ 的列矩阵）的集合。为方便起见，集合  { $\mathcal { F } } ^ { m \times 1 }$ 常简记为  { $\mathcal { F } } ^ { m }$ 。与此不同，符号 $\mathcal { F }$ _ { $\pmb { \mathscr { n } } }$ 表示数域 $\mathcal { F } .$ 中所有有序 $ n $ 元组构成的集合。借鉴某些几何术语，我们将 $[ \pmb { a }$ _ { 1 } $\quad \pmb { a }$ _ { 2 } $\quad \cdots \quad \pmb { a }$ _ { m } ] ^ { $\mathtt { T } } （$ 属于  { $\mathcal { F } } ^ { m }$ ）、 ( a _ { 1 } , a _ { 2 } $, \ldots , a$ _ { m } ) （属于  { $\mathcal { F } }$ _ { m } ）以及 $[ \pmb { a }$ _ { 1 } $\quad \pmb { a }$ _ { 2 } $\quad \cdots \quad \pmb { a }$ _ { m } $] \in \mathcal { F } ^ { 1 \times m }$ ，统称为阶为  { $\pmb m } ,  $ 的向量。
