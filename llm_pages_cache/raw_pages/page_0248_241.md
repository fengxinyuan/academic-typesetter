$$

$$

解．显然，特征多项式为 $c ( \lambda ) = ( \lambda - 2 ) ^ { 4 }$ 且 $\dim ( \operatorname { K e r } ( A - 2 I ) ) = 2 .$。因此，若尔当标准形由两个若尔当块组成。为确定它们的阶数（是 2 和 2，还是 3 和 1），我们计算得  
$( A - 2 I ) ^ { 2 }$，  
$= O$，  
从而习题 6.4.2 中的数 $k _ { 2 }$ 等于 2。故 $k _ { 2 } = 2 l _ { 2 } - l _ { 1 } - l _ { 3 } = 8 - 2 - 4 = 2$，进而存在两个阶数均为 2 的若尔当块：  

$$

$$  

存在一个概念，用于统括若尔当标准形的参数。设 $A \in \mathbb { C } ^ { n \times n }$，令 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 表示其所有互异的特征值，其几何重数分别为 $p _ { 1 } , p _ { 2 } , \ldots , p _ { s }$。于是，在矩阵 A 的若尔当标准形 J 中，对应于特征值 $\lambda _ { j }$ 的若尔当块共有 $p _ { j }$ 个，即 $( 1 \leq j \leq s )$。记这些块的阶数为 $\delta _ { j } ^ { ( 1 ) } \geq \delta _ { j } ^ { ( 2 ) } \geq \cdot \cdot \cdot \geq \delta _ { j } ^ { ( p _ { j } ) }$，并写成  

$$
\{ ( \delta _ { 1 } ^ { ( 1 ) } , \delta _ { 1 } ^ { ( 2 ) } , \ldots , \delta _ { 1 } ^ { ( p _ { 1 } ) } ) , ( \delta _ { 2 } ^ { ( 1 ) } , \delta _ { 2 } ^ { ( 2 ) } , \ldots , \delta _ { 2 } ^ { ( p _ { 2 } ) } ) , \ldots , ( \delta _ { s } ^ { ( 1 ) } , \delta _ { s } ^ { ( 2 ) } , \ldots , \delta _ { s } ^ { ( p _ { s } ) } ) \} .\tag{2}
$$

形式 (2) 被称为矩阵 $ A $ 的**塞格雷特征**†。显然，该特征连同矩阵的特征值一起，唯一确定了其若尔当标准形。注意：数 $ \text{$q _ { j } $= \delta$ _ { j } ^ { ( 1 ) } $+ \delta$ _ { j } ^ { ( 2 ) }$} $、$ \text{${ } $+ \cdot \cdot \cdot { } + \delta$ _ { j } ^ { ( p _ { j } ) } , j = 1 , 2 , . . . , s ,$} $ 分别是特征值 $ \text{$\lambda _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { s }$} $ 的代数重数。
