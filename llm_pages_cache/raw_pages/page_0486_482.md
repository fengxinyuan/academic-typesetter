## 13.10 柯西指标及其应用  

有理函数的柯西指标这一概念，有助于阐明出现在商式中的多项式的若干性质，因而其在稳定性问题中起着重要作用。

考虑一个实有理函数 $r ( \lambda ) = b ( \lambda ) / c ( \lambda )$，其中 $b ( \lambda )$ 与 $c ( \lambda )$ 均为实系数多项式。当参数 λ 从 a 单调递增至 b（$( a , b \in \mathbb { R } , a < b )$）时，$r ( \lambda )$ 在区间上发生从 $- \infty \ t \ o \ + \infty$ 的跳跃间断点的个数，与 $r ( \lambda )$ 在同一区间上发生从 +∞ 到 −∞ 的跳跃间断点的个数之差，称为 $r ( \lambda )$ 在区间 $( a , b )$ 上的柯西指标（Cauchy index），记作 $I _ { a } ^ { b } b ( \lambda ) / c ( \lambda )$。注意：a 与 b 可取广义值，即允许设 a = −∞ 和/或 $b = + \infty$。

习题 1．验证：若 $r ( \lambda ) = \mu _ { 0 } / ( \lambda - \lambda _ { 0 } )$，其中 $\mu _ { 0 }$ 与 $\lambda _ { 0 }$ 均为实数，则  

$$
I _ { - \infty } ^ { + \infty } = \mathrm { s g n } \mu _ { 0 } = \left\{ \begin{array} { r l } { { 1 } } & { { ~ \mathrm { i f } \mu _ { 0 } > 0 , } } \\ { { - 1 } } & { { ~ \mathrm { i f } \mu _ { 0 } < 0 , } } \\ { { 0 } } & { { ~ \mathrm { i f } \mu _ { 0 } = 0 . } } \end{array} \right.
