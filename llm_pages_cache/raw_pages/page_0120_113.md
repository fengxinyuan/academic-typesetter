## 3.14 其他习题

在酉空间中，两组元素  \{ $\pmb { x }$ _ { 1 } $, \pmb { x }$ _ { 2 } $, \ldots , \pmb { x }$ _ { k } \}  与  \{ y _ { 1 } , y _ { 2 } $, \ldots , x$ _ { k } \}  称为双正交的（biorthogonal），若满足  
$$
$( x _ { i } , y _ { j } ) = \delta _ { i j } \left( 1 \leq i , j \leq k \right)$
$$

**习题 9.** 证明：若  \left\{ x _ { j } $\right\}$ _ { i = 1 } ^ { k }  与 $\left\{ y \right\}$ _ { j = 1 } ^ { k }  构成一个双正交系统，则每一组元素均线性无关。

**习题  { $\pmb 1 0 } . .**$ 证明：若  \{ { $\pmb x }$ _ { i } \} _ { i = 1 } ^ { n }  与  \{ y _ { j } \} _ { j = 1 } ^ { n }  是  { $\pmb u } ,$ 的一组双正交基，则对任意正整数  k < n ，有  
$$
$( \operatorname { s p a n } \{ x _ { 1 } , \ldots , x _ { k } \} ) ^ { \perp } = \operatorname { s p a n } \{ y _ { k + 1 } , y _ { k + 2 } , \ldots , y _ { n } \}$
$$

**习题 11.** 设  \{ { $\pmb x }$ _ { i } \} _ { i = 1 } ^ { n }  与 $\left\{ y$ _ { j } $\right\}$ _ { j = 1 } ^ { n }  是  { $\pmb q } ,$ 中的一组双正交系统。证明：对任意 $\mathbf { x } \in \mathcal { U }  $，恒有  
$$

( \pmb { x } , \pmb { x } ) = \sum _ { i = 1 } ^ { n } ( \pmb { x } , \pmb { x } _ { i } ) ( \pmb { y } _ { i } , \pmb { x } )
$$
  
当且仅当系统  \{ { $\pmb x }$ _ { i } \} _ { i = 1 } ^ { n }  构成  { $\pmb u } .  $ 的一组基。由此导出帕塞瓦尔等式（式 (3.12.2)）。

**习题 12.** 设 $ U $ 是一个酉空间。  
(a) （参见习题 3.11.9）设  \pmb { x } $, \pmb { y } \in \mathcal { U } .  $。证明：  
$$

\| { \boldsymbol { \mathbf { x } } } + { \boldsymbol { \mathbf { y } } } \| ^ { 2 } = \| { \boldsymbol { \mathbf { x } } } \| ^ { 2 } + \| { \boldsymbol { \mathbf { y } } } \| ^ { 2 }\tag{3}

(b) 相比之下，设 ${ \mathcal { X } } , { \mathcal { Y } }$ 是 ${ \pmb q } ,$ 的子空间，并证明：这些子空间相互正交当且仅当对所有 $\pmb { x } \in \mathcal X$ 和 $\boldsymbol { y } \in \mathcal { Y }$，式 (3) 成立。□  

## 3.14 杂项习题  

1. 求由 ${ \pmb a } _ { 1 } =$、$[ 1 \quad 0 \quad 2 \ - 1 ] ^ { \boldsymbol { \mathsf { T } } } , \ a _ { 2 } = [ 0 \ - 1 \quad 2 \quad 0 ] ^ { \boldsymbol { \mathsf { T } } } , \ a \mathrm { n d } \ a _ { 3 } = [ 2 \ - 1 \quad 6 \ - 2 ] ^ { \boldsymbol { \mathsf { T } } } .$ 所张成的子空间 $\mathcal { S } _ { 1 }$ 的一组基与维数。  

答：集合 $\{ a _ { 1 } , a _ { 2 } \}$ 是 $\mathcal { S } _ { 1 }$ 的一组基，且 dim $\mathcal { S } _ { 1 } = 2 .$。  

2. 设  

$$
\begin{array} { r } { b _ { 1 } = [ 1 ~ - 1 ~ 4 ~ - 1 ] ^ { \mathrm { T } } , ~ b _ { 2 } = [ 1 ~ 0 ~ 0 ~ 1 ] ^ { \mathrm { T } } , ~ b _ { 3 } = [ - 1 ~ - 2 ~ 2 ~ 1 ] ^ { \mathrm { T } } , } \end{array}
$$  

并设 $\mathcal { S } _ { 2 } = \operatorname { s p a n } \{ b _ { 1 } , b _ { 2 } , b _ { 3 } \} . \operatorname { I f } \mathcal { S } _ { 1 }$ 的定义同习题 1，证明 $\dim ( { \mathcal { S } } _ { 1 } \cap { \mathcal { S } } _ { 2 } ) = 2 , \dim ( { \mathcal { S } } _ { 1 } + { \mathcal { S } } _ { 2 } ) = 3 .$。  

3. 设 $\mathcal { S } _ { 1 } , \mathcal { S } _ { 2 }$ 是 n 维线性空间 $\mathcal { S }$ 的子空间。证明：若 dim $\mathcal { S } _ { 1 } + \mathrm { d i m } \mathcal { S } _ { 2 } > n ,$，则 ${ \mathcal { S } } _ { 1 } \cap { \mathcal { S } } _ { 2 } \neq \{ \mathbf { 0 } \}$。

4. 域 $ F $ 上的两个线性空间 $ S $ 与 $ S_1 $ 同构，当且仅当存在一个一一对应关系 $\mathcal { S }   \mathcal { S }$ _ { 1 } $\mathcal { F }   \pmb { x }  \pmb { x }$ _ { 1 } ，将 $ S $ 的元素 $\pmb { x } \in \mathcal { S }$ 与 $ S_1 $ 的元素 $\pmb { x }$ _ { 1 } $\in \mathcal { S }$ _ { 1 }  关联起来，使得：若 $\mathbf { \nabla } \pmb { x } \nleftrightarrow \mathbf { x }$ _ { 1 }  且 $\mathbf { \nabla } \mathbf { y }  \mathbf { y }$ _ { 1 } ，则  { $\pmb x } + { \pmb y }  { \pmb x }$ _ { 1 } + { $\pmb y }$ _ { 1 } ，且对任意 $ \alpha \in F $，有 $ \alpha x \leftrightarrow \alpha x_1   $( $\boldsymbol { y } \in \mathcal { S } , \ \boldsymbol { y }$ _ { 1 } $\in \mathcal { S }$ _ { 1 } , \  $\alpha \in \mathcal { F }$ ) 。证明：两个有限维线性空间同构，当且仅当它们具有相同的维数。（定义同构线性空间的这种对应关系或映射称为**同构映射**（isomorphism）。）
