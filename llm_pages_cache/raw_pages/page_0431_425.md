矩阵  A  $\in \mathcal { F } ^ { m \times n }$ 称为左可逆（相应地，右可逆）的，若存在一个矩阵  A _ { $\mathbf { L } } ^ { - 1 } （$ 相应地， A _ { $\tt R } ^ { - 1 } )$ ），属于 $\mathcal { F } ^ { n \times m }  $，使得  

$$
A _ { \bf L } ^ { - 1 } A = I _ { n } \qquad \mathrm { ( r e s p e c t i v e l y , } \quad A A _ { \bf R } ^ { - 1 } = I _ { m } \mathrm { ) . }\tag{1}
$$

一个满足式 (1) 的矩阵 $A _ { \mathbf { L } } ^ { - 1 }$（相应地，$A _ { \mathbb { R } } ^ { - 1 } )$）称为矩阵 $ A $ 的左逆（相应地，$r i g h t )$ 逆）。显然，若 $m = n$ 且 $ A $ 是非奇异的，则 $ A $ 的单侧逆与通常的逆 $A ^ { - 1 }$ 重合。

首批结论可直接由定理 4.6.1 与 4.6.2 推出，其依据在于将 ${ \mathcal { F } } ^ { m \times n }$ 中的元素解释为从 $\mathbb { C } ^ { n }$ 到 $\mathbb { C } ^ { m }$ 的线性变换。

**定理 1.** 对任一矩阵 $\pmb { A } \in \mathcal { F } ^ { m \times n }$，下列命题等价：

(a) 矩阵 $ A $ 左可逆；

(b) $m \geq n$ 且 $ \operatorname{rank} A = n $；

(c) $ A $ 的列向量作为 ${ \mathcal { F } } ^ { m }$ 中的元素线性无关；

(d) $ \operatorname{Ker} A = \{0\} $。

**定理 2.** 对任一矩阵 $\pmb { A } \in \mathcal { F } ^ { m \times n }$，下列命题等价：

(a) 矩阵 $ A $ 右可逆；

(b) $m \leq n$ 且 $ \operatorname{rank} A = m $；

(c) $ A $ 的行向量作为 ${ \mathcal { F } } ^ { n }$ 中的元素线性无关；

(d) $ \operatorname{Im} A = \mathbb{F}^m $。

因此，满秩的 $ m \times n $ 矩阵（参见第 3.8 节）——且仅此类矩阵——是单侧可逆的：当 $m \geq n$ 时，它左可逆；当 $m \leq n$ 时，它右可逆。在 $m = n \textbf { a }$ 的情形下，满秩矩阵是（双侧）可逆的。
