现令  \pmb { x } $\in K$ _ { j } = K _ { j + 1 } 。于是，利用式 (2)，有  

$$

X T ^ { j + 1 } x = ( X T ^ { j } ) T x = E \left[ \begin{array} { c } { X } \\ { X T } \\ { \vdots } \\ { X T ^ { j - 1 } } \end{array} \right] T x = E \left[ \begin{array} { c } { X T } \\ { X T ^ { 2 } } \\ { \vdots } \\ { X T ^ { j } } \end{array} \right] x = 0 ,
$$
  

这是因为  \pmb { x } $\in K$ _ { j + 1 } 。从而， { $\pmb x } \in { \bf K e r } ( X T ^ { j + 1 }$ )，故 $\pmb { x } \in K$ _ { j + 2 } 。由此可归纳得出：对任意 $i \geq j ,$ ，均有  K _ { i } = K _ { j } 。

引理现在表明，序列  
$K _ { 1 } \supset K _ { 2 } \supset K _ { 3 } = \cdots$  
中的包含关系均为真包含，直至首次出现等号为止；此后所有  
$K _ { j } { \mathrm { ' s } }$  
均相等。使得  
$K _ { s } = K _ { s + 1 }$  
成立的最小正整数 $ s $，称为容许对  
$( . 5 , T )$  
的特征量，亦称为该对的**稳定化指数**（index of stabilization）。因此，若  
$K _ { j }$  
的维数为  
$k _ { j }$  
，则有  
$k _ { 1 } > k _ { 2 } > \dots > k _ { s } = k _ { s + 1 } = \cdot \cdot \cdot$  
由于前  
$s - 1$  
个包含关系均为真包含，显然有  
$s \leq p$  
（另参见下方习题 3）。子空间  
$K _ { s }$  
被称为**剩余子空间**（residual subspace）。

接下来需区分两种情形：其一为剩余子空间  
$K _ { s }$  
恰好等于  
$\{ \theta \}$  
，即  
$k _ { s } = 0$  
；其二为  
$K _ { s }$  
含有非零向量，即  
$k _ { s } \geq 1$  
。若 $ s $ 是容许对  
$( X , T )$  
的稳定化指数，且  
$k _ { s } = 0 .$  
，则称对  
$( X , T )$  
是**可观测的**（observable）。否则，剩余子空间  
$K _ { s }$  
被称为**不可观测的**（unobservable），这一术语源自系统理论（参见第 9.11 节）。
