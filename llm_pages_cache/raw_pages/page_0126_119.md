例 4．设 $ T $ 是一个线性变换，它将域 $ F $ 上次数不超过 $ n $ 的多项式构成的线性空间 $ P_n $（即 $\pmb { T } P ^ { n }$ 多项式空间）映射到 $\mathcal { F } P ^ { n - 1 }$，其作用规则为  

$$
T ( p _ { n } ( x ) ) = p _ { n } ^ { \prime } ( x ) .
$$  

即，$T$ 将 $ P_n $ 中的一个多项式映为它的导数（该导数仍属于 $P ^ { n - 1 } )$）。  

回顾导数所满足的相关性质，易见条件 (1) 成立，故该变换是线性的。若将多项式 $\begin{array} { r } { { \dot { p } } _ { n } ( x ) = \sum _ { i = 0 } ^ { n } a _ { i } x ^ { i } } \end{array}$ 与向量 $p = [ a _ { 0 } \quad a _ { 1 } \quad \cdots \quad a _ { n } ] ^ { \mathrm { T } }$ 相对应，则可将该变换视为一个从 ${ \mathcal { F } } ^ { n + 1 }$ 到 ${ \mathcal { F } } ^ { n } ,$ 的映射 $ T $，其作用规则为

$$
\widetilde { T } ( p ) = \left[ \begin{array} { l l l l } { 0 } & { 1 } & { 0 } & { \cdots } & { 0 } \\ { \vdots } & { 0 } & { . 2 } & { \vdots } \\ { 0 } & { \cdots } & { \cdots } & { \dot { 0 } } & { n } \end{array} \right] p = p _ { 1 } ,
$$  

其中该矩阵为 $n \times ( n + 1 )$，且 $p _ { 1 } = [ a _ { 1 } \quad 2 a _ { 2 } \quad \cdots \quad n a _ { n } ] ^ { \mathrm { T } } . \quad \square$。  

我们用 $\mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 表示所有将线性空间 $\mathcal { S } _ { 1 }$ 映射到线性空间 $\mathcal { S } _ { 2 }$ 的线性变换的集合。全书始终假设这两个空间均为有限维的，且定义在同一数域 $\mathcal { F } .$ 上。当 $\mathcal { S } _ { 1 } = \mathcal { S } _ { 2 } = \mathcal { S } ,$ 时，我们简记 ${ \mathcal { L } } ( { \mathcal { S } } )$，而不写 ${ \mathcal { L } } ( { \mathcal { S } } , { \mathcal { S } } )$。  

注意：结合 (1) 中的条件，一个变换 $T \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 可由如下单一条件刻画：  

$$
T ( \alpha \mathbf { x } _ { 1 } + \beta \mathbf { x } _ { 2 } ) = \alpha T ( \mathbf { x } _ { 1 } ) + \beta T ( \mathbf { x } _ { 2 } )\tag{2}
$$  

对任意元素 $\mathbf { x } _ { 1 } , \mathbf { x } _ { 2 }$（属于 $\mathcal { S } _ { 1 }$）及任意 $\alpha , \beta \in { \mathcal { F } } .$ 均成立。由此可推出一个更一般的结论：  

$$
T { \Bigg ( } \sum _ { i = 1 } ^ { k } \alpha _ { i } \mathbf { x } _ { i } { \Bigg ) } = \sum _ { i = 1 } ^ { k } \alpha _ { i } T ( \mathbf { x } _ { i } ) ,
$$  

其中 ${ \pmb x } _ { i } \in \mathcal { S } , \alpha _ { i } \in \mathcal { F } \left( i = 1 , 2 , . . . , k \right)$。特别地，

$$
\begin{array} { c } { { T ( \pmb { \theta } ) = \pmb { \theta } , } } \\ { { T ( - \pmb { x } ) = - T ( \pmb { x } ) , } } \\ { { T ( \pmb { x } _ { 1 } - \pmb { x } _ { 2 } ) = T ( \pmb { x } _ { 1 } ) - T ( \pmb { x } _ { 2 } ) . } } \end{array}
$$
