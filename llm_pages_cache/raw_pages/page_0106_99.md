将式 (1) 代入 ${ \pmb { a } } _ { j }$，可得

$$
\sum _ { j = 1 } ^ { m } \beta _ { j } { a } _ { j } = \sum _ { j = 1 } ^ { m } \beta _ { j } \biggl ( \sum _ { i = 1 } ^ { m } \alpha _ { i j } { a } _ { i } ^ { \prime } \biggr ) = \sum _ { i = 1 } ^ { m } \biggl ( \sum _ { j = 1 } ^ { m } \alpha _ { i j } \beta _ { j } \biggr ) { a } _ { i } ^ { \prime } .
$$  

因此  

$$
{ \pmb b } = \sum _ { i = 1 } ^ { m } \beta _ { i } ^ { \prime } { \pmb a } _ { i } ^ { \prime } = \sum _ { i = 1 } ^ { m } \bigg ( \sum _ { j = 1 } ^ { m } \alpha _ { i j } \beta _ { j } \bigg ) { \pmb a } _ { i } ^ { \prime }
$$  

由于任一元素关于给定基的表示是唯一的（命题 3.5.1），故有  

$$
\beta _ { i } ^ { \prime } = \sum _ { j = 1 } ^ { m } \alpha _ { i j } \beta _ { j } , \qquad i = 1 , 2 , \ldots , m .
$$  

将最后一个等式改写为矩阵形式，我们最终得到如下结论：  

**定理 1**．设 $ b $ 是域 $ F $ 上 $ m $ 维线性空间 $\mathcal { S }$ 中的一个元素．若 $ \beta $ 与 $\beta ^ { \prime } \left( \in \mathcal { F } ^ { m } \right)$ 分别为 $ b $ 关于 $\pmb { \delta }$ 和 $\clubsuit ^ { \prime }$ 这两组 ${ \mathcal { S } } ,$ 的基的坐标表示，则  

$$
\mathbf { \boldsymbol { \mathsf { \pmb { \beta } } } } ^ { \prime } = { \cal { P } } \mathbf { \boldsymbol { \beta } } ,\tag{2}
$$  

其中 $ P $ 是从基 $\pmb { \delta }$ 到基 $8 ^ { \prime }$ 的过渡矩阵．  

**习题 2**．验证关系式 (2)，即对习题 3.7.1 中定义的向量 $\pmb { b } = [ 1 \ \pmb { 2 } \ - \pmb { 1 } ]$，分别关于基 $\{ e _ { 1 } , e _ { 2 } , e _ { 3 } \}$ 和基 $\{ a _ { 1 } , a _ { 2 } , a _ { 3 } \}$ 的坐标表示，检验该关系式是否成立．

习题 3．设 $ m \times n $ 矩阵 $ A $ 与 $\pmb { A } ^ { \prime } .$ 分别表示系统 $\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \}$ 关于 $ \mathbb{R}^n $ 与 $ \mathbb{R}^m $ 的基 $\pmb { \mathcal { B } }$ 与 $\overline { 6 } ^ { \prime }$ 的矩阵表示（其中 $ \dim \mathbb{R}^n = n $，$ \dim \mathbb{R}^m = m $，分别）。证明：

$$
A ^ { \prime } = P A ,\tag{3}
$$

其中 $P$ 是从基 $8$ 到基 $\clubsuit ^ { \prime }$ 的过渡矩阵。

提示：对系统 $\left\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \right\}$ 中的每一个元素，应用公式 (2)。□

在习题 3 中，我们再次看到同一系统关于不同基的表示之间的等价性。（参见定理 3.7.2 后的注记。）

习题 4．验证本节习题 1 与习题 3.7.1 中所求得的矩阵满足公式 (3)。

关系式 (2) 在如下意义上刻画了过渡矩阵的特征：

命题 1．设对任意向量 $ b \in \mathbb{R}^n $（其中 $ \dim \mathbb{R}^n = n $），其关于固定基 $\pmb { \ 8 }$ 与 $\delta ^ { \prime }$ 的表示 $\beta$ 与 $\pmb { \beta } ^ { \prime }$ 均满足公式 (2)。则 $ P $ 即为从基 $\pmb { \ 8 }$ 到基 $\mathbf { \delta } ^ { \pmb { \mathcal { B } } ^ { \prime } }$ 的过渡矩阵。
