## 14.8 倍式与因式  

矩阵多项式之间的“除法”概念已在第 7.2 节中引入。回顾：若矩阵多项式  L _ { 1 } $( \lambda$ )的首项系数可逆，则称其为矩阵多项式 $L ( \lambda$ )的一个右因式（right divisor），当且仅当存在另一个矩阵多项式  L _ { 2 } $( \lambda$ )，使得 $L ( \lambda ) =  = $L _ { 2 } $( \lambda ) L$ _ { 1 } $( \lambda$ )。要求  L _ { 1 } $( \lambda$ )  的首项系数可逆，是为了避免因式分解中出现非本质的重数现象。例如，如下形式的因式分解  

$$

{ \left[ \begin{array} { l l } { 0 } & { 0 } \\ { 0 } & { 0 } \end{array} \right] } = { \left[ \begin{array} { l l } { a \lambda ^ { k } } & { 0 } \\ { b \lambda ^ { l } } & { 0 } \end{array} \right] } { \left[ \begin{array} { l l } { 0 } & { 0 } \\ { c \lambda ^ { m } } & { d \lambda ^ { n } } \end{array} \right] } ,
$$


其中形如 $a , b , c , d \in \mathbb { C }$ 且 $ k, l, m, n $ 为非负整数的分解式，应予排除——这不仅是因为此类候选分解数量庞大，更主要的原因在于：这类分解所提供的信息甚少。此处我们稍作推进，将注意力限定于**首一（monic）因子**，即其关于 $ \lambda $ 的最高次幂的系数为单位矩阵 $ I $。事实上，为方便起见，我们仅考虑**首一矩阵多项式**的首一因子。

事实表明，从谱理论的观点来看，对矩阵多项式的**倍式（multiples）** 的分析，通常比对因子（divisors）的研究更为简便。造成这一差别的一个关键原因，正在于因子的存在性问题。例如，不难验证：如下首一矩阵多项式  

$$
\left[ { \begin{array} { l l } { \lambda ^ { 2 } } & { 1 } \\ { 0 } & { \lambda ^ { 2 } } \end{array} } \right]\tag{1}
$$  

在 $ \lambda $ 上不存在任何一次首一因子。关于因子存在性的深入分析，已超出本节对谱理论、倍式与因子等相关问题所作之简要介绍的范围。

若已知各因子的**标准三元组（standard triples）**，则其乘积的标准三元组（从而通过约当三元组导出的谱性质）便相对容易刻画。首先注意到，如下关于首一矩阵多项式的等式关系  

$L ( \lambda ) = L _ { 2 } ( \lambda ) L _ { 1 } ( \lambda )$  

蕴含若干显然的结论：  

$$
\mathrm { ( a ) } \ \sigma ( L _ { 1 } ) \cup \sigma ( L _ { 2 } ) = \sigma ( L ) ;
$$  

（b）$ \mathrm{Latent\ vectors} $（隐向量） of $L _ { 1 } ( \lambda )$ 与 $L _ { 2 } ^ { \mathrm { T } } ( \lambda )$ 分别也是 $L ( \lambda )$ 与 $L ^ { \mathrm { { T } } } ( \lambda )$ 的隐向量。

该理论中的一些复杂性与条件 (a) 中出现  \sigma ( L _ { 1 } $) \cap \sigma ( L$ _ { 2 } $) \neq \emptyset  $ 的情形相关。无论如何，陈述 (b) 均可被大幅推广。这一推广将在下述定理的第一个推论中给出。
