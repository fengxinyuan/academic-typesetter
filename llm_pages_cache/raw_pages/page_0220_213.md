引理 1．设  ( X , T )  是一个 $ p $ 阶容许对，且如前所述定义子空间序列  K _ { 1 } , K _ { 2 } $, \ldots o f$ ： $o f \mathbb { C } ^ { p }$ 。若  K _ { j } = K _ { j + 1 } ，则  K _ { j } =   K _ { j + 1 } = K _ { j + 2 } $= \cdots  $。

**证明．** 矩阵  

$$

{ \left[ \begin{array} { l } { \quad X } \\ { X T } \\ { \vdots } \\ { X T ^ { j - 1 } } \end{array} \right] } \qquad { \mathrm { a n d } } \qquad { \left[ \begin{array} { l } { \quad X } \\ { X T } \\ { \vdots } \\ { X T ^ { j } } \end{array} \right] }\tag{1}
$$
  

的尺寸分别为  j  $r \times p$ 和 $( j + 1 ) r \times p ,$ 。若  K _ { j } = K _ { j + 1 } ，则根据命题 3.8.1，可知这两个矩阵具有相同的秩。从“行秩”的角度理解，这意味着  X T ^ { j }  的每一行均可表为式 (1) 中第一个矩阵各行的线性组合。因此，存在一个 $r \times j r$ 矩阵 $ E $，使得  

$$

X T ^ { j } = E \left[ \begin{array} { c } { { X } } \\ { { X T } } \\ { { \vdots } } \\ { { X T ^ { j - 1 } } } \end{array} \right] .\tag{2}
$$
