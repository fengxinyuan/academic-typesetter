## 变分法

本章所发展的技巧，可视作将实对称矩阵  3  $\times 3$ 的特征值问题之几何方法加以推广。我们在习题 5.10.5 中已知：可通过方程  x ^ { $\mathsf { T } } H x = 1$ 或 $( H \pmb { x } , \pmb { x } ) = 1$ ，其中 $\mathbf { x } \in \mathbb { R } ^ { 3 }$ ，将一个二次曲面与这样的矩阵 $ H $ 相关联。特别地（参见习题 5.10.6），若 $ H $ 是正定矩阵，则对应的曲面是一个椭球面。此时，从原点指向该椭球面上距离原点最远一点的向量 $\vert \pmb { x$ _ { 0 } } $\in \mathbb { R } ^ { 3 }$ ，可描述为使函数  ( { $\pmb x } , { \pmb x }$ )在约束条件 $ x $ 满足 $( H \pmb { x } , \pmb { x } ) = 1  $ 下取得最大值的向量。

于是，该问题可重新表述为：在消去约束条件的前提下，寻求商式  
$$
$( { \pmb x } , { \pmb x } ) / ( H { \pmb x } , { \pmb x } )$
$$  
的最大值，其中 $ x $ 取遍 $\mathbb { R } ^ { 3 }  $ 中所有非零向量。或者，等价地（本质上相同），我们寻求瑞利商（Rayleigh quotient）的最小值：

$$

{ \frac { ( H x , \ x ) } { ( x , \ x ) } } , \qquad x \neq \theta .
$$


现在，该商式对任意 $ n \times n $ 埃尔米特矩阵 $ H $ 和向量 $\pmb { x } \in \mathbb { C } ^ { n }$ 均有定义，并且在这一更一般的情形下，亦被称为 $ H $ 的瑞利商（Rayleigh quotient）。本章的主要内容之一，便是研究该商式在此类情形下的性质。
