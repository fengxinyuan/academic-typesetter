定理 3′：线性变换 $T \in { \mathcal { L } } ( { \mathcal { U } } )$ 是正规变换，当且仅当



$$
T T ^ { * } = T ^ { * } T .\tag{3}
$$



接下来讨论若干特殊类型的正规变换。我们首先定义：若线性变换 $T \in \mathcal { L } ( \pmb { \mathcal { U } } )$ 满足 $T = T ^ { * }$，则称其为自伴变换（或埃尔米特变换）；若满足 $T T ^ { * } = T ^ { * } T = I$，则称其为酉变换。

习题 6：验证：线性变换 $T \in { \mathcal { L } } ( { \mathcal { U } } )$ 是自伴变换（相应地，酉变换），当且仅当它关于任一标准正交基的矩阵表示为埃尔米特矩阵（相应地，酉矩阵）。

习题6的重要结果使我们能够从后续各节中所研究的相应矩阵的性质，推导出自伴变换与酉变换的性质。除非另有说明，空间 ${ \mathcal { F } } ^ { n }$ 中的内积均假定为标准内积，即对任意 $\mathbf { x } , \mathbf { y } \in \mathcal { F } ^ { n }$，有 $( { \pmb x } , { \pmb y } ) = { \pmb y } ^ { * } { \pmb x }$。
