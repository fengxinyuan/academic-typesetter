考虑三个定义在域 ${ \mathcal { F } } ,$ 上的线性空间 $\mathcal { S } _ { 1 } , \mathcal { S } _ { 2 }$、$\mathcal { S } _ { 3 }$ 与（隐含的第三个空间，由上下文可知为）$\mathcal { S } _ { 3 }$（注：原文此处仅列出两个空间，但后文涉及三重映射，实际应为三个空间；依原文表述直译），并设 $T _ { 1 } \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } ) , T _ { 2 } \in \mathcal { L } ( \dot { \mathcal { S } } _ { 2 } , \mathcal { S } _ { 3 } )$。若 $\pmb { x } \in \mathcal { S } _ { 1 }$，则 $T _ { 1 }$ 将向量 x 映为元素 $\boldsymbol { y } \in \mathcal { S } _ { 2 }$，随后 $T _ { 2 }$ 将 y 映为元素 $\pmb { z } \in \mathcal { S } _ { 3 }$。因此，相继应用 $T _ { 1 }$ 与 $T _ { 2 }$ 实现了从 $\mathcal { S } _ { 1 }$ 到 $\mathcal { S } _ { 3 }$ 的一个变换。该变换 $T$ 称为 $T _ { 2 }$ 与 $T _ { 1 }$ 的复合（composition），记作 $T = T _ { 2 } T _ { 1 }$。其形式化定义为  

$$
T ( \pmb { x } ) \triangleq T _ { 2 } ( T _ { 1 } ( \pmb { x } ) )\tag{3}
$$  

对所有 $\pmb { x } \in \mathcal { S } _ { 1 }$ 成立。  

习题 9．证明：由式 (3) 所定义的映射 T 是从 $\mathcal { S } _ { 1 }$ 到 $\mathcal { S } _ { 3 }$ 的线性变换，即满足 $T \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 3 } )$。□  

类似地，在同一域 $T = T _ { k } T _ { k - 1 } \cdot \cdot \cdot T _ { 1 }$ 上、定义于适当线性空间之间的若干线性变换的复合，按如下规则定义：  

$$
T ( \pmb { x } ) \triangleq T _ { k } ( T _ { k - 1 } ( \cdot \cdot \cdot ( T _ { 2 } ( T _ { 1 } ( \pmb { x } ) ) \cdot \cdot \cdot ) ) \qquad \mathrm { f o r ~ a l l ~ } \pmb { x } \in \mathcal { S } .
