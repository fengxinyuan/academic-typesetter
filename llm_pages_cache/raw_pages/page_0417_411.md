## 12.2 克罗内克积与复合矩阵的特征值  

人们关注克罗内克积的一个主要原因，在于矩阵 A、B 与其克罗内克积 A © B 的特征值之间存在一种极为优美的简单关系。该关系可由一个关于克罗内克积复合矩阵的更一般性结果导出。

考虑一个关于两个变量 x 和 $y ,$ 的多项式 p，其系数为复数。于是，对某些复数 $c _ { i j }$ 及某个正整数 l，有  

$$
p ( x , y ) = \sum _ { i , j = 0 } ^ { l } c _ { i j } x ^ { i } y ^ { j } .
$$  

若 $A \in \mathbb { C } ^ { m \times m }$ 且 $\pmb { { \cal B } } \in \mathbb { C } ^ { n \times n }$，则我们考察 $\mathbb { C } ^ { m n \times m n }$ 中形如  

$$
p ( A ; B ) = \sum _ { i , j = 0 } ^ { l } c _ { i j } A ^ { i } \otimes B ^ { j } .
$$  

的矩阵。

例如，若  p ( x , y ) = 2 x + x y ^ { 3 } ，我们写作 $ 2x\,$+ \ x y ^ { 3 } = 2 x ^ { 1 } y ^ { 0 } + x ^ { 1 } y ^ { 3 } ，且  

$$

p ( A ; B ) = 2 A \otimes I _ { n } + A \otimes B ^ { 3 } .
$$
  

下一个定理给出了矩阵 $ A $ 与 $ B $ 的特征值和矩阵  p ( A ; B )  的特征值之间的联系。  

**定理 1（C. 斯特凡诺斯†）**：设  I  $f \lambda$ _ { 1 } $, \ldots , \lambda$ _ { m }  是矩阵 $A \in \mathbb { C } ^ { m \times m }$ 的全部特征值， $\mu$ _ { 1 } $, \ldots , \mu$ _ { n }  是矩阵  \ b { B } $\in \mathbb { C } ^ { n \times n }$ 的全部特征值，则矩阵  p ( A ; B )  的特征值为全部 $ mn $ 个数 $p ( \lambda$ _ { r } $, \mu$ _ { s } ) ，其中 $r = 1 , 2 , \ldots , m$ ， $s = 1 , 2 , \ldots , n .  $。  

**证明**：令矩阵  P  $\in \mathbb { C } ^ { m \times m }$ 与 $Q \in \mathbb { C } ^ { n \times n }  $ 满足  

$$

P A P ^ { - 1 } = J _ { 1 } , \qquad Q B Q ^ { - 1 } = J _ { 2 } ,
$$
  

其中  J _ { 1 }  与  J _ { 2 }  均为若尔当标准形矩阵（见第 6.5 节）。显然， J _ { 1 } ^ { i }  是一个上三角矩阵，其主对角线元素为 $\lambda$ _ { 1 } ^ { i } $, \ldots , \lambda$ _ { m } ^ { i } ；类似地， $\mu$ _ { 1 } ^ { j } $, \ldots , \mu$ _ { n } ^ { j }  是上三角矩阵  J _ { 2 } ^ { j }  的主对角线元素。
