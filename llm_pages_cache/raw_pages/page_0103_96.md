我们称 $ \text{$A  $\in \mathcal { F } ^ { m \times n } } $ 为**满秩矩阵**（matrix of full rank），若 $\operatorname{rank} \text{ $A  $= \operatorname* { m i n } ( m , n$ )$ }$。根据定理 3.7.1 及其后的评注，显然：当 $ \text{$m  $\geqslant n , } $ 时，$ A $ 为满秩矩阵当且仅当其列向量在 $ \text{${ $\mathcal { F } } ^ { m } } $ 中线性无关；而当 $ \text{$m  $\leqslant n , } $ 时，$ A $ 为满秩矩阵当且仅当其行向量在 $ \text{${ $\mathcal { F } } ^ { n } } $ 中线性无关。特别地，一个 $ \text{$n  $\times n } $ 阶方阵为满秩矩阵当且仅当其列向量组与行向量组均在 $ \text{${ $\mathcal { F } } ^ { n } } $ 中线性无关。

借助定理 3.7.1 与习题 2.8.2，易得如下命题成立：

**习题 1**．设 $ A $ 是一个 $ n \times n $ 非奇异矩阵。证明：$ A $ 的任一由 $ r $ 个完整列（或行）构成的子矩阵（即取 $ A $ 的 $ r $ 列（或 $ r $ 行）所形成的 $ \text{$A  $\left( 1 \leq r \leq n \right$ )$} $ 子矩阵）均为满秩矩阵。

**习题 2**．设 $ \operatorname{rank} \text{ $A = r .$ } = r $。证明：在 $ A $ 的 $ r $ 个线性无关列（或行）所构成的“带状”子区域中，至少存在一个 $ \text{$r  $\times r } $ 阶子矩阵是非奇异的。

习题 3．利用比内–柯西（Binet–Cauchy）公式证明：若 $A \in \mathbb { C } ^ { m \times n }$ 且 $m \leq n ,$，则 det $( A A ^ { * } ) > 0$ 当且仅当 A 具有满秩。（参见习题 2.5.2。）

命题 2．对任意矩阵 A，有 $B \in \mathcal { F } ^ { m \times 1 }$  

$$
\operatorname { r a n k } ( A + B ) \leq \operatorname { r a n k } A + \operatorname { r a n k } B .
$$  

**证明．** 考虑由 A 与 B 的所有列向量张成的子空间 $\mathcal { S } _ { \mathfrak { d } }$。显然，dim $\mathcal { S } _ { 0 } \leq$ ≤ rank $A +$ + rank B。另一方面，$A + B$ 的列空间包含于 $\mathcal { S } _ { \mathfrak { d } }$ 中，因此，依据定理 3.7.1，有  

$$
\operatorname { r a n k } ( A + B ) \leq \dim { \mathcal { S } } _ { 0 } .
$$  

结论得证。
