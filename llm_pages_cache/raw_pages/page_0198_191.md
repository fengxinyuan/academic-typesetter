习题 1. 证明：任一 $A \in { \mathcal { F } } ^ { n \times n }$ 均可表为如下形式：

$$
A = U _ { 1 } H _ { 1 } ,\tag{5}
$$

其中 $H _ { 1 } = ( A ^ { * } A ) ^ { 1 / 2 }$，且 $U _ { 1 }$ 是酉矩阵。□

对于正规矩阵，上述两种分解在如下意义上重合。

命题 1. 矩阵 $A \in { \mathcal { F } } ^ { n \times n }$ 是正规的，当且仅当式 (1) 中的矩阵 $ H $ 与 $ U $ 可交换。

证明：若 $A = H U = U H _ { \cdot }$，则

$$
A ^ { * } A = ( H U ^ { * } ) ( U H ) = H ^ { 2 } = ( H U ) ( U ^ { * } H ) = A A ^ { * }
$$

故 $ A $ 是正规矩阵。

反之，设 $ A $ 是正规矩阵，并沿用定理 1 证明中所采用的记号。由于 $A A ^ { * } = A ^ { * } A$，故系统 $\{ { \pmb x } _ { i } \} _ { i = 1 } ^ { n }$ 构成 $A A ^ { * }$ 的一组标准正交特征基，从而也是 $\dot { H } = ( A A ^ { * } ) ^ { 1 / 2 }$ 的一组标准正交特征基。因此，对每个 $i = 1 , 2 , \ldots , n ,$，有

$$
U H \mathbf { x } _ { i } = { \sqrt { \lambda _ { i } } } U \mathbf { x } _ { i } .\tag{6}
$$

此外，由 $A = H U$ 可得 $\lambda _ { i } { x _ { i } } = A ^ { * } A { x _ { i } } = U ^ { * } H ^ { 2 } U { x _ { i } }$，从而 $H ^ { 2 } U { \bf x } _ { i } = \lambda _ { i } U { \bf x } _ { i }$。于是向量 $U { \pmb x } _ { i }$ 均为 $ A $ 的特征向量。
