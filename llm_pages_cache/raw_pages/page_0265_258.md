第二步：在形如 (3) 的矩阵中，现在可能出现某些非零元素 $a _ { i j } ( \lambda ) , 2 \leq i ,$ 和 $j \leq n ,$，其次数小于 $a _ { 1 1 } ( \lambda )$ 的次数。若存在这样的元素，则我们再次重复第一步，从而得到另一个具有形式 (3) 的矩阵，但此时 $a _ { 1 1 } ( \lambda )$ 的次数进一步降低。因此，只要足够多次地重复第一步，我们便能求得一个与 $A ( \lambda )$ 等价、且其 $a _ { 1 1 } ( \lambda )$ 为所有非零元素中次数最小者（即次数最低的非零元）的形如 (3) 的矩阵。

第三步：完成第二步后，我们进一步考察：是否存在不被 $a _ { 1 1 } ( \lambda )$ 整除的非零元素？若存在这样的元素，例如 $a _ { i j } ( \lambda )$，我们将第 j 列加到第 1 列上，再对所得的新第 1 列各项分别作以 $a _ { 1 1 } ( \lambda )$ 为除式的带余除法，求出相应的余式与商式，然后继续重复第一、二步，最终仍得到一个形如 (3) 的矩阵，但其中的 $a _ { 1 1 } ( \lambda )$ 被替换为一个次数更小的多项式。

同样，该过程至多只能进行有限步，之后必将抵达一个形如

$$
{ \left[ \begin{array} { l l l l } { a _ { 1 } ( \lambda ) } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { b _ { 2 2 } ( \lambda ) } & { \cdots } & { b _ { 2 n } ( \lambda ) } \\ { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { 0 } & { b _ { n 2 } ( \lambda ) } & { \cdots } & { b _ { n n } ( \lambda ) } \end{array} \right] } ,
$$  

其中，必要时先施行一次第一类初等变换，使得 $a _ { 1 } ( \lambda )$ 是首一多项式，且所有非零元素 $b _ { i j } ( \lambda )$ 均可被 $a _ { 1 } ( \lambda )$ 整除（即整除无余）。  

第四步：若所有 $b _ { i j } ( \lambda )$ 均为零，则定理得证；否则，上述矩阵可进一步化为如下形式：  

$$
\left[ { \begin{array} { c c c c c } { a _ { 1 } ( \lambda ) } & { 0 } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { a _ { 2 } ( \lambda ) } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { 0 } & { c _ { 3 3 } ( \lambda ) } & { \cdots } & { c _ { 3 n } ( \lambda ) } \\ { \vdots } & { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { 0 } & { 0 } & { c _ { n 3 } ( \lambda ) } & { \cdots } & { c _ { n n } ( \lambda ) } \end{array} } \right]
$$  

其中 $a _ { 2 } ( \lambda )$ 可被 $a _ { 1 } ( \lambda )$ 整除，且元素 $c _ { i j } ( \lambda ) , 3 \leq i , j \leq n ,$ 均可被 $a _ { 2 } ( \lambda )$ 整除。继续这一过程，最终即可得到定理所断言的结论。■
