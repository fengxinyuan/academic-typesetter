习题 2．若 $ a $ 是一个 $ m $ 阶列矩阵，而 $\pmb { b } ^ { \dagger }$ 是一个 $ n $ 阶行矩阵，则证明  { $\pmb a } { \pmb b } ^ { \dagger }$ 是一个 $ m \times n $ 矩阵。（该矩阵有时称为 $ a $ 与 $ b $ 的**外积**（outer product）。）□

上述矩阵乘法的定义是标准定义；它侧重于第一个因子的行与第二个因子的列。还存在另一种关于乘积 $ AB $ 的表示形式，该形式在许多场合下十分有用；与标准定义相反，它以第一个因子的列和第二个因子的行来表达。

首先，请仔细领会习题 2 的结论。设 $ A $ 为 $m \times l$ ，$ B $ 为 $l \times n （$ 从而 $ A $ 与 $ B $ 关于矩阵乘法是相容的）。设 $ A $ 的列为  { a } _ { 1 } , { a } _ { 2 } $, \ldots , { a }$ _ { l } ，$ B $ 的行为 $\pmb { b }$ _ { 1 } ^ { $\top } , \bar { \pmb { b } }$ _ { 2 } ^ { $\top } , \ldots , \pmb { b }$ _ { l } ^ { $\top }  $。则断言成立：

$$

A B = \sum _ { k = 1 } ^ { l } a _ { k } \boldsymbol { b } _ { k } ^ { \mathrm { T } } ,\tag{6}
$$


且显然，每个乘积  { $\pmb a }$ _ { k } $\pmb { b }$ _ { k } ^ { $\sf T }$ 均为一个 $m \times n  $ 矩阵。

习题 3．验证公式 (6) 成立。

矩阵乘法在一定程度上保持了标量乘法的某些性质。

习题 4．验证：对任意阶数适当（即相容）的矩阵，以下各式均成立：

$$
\begin{array} { c } { { A I = I A = A , } } \\ { { A ( B + C ) = A B + A C , \qquad ( B + C ) D = B D + C D } } \\ { { A ( B C ) = ( A B ) C \qquad ( \mathrm { a s s o c i a t i v e \ l a w } ) . \quad \bigtriangledown } } \end{array}
$$  

（分配律），  

然而，矩阵乘法并不保持标量乘法所具有的若干重要性质，接下来的习题将对此予以说明。  

**习题 5.** 取  

$$
A = { \left[ \begin{array} { l l } { 2 } & { 1 } \\ { 0 } & { 0 } \\ { 1 } & { 0 } \end{array} \right] } \qquad { \mathrm { a n d } } \qquad B = { \left[ \begin{array} { l l l } { 0 } & { 1 } & { 2 } \\ { - 1 } & { 0 } & { 0 } \end{array} \right] }
$$  

或  

$$
A = { \left[ \begin{array} { l l } { 2 } & { 1 } \\ { 0 } & { 0 } \end{array} \right] } \qquad { \mathrm { a n d } } \qquad B = { \left[ \begin{array} { l l } { 1 } & { 0 } \\ { - 1 } & { 0 } \end{array} \right] } ,
$$  

验证 $ AB \neq BA $。 □  

因此，矩阵乘法在一般情况下不满足交换律。
