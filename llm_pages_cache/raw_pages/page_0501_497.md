## 14.2 标准三元组与标准对

该定理表明：一个标准三元组完全由其前两个成员所确定。在实际应用中，常常以这样的二元组为基本对象进行工作，因此我们赋予它一个专门的名称：称  L  $( \lambda$ )的一个**标准对**（standard pair）为任意一个 $L ( \lambda$ )的标准三元组的前两个成员。于是， ( U , T )  是 $L ( \lambda$ )  的一个标准对，当且仅当它满足该定理中的条件 (a) 和 (b)。

**习题 2.** 证明：若  ( U , T )  是 $L ( \lambda ) .$ 的一个标准对，则  ( U , T )  也是形如 $A L ( \lambda$ )的任一矩阵多项式的标准对，其中 $ \det $A  $\neq 0 .  $。

**习题 3.** 设  C _ { 2 }  是 $L ( \lambda$ )  的第二个友矩阵（second companion matrix），其定义见习题 14.1.6。证明：如下可容许三元组（admissible triple）

$$
[ 0 \quad \cdots \quad 0 \quad L _ { l } ^ { - 1 } ] , \qquad C _ { 2 } , \qquad \left[ { \begin{array} { l } { I } \\ { 0 } \\ { \vdots } \\ { 0 } \end{array} } \right]
$$

构成  L  $( \lambda$ )  的一个标准三元组。

**习题 4.** 设  ( U , T , V )  是 $L ( \lambda ) ,$ 的一个标准三元组，Γ 是复平面上的一条围道（contour），使得 $\sigma ( L$ )位于 Γ 的内部。若 $f ( \lambda$ )  是一个在 Γ 内部解析、在 Γ 上连续的函数，证明：

$$
{ \frac { 1 } { 2 \pi i } } \int _ { \Gamma } f ( \lambda ) L ( \lambda ) ^ { - 1 } d \lambda = U f ( T ) V .
$$

**习题 5.** 若 $ (U, T) $ 是 $L ( \lambda$ )的一个标准对，则依第 5.13 节的术语，$ (U, T) $ 是一个指标为 $ l $ 的可观测对（observable pair of index $ l $）。（这同时也是如下结论的充分条件：尺寸分别为 $ n \times ln $ 的矩阵  ( U , T )  与尺寸为 $ n \times n $ 的矩阵 $l n \times l n ,$ 构成某个首一（monic）矩阵多项式（次数为 $ l $）的一个标准对；参见定理 1）。□

对于定理 2，还存在一个有用之逆命题。

定理 4．设  ( U , T , V )  是 $ L(\lambda) $ 的一个容许三元组，且假设  

$$

L ( \lambda ) ^ { - 1 } = U ( \lambda I - T ) ^ { - 1 } V .\tag{8}
$$
  

则  ( U , T , V )  是 $ L(\lambda) $ 的一个标准三元组。  

**证明．** 当 $ |\lambda| $ 充分大时， $L ( \lambda ) ^ { - 1 }  $ 具有如下形式的洛朗展开式：  

$$

L ( \lambda ) ^ { - 1 } = \lambda ^ { - l } L _ { l } ^ { - 1 } + \lambda ^ { - l - 1 } A _ { 1 } + \lambda ^ { - l - 2 } A _ { 2 } + \cdots ,\tag{9}
$$
  

其中  A _ { 1 } , A _ { 2 } $, \ldots$ 为某些矩阵。现令 $ \Gamma $ 为复平面上以原点为圆心的圆周，且使得 $\sigma ( L$ )与 $ T $ 的所有特征值均位于其内部。
