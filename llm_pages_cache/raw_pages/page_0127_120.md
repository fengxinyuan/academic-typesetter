习题 5．设  $T \in { \mathcal { L } } ( { \mathcal { S } } _ { 1 } , { \mathcal { S } } _ { 2 } )$ 。证明：若元素  $\begin{array} { r } { \pmb { x } _ { i } \in \mathcal { S } _ { 1 } \mathrm { ~ } ( i = } \end{array}$ 与 $1 , 2 , \ldots , k )$ 线性相关，则它们的像  $T ( \pmb { x } _ { i } ) ( i = 1 , 2 , . . . , k )$ 亦线性相关。口

习题 5 表明：线性变换将线性相关的向量组映为另一线性相关的向量组。然而，线性变换也可能将线性无关的元素映为线性相关的集合。例如，将  $\mathcal { S } _ { 1 }$ 中每个元素都映到  $\mathcal { S } _ { 2 }$ 的零元素的变换。

例 6．由下式定义的变换  $T \in \mathcal { L } ( \mathbb { R } ^ { 4 } , \mathbb { R } ^ { 3 } )$：



$$
T \left( { \left[ \begin{array} { l } { x _ { 1 } } \\ { x _ { 2 } } \\ { x _ { 3 } } \\ { x _ { 4 } } \end{array} \right] } \right) = { \left[ \begin{array} { l } { x _ { 1 } - x _ { 2 } + x _ { 3 } } \\ { x _ { 2 } - x _ { 3 } + x _ { 4 } } \\ { 0 } \end{array} \right] }
$$

将线性无关的向量 $[ - 1 \phantom { \frac { 1 } { 2 } } \ \mathbf { 0 } \phantom { \frac { 1 } { 2 } } \ \mathbf { 1 } \phantom { \frac { 1 } { 2 } } \mathbf { \Omega } \mathbf { 1 } ] ^ { \mathbf { T } }$ 和 $[ 0 \mathrm { ~ \bf ~ \mathfrak ~ { ~ 0 ~ } ~ } \textbf { 0 ~ } \textbf { 1 } ] ^ { \mathtt { T } }$ 分别映射为（线性相关的）向量 0 和 $[ 0 \mathrm { ~ \bf ~ 1 ~ } 0 ] ^ { \tt T }$。□

本节其余部分将聚焦于集合 $\mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 的代数性质。事实证明，若如下定义线性变换的加法与标量乘法，则 $\mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 本身构成一个在域 $\mathcal { F }$ 上的线性空间：

对任意 $T _ { 1 } , T _ { 2 } \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 及任意 ${ \pmb x } \in \mathcal { S } _ { 1 }$ 1，

$$
( T _ { 1 } + T _ { 2 } ) ( x ) \triangleq T _ { 1 } ( x ) + T _ { 2 } ( x ) .
$$

对任意 $T \in \mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$、α ∈ F 及任意 $\pmb { x } \in \mathcal { S } _ { 1 }$ 1，

$$
( \alpha T ) ( \pmb { x } ) \triangleq \pmb { \alpha } T ( \pmb { x } ) .
$$

需注意：若两个从 $\mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 出发的变换 $T _ { 1 }$ 与 $T _ { 2 }$ 满足 $T _ { 1 } ( \mathbf { x } ) = T _ { 2 } ( \mathbf { x } )$ 对每一个 $\pmb { x } \in \mathcal { S } _ { 1 }$ 均成立，则称它们相等（或恒等）。显然，零变换 $\theta$（即满足 $0 ( { \boldsymbol { \mathbf { x } } } ) = \pmb { \theta }$ 对所有 $\pmb { x } \in \mathcal { S } _ { 1 }$ 成立的变换）在 $\mathcal { L } ( \mathcal { S } _ { 1 } , \mathcal { S } _ { 2 } )$ 中充当零元素。
