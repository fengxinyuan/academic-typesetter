\alpha _ { 1 } x _ { 1 } + \alpha _ { 2 } x _ { 2 } + \cdot \cdot \cdot + \alpha _ { n } x _ { n } = 0 ,
$$  

其中，并非所有 $a _ { j }$ 均为零。显然，若 $\alpha _ { j } \neq 0$，则可利用该约束将 $x _ { j }$ 表示为其余 $\pmb { x } ^ { \prime } \mathbf { s } ,$ 的线性组合，代入 $R ( { \pmb x } )$ 后，即得一个仅含 $n - 1$ 个变量的新商式；其驻点值（以及与之关联的 $n - 1$ 个特征值）可直接分析，无需再显式涉及约束条件。然而事实上，这一看似自然的解题路径并非最富成效；相反，倘若我们已掌握无约束系统的性质，则可对带约束系统作出相当丰富的刻画。我们将此类带约束问题的特征值与特征向量分别称为**约束特征值**（constrained eigenvalues）与**约束特征向量**（constrained eigenvectors）。

更一般地，考虑满足 $ r $ 个约束条件的特征值问题：  

$$
( \mathbf { x } , \pmb { a } _ { i } ) = \pmb { a } _ { i } ^ { * } \mathbf { x } = 0 , \qquad i = 1 , 2 , \ldots , r ,\tag{1}
$$

其中，${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { r }$ 是 $\mathbb { C } ^ { n } .$ 中线性无关的向量。给定一个埃尔米特矩阵 $H \in \mathbb { C } ^ { n \times n }$，我们希望求出 $ H $ 的约束特征值与约束特征向量，即寻找标量 $\lambda \in \mathbb { C }$ 与向量 $\pmb { x } \in \mathbb { C } ^ { n }$，使得  

$$
H \mathbf { x } = \lambda x , \quad x \neq 0 , \quad \quad { \mathrm { a n d } } \quad \quad ( \mathbf { x } , \mathbf { a } _ { i } ) = a _ { i } ^ { * } x = 0 , i = 1 , 2 , \ldots , r .\tag{2}
$$  

令 $\mathcal { A } _ { r }$ 为由式 (1) 中出现的 ${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { \mathfrak { i } }$ 所生成的子空间，并令 $\boldsymbol { \mathcal { C } } _ { n - r }$ 表示 $\mathcal { A } _ { r }$ 在 $\mathbb { C } ^ { n }$ 中的正交补空间：  

$$
\mathcal { A } _ { r } \oplus \mathcal { C } _ { n - r } = \mathbb { C } ^ { n } .
$$  

若 $b _ { 1 } , b _ { 2 } , \ldots , b _ { n - r }$ 是 $\boldsymbol { \mathcal { C } } _ { n - r }$ 中的一组标准正交基，且  

$$
B = [ { \pmb b } _ { 1 } \quad { \pmb b } _ { 2 } \quad \cdots \quad { \pmb b } _ { n - r } ] ,
$$  

则显然有 $\begin{array} { r } { B \in \mathbb { C } ^ { n \times ( n - r ) } , B ^ { * } B = I _ { n - r } , } \end{array}$，且 $B B ^ { * }$ 是到 $\boldsymbol { \mathcal { C } } _ { n - r }$ 上的正交投影算子（参见第 5.8 节）。

向量 $\pmb { x } \in \mathbb { C } ^ { n }$ 满足式 (1) 所给出的约束条件，当且仅当 $\pmb { x } \in \mathcal { C } _ { n - r }$。即，$B B ^ { * } x = x$，且向量 $\mathbf { y } = B ^ { * } \mathbf { x } \in \mathbb { C } ^ { n - r }$ 满足 $x = B y , \mathrm { S o }$，其中 $\qquad x \neq \theta ,$。

$$
R _ { H } ( { \pmb x } ) = \frac { ( H { \pmb x } , { \pmb x } ) } { ( { \pmb x } , { \pmb x } ) } = \frac { ( H B { \pmb y } , B { \pmb y } ) } { ( B { \pmb y } , B { \pmb y } ) } = \frac { ( B ^ { \ast } H B { \pmb y } , { \pmb y } ) } { ( B ^ { \ast } B { \pmb y } , { \pmb y } ) } .
$$

由于 $B ^ { * } B = I _ { n - r } ,$，我们得到

$$
R ( \pmb { x } ) \equiv R _ { H } ( \pmb { x } ) = R _ { B ^ { * } H B } ( \pmb { y } )\tag{3}
$$

于是，式 (2) 所述问题便化归为标准形式：求矩阵 $( n - r ) \times ( n - r )$ 的埃尔米特矩阵 $B ^ { * } H B$ 的瑞利商（Rayleigh quotient）的驻点值（参见第 8.3 节）。我们已知，这些驻点值仅在 $B ^ { * } H B$ 的特征值处取得。因此，λ 是矩阵 H 在给定约束下的约束特征值，且 x 为其对应的约束特征向量，当且仅当 λ 是 $B ^ { * } H B$ 的一个特征值，且 y 为其对应的特征向量，其中 $\boldsymbol { x } = B \boldsymbol { y }$。
