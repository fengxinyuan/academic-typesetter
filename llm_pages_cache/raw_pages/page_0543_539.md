**定理 1（H. 维兰特†）**．设矩阵  A  $\in \mathbb { C } ^ { n \times n } , B \in \mathbb { R } ^ { n \times n }$ 满足 $| A | \leq B$ ，且 $ B $ 为不可约矩阵。则 $\mu$ _ { _ { A } } = r , ，其中 $\mu$ _ { A }  与 $ r $ 分别为 $ A $ 与 $ B $ 的谱半径，当且仅当 $ A $ 具有如下形式：

$$

\pmb { A } = \omega \pmb { D } \pmb { B } \pmb { D } ^ { - 1 } ,\tag{1}
$$


其中  | $\omega | = 1 , | D | = I ,$ 且 $\omega r \in \sigma ( A$ ) 。

首先指出：由定理 15.3.1 可知，$ r $ 实际上是 $ B $ 的一个特征值。

**证明**．若 $ A $ 具有形式 (1)，则显然 $ A $ 与 $ B $ 具有相同的谱半径。

反之，设  \mu _ { A } = r  且 $\lambda \in \sigma ( A$ )，其中 $| \lambda | = \mu$ _ { A } = r 。令 $ \mathbf{a} $ 为 $ A $ 关于 $\lambda ,$ 的一个左特征向量，即满足  { $\pmb a } \neq { \pmb \theta }$ 且  a ^ { * } $A = \lambda a ^ { * }  $。于是

$$

| \lambda \pmb { a } ^ { * } | = | \lambda | | \pmb { a } ^ { * } | = r | \pmb { a } ^ { * } | \leq | \pmb { a } ^ { * } | | \boldsymbol { A } | \leq | \pmb { a } ^ { * } | \pmb { B } .\tag{2}
$$


因此，对任一正向量 $ \mathbf{u} $，均有

$$

r | \mathbf { \mu } \mathbf { \pmb { a } } ^ { * } | \mathbf { \mu } \leq | \mathbf { \mu } \mathbf { \pmb { a } } ^ { * } | B \mathbf { \mu } .\tag{3}
$$


根据定理 15.3.1，存在一个 $u > \theta$，使得 $B u = r u .$，因此对这个 u，我们有 $r | \mathbf { \nabla } a ^ { * } | \mathbf { \nabla } u = | \mathbf { \nabla } a ^ { * } | B u$。于是，对这一选取的 u，式 (3) 中取等号，从而式 (2) 中各处亦均取等号。由此可得 $| a ^ { * } | B = r | a ^ { * } |$；再次应用定理 15.3.1，必有 $| \pmb { a } ^ { * } | > 0$。

进而，式 (2) 还给出  

$$
| a ^ { * } | ( B - | A | ) = \theta ^ { * }
$$  

该式与 $B \geq | A |$ 联立，推出 $B = | A |$。

现在定义 $\omega = \lambda / r$，并令  

$$
D = \mathrm { d i a g } \biggl [ \frac { a _ { 1 } } { | a _ { 1 } | } , \ldots , \frac { a _ { n } } { | a _ { n } | } \biggr ] ,
$$  

其中 $\mathbf { \Omega } \bullet = [ a _ { 1 } \quad \cdots \quad a _ { n } ] ^ { \mathbf { T } } .$。于是 $| \omega | = 1 , | D | = I$，且易验证 $a ^ { * } D = | a ^ { * } |$。又由 $a ^ { * } A = \lambda a ^ { * }$ 可得  

$$
| a ^ { * } | D ^ { - 1 } A = \lambda | a ^ { * } | D ^ { - 1 } ,
$$  

从而  

$$
| { \pmb a } ^ { * } | D ^ { - 1 } A D = \omega r | { \pmb a } ^ { * } | ,
$$  

以及  

$$
| \pmb { a } ^ { * } | \omega ^ { - 1 } D ^ { - 1 } A D = r | \pmb { a } ^ { * } | = | \pmb { a } ^ { * } | B .
$$  

换言之，  

$$
| a ^ { * } | ( \omega ^ { - 1 } D ^ { - 1 } A D - B ) = 0 ^ { * } .\tag{4}
$$
