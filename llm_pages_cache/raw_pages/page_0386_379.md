最后应指出，$n \rho$ 即习题 10.3.7a 中所定义的范数。因此，结果 $| \lambda | \leq n \rho$ 是定理 10.3.1 的一个特例。

推论 2（I. 本迪克松†）：若 $A \in \mathbb { R } ^ { n \times n }$ 且 $\begin{array} { r } { \tau = { \frac { 1 } { 2 } } \operatorname* { m a x } _ { r , s } | a _ { r s } - a _ { s r } | } \end{array}$，则对矩阵 $ A $ 的任一特征值 $ \lambda $，均有  

$$
| { \mathcal I } _ { \mathcal M } \lambda | \leq \tau \sqrt { n ( n - 1 ) / 2 } .
$$  

**证明**：当 $ A $ 为实矩阵时，定理 1 的第三个不等式表明  

$$
\sum _ { i = 1 } ^ { n } \mid \mathcal { I } _ { \mathcal { M } } \lambda _ { i } \mid ^ { 2 } \leq \sum _ { r , s = 1 , r \neq s } ^ { n } \left| \frac { a _ { r s } - a _ { s r } } { 2 } \right| ^ { 2 } \leq \tau ^ { 2 } n ( n - 1 ) .
$$  

由于 $ A $ 是实矩阵，其所有复特征值必以共轭对形式成对出现，因此左边求和式中每个非零项至少出现两次。故有 $ 2 \mid \operatorname{Im}  \lambda _ { i } | ^ { 2 } \leq \tau ^ { 2 } n ( n - 1 )$，结论得证。

在结束这些结果之前，我们应指出：推论中所得的界，通常不如由盖尔施戈林（Geršgorin）定理所导出的相应界精确。这一现象在将推论 1 应用于习题 10.6.1 时表现得尤为明显。

**习题 1**：证明 $ |\det  A | \leq n ^ { n / 2 } \rho ^ { n }$，其中 $\rho = \operatorname* { m a x } _ { r , s } | a _ { r s } | .$。

**解**：首先注意算术–几何平均不等式：对任意非负数 $a _ { 1 } , a _ { 2 } , \ldots , a _ { n } .$，有  

$$
( a _ { 1 } a _ { 2 } \cdots a _ { n } ) ^ { 1 / n } \leq { \frac { a _ { 1 } + a _ { 2 } + \cdots + a _ { n } } { n } } .
$$  

设 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ 为 $ A $ 的全部特征值，则由定理 1 可得

$$
\begin{array} { r l } & { | \det A | ^ { 2 } = | \lambda _ { 1 } | ^ { 2 } | \lambda _ { 2 } | ^ { 2 } \cdot \cdot \cdot | \lambda _ { n } | ^ { 2 } } \\ & { \qquad \leq \left( \frac { | \lambda _ { 1 } | ^ { 2 } + \cdot \cdot \cdot + | \lambda _ { n } | ^ { 2 } } { n } \right) ^ { n } } \\ & { \qquad \leq \left( \frac { 1 } { n } \| A \| _ { \mathbf { E } } ^ { 2 } \right) ^ { n } \leq \left( \frac { 1 } { n } n ^ { 2 } \rho ^ { 2 } \right) ^ { n } , } \end{array}
$$  

对两边取平方根即得所求结果。
