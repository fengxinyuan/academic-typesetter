习题 2．验证下列矩阵  

$$
S _ { 1 } = { \left[ \begin{array} { l l } { 0 } & { 1 } \\ { 0 } & { 0 } \end{array} \right] } , \qquad S _ { 2 } = { \left[ \begin{array} { l l } { 1 } & { 0 } \\ { - 2 } & { 1 } \end{array} \right] } , \qquad S _ { 3 } = { \left[ \begin{array} { l l } { 0 } & { 0 } \\ { 0 } & { 1 } \end{array} \right] }
$$  

均为矩阵多项式  

$$
L ( \lambda ) = \lambda ^ { 2 } I + \lambda { \left[ \begin{array} { l l } { ~ 1 } & { ~ 1 } \\ { - 2 } & { - 3 } \end{array} \right] } + { \left[ \begin{array} { l l } { 0 } & { - 1 } \\ { 0 } & { 2 } \end{array} \right] } . \boxed { 1 }
$$  

的解矩阵。

标量多项式的例子提示我们去探讨如下可能性：能否用一组 $ n $ 个相容解（solvents）来刻画一个 $ l $ 次首一多项式 $L ( \lambda$ )的谱信息。因此，定义 $L ( \lambda$ )的一组相容解  S _ { 1 } , S _ { 2 } $, \ldots , S$ _ { l }  为 $L ( \lambda$ )  的**完备相容解集**（complete set of solvents），若其对应的范德蒙德（分块）矩阵  

$$
V = \left[ \begin{array} { c c c c } { I } & { I } & { . . . } & { I } \\ { S _ { 1 } } & { S _ { 2 } } & { . . . } & { S _ { l } } \\ { . . } & { . . } & { . . } \\ { S _ { 1 } ^ { l - 1 } } & { S _ { 2 } ^ { l - 1 } } & { . . . } & { S _ { l - 1 } ^ { l } } \end{array} \right] \in \mathbb { C } ^ { l n }\tag{3}
$$  

是非奇异的。注意，在情形  l = 2  下，该条件等价于 $n \times n$ 阶矩阵  s _ { 2 } - s _ { 1 }  的非奇异性。  

显然，在标量情形  ( n = 1 )  下，若 $L ( \lambda$ )具有一组互异的 $ l $ 个零点，则根据上述定义，这组零点即构成该多项式的完备相容解集（即完备零点集）。这一观察表明：并非每个（矩阵或标量）多项式都存在完备相容解集。然而，若这样的相容解集确实存在，则其理论与标量多项式方程的理论之间存在显著的类比关系。  

**定理 2.** 若  S _ { 1 } , S _ { 2 } $, \ldots , S$ _ { l }  是首一 $n \times n$ 阶矩阵多项式 $L ( \lambda ) ,$ 的一组完备相容解集，则分块对角矩阵 $ \operatorname{diag}_l\, $[ S _ { 1 } , S _ { 2 } $, \ldots , S$ _ { l } ]  是 $ L(\lambda) $ 的一个线性化（linearization）。特别地，  

$$
\sigma ( L ) = \bigcup _ { i = 1 } ^ { l } \sigma ( S _ { i } ) .
$$  

**证明.** 该定理的断言可直接由下述易验证的关系式推出：  

$$
C _ { L } V = V \mathrm { d i a g } [ S _ { 1 } , S _ { 2 } , \ldots , S _ { l } ] ,\tag{4}
$$

其中 $ V $ 由式 (3) 给出（参见习题 7.11.14）。

给定一组溶剂，反向求取一个首一矩阵多项式的问题可轻易解决；该问题构成了下一习题的内容。
