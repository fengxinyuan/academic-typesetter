## 3.5 基的概念

设非全为零的元素 $${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , \dots , { \pmb a } _ { m }$$ 属于域 $${ \mathcal { F } } ,$$ 上的线性空间 $$\mathcal { S }$$，且  

$$

\mathcal { S } _ { 0 } = \operatorname { s p a n } \{ \pmb { a } _ { 1 } , \pmb { a } _ { 2 } , . . . , \pmb { a } _ { m } \} .
$$
  

若元素 $${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , \ldots , { \pmb a } _ { m }$$ 线性无关，即其中任一元素均不能表示为其余元素的线性组合，则根据定理 3.4.1，所有 $$\mathbf { a } _ { i } ( i = 1 , 2 , \ldots , m )$$ 均为生成 $$\mathcal { S } _ { 0 }$$ 所必需。而在元素 $$a _ { 1 } , a _ { 2 } , \ldots , a _ { m }$$ 线性相关的情形下，依据该定理，我们可以删去集合中所有可表为其余向量之线性组合的向量，从而使得剩余（线性无关的）$n$ 个元素的生成子空间仍为 $$\mathcal { S } _ { 0 }$$。因此，我们总可将 $$\mathcal { S } _ { 0 }$$ 视为 $n$ 个线性无关元素的线性包络（即由它们张成的子空间），其中 $$1 \leq n \leq m$$。

设 $$\mathcal { S }$$ 表示域 $$\mathcal { F } .$$ 上的任一线性空间。考虑其一个有限元素集  

$$

\{ a _ { 1 } , a _ { 2 } , \ldots , a _ { n } \}\tag{1}
$$


若向量组满足线性无关，且  \pmb { a } $\in \mathcal { S }$ 中每个元素均可表示为该向量组（即式 (1)）中各元素的线性组合，则称该向量组为 $\mathcal { S }  $ 的一个（有限）基：

$$

\pmb { a } = \sum _ { i = 1 } ^ { n } \alpha _ { i } \pmb { a } _ { i } \qquad \alpha _ { i } \in \mathscr { F } , i = 1 , 2 , \ldots , n .\tag{2}
$$


换言之，式 (1) 中的元素构成  \mathcal { S }  的一个基，当且仅当下列两个条件同时成立：

$$

\mathcal { S } = \operatorname { s p a n } \{ \pmb { a } _ { 1 } , \pmb { a } _ { 2 } , \dots , \pmb { a } _ { n } \}\tag{3}
$$
