$$
G \pmb { x } = \pmb { c } ,\tag{2}
$$

**证明**．由命题 12.1.4 可知，对每个  j  $= 1 , 2 , \ldots , p .$ ，有 $ \operatorname{vec} $( A _ { j } X B _ { j } ) = ( B _ { j } ^ { $\operatorname { T } } \otimes A$ _ { j } )$ = \operatorname{vec} X $。又因向量化映射 $ \operatorname{vec} A $ 是线性的，故

$$

\mathrm { v e c } ~ C = \sum _ { j = 1 } ^ { p } ~ ( B _ { j } ^ { \mathrm { T } } \otimes A _ { j } ) \mathrm { v e c } ~ X

**推论 1**．方程 (1) 存在解 $ X $ 当且仅当 $ \operatorname{rank}[G\; c] = \operatorname{rank}\, G $。

**推论 2**．方程 (1) 存在唯一解当且仅当式 (2) 中的矩阵 $ G $ 是非奇异的。

下面我们考虑方程 (1) 的一个重要特例：矩阵方程

$$

A X + X B = C .\tag{3}
$$


**定理 2**．方程 (3) 存在唯一解当且仅当矩阵 $ A $ 与 $ -B $ 没有公共特征值。

**证明**．在当前情形下，式 (2) 中的矩阵 $ G $ 为 $\left( { { I }$ _ { n } } $\otimes A \right) +$ ，即  ( B ^ { $\boldsymbol { \mathsf { T } } } \otimes I$ _ { m } ) ；由推论 12.2.2，其特征值恰为诸数 $\lambda$ _ { r } $+ \mu$ _ { s }  与 $r = 1 , 2 , \ldots , m , s = 1 , 2 , \ldots , n .  $。现只需应用推论 2，并回顾如下事实：一个矩阵是非奇异的当且仅当它的所有特征值均非零。■
