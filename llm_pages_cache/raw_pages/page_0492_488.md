**解**．为求  $a ( \lambda )$  的牛顿和，可使用公式 (9) 和 (10)，或采用表示式 (11)。我们有  $s _ { 0 } = 4 , s _ { 1 } = 2 , s _ { 2 } = 0 , s _ { 3 } = 2  s _ { 4 } = 4 , s _ { 5 } = 2 , s _ { 6 } = 0$ ，因此相应的汉克尔矩阵 $ H $ 为  

$$
H = { \left[ \begin{array} { l l l l } { 4 } & { 2 } & { 0 } & { 2 } \\ { 2 } & { 0 } & { 2 } & { 4 } \\ { 0 } & { 2 } & { 4 } & { 2 } \\ { 2 } & { 4 } & { 2 } & { 0 } \end{array} \right] } .
$$  

由于  $H = \{ 2 , 1 , 1 \}$ ，故存在一对互异的复共轭零点（$ \nu = 1 $），以及一个实零点  $( \pi - \nu = 1 )$ 。易验证，实际上  $a ( \lambda ) = ( \lambda - 1 ) ^ { 2 } ( \lambda ^ { 2 } + 1 )$ ，所得结果由此得到确认。
