所有元素均为零的矩形矩阵也称为零矩阵。

一个方阵 $ A $ 若满足如下条件，则称为埃尔米特矩阵（或自伴矩阵）：其主对角线上的元素均为实数，且任意两个关于主对角线对称位置的元素互为复共轭。换言之，埃尔米特矩阵具有如下形式：

$$
{ \left[ \begin{array} { l l l l } { a _ { 1 1 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 n } } \\ { { \bar { a } } _ { 1 2 } } & { a _ { 2 2 } } & { \cdots } & { a _ { 2 n } } \\ { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { { \bar { a } } _ { 1 n } } & { { \bar { a } } _ { 2 n } } & { \cdots } & { a _ { n n } } \end{array} \right] } ,
$$

即对所有 $ i,j = 1,2,\dots,n $，有  a _ { j i } $= \vec { a }$ _ { i j } ，其中 $\overline { { a } }$ _ { i j }  表示复数  a _ { i j }  的复共轭。

若所有关于主对角线对称位置的元素彼此相等，则该方阵称为对称矩阵：

$$
{ \left[ \begin{array} { l l l l } { a _ { 1 1 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 n } } \\ { a _ { 1 2 } } & { a _ { 2 2 } } & { \cdots } & { a _ { 2 n } } \\ { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { a _ { 1 n } } & { a _ { 2 n } } & { \cdots } & { a _ { n n } } \end{array} \right] } .
$$

显然，在实矩阵（即所有元素均为实数的矩阵）的情形下，埃尔米特矩阵与对称矩阵这两个概念重合。

$i = 1 , 2 , \ldots , n , j = 1 , 2 , \ldots , n ,$



$$
\pmb { b } = \left[ \begin{array} { c } { b _ { 1 } } \\ { b _ { 2 } } \\ { \vdots } \\ { b _ { n } } \end{array} \right] , \qquad \pmb { c } ^ { \operatorname { T } } = [ c _ { 1 } \quad c _ { 2 } \quad \cdots \quad c _ { n } ] .

上标符号 $ T $（表示行矩阵）的用意，将在第 1.5 节中予以阐明。

此类形如 $n \times 1$ 与 $1 \times n$ 的矩阵亦被称为向量或有序 $ n $ 元组；当 $ n = 1, 2, 3 $ 时，它们在几何上具有直观意义：可解释为空间中某一点 $ P $ 的坐标（或解释为向量 $\overrightarrow { \mathbf { O P } } )$ 在一维、二维或三维空间中相对于坐标轴的分量，参见图 1.1）。
