## 10.8 舒尔定理

接下来，我们介绍一个源自I. 舒尔（I. Schur）的、风格迥异的重要结果。  
我们先回顾任意矩阵 $A \in \mathbb { R } ^ { n \times n }$ 可唯一分解为一个埃尔米特矩阵 $ B $ 与一个斜埃尔米特矩阵 $ C $ 之和：写作  
$\begin{array} { r } { B = \frac { 1 } { 2 } ( A + A ^ { * } ) } \end{array}$ 7 $\begin{array} { r } { C = \frac { 1 } { 2 } ( A - A ^ { * } ) } \end{array}$，  
并注意到 $A = B + C , B ^ { * } = B ,$ 且 $C ^ { * } = - C$。  
现在，若 $A ^ { * } = A$，则 $C = O$，从而 $ A $ 的所有特征值均为实数。这提示我们：$ C $ 的某种范数可能给出 $ A $ 的特征值之虚部绝对值的一个上界。类似地，若 $A ^ { * } = - A$，则 $B = o$，从而 $ A $ 的所有特征值的实部均为零，因此 $ B $ 的某种范数预期可给出 $ A $ 的特征值之实部绝对值的一个上界。舒尔定理（Schur’s theorem）即包含此类结论。在以下叙述中，记 $ \lambda $ 为复数，$\mathcal { R } e \ \lambda$ 和 $\mathcal { I } _ { M } ~ \lambda$ 分别表示 $ \lambda $ 的实部与虚部。
