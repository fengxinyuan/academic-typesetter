## 4.9 线性变换的特征值与特征向量  

设 $ \text{$T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )$} $。我们从刻画一维 $ T $-不变子空间的元素入手，开始对这类子空间的研究。  

命题 1．设 $ \text{$T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )$} $，且设 $ \text{$\mathcal { S } _ { 0 } $\subset \mathcal { S } } $ 是 $ T $ 的一个一维 $ T $-不变子空间。则对任意非零向量 $ \text{$\pmb { x } $\in \mathcal { S }$ _ { $\mathbf { 0 } } } $，均存在一个标量 $ \text{$\lambda  $\in \mathcal { F } } $（该标量与 $ x $ 无关），使得  

$$
\text{$$
 $T ( \mathbf { x } ) = \lambda \mathbf { x } .\tag{1}$ 
$$}
$$  

**证明**．由于 $ \text{$\mathcal { S } _ { 0 }$} $ 是一维的，故必形如  

$$
\text{$$
 $\mathcal { S }$ _ { 0 } = \{ $\alpha \mathbf { x }$ _ { 0 } : $\boldsymbol { \theta } \neq \mathbf { x }$ _ { 0 } $\in \mathcal { S }$ _ { 0 } $\mathrm { ~ a n d ~ } \alpha \in \mathcal { F } \} .$ 
$$}
$$

子空间  \mathcal { S } _ { $\mathbf { 0 } }$ 的 $ T $-不变性意味着对每个非零向量 $\pmb { x } \in \mathcal { S }$ _ { 0 } ，均有 $T ( \pmb { x } ) \in \mathcal { S }$ _ { 0 } ；因此，若将 $ x $ 表示为 $\alpha$ _ { 0 } $\pmb { x }$ _ { 0 } ，则有 $T ( \alpha$ _ { 0 } { $\pmb x }$ _ { 0 } $) = \alpha { \pmb x }$ _ { 0 } 。于是，条件 (1) 对 $\lambda = \alpha / \alpha$ _ { 0 } \  $( \alpha$ _ { 0 } $\neq 0$ )成立。若 $\mathbf { x }$ _ { 1 }  是 $\mathcal { S }$ _ { $\mathbf { 0 } }$ 中另一元素，则存在某个 $\gamma \in \mathcal F$ 与 $T ( \mathbf { x }$ _ { 1 } $) = \gamma T ( \mathbf { x }$ _ { 0 } $) = \gamma \lambda \mathbf { x }$ _ { 0 } $= \lambda \mathbf { x }$ _ { 1 } ，使得  { $\pmb x }$ _ { 1 } $= \gamma { \pmb x }$ _ { 0 } ，这表明式 (1) 中的 $ \lambda $ 是唯一的。

注意：只要式 (1) 至少对某个非零向量 $ x $ 成立，则必存在一个一维的 $ T $-不变子空间。
