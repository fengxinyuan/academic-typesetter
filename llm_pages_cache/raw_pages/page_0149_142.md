## 4.7 变换的限制、不变子空间与直和

设 $ T $ 为 $ \mathbb{C}^n $ 上的一个线性变换，即 $T \in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } ) ，并设 $ \mathcal{M} $ 是 $ \mathbb{C}^n $ 中的一个线性子空间，即 $\mathcal { S }$ _ { 0 }  是 $\mathcal { S }$ _ { 1 }  的一个线性子空间。对每个 $ x \in \mathcal{M} $，定义变换 $ T|_{\mathcal{M}} $ 为  
$$
(T|_{\mathcal{M}})(x) = T(x),
$$  
即  \tilde { T } : $\mathcal { S }$ _ { 0 } $\bar { \mathcal { S } }$ _ { 2 }  由 $\tilde { T } ( \mathbf { x } ) = T ( \mathbf { x }$ )对每个 $\boldsymbol { x } \in \mathcal { S }$ _ { 0 }  所定义。该变换称为 $ T $ 在 $ \mathcal{M} $ 上的**限制**，记作 $T \vert$ _ { $\mathcal { S }$ _ { 0 } } 。显然， T | _ { $\mathcal { S }$ _ { 0 } } $\in \mathcal { L } ( \mathcal { S }$ _ { 0 } $, \mathcal { S }$ _ { 2 } ) 。  

相反地，若线性变换 $ \widetilde{T}:\mathbb{C}^n \to \mathbb{C}^n $ 满足 $ \widetilde{T}(x) = T(x) $ 对所有 $ x \in \mathcal{M} $ 成立，即 $T \in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } )  在 $\mathcal { S }$ _ { 0 } $\subset \mathcal { S }$ _ { 1 }  上与 $\widetilde { T }$ 相重合，则称 $ \widetilde{T} $ 为 $ T|_{\mathcal{M}} $ 的一个**延拓**（extension），即 $\tilde { \cal T } .  $ 的一个延拓。
