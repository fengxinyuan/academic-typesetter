这些性质恰好对应于度量（metric）的公理——即定义在集合 $\mathcal { S }$ 的元素对上的函数，该函数在数学意义上是一种合理而严谨的距离度量。

在赋范线性空间中，所有到某固定点 $\scriptstyle { \mathbf { x } _ { 0 } }$ 的距离恰好为 $r > 0$ 的向量所构成的集合，称为以 $\scriptstyle { \mathbf { x } } _ { 0 }$ 为中心、半径为 $r$ 的球面（sphere）。于是，用范数显式写出，该球面即为

$$
\{ \pmb { x } \in \mathcal { S } : \| \pmb { x } - \pmb { x } _ { 0 } \| = r \} .
$$  

满足条件  \| { $\pmb x } - { \pmb x }$ _ { 0 } \| $\le r$ 的所有 $\pmb { x } \in \mathcal { S }$ 构成的集合，是以 $\scriptstyle { \mathbf { 1 } }$ _ { 0 }  为中心、半径为  r .  的球（ball）；以 $\theta$ 为中心、半径为  r = 1  的球面（sphere）称为**单位球面**（unit sphere），它在赋范线性空间的分析中起着重要作用——正如它在定理 10.1.2 的证明中所起的作用一样。相应地，**单位球**（unit ball）自然就是  \{ { $\pmb x } \in { \mathcal { S } } { : } \| { \pmb x } \| \leq 1 \}  $。
