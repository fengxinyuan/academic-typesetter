现在假设我们进一步要求 $A ( \zeta )$ 是埃尔米特矩阵，且在复平面上某点 $\zeta = \zeta _ { 0 }$ 的邻域 $\mathcal { N }$ 内解析。设 $a _ { j k } ( \zeta )$ 是 $A ( \zeta )$ 中的一个元素，满足 $j \neq k$；再设 $z = x + i y$，其中 x 与 y 为实数。于是定义 $a _ { j k } ( x + i y ) = u ( x , y ) + i v ( x , y )$，其中 u 与 v 是实值函数。

在上述定义下，柯西–黎曼方程意味着

$$
{ \frac { { \hat { c } } u } { { \hat { \partial } } x } } = { \frac { { \hat { \partial } } v } { \partial y } } \qquad { \mathrm { a n d } } \qquad { \frac { { \hat { c } } u } { \partial y } } = - { \frac { { \hat { c } } v } { \partial x } } .
$$

但 $a _ { k j } ( \zeta ) = a _ { j k } ( \zeta ) = u ( x , y ) - i v ( x , y )$ 也在 $\mathcal { N }$ 上解析。

$$
\frac { \hat { c } \pmb { u } } { \hat { c } \pmb { x } } = - \frac { \hat { c } \pmb { v } } { \hat { \partial } \pmb { y } } \quad \mathrm { a n d } \quad \frac { \hat { c } \pmb { u } } { \hat { \partial } \pmb { y } } = \frac { \hat { c } \pmb { v } } { \hat { \partial } \pmb { x } } .
$$  

这些方程合起来表明，$a _ { j k } ( \zeta )$ 在 ${ \mathcal { N } } ,$ 上为常数，从而丢失了参数依赖性。这意味着，以复变函数意义下的解析依赖性作为假设过强；因此，在分析既解析又埃尔米特的矩阵时，我们必须将注意力限制在实参数 $\zeta$ 上，并假定：对每个 $j$ 和每个 k，$a _ { j k }$ 的实部与虚部均为实变量 $\zeta .$ 的实解析函数。

正因如此，本章的最终定理（关于正规矩阵）必须以实参数 $\zeta .$ 表述。当该定理应用于埃尔米特矩阵时，这意味着扰动后的特征值保持为实数，且各分量矩阵（如定理 11.4.1 所研究者）亦为埃尔米特矩阵。此外还可证明：在此情形下，无论未扰动特征值的重数如何，扰动后的特征值均为 $\zeta ,$ 的解析函数。扰动后的分量矩阵同样解析，因而可设 $A ( \zeta )$ 的特征向量在整个 $\zeta = 0$ 的某个邻域内均为解析且标准正交的。这些重要结果最早由 F. Rellich 于 20 世纪 30 年代初证明。Rellich 的首个证明主要依赖于扰动后特征值为实数这一事实。我们将借助 Kato 提出的一种较新技巧，证明一个包含上述结果的定理（定理 2）。（参见附录 3 中的参考文献。）

在作了上述铺垫之后，我们现在回到一个扰动问题，且对矩阵 $A ( \zeta )$ 的对称性不作任何假设。在我们对 $A ( \zeta )$ 的对称性作出某种假设之前，我们仍保留其依赖于复参数 $\zeta .$ 的假设。对于实变量 $\zeta$ 情形所对应的结论之表述，留作习题。

我们首先证明：若 $\lambda$ 是矩阵 A 的一个指标为 1 的特征值，且 $\lambda _ { j } ( \zeta )$ 是 $A ( \zeta )$ 的一个特征值，满足当 $\zeta \to 0 ,$ 时有 $\lambda ( \zeta )  \lambda$，则当 $\zeta \to 0$ 时，

$$
\lambda _ { j } ( \zeta ) = \lambda + \alpha _ { j } \zeta + O ( | \zeta | ^ { 1 + ( 1 / l ) } ) .
