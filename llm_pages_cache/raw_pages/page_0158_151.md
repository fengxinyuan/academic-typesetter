推论 2．设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，且 dim ${ \mathcal { S } } = n .$。若 T 具有 n 个互异的特征值，则存在 $\mathcal { S }$ 的一组基，该基由 T 的特征向量构成。

此时，我们也称线性变换 $ T $ 的特征向量张成空间 $\mathcal { S }$，或称 $T$ 在 $ S $ 中具有一个特征基（eigenbasis）。注意：习题 6 表明，即使线性变换 ${ \mathcal { S } } .$ 具有 $n _ { 0 } < n$ 个互异的特征值，它仍可能拥有一个特征基。另一方面，并非每个线性变换（参见习题 5）都拥有足够多的线性无关特征向量以张成整个空间。事实上，$ T $ 在 $ S $ 中存在特征基，当且仅当 $T \mathcal { S }$，等价于说 $ T $ 是一个单重变换（simple transformation）。

**定理 2.** 线性变换 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 是单重变换，当且仅当它在 ${ \mathcal { S } } .$ 中具有一个特征基。

**证明.** 若 $\left\{ { \pmb x } _ { j } \right\} _ { j = 1 } ^ { n }$ 是 ${ \mathcal { S } } ,$ 中的一个特征基，则令 ${ \mathcal { S } } _ { i } = \operatorname { s p a n } \{ { \pmb x } _ { i } \}$（其中 $1 \leq i \leq n ,$），我们便得到直和分解 $\begin{array} { r } { T = \sum _ { i = 1 } ^ { n } { \bf \dot { \nabla } } T _ { i } } \end{array}$，其中 $T _ { i }$ 作用于 $\mathcal { S } _ { i }$ 上，且 dim $\mathcal { S } _ { i } = 1 ( 1 \leq i \leq n )$。因此 $T$ 是单重变换。  
反之，设 $\begin{array} { r } { \mathcal { S } = \sum _ { i = 1 } ^ { n } \dot { \mathcal { S } } _ { i } } \end{array}$，其中各子空间 $\mathcal { S } _ { i }$ 均为一维且关于 $ T $ 不变，$i = 1 , 2 , \ldots , n .$。由命题 1 可知，$ S $ 中任一非零元（例如 $ x $）均为 $\mathcal { S } _ { i }$ 的特征向量，$\mathbf { { \boldsymbol { x } } } _ { i } ,$、$T ,$、$1 \leq i \leq n$。显然，所有此类 $x _ { i } ( i = 1 , 2 , \ldots , n )$ 构成 $ T $ 在 ${ \mathcal { S } } .$ 中的一个特征基。

鉴于定理 2，推论 2 给出了 $T$ 为单重变换的一个充分条件（但非必要条件）（参见习题 5）。
