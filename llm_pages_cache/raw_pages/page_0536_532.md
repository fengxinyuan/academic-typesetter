或者，若 \( A \) 是不可约的，且  

$$
a _ { i i } \geq \sum _ { j = 1 , \ j \neq i } ^ { n } | a _ { i j } | , \qquad i = 1 , 2 , \ldots , n ,
$$  

其中至少对一个 \( i \) 严格不等式成立，则 \( A \) 是一个 M-矩阵。  

**证明.** 首先考虑 \( A \) 对角占优的情形。令 $D = \mathrm { d i a g } [ a _ { 1 1 } , \dotsc , a _ { n n } ]$，并定义 $B = I - D ^ { - 1 } A$。注意：\( B \) 的主对角线上元素全为零，且 $B \geq 0$。此外，\( A \) 的对角占优性意味着  

$$
\sum _ { j = 1 } ^ { n } | b _ { i j } | < 1 , \qquad i = 1 , 2 , \ldots , n .
$$

由盖尔施戈林定理（第 10.6 节）可立即推出  
$\mu _ { B } < 1$

$D ^ { - 1 } A = I - B ,$

$D ^ { - 1 } A$  
是一个 M-矩阵。因此，A 本身也是一个 M-矩阵。

习题 5．证明：若 A 是一个 M-矩阵，D 是一个非负对角矩阵，则  
$A + D$

习题 6．证明：对称的 M-矩阵是正定矩阵。（此类矩阵称为斯蒂尔杰斯矩阵（Stieltjes matrix）。）

【解】设 A 是一个对称的 M-矩阵，且  
$\lambda \in \sigma ( A )$  
若  
$\lambda \leq 0$  
则由习题  
$5 , A - \lambda I$  
可知，它也是一个 M-矩阵，因而必为非奇异矩阵。这与假设  
$\lambda \in \sigma ( A )$  
相矛盾。因此，  
$\lambda \in \sigma ( A )$  
蕴含  
$\lambda > 0$  
，从而 A 是正定矩阵。□

## 15.3 佩龙–弗罗贝尼乌斯定理（I）

显然，若  
$A \geq 0$  
，则对任意正整数 p，均有  
$A ^ { p } \geq 0$  
。我们还可能预期：若 A 具有足够高的非零元密度，则当 p 充分大时，将有  
$A ^ { p } > 0 .$  
。我们的第一个结果即属此类。
