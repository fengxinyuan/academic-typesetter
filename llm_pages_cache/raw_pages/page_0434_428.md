## 12.7 广义逆

在前一节中，我们引入了  A  $\in \mathcal { F } ^ { m \times n }$ 的单侧逆的概念，并指出：这样的单侧逆存在当且仅当矩阵 $ A $ 具有满秩。本节的目标是定义一种适用于任意 $ m \times n $ 矩阵 $ A $ 的、对单侧逆概念的推广。为此，我们首先注意到：若 $ A $ 存在单侧逆 $ X $，则该 $ X $ 必满足下列两个方程：

$$

A X A = A ,\tag{1}
$$


$$

X A X = X .\tag{2}
$$


因此，我们定义矩阵 $A \in \mathcal { F } ^ { m \times n }$ 的一个广义逆为满足式 (1) 和 (2) 的矩阵 $\pmb { X } \in \mathcal { F } ^ { n \pmb { \times } m }$，并将这样的矩阵记作 $X = A ^ { I }$。

**命题 1.** 对任意矩阵 $A \in \mathcal { F } ^ { m \times n }$，其广义逆 $A ^ { \parallel }$ 恒存在。

**证明.** 首先注意到，$ m \times n $ 零矩阵以 $ n \times m $ 零矩阵为其广义逆。设 $r \neq 0$ 为矩阵 $ A $ 的秩。则（参见第 2.7 节）存在非奇异矩阵 $R \in \mathcal { F } ^ { m \times m } , V \in \mathcal { F } ^ { n \times n }$，使得  

$$
A = R { \binom { I _ { r } } { 0 } } V ,\tag{3}
$$  

成立。容易验证：对任意 $B _ { 1 } \in \mathcal { F } ^ { r \times ( n - r ) } , B _ { 2 } \in \mathcal { F } ^ { ( m - r ) \times r }$，形如  

$$
A ^ { \mathrm { I } } = V ^ { - 1 } { \binom { I _ { r } } { B _ { 2 } } } B _ { 1 } \biggr ] { R ^ { - 1 } } ,\tag{4}
$$  

的矩阵均满足条件 (1) 和 (2)。■
