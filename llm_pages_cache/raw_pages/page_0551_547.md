**习题 6.** 验证如下矩阵  

$$
{ \begin{array} { r l } { { \frac { 1 } { 1 0 } } { \left[ \begin{array} { l l l l } { 9 } & { 0 } & { 1 } & { 1 } \\ { 1 } & { 7 } & { 0 } & { 1 } \\ { 0 } & { 2 } & { 8 } & { 0 } \\ { 0 } & { 1 } & { 1 } & { 8 } \end{array} \right] } \qquad { \mathrm { ~ a n d ~ } } \qquad { \left[ \begin{array} { l l l } { 0 } & { { \frac { 1 } { 2 } } } & { { \frac { 2 } { 3 } } } \\ { { \frac { 3 } { 4 } } } & { 0 } & { { \frac { 1 } { 3 } } } \\ { { \frac { 1 } { 4 } } } & { { \frac { 1 } { 2 } } } & { 0 } \end{array} \right] } } \end{array} }
$$  

均为本原矩阵。□  

对于 $ n \times n $ 非负本原矩阵 $ A $，满足 $p$ 的最小正整数（即本原指数）可如下估计：  

$$
p \leq n ^ { 2 } - 2 n + 2 .
$$  

由于对上述矩阵有 $p = n ^ { 2 } - 2 n + 2$，

$$
A = { \left[ \begin{array} { l l l l l } { 0 } & { 1 } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { 0 } & { 1 } & & \\ { \vdots } & & & { \ddots } & \\ { 0 } & & & & { 1 } \\ { 1 } & { 1 } & { 0 } & { \cdots } & { 0 } \end{array} \right] } , \qquad A \in \mathbb { R } ^ { n \times n } ,
$$  

估计式 (3) 是精确的。证明从略。

## 15.7 随机矩阵  

实矩阵 $P = [ p _ { i j } ] _ { i , j = 1 } ^ { n }$ 称为随机矩阵，若 $P \geq \theta$ 且其所有行和均等于 1：  

$$
\sum _ { j = 1 } ^ { n } p _ { i j } = 1 , \qquad i = 1 , 2 , \ldots , n .\tag{1}
$$  

此类矩阵出现在概率论问题中，我们将在第 15.8 节引入相关背景。本节将推导随机矩阵的一些重要性质。

**定理 1.** 一个非负矩阵 $ P $ 是随机矩阵，当且仅当它以 1 为特征值，且对应的（右）特征向量为 $\pmb { \mathscr { u } } = [ 1 \quad 1 \quad \cdots \quad 1 ] ^ { \mathbf { T } }$。此外，随机矩阵的谱半径为 1。

**证明.** 若 $ P $ 是随机矩阵，则条件 (1) 显然可写为 $P _ { \mathbf { \delta } } \mathbf { \delta } _ { u } = \mathbf { \delta } _ { u }$。因此 1 是 $ P $ 的一个特征值，且对应的（右）特征向量为 $ \mathbf{u} $。

反之，$P _ { \mathbf { \delta } } \mathbf { \delta } _ { u } = \mathbf { \delta } _ { u }$ 蕴含等式 (1)，从而推出 $ P $ 是随机矩阵。

对于该定理的最后一部分，我们利用习题 15.3.7 证明：$ P $ 的主实特征值为 1。
