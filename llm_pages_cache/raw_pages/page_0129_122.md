在习题 3.1.3(b) 中已证明，$\mathcal { F } ^ { n \times n }$ 是一个线性空间。空间 ${ \mathcal { F } } ^ { n \times n }$ 连同矩阵乘法运算一起，构成了代数（algebra）的另一个例子。

关于线性变换的多项式，其定义方式与关于方阵的多项式相同（参见第 1.7 节）。

**习题 12.** 证明：对任意 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，均存在一个非零标量多项式 $\begin{array} { r } { p ( \lambda ) = \sum _ { i = 0 } ^ { l } p _ { i } \lambda ^ { i } } \end{array}$，其系数取自 $\mathcal { F }$，使得 $\begin{array} { r } { p ( T ) \triangleq \sum _ { i = 0 } ^ { l } p _ { i } T ^ { i } } \end{array}$ 为零变换。

**解．** 由于（由习题 8 可知）空间 ${ \mathcal { L } } ( { \mathcal { S } } )$ 是有限维的，故存在足够大的正整数 $ l $，使得变换 $I ,$、$T , T ^ { 2 } , \dots , T ^ { l }$（视作 ${ \mathcal { L } } ( { \mathcal { S } } )$ 中的元素）线性相关。因此，存在不全为零的标量 $p _ { 1 } , p _ { 2 } , \ldots , p _ { l }$（取自 ${ \mathcal { F } } ,$），使得 $\sum _ { i = 0 } ^ { l } p _ { i } T ^ { i } = 0 .$。

## 4.2 线性变换的矩阵表示

设  T  $\in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } ) . ，其中 $\dim $\mathcal { S } _ { 1 } = n$$ 且 $\dim $\mathcal { S } _ { 2 } = m$$。我们在例 4.1.3 中已看到，在特殊情形  \mathcal { S } _ { 1 } $= \mathcal { F } ^ { n }$ 与 $\mathcal { S }$ _ { 2 } $= \mathcal { F } ^ { m }$ 下，任一 $m \times n$ 矩阵均定义了一个线性变换 $T \in { \mathcal { L } } ( { \mathcal { F } } ^ { n } , { \mathcal { F } } ^ { m }$ )。现在我们证明：任一线性变换 $T \in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } )  均对应于一族 $m \times n$ 矩阵。设 $\mathcal { E } = \{ \mathbf { { x } }$ _ { 1 } $, \mathbf { { x } }$ _ { 2 } $, \ldots , \mathbf { { x } }$ _ { n } \}  与 $\mathcal { G } = \{ \boldsymbol { y }$ _ { 1 } $, \boldsymbol { y }$ _ { 2 } $, \ldots , \boldsymbol { y }$ _ { m } \}  分别为向量空间 $\mathcal { S }$ _ { 1 }  与 $\mathcal { S }$ _ { 2 }  在数域  { $\mathcal { F } } ,$ 上的任意一组基。计算像向量 $T ( \pmb { x }$ _ { j } ) 、 ( j = 1 , ~ 2 , ~ . . . , ~ n ) ，并求该向量组  \{ $T ( \pmb { x }$ _ { 1 } ) , 、 $T ( \mathbf { x }$ _ { 2 } $) , \dots , T ( \mathbf { x }$ _ { n } ) \}  关于基 $\mathscr { G }  $ 的坐标表示（参见第 3.7 节），即可得到  

$$
T ( x _ { j } ) = \sum _ { i = 1 } ^ { m } a _ { i j } y _ { i } , \qquad j = 1 , 2 , \ldots , n .\tag{1}
$$

矩阵 $A _ { \mathcal { E } , \mathcal { G } } = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } \in \mathcal { F } ^ { m \times n }$ 由该关系式定义，并称其为线性变换 $T$ 关于基 $( \mathcal { E } , \mathcal { G } )$ 的（矩阵）表示。注意：线性变换 $T$ 的表示矩阵 $A _ { \delta , \mathcal { G } }$ 的各列，恰好是向量 $T ( \mathbf { x } _ { 1 } ) , T ( \mathbf { x } _ { 2 } ) , \ldots , T ( \mathbf { x } _ { n } )$ 关于基 $\mathscr { G }$ 的坐标；此外，如第 3.7 节所指出的，系统 $\{ T ( \pmb { x } _ { j } ) \} _ { j = 1 } ^ { n }$ 关于基 $\mathscr { G }$ 的表示是唯一的。因此，若进一步固定基 $\mathbf { \delta } _ { \mathbf { \delta } } ^ { \mathcal { O } } ,$，则线性变换 $T$ 关于基对 $( \mathcal { E } , \mathcal { G } )$ 的（矩阵）表示亦唯一确定。
