## 矩阵函数

本章中，我们考虑属于 $C ^ { n \times n }$ 的矩阵 A（其中包括 $\mathbb { R } ^ { n \times n }$ 中的矩阵作为特例），并探讨如何赋予表达式 $f ( A )$ 以合理含义，其中 $f ( \lambda )$ 是一个复变量的复值函数。我们希望对尽可能广泛的函数类 $f ( \lambda )$ 都能给出 $f ( A )$ 的明确定义。我们已经看到，若 $f ( \lambda ) = p ( \lambda )$ 是一个复系数多项式，则该问题可轻易解决；此时有  

$$
p ( A ) \triangleq \sum _ { i = 1 } ^ { l } p _ { i } A ^ { i } \qquad { \mathrm { i f } } \qquad p ( \lambda ) = \sum _ { i = 0 } ^ { l } p _ { i } \lambda ^ { i } .
$$  

此外，若 $m ( \lambda )$ 是矩阵 $A ,$ 的极小多项式，则对任一多项式 $p ( \lambda )$，均存在多项式 $q ( \lambda )$ 和 $r ( \lambda )$，使得  

$$
\begin{array} { r } { p ( \lambda ) = m ( \lambda ) q ( \lambda ) + r ( \lambda ) , } \end{array}
$$  

其中 $r ( \lambda )$ 为零多项式，或其次数严格小于 $m ( \lambda )$ 的次数。于是，由于 $m ( A ) = O ,$，可得 $p ( A ) = r ( A )$。

我们将考虑的更一般的函数 $f ( \lambda )$ 将保持这一性质；换言之，对给定的 $f ( \lambda )$ 与矩阵 A，存在一个多项式 $r ( \lambda )$（其次数小于 A 的极小多项式的次数），使得  
$A ) f ( A ) = r ( A )$  
令人惊讶但确凿无疑的是，即使施加了这一约束，仍为可容许的函数 $f ( \lambda )$ 留下了相当大的自由度。
