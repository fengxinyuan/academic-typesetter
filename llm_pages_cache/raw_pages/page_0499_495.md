**证明．** 由于 $( U , T , V )$ 是一个标准三元组，故存在一个非奇异矩阵 $ S $，使得  

$$
P _ { 1 } = U S , \qquad C _ { L } = S ^ { - 1 } T S , \qquad R _ { 1 } = S ^ { - 1 } V .
$$

注意，$( \lambda I - C _ { L } ) ^ { - 1 } = ( S ^ { - 1 } ( \lambda I - T ) S ) ^ { - 1 } = S ^ { - 1 } ( \lambda I - T ) ^ { - 1 } S ,$，并将其代入式 (1) 即得所求结果。

于是，我们得到了 $L ( \lambda )$ 的预解式（resolvent）的一种表示，该表示以 $L ( \lambda )$ 的任一线性化形式的预解式为基本构件。接下来的目标是，以一种更具构造性与直接性的方式刻画 $L ( \lambda )$ 的标准三元组（standard triple）；通常而言，试图显式地求出定理 2 证明中所涉及的矩阵 $ S $ 并不现实。首先，我们将说明：如何从任意给定的标准三元组出发，“复原”出友矩阵（companion matrix）$C _ { L }$。

**引理 1.** 设 $ (X, T, Y) $ 是 $L ( \lambda )$ 的一个标准三元组，并定义  

$$
\boldsymbol { Q } = \left[ \begin{array} { c } { \boldsymbol { U } } \\ { \boldsymbol { U } \boldsymbol { T } } \\ { \vdots } \\ { \boldsymbol { U } \boldsymbol { T } ^ { l - 1 } } \end{array} \right] .\tag{5}
$$  

则 $Q$ 是非奇异的，且 $C _ { L } = Q T Q ^ { - 1 }$。

**证明.** 回顾可知，$P _ { 1 } = [ I _ { n } \quad 0 \quad \cdots \quad 0 ]$，而 $C _ { L }$ 由式 (14.1.3) 给出。容易验证  

$$
\left[ \begin{array} { c } { P _ { 1 } } \\ { P _ { 1 } C _ { L } } \\ { \vdots } \\ { P _ { 1 } C _ { L } ^ { l - 1 } } \end{array} \right] = I _ { l N } .\tag{6}
$$  

将式 (4) 中给出的 $P _ { 1 }$ 与 $C _ { L }$ 的表达式代入，即得 $Q S = I _ { l n }$。显然，$ Q $ 是非奇异的，且 $S = Q ^ { - 1 }$。特别地，$C _ { L } = Q T Q ^ { - 1 }$。 □  

事实上，该引理表明：对 $L ( \lambda )$ 的任意标准三元组 $( U , T , V ) ,$，只要取 $S = Q ^ { - 1 }$（其中 $ Q $ 由式 (5) 给出），即可由式 (4) 复原出其本原三元组（primitive triple）$( P _ { 1 } , C _ { L } , R _ { 1 } )$。

定理 3．L(λ) 的一个容许三元组 (U, T, V) 是标准三元组，当且仅当下列三个条件同时成立：

(a) 式 (5) 中定义的矩阵 Q 是非奇异的；

(b) $\begin{array} { r } { L _ { l } U T ^ { l } + L _ { l - 1 } U T ^ { l - 1 } + \cdots + L _ { 1 } U T + L _ { 0 } U = 0 . } \end{array}$  

(c) $V = Q ^ { - 1 } R _ { 1 }$，其中 Q 与 $R _ { 1 }$ 分别由式 (5) 和式 (2) 给出。
