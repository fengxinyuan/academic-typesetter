习题 1．验证：任意正矩阵均为原始矩阵。

习题 2．验证下列矩阵  

$$
A = { \left[ \begin{array} { l l l } { 0 } & { 1 } & { 0 } \\ { 1 } & { 0 } & { 1 } \\ { 0 } & { 1 } & { 0 } \end{array} \right] }
$$  

的非原始性指标等于 2。□  

若已知特征多项式，则非原始性指标可便捷地确定（参见习题 2）。设  

$$
c ( \lambda ) = \lambda ^ { n } + a _ { 1 } \lambda ^ { n _ { 1 } } + a _ { 2 } \lambda ^ { n _ { 2 } } + \cdot \cdot \cdot + a _ { t } \lambda ^ { n _ { t } }\tag{1}
$$  

为矩阵  A  $\in \mathbb { R } ^ { n \times n }$ 的特征多项式，其中  a _ { 1 } , a _ { 2 } $, \ldots , a$ _ { t }  非零，且  

$$
n > n _ { 1 } > n _ { 2 } > \cdots > n _ { t } \geq 0 .
$$

若 $ \lambda $ 是 $ A $ 的任一特征值，而 $ \omega_1, \omega_2, \dots, \omega_k $ 是 $ k $ 次单位根，则由定理 15.3.1 可知，$ \omega_1 \lambda, \omega_2 \lambda, \dots, \omega_k \lambda $ 均为 $ A $ 的特征值。因此，$ A $ 的特征多项式  
$$
\det(\lambda I - A)
$$  
可被乘积  

$$
( \lambda - \omega _ { 1 } \lambda _ { 0 } ) ( \lambda - \omega _ { 2 } \lambda _ { 0 } ) \cdots ( \lambda - \omega _ { k } \lambda _ { 0 } ) = \lambda ^ { k } - \lambda _ { 0 } ^ { k } ,
$$  

整除（即无余项）。于是，对某个多项式 $ g(\lambda) $ 及某个整数 $ s $，我们有  

$$
c ( \lambda ) = g ( \lambda ^ { k } ) \lambda ^ { s } .
$$  

将此式与式 (1) 比较，可知 $ k $ 是各差值  
$n - n _ { j } , j = 1 , 2 , . . . , t .$  
的一个公因数。设 $ l $ 为这些差值的最大公因数；则利用逆向推理可知，$ A $ 的谱在旋转变换  
$2 \pi / l .$  
下保持不变。若 $ l < k $，则 $ l \mid k $，从而 $ A $ 在 $ 2\pi/l $ 角度的旋转下不变，这与 $ k $ 作为 $ A $ 的非本原性指数（index of imprimitivity）的定义相矛盾。故必有  
$k = l$  
由此我们确立了如下事实。

**命题 1**．若 $ A $ 是不可约且非负的矩阵，且其特征多项式 $ \det(\lambda I - A) $ 按式 (1) 写成  
$c ( \lambda )$  
的形式，则 $ A $ 的非本原性指数 $ k $ 等于各差值  

$$
n - n _ { 1 } , \qquad n - n _ { 2 } , \ldots , n - n _ { t } .
$$  

的最大公因数。

例如，若  

$$
c ( \lambda ) = \lambda ^ { 1 0 } + a _ { 1 } \lambda ^ { 7 } + a _ { 2 } \lambda , \qquad a _ { 1 } , a _ { 2 } \ne 0 ,
$$  

则 $ k = 3 $。然而，若  

$$
c ( \lambda ) = \lambda ^ { 1 0 } + a _ { 1 } \lambda ^ { 7 } + a _ { 2 } \lambda + a _ { 3 } , \qquad a _ { 1 } , a _ { 2 } , a _ { 3 } \ne 0 ,
$$  

则 $ k = 1 $。

$\lambda _ { 0 } \omega _ { 1 } , \ldots , \omega _ { k } \omega _ { j } \lambda _ { 0 } , j = 1 , 2 , \ldots , k _ { : } k < l , 2 \pi / l < 2 \pi / k 2 \pi / l A \in \mathbb { R } ^ { n \times n } k = 3 .$
