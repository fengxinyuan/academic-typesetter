定理 1（连同定理 7.5.1 及其推论）表明：矩阵 $L ( \lambda )$ 与 $\lambda I - C _ { L }$ 的所有非平凡不变因子（从而亦即所有初等因子）完全相同。此处，“非平凡”意指不恒等于 1 的多项式。

习题 1．建立关系式 (4) 和 (5)。

习题 2．证明：若 λ 是 $C _ { L }$ 的一个特征值，则 $\mathsf { K e r } ( \lambda I - C _ { L } )$ 的维数不超过 n。（注意特例 $n = 1 . )$）

习题 3．写出第一个友矩阵，并求出下列矩阵的全部初等因子：(a) $L ( \lambda ) = \lambda ^ { l } I _ { n }$；(b) $L ( \lambda ) = \lambda ^ { l } I _ { n } - I _ { n }$ □

现在注意到，除 $C _ { L }$ 外，还存在其他矩阵 A，使得 $\lambda I - A$ 与 $\mathrm { d i a g } [ L ( \lambda ) , I _ { ( l - 1 ) n } ]$ 等价。特别地，若 A 是与 $C _ { L } .$ 相似的矩阵，即存在可逆矩阵 P 使得 $A = \dot { T } \dot { C _ { L } } T ^ { - 1 }$，则有 $\lambda I - A = T ( \lambda I - C _ { L } ) T ^ { - 1 }$，从而 $\lambda I - A$ 与 $\lambda I - C _ { L }$ 等价；再由等价关系的传递性可知，$\lambda I - A$ 与 diag[$L ( \lambda ) , I _ { ( l - 1 ) n } ]$] 等价。为此，我们给出如下形式化定义：若 $L ( \lambda )$ 是一个 l 次的 $n \times n$ 矩阵多项式，且其首项系数为非奇异矩阵，则任何满足 $\lambda I - A$ 与 diag[L(λ), $I _ { ( \ell - 1 ) n } ]$] 等价的 ln × ln 矩阵 A，均称为 $L ( \lambda )$ 的一个线性化（linearization）。

下一个定理表明：所有与 $C _ { L }$ 相似的矩阵 A，恰好构成了 $L ( \lambda )$ 的全部线性化。

**定理 2.** 矩阵 A 是 $L ( \lambda )$ 的一个线性化，当且仅当 A 与 L(λ) 的友矩阵 $C _ { L }$ 相似。

**证明.** 前已证得：若 A 与 $C _ { L }$ 相似，则 A 是 $L ( \lambda )$ 的一个线性化。反之，若 A 是 $L ( \lambda )$ 的一个线性化，则 $\lambda I - A \sim L ( \lambda ) \dot { + }$ \~ $I _ { ( l - 1 ) n }$（此处用符号 \~ 表示“等价于”）。但由定理 $\dot { 1 , } L ( \lambda ) \dot { + } I _ { ( l - 1 ) n } \sim \lambda I - C _ { L }$ 可知，$\lambda I - A \sim \lambda I - C _ { L }$；再次利用等价关系的传递性，即得 $\lambda I - A \sim \lambda I - C _ { L }$。于是，由定理 7.6.1 可知，A 与 $C _ { L }$ 相似。

该结果，结合定理 6.5.1（或 7.8.2），表明存在一个 Jordan 标准形矩阵，它是  L  $( \lambda$ )的线性化，因而完整包含了关于 $L ( \lambda$ )  的特征值（即“隐根”，latent roots）及其代数重数的全部信息（亦即，包含在第 6.6 节所定义的 Segre 特征中的全部信息）。
