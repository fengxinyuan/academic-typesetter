习题 3．验证：矩阵 $ A $ 是正规矩阵，当且仅当它的实部 $ \operatorname{Re} A = $( { $\mathcal { R } } A$ )与虚部 $ \operatorname{Im} A = $( $\mathcal { P } { M } A$ )  可交换。

习题 4．证明：若 $ A $ 是正规矩阵且 $\lambda \in \sigma ( A$ )，则 $\lambda = \lambda$ _ { 1 } $+ i \lambda$ _ { 2 } ，其中 $\lambda$ _ { 1 } $\in \sigma ( \mathscr { R e } A$ )且 $\lambda$ _ { 2 } $\in \sigma ( { \mathcal { A } }$ _ { { $\mathcal { M } } } ~ A ) . ~ \varbigcup  $。

考虑一个 $ n $ 阶埃尔米特矩阵 $ H $。由于 $ H $ 的所有特征值均为实数，故可将其排序为： $\lambda$ _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n } 。在所有特征值同号的情形中，尤以全为正或全为负者最为重要。若埃尔米特矩阵 $ A $ 的所有特征值均为正（ respectively，均为负），则称 $ A $ 为正定（ respectively，负定）矩阵。显然，任一确定符号的矩阵（即正定或负定矩阵）必为非奇异矩阵（参见习题 4.10.3）。我们还需引入若干更精细的分类：若埃尔米特矩阵的所有特征值均非负（ respectively，均非正），则称其为半正定（ respectively，半负定）矩阵，或称其为非负定（ respectively，非正定）矩阵。此处“半定矩阵”即指上述两类之一。我们分别用记号  H > 0  与 $H \geq 0$ 表示正定矩阵与半正定矩阵。类似地，记号  H < 0  与 $H \leq 0  $ 分别用于表示负定矩阵与半负定矩阵。

如下结论极为重要，且常被用于定义定矩阵。该结论的一大优势在于，其表述完全不依赖于矩阵 $ A $ 的谱（即特征值集合）的相关概念。

定理 3．设 $ H $ 是一个埃尔米特矩阵，则 $ H $ 是半正定的当且仅当 $ \mathbf{x}^* H \mathbf{x} \ge 0 $ 对所有非零向量 $ \mathbf{x} \in \mathbb{C}^n $ 成立。

证明．该条件的必要性将在推论 5.4.1 中给出。

设对所有 $ \mathbf{x} \in \mathbb{C}^n $，均有 $ \mathbf{x}^* H \mathbf{x} \ge 0 $，并设 $ H $ 关于特征值 $ \lambda_1, \lambda_2, \dots, \lambda_n $ 的特征向量 $ \mathbf{u}_1, \mathbf{u}_2, \dots, \mathbf{u}_n $ 构成 $ \mathbb{C}^n $ 中的一组标准正交基。由于

$$
0 \leq ( H \pmb { u } _ { i } , \pmb { u } _ { i } ) = \lambda _ { i } ( \pmb { u } _ { i } , \pmb { u } _ { i } ) = \lambda _ { i }
$$

对所有 $ \mathbf{x} \in \mathbb{C}^n $ 成立，故矩阵 $ H $ 是半正定的。

正定情形可类似证明。■

注意：与定理 3 类似的结果对负定矩阵及半负定矩阵亦成立。
