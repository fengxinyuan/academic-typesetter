习题 6．设  A  $\in \mathbb { C } ^ { n \times n }$ ，并设  f _ { 0 } , f _ { 1 } $, \ldots$ 是 $\mathbb { C } ^ { n }  $ 中给定的一个向量序列。试证：差分方程  

$$
{ \pmb x } _ { r + 1 } = A { \pmb x } _ { r } + { \pmb f } _ { r } , \qquad r = 0 , 1 , 2 , \ldots ,
$$  

的任意解……

可表示为形式 $\mathbf { \delta x } _ { 0 } = \mathbf { \delta z }$，且对 $j = 1 , 2 , \dots$  

$$
{ \bf x } _ { j + 1 } = A ^ { j } z + \sum _ { k = 0 } ^ { j - 1 } A ^ { j - k - 1 } f _ { k } ,
$$  

对某个 $\pmb { z } \in \mathbb { C } ^ { n } . \quad \square$ 成立。

## 9.11 可观与可控系统

本节将整合本书本章及此前各章所建立的若干重要结果。这使我们得以呈现系统与控制理论中一些有趣的思想与结论。

设 $A \in \mathbb { C } ^ { n \times n }$ 与 $C \in \mathbb { C } ^ { r \times n }$，并考虑如下方程组：  

$$
\begin{array} { r l } { \dot { \mathbf { x } } ( t ) = A \mathbf { x } ( t ) , \quad } & { { } \mathbf { x } ( 0 ) = \mathbf { x } _ { 0 } , } \\ { \mathbf { y } ( t ) = C \mathbf { x } ( t ) . } \end{array}\tag{1}
$$  

于是，$\mathbf { \boldsymbol { x } } ( t )$ 取值于 $\mathbb { C } ^ { n }$，由初值问题（假设 $\mathbf { x } _ { 0 } \in \mathbb { C } ^ { n }$ 给定）所确定，称为状态向量。进而，对每个 $t \geq 0$，$\mathbf { y } ( t ) \in \mathbb { C } ^ { r }$ 成立，称为观测向量或输出向量。它表示系统状态经矩阵 C “滤波”后所能记录的信息。若仅当 $\mathbf { \boldsymbol { x } } _ { 0 } = \mathbf { \boldsymbol { \theta } }$ 时才有 $\boldsymbol { y } ( t ) \equiv \boldsymbol { \theta }$，则称系统 (1) 是可观的。换言之，为使系统可观，所有非零初始向量都必须导出一个可观测的解——即其输出向量不恒等于零。

与第 5.13 节中引入的可观测对（observable pairs）之间的联系，由第一个定理予以确立。为方便起见，记  

$$
Q = Q ( C , A ) = \left[ \begin{array} { c } { { C } } \\ { { C A } } \\ { { \vdots } } \\ { { C A ^ { n - 1 } } } \end{array} \right] ,
$$  

为一个大小为 $n r \times n .$ 的矩阵。
