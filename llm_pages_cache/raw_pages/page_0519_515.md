**证明.** 首先注意到，齐次方程 (2) 的通解 $\mathbf { x } ^ { ( 0 ) } = \bigl ( \mathbf { x } _ { 0 } ^ { ( 0 ) } , \mathbf { x } _ { 1 } ^ { ( 0 ) } , \ldots \bigr )$ 可表为  

$$
\mathfrak { x } _ { j } ^ { ( 0 ) } = { P } _ { 1 } C _ { L } ^ { j } z , \qquad j = 0 , 1 , 2 , \dotsc ,\tag{6}
$$  

其中 $z \in \mathbb { C } ^ { l n }$ 为任意矩阵。该表达式可通过直接代入验证；再结合定理 7.10.2，即可证得式 (6) 给出了方程 (2) 的全部解。

因此，只需证明序列 $( \pmb { \theta } , \pmb { x } _ { 1 } ^ { ( 1 ) } , \pmb { x } _ { 2 } ^ { ( 1 ) } , \dots )$（其中  

$$
\pmb { x } _ { j } ^ { ( 1 ) } = P _ { 1 } \sum _ { k = 0 } ^ { j - 1 } C _ { L } ^ { j - k - 1 } R _ { 1 } \pmb { f } _ { k } , \qquad j = 1 , 2 , \ldots ,
$$  

）是方程 (1) 的一个特解。此结论留作习题。我们仅指出：该证明特别依赖于将定理 14.2.3 与习题 14.2.6 应用于友三元组 $( P _ { 1 } , C _ { L } , R _ { 1 } )$。  

利用 L(λ) 的标准三元组之间的相似性以及引理 1 的断言，我们可立即得到定理 14.5.1 的如下类比结果。  

**定理 3.** 若 (U, T, V) 是 L(λ) 的一个标准三元组，则方程 (2) 的任一解均具有形式 $\begin{array} { r } { { \bf x } _ { 0 } = U { \bf z } , } \end{array}$；且对 $j = 1 , 2 , \ldots$，有  

$$
\pmb { x } _ { j } = U T ^ { j } \pmb { z } + U \sum _ { k = 0 } ^ { j - 1 } T ^ { j - k - 1 } V \pmb { f } _ { k } ,
$$  

其中 $\pmb { z } \in \mathbb { C } ^ { t n } ,$。  

本节最后给出差分方程组初值问题的一个显式解法（参见定理 14.5.2）。  

**定理 4.** 设 $( U , T , V )$ 是 L(λ) 的一个标准三元组。则对任意给定向量 $\mathbf { \Delta } _ { a _ { 0 } } , \mathbf { \Delta } _ { a _ { 1 } } , \dots , \mathbf { \Delta } _ { a _ { l - 1 } } \in \mathbb { C } ^ { n }$，方程 (1) 满足初始条件  

$$
\begin{array} { r } { \pmb { x } _ { j } = \pmb { a } _ { j } , \qquad j = 0 , 1 , \ldots , l - 1 , } \end{array}\tag{7}
$$  

的解存在且唯一。该解由定理 3 的结果及适当的选取所明确给出。

$$
\boldsymbol { z } = [ V \quad T V \quad \cdots \quad T ^ { l - 1 } V ] \boldsymbol { S } _ { L } \left[ \begin{array} { c } { \mathbf { 0 } _ { 0 } } \\ { \mathbf { 4 } _ { 1 } } \\ { \vdots } \\ { \mathbf { 4 } _ { l - 1 } } \end{array} \right] ,
$$  

其中，$S _ { L }$ 是算子 $ L(\lambda) $ 的对称化子（symmetrizer）。

该结论的证明与定理 14.5.2 的证明类似。
