**习题 1.** 证明：矩阵 $ A $ 的广义逆唯一当且仅当 $A = 0$，或 $ A $ 为方阵且非奇异。

以下关于广义逆的性质可直接由定义关系式 (1) 和 (2) 推出。

**命题 2.** 若 $A \in { \mathcal { F } } ^ { m \times n }$，且 $A ^ { \boldsymbol { \mathsf { I } } }$ 是其一个广义逆，则  

(a) $A ^ { 1 } A$ 与 $A A ^ { \boldsymbol { \mathsf { I } } }$ 均为幂等矩阵；  

(b) $ \operatorname{rank} A^\dagger = \operatorname{rank} A $。

（c）矩阵 $( A ^ { 1 } ) ^ { * }$ 是 $A ^ { * } .$ 的一个广义逆。

**证明**：（a）与（c）两部分可直接由定义性质（1）和（2）应用于 $A ^ { 1 } .$ 而得；（b）部分则通过对同一组关系应用习题 3.8.5 的结论而得。■

若 $A \in { \mathcal { F } } ^ { \mathfrak { n } \times n }$ 是非奇异矩阵，则 $A ^ { - 1 }$ 亦为非奇异矩阵，且显然有  

$$
\mathbf { I m } ~ A \ + ~ \mathbf { K e r } ~ A ^ { - 1 } = { \mathcal { F } } ^ { n } + \{ \pmb { \theta } \} = { \mathcal { F } } ^ { n } ,
$$
 $\operatorname { K e r } A + \operatorname { I m } A ^ { - 1 } = \{ \pmb { \theta } \} + \mathcal { F } ^ { n } = \mathcal { F } ^ { n } .$ 
$$  

下一个结果将上述结论推广至任意矩阵 $ A $ 及其广义逆。

**命题 3**．若 $A \in \mathcal { F } ^ { m \times n }$，且 $A ^ { \parallel }$ 表示 $ A $ 的一个广义逆，则  

$$
 $\operatorname { I m } A + \operatorname { K e r } A ^ { \operatorname { I } } = { \mathcal { F } } ^ { m }\tag{5}$ 
$$

\operatorname { K e r } A + \operatorname { I m } A ^ { \mathbf { I } } = { \mathcal { F } } ^ { n } .\tag{6}
$$  

**证明**．由命题 $2 ( \mathsf { a } )$ 已知，$A A ^ { \boldsymbol { \mathsf { I } } }$ 是一个投影矩阵；且显然有 $ \operatorname{Im} \, \text{$( A A ^ { $\mathsf { I } } ) \subset \operatorname { I m } A } $。我们进一步证明：实际上，$A A ^ { \boldsymbol { \mathsf { I } } }$ 将向量空间投影到 $ \operatorname{Im} A $ 上。若 $ y \in \operatorname{Im} A $，则存在 $ x $ 使得 $ y = A x $；由于  A = A A ^ { 1 } A , \ y = ( A A ^ { 1 } $) ( A x ) \in \operatorname { I m } ( A A ^ { 1 }$ )，故 $\mathbf { y } = A \mathbf { x } \in \operatorname { I m } A$ 。因此 $ \operatorname{Im} A \subseteq \operatorname{Im} \, \text{$A  $\subset \operatorname { I m } ( A A ^ { \operatorname { I } }$ )$} $，从而 $\operatorname { I m } ( A A ^ { \mathrm { I } } ) = \operatorname { I m } A  $。

由此，并结合命题 2(b)，可推出  

$$
\operatorname { r a n k } A = \operatorname { r a n k } ( A A ^ { \mathrm { I } } ) = \operatorname { r a n k } A ^ { \mathrm { I } } ,
$$  

进而得到 $\operatorname{Ker} $A ^ { $\boldsymbol { \mathsf { I } } } = \mathbf { K e r } ( A A ^ { \boldsymbol { \mathsf { I } } }$ )$$。对于 $\operatorname{Ker} $A ^ { \mathsf { I } } \subset \mathsf { K e r } ( A A ^ { \iota } )$$，显然成立。此外，由定理 4.5.5 还有  

$$
\dim ( \operatorname { K e r } A ^ { \operatorname { I } } ) = m - \operatorname { r a n k } A ^ { \operatorname { I } } = m - \operatorname { r a n k } ( A A ^ { \operatorname { I } } ) = \dim \operatorname { K e r } ( A A ^ { \operatorname { I } } ) .
$$  

因此，$\operatorname{Ker} $A ^ { $\boldsymbol { \mathsf { I } } } = \mathbf { K e r } ( A A ^ { \boldsymbol { \mathsf { I } } }$ )$$。
