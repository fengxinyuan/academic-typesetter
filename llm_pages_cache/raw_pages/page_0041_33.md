定理 1（代数余子式展开式，Cofactor expansion）．设 $ A $ 为任意一个 $n \times n$ 矩阵。则对任意 $\begin{array} { r l } { i , j } & { { } ( 1 \leq i , j \leq n ) } \end{array}$，

$$
 $\operatorname* { d e t } A = a$ _ { i 1 } A _ { i 1 } + a _ { i 2 } A _ { i 2 } $+ \cdot \cdot \cdot + a$ _ { i n } A _ { i n } $\tag{1}$ 
$$

$o r ,$；类似地，

$$
 $\operatorname* { d e t } A = a$ _ { 1 j } A _ { 1 j } + a _ { 2 j } A _ { 2 j } $+ \cdot \cdot \cdot + a$ _ { n j } A _ { n j } $,\tag{2}$ 
$$

其中 $A _ { p q } = ( - 1 ) ^ { p + q } M _ { p q }$。
$$


在深入展开证明的细节之前，请注意：数值 $\begin{array} { r l } { A _ { p q } } & { { } ( 1 \leq p , q \leq n ) } \end{array}$ 被称为元素 $a _ { p q }$ 的代数余子式，因此公式（1）与（2）分别被称为行列式 det A 按第 i 行与按第 j 列的代数余子式展开式。于是，代数余子式 $A _ { p q }$ 恰为子式 $M _ { p q }$ 乘以 +1 或 −1，其符号由下标之和 i + j 的奇偶性决定：若 i + j 为偶数，则取正号；若为奇数，则取负号。

**证明**．证明始于如下观察：det A 的表达式（2.1.8）中的每一项均包含第 i 行的一个元素。因此，将所有含元素 $a _ { i j } ( j = 1 , 2 , \ldots , n )$ 的项归并起来，我们得到  

$$
\operatorname* { d e t } A = a _ { i 1 } \widetilde A _ { i 1 } + a _ { i 2 } \widetilde A _ { i 2 } + \cdot \cdot \cdot + a _ { i n } \widetilde A _ { i n } \qquad ( 1 \leq i \leq n ) .\tag{3}
$$  

故为证公式（1），只需证明对所有 $i , j .$，均有  

$$
\tilde { A _ { i j } } = A _ { i j }\tag{4}
$$  

首先考虑情形 $i = j = 1$；我们来证明 $\tilde { A } _ { 1 1 } = A _ { 1 1 }$。事实上，由（2.1.8）式及（3）式中对 $\tilde { A } _ { 1 1 }$ 的构造可知，  

$$
\widetilde { A } _ { 1 1 } = \sum _ { j } ( - 1 ) ^ { t ( j ) } a _ { 2 j _ { 2 } } a _ { 3 j _ { 3 } } \cdot \cdot \cdot a _ { n j _ { n } } ,\tag{5}
$$  

其中 $t ( j )$ 表示排列 $( 1 , j _ { 2 } , j _ { 3 } , . . . . j _ { n } )$ 的逆序数，等价地，也表示排列 $( j _ { 2 } , j _ { 3 } , \ldots , j _ { n } )$ 关于数集 $2 , 3 , \ldots , n .$ 的逆序数。

利用行列式定义，对矩阵 $ A $ 删除第一行与第一列后所得的 $( n - 1 ) \times ( n - 1 )$ 阶矩阵计算其行列式，可立即得出：式 (5) 中的表达式即为此行列式，亦即 $M _ { 1 1 }$。因此，$\tilde { A } _ { 1 1 } = M _ { 1 1 } = ( - 1 ) ^ { 1 + 1 } M _ { 1 1 } = A _ { 1 1 }$。
