为证 $ \text{$H < O$} $，计算  

$$
\text{$$
x ^ { * } $H x = - \int$ _ { 0 } ^ { $\infty } ( x ^ { * } e ^ { A t } ) W ( x ^ { * } e ^ { A t } ) ^ { * } \ d t ,\tag{4}$ 
$$}
$$  

并注意到：$ W $ 的正定性，以及对所有 $ t $，$ \text{$e ^ { A t }$} $ 的非奇异性，保证了方程 (4) 中被积函数的正定性。因此，对所有非零向量 $ \text{$\pmb { x } $\in \mathbb { C } ^ { n } } $，均有 $ \text{$x ^ { * } H x < 0$} $，从而 $ \text{$H  $< \theta } $。  

(b) 反之，设 $ \lambda $ 是 $ \text{$A ^ { * } ,$} $ 的一个特征值，其中 $ \text{$A ^ { * } $x = \lambda { \bf { x } } } $，且 $ \text{$\pmb { x } $\neq \pmb { \theta } } $。于是亦有 $ \text{${ $\pmb x } ^ { * } { \pmb A } = \bar { \lambda } { \pmb x } ^ { * } } $。将方程 (3) 左乘 $ \text{$\pmb { x } ^ { * }$} $、右乘 $ x $，得  

$$
\text{$$
 $( \bar { \lambda } + \lambda ) { \pmb x } ^ { * } H { \pmb x } = { \pmb x } ^ { * } W { \pmb x } .\tag{5}$ 
$$}
$$  

由我们的假设可知 $ \text{$x ^ { * } H x < 0$} $，且亦有 $ \text{${ $\pmb x } ^ { * } W { \pmb x } > 0 , } $，故得 $ \text{$\bar { $\lambda } + \lambda < 0 , } $，即 $ \text{$\mathcal { R } $\mathscr { \lambda } < 0 } $。由于该结论对每个特征值 $ \lambda $ 均成立，因此 $ A $ 是稳定的。

注意，事实上，我们已证明了一个比该定理第 (b) 部分略强的结论：若 $ H $ 是负定矩阵且满足李雅普诺夫方程 $A H + H A ^ { * } = W$，则只要对 $ A^* $ 的每个特征值所对应的**某一个**特征向量 $ x $，均有 ${ \pmb x } ^ { * } { \pmb W } { \pmb x } < 0$ 成立，即可推出 $ A $ 的稳定性。因此，若 $ A $ 具有 $A ^ { * }$ 重特征值，则 $ W $ 并不必在整个空间 $\mathbb { C } ^ { n } .$ 上定号。

**习题 1.** 验证：若 $a > 0$，则矩阵  

$$
A = { \binom { 7 0 \ - 1 } { 1 } }
$$  

的两个特征值均具有正实部。进一步证明矩阵  

$$
H = \left[ \begin{array} { c c } { { 4 + a ^ { 2 } } } & { { - 2 a } } \\ { { - 2 a } } & { { 4 + a ^ { 2 } } } \end{array} \right]
$$  

是正定矩阵，且 $A H + H A ^ { \boldsymbol { \mathsf { T } } }$ 也是正定矩阵。

**习题 2.** 验证：对任意斜埃尔米特矩阵 $ S $，形如  

$$
A = P ( S - Q ) ,
$$  

的矩阵（其中 $ P $ 与 $ Q $ 均为正定矩阵）是稳定的。

$$
