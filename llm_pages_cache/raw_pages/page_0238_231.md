习题 5．验证：$T$ 的任一 Jordan 子空间都是 $T$-不变的。

习题 6．证明：$T$ 的任一 Jordan 子空间中仅包含唯一一个（在相差一个非零标量倍意义下）线性无关的特征向量。

$$
{ \mathcal { J } } = \operatorname { s p a n } \{ x _ { 1 } , x _ { 2 } , . ~ . ~ . , x _ { r } \} ,\tag{4}
$$



解．设该若尔当子空间由链  
$\mathbf { x } _ { 1 } , \cdots , x _ { r }$  
生成，且对应的特征值为 λ。若 $\begin{array} { r } { \pmb { x } = \sum _ { i = 1 } ^ { r } \pmb { \alpha _ { i } } \pmb { x _ { i } } } \end{array}$ 是算子 T 关于 $\lambda _ { 0 }$ 的一个特征向量，则利用式 (2)，我们有（其中 $x _ { 0 } = \theta )$）  

$$
\lambda _ { 0 } \sum _ { i = 1 } ^ { r } \alpha _ { i } \mathbf { x } _ { i } = T { \Biggr ( } \sum _ { i = 1 } ^ { r } \alpha _ { i } \mathbf { x } _ { i } { \Biggr ) } = \sum _ { i = 1 } ^ { r } \alpha _ { i } ( \lambda x _ { i } + \mathbf { x } _ { i - 1 } ) .
$$  

因此，比较系数（参见习题 4），可得  

$$
\begin{array} { r l } & { \lambda _ { 0 } \alpha _ { i } = \lambda \alpha _ { i } + \alpha _ { i + 1 } , \qquad 1 \leq i \leq r - 1 , } \\ & { \lambda _ { 0 } \alpha _ { r } = \lambda \alpha _ { r } , } \end{array}
$$  

从而 $\lambda = \lambda _ { 0 }$ 且 $\alpha _ { 2 } = \alpha _ { 3 } = \cdot \cdot \cdot = \alpha _ { r } = 0$。故 $\pmb { x } = \pmb { \alpha } _ { 1 } \pmb { x } _ { 1 }$，其中 $\mathfrak { x } _ { 1 } \neq 0 ,$，符合要求。□  

设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，且子空间 $\mathcal { S } _ { \mathfrak { d } } \subset \mathcal { S }$ 是 T-不变的。若 $\pmb { x } \in \mathcal { S } _ { \pmb { 0 } }$，且在 $\mathcal { S } _ { \mathfrak { d } }$ 中存在形如  

$$
\{ x , T ( x ) , \ldots , T ^ { k - 1 } ( x ) \} , \qquad k = \dim \mathcal { S } _ { 0 } ,
$$  

的一组基，则称 $\mathcal { S } _ { 0 }$ 为 $\mathcal { S }$ 的一个循环子空间（关于 $T$ 或关于 $T | _ { \mathcal { S } _ { \mathfrak { o } } } )$）。  

命题 1．任一若尔当子空间均为循环子空间。

**证明**．设  x _ { 1 } , x _ { 2 } $, \ldots , x$ _ { r }  是一个若尔当链，并注意到式 (3) 蕴含  

$$

\begin{array} { r } { \begin{array} { c } { x _ { r - 1 } = ( T - \lambda I ) x _ { r } , } \\ { \vdots } \\ { x _ { 2 } = ( T - \lambda I ) ^ { r - 2 } x _ { r } , } \\ { x _ { 1 } = ( T - \lambda I ) ^ { r - 1 } x _ { r } . } \end{array} } \end{array}\tag{5}
$$
  

利用二项式定理可知，由  x _ { 1 } , x _ { 2 } $, \ldots , x$ _ { r }  生成的若尔当子空间亦可由  x _ { r } , T x _ { r } $, \ldots , T ^ { r ^ { - 1 } } x$ _ { r }  生成。由于该若尔当子空间关于线性算子 $ T $ 是不变的（见习题 5），且  x _ { r }  属于该子空间，因此该子空间关于  T .  是循环的。
