**习题 1** 证明：单位酉空间中的任一正交集必线性无关。□

若一个正交系中每个元素均为单位向量，则称其为**标准正交系**（或**规范正交系**）。显然，在配备标准内积的 $ \mathbb{C}^n $（或 $ \mathbb{R}^n $）中，全体单位向量所成集合的任意子集，即为标准正交系的典型例子。

考虑习题 1 的逆命题是否成立。给定一个酉空间中的线性无关集 $\{ \pmb { x } _ { 1 } , \pmb { x } _ { 2 } , \ldots , \pmb { x } _ { r } \}$，我们能否在该集合张成的子空间 span $\{ \pmb { x } _ { 1 } , \ldots , \pmb { x } _ { r } \} ?$ 中构造出一个正交集？答案是肯定的；一旦获得这样一个正交集，只需将其中每个元素单位化，即可得到一个标准正交集。完成这一过程的一种方法称为格拉姆–施密特正交化过程（Gram–Schmidt orthogonalization process），我们下面予以阐述。

设 $\{ \pmb { x } _ { 1 } , \ldots , \pmb { x } _ { r } \}$ 是酉空间 ${ \pmb u } .$ 中的一个线性无关集。我们将构造一个正交集 $\left\{ y _ { 1 } , y _ { 2 } , \ldots , y _ { r } \right\}$，使其具有如下性质：对每个 $k = 1 , 2 , \ldots , r ,$，

$$
\operatorname { s p a n } \{ y _ { 1 } , \dots , y _ { k } \} = \operatorname { s p a n } \{ x _ { 1 } , \dots , x _ { k } \} .\tag{1}
$$

首先令 ${ \bf y } _ { 1 } = { \bf x } _ { 1 }$，并寻求一个元素 ${ \bf y } _ { 2 } \in \tt s p a n \{ { \bf x } _ { 1 } , { \bf x } _ { 2 } \}$，使之与 ${ \bf y } _ { 1 }$ 正交。记 ${ \pmb y } _ { 2 } = \alpha _ { 1 } { \pmb y } _ { 1 } + { \pmb x } _ { 2 }$，并确定 $\alpha _ { 1 }$，使得 $( { \bf y } _ { 1 } , { \bf y } _ { 2 } ) = 0$ 成立。容易看出，$\alpha _ { 1 } = { \bf \alpha } - ( y _ { 1 } , x _ { 2 } ) / ( y _ { 1 } , y _ { 1 } )$。注意，$\mathbf { x } _ { 1 }$ 与 $\mathbf { x } _ { 2 }$ 的线性无关性保证了 $y _ { 2 } \neq \pmb { \vartheta } .$。若 $r = 2 .$，则该过程即告完成；更一般地，可通过归纳法证明该结论，如下一习题所示。

显然，我们刚刚描述的这一过程可用于构造一个酉空间的标准正交向量基，即标准正交基。事实上，我们有如下重要结论：

定理 1．每一个有限维酉空间都存在一个标准正交基。

证明．从空间  { $\pmb q } ,$ 的任意一组基出发，通过格拉姆–施密特（Gram–Schmidt）正交化过程，可得到一个含 $ n $ 个元素的正交集，其中 $n = \dim \mathcal { U }$ 。再对该正交集进行单位化，并结合习题 1 与习题 3.5.4，即可构造出 $\pmb { \mathcal U }  $ 的一个标准正交基。

与其他基相比，标准正交基具有显著优势：空间中任一元素的坐标表示易于获得，任意两个元素的内积亦可直接计算。接下来的习题将给出具体细节。
