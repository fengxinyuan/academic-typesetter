现设 $A = D + C$，其中 $D = \mathrm { d i a g } [ a _ { 1 1 } , \dotsc , a _ { n n } ]$，且令 $B ( t ) = D + t C$。则有 $B ( 0 ) = D$ 且 $B ( 1 ) = A$。我们考察矩阵 B(t) 的特征值随参数 t 在区间 [0, 1] 上变化时的行为，并利用特征值关于 t 的连续性。因此，对区间内任意 t，矩阵 $B ( t )$ 的特征值均位于以 $a _ { j j }$ 为圆心、以 $t \rho _ { j } , j = 1 , 2 , \ldots , n ,$ 为半径的圆盘内。

现在假设  A = B ( 1 )  的第 $ j $ 个圆盘与其余  n - 1  个圆盘无公共点。那么显然，对任意 $ t \in [0, 1] $，矩阵 $ B(t) $ 的第 $ j $ 个圆盘也始终与其他圆盘相互隔离。当  t = 0 ,  时， B ( 0 )  的特征值为  a _ { 1 1 } $, \ldots , a$ _ { n n } ；其中，仅有  a _ { j j }  位于第 $ j $ 个（退化的）圆盘内。由于  B ( t )  的特征值是  t ,  的连续函数，且第 $ j $ 个圆盘始终与其他圆盘隔离，因此可知：对所有 $t \in [ 0 , 1$ ]， B ( t )  恰有一个且仅有一个特征值位于第 $ j $ 个圆盘中。特别地，这一结论在  t = 1  与  B ( 1 ) = A  时亦成立。

这就证明了该定理第二部分对  m = 1  成立。对于任意 $m \leq n  $，定理的完整证明留作习题。

注意：若将本定理应用于  A ^ { $\boldsymbol { \mathsf { T } } } ,$ ，则可得到一个类似结论——此时以矩阵 $ A $ 的列和（而非行和）来定义新圆盘的半径。式 (1) 中的 $ n $ 个圆盘通常称为**盖尔沙林圆盘（Geršgorin disks）**。

**习题 2.** 若  A  $\in \mathbb { C } ^ { n \times n }$ ，证明：$ A $ 的所有特征值均落在圆盘 $\left\{ z \in \mathbb { C } { : } | z | \leq \operatorname* { m i n } ( \rho , \nu ) \right\}  $ 内，其中

$$
\rho = \operatorname* { m a x } _ { 1 \leq j \leq n } \sum _ { k = 1 } ^ { n } | a _ { j k } | , \qquad \nu = \operatorname* { m a x } _ { 1 \leq k \leq n } \sum _ { j = 1 } ^ { n } | a _ { j k } | .\tag{2}
$$  

**解**．对矩阵  A  $\left( 1 \leq i \leq n \right$ )的任意一个特征值 $\lambda$ _ { i } ，  

$$
| \lambda _ { i } | - | a _ { j j } | \leq | \lambda - a _ { j j } | \leq \rho _ { j } .
$$  

因此，  

$$
| \lambda _ { i } | \leq \rho _ { j } + | a _ { j j } | = \sum _ { k = 1 } ^ { n } | a _ { j k } | \leq \rho .
$$
