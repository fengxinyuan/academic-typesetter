下一习题提示了求解方程 (2) 的第二种途径，其基本观察是：$ \operatorname{Im} X $ 是 $ A $-不变子空间。

**习题 1.** 证明：方程  A X = X B  存在秩为 $ r $ 的解 $ X $，当且仅当 $ A $ 与 $ B $ 恰好有 $ r $ 个公共特征值，且这些特征值在 $ A $ 与 $ B $ 中对应的偏重数（partial multiplicities）相等。

解法概要：首先注意到 $\operatorname{Im} X$ 是 $A$-不变子空间。然后利用习题 6.5.3，证明 $X$ 具有分解式  
$X = E X _ { 0 }$，  
其中 $E$ 是 $m \times r$ 矩阵，$\times \ r , \ X _ { 0 }$ 是 $r \times r$ 矩阵，$r \times n ,$ 是 $r \times n$ 矩阵，二者均具有满秩，且 $E$ 的列由 $A$ 的若尔当链构成。于是有  
$A E = E J$，  
其中 $J$ 是一个 $r \times r$ 矩阵，且为若尔当标准形。进而证明  
$X _ { 0 } B = J X _ { 0 }$，  
并由此得出：$J$ 的特征值（及其偏重数）同时为 $A$ 与 $B$ 所共有。

反之，取满秩矩阵 $E$ 与 $X _ { 0 }$，使得  

$$
A E = E J , \qquad X _ { 0 } B = J X _ { 0 } ,
$$  

并验证 $X = E X _ { 0 }$ 满足  
$A X = X B . \quad \sqcup$。

接下来考虑一般方程  

$$
A X + X B = C ,\tag{5}
$$，  

其中 $A \in \mathbb { C } ^ { m \times m } , B \in \mathbb { C } ^ { n \times n } , X , C \in \mathbb { C } ^ { m \times n }$。将该方程重写为含 $mn$ 个线性（标量）方程的方程组后，易见：方程 (2)（同样重写为此类方程组形式）即为其对应的齐次方程。因此，可将第 3.10 节的结果与前述讨论相结合。

**定理 2**．若方程 (5) 可解，则它或者具有唯一解（当 $\sigma ( A ) \cap \sigma ( - B ) = \emptyset )$ 时），或者具有无穷多解，其通解由下式给出：  

$$
X = X _ { 0 } + \tilde { X } ,
$$，  

其中 $X _ { 0 }$ 是方程 (5) 的一个特解，而 ${ \tilde { X } } ,$ 是齐次方程 (2) 的通解，且具有形式 (3)。

因此，为完成对方程 (5) 的完整分析，尚需建立一个以矩阵 $A$、$B$ 与 $C$ 表达的可解性判据。该判据由 W. E. Roth† 给出；此处所采用的证明则出自 H. Flanders 与 H. K. Wimmer。

定理 3．方程 (5) 有解当且仅当如下两个矩阵  

$$
{ \begin{array} { r l } { \left[ A \quad \quad 0 \right] \quad } & { { \mathrm { } a n d } \quad } \\ { \left[ 0 \quad - B \right] \quad } & { { \mathrm { } a n d } \quad } \end{array} } \quad { \begin{array} { r l } { \left[ A \quad c \right] } \\ { \left[ 0 \quad - B \right] } \end{array} }\tag{6}
$$  

彼此相似。
