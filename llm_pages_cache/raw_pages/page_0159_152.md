## 4.10 矩阵的特征值与特征向量

设  A  $\in { \mathcal { F } } ^ { n \times n }$ 。矩阵 $ A $ 可视为作用在  { $\mathcal { F } } ^ { n }$ 上的一个线性变换（参见习题 4.1.3）。因此，我们定义非零向量 $\alpha \in \mathcal { F } ^ { n }$ 为矩阵 $ A $ 关于特征值 $ \lambda $ 的特征向量，当且仅当

$$
A { \pmb \alpha } = \lambda { \pmb \alpha } , \qquad { \pmb \alpha } \neq { \pmb \theta } .\tag{1}
$$

矩阵 $ A $ 的所有互异特征值构成的集合称为 $ A $ 的**谱**，记作 $\sigma ( A )$。注意，谱在相似变换下保持不变。

**命题 1.** 相似矩阵具有相同的谱。

**证明.** 设式 (1) 成立，且设 $ \mathbf{v} $ 是 $ A $ 关于特征值 $ \lambda $ 的一个特征向量，即  A = P B P ^ { - 1 } 。则  

$$
B ( P ^ { - 1 } \alpha ) = P ^ { - 1 } A \alpha = \lambda ( P ^ { - 1 } \alpha )
$$  

且由于 $ \alpha $ 满足 $\neq \pmb { \theta } ,$，故向量 $P ^ { - 1 } \alpha$ 是矩阵 $ B $ 关于同一特征值 $ \lambda $ 的一个特征向量。因此有 $\lambda \in \sigma ( B )$ 且 $\sigma ( A ) \subset \sigma ( B )$。反向包含关系可类似地证得。

值得注意的是，实际上我们已证明了更强的结论。

**命题 2.** 若 $ \alpha $ 是 $ A $ 关于特征值 $\lambda ,$ 的一个特征向量，则 $\alpha ^ { \prime } = P ^ { - 1 } \alpha$ 是矩阵 $B = P ^ { - 1 } A P$ 关于同一特征值 $ \lambda $ 的一个特征向量。

因此，线性变换 $ T $ 的所有矩阵表示所构成的等价类 $\mathcal { A } _ { T } ^ { 0 }$ 中的每一个矩阵，其特征值均相同，且对应形如 $P ^ { - 1 } \mathbf { x } ,$ 的特征向量（其中 $ P $ 为过渡矩阵）。特别地，等价类 $\mathcal { A } _ { T } ^ { 0 }$ 中各矩阵的谱由变换 $ T $ 唯一确定。由此可知，变换 $ T $ 的谱与其各种矩阵表示之间存在紧密联系。

**定理 1.** 设  T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )，并令 $\mathcal { A } _ { \mathrm { ~ T ~ } } ^ { 0 }$ 表示 $ T $ 对应的矩阵表示等价类。则对任意 $A \in \mathcal { A }$ _ { T } ^ { 0 } ，均有  

$$
\sigma ( T ) = \sigma ( A )\tag{2}
$$

**证明**． 鉴于命题 1，只需证明：对 $ \mathcal{M}_n(\mathbb{F}) $ 中至少一个矩阵 $ A $，方程 (2) 成立．令  
$$
$\lambda \in \sigma ( T )$
$$  
且  

$$

T ( \mathbf { x } ) = \lambda \mathbf { x } , \qquad \mathbf { x } \neq { \pmb \theta } .\tag{3}
$$
