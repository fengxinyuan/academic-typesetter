复平面 ℂ 中的一个集合 $\mathcal { S }$ 称为凸集，若对任意 ${ \mathfrak { X } } _ { 1 } , { \mathfrak { X } } _ { 2 } \in { \mathcal { S } }$ 及任意 $\theta \in [ 0 , 1 ]$，均有  

$$
( 1 - \theta ) { \alpha } _ { 1 } + \theta { \alpha } _ { 2 } \in \mathcal { S } .
$$

包含点集 $\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { k }$ 且被任意其他包含该点集的凸集所包含的凸集，称为点集 $\alpha _ { 1 } , \alpha _ { 2 } \dots , \alpha _ { k }$ 的**凸包**。换言之，凸包是包含给定点集的最小凸集。

**习题 2.** 证明：$\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { k }$ 在 $\mathbb { C }$ 中的凸包，即为形如  

$$
\theta _ { 1 } \alpha _ { 1 } + \theta _ { 2 } \alpha _ { 2 } + \cdot \cdot \cdot + \theta _ { k } \alpha _ { k } , \qquad \theta _ { i } \geq 0 \quad \mathrm { a n d } \quad \sum _ { i = 1 } ^ { k } \theta _ { i } = 1 .\tag{1}
$$  

的所有线性组合所构成的集合。  
（此类和式称为**凸线性组合**。）  
**提示：** 首先证明由式 (1) 所给出的元素集合是凸集；然后通过归纳法验证其在前述意义下的极小性。

凸性的概念可自然地推广至线性空间。设 $\mathcal { X }$ 是域 $\mathcal { F }$ 上的一个线性空间（其中 $\mathcal { F }$ 为实数域 $\mathbb{R}$ 或复数域 $\mathbb{C}$）。对 $\mathcal { X }$ 中任意两个元素 $x$ 与 $\pmb { y }$，连接它们的**线段**定义为形如 $( 1 - \theta ) { \mathbf x } + \theta { \mathbf y }$ 的所有元素构成的集合，其中 $\theta \in [ 0 , 1 ]$。于是，$\mathcal { X }$ 的子集 $\mathcal { S }$ 称为**凸集**，若对 ${ \mathcal { S } } ,$ 中任意一对元素 $x$ 与 $y$，连接 $x$ 与 $\pmb { y }$ 的线段也完全包含于 $\mathcal { S } .$ 中。例如，易见 $\mathcal { X }$ 的任一子空间均为凸集。
