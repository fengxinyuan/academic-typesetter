事实上，若 $ \text{$k  $\leq r \ \mathrm { o r } \ s \leq r , } $，则该子式为零，因为此时存在重复的行或列；若 $ \text{$k  $> r \mathrm { o r } s > r , } $，则该子式亦为零，因为矩阵 $ A $ 的秩为 $ r $，而任何阶数超过 $ r $ 的子式均为零。  

现令 $ \text{$A _ { k j } $\left( j = 1 , 2 , \ldots , r \mathrm { o r } j = s \right$ )$} $ 表示 $ \text{${ $\tilde { A } } . } $ 的最后一行各元素所对应的代数余子式。将 $ \det\,\overline{A} $ 按其最后一行展开，可得  

$$
a _ { k 1 } A _ { k 1 } + a _ { k 2 } A _ { k 2 } + \cdot \cdot \cdot + a _ { k r } A _ { k r } + a _ { k s } A _ { k s } = 0 , \qquad 1 \leq k \geq m .\tag{6}
$$  

再注意到，数 $ \text{$A _ { k j } $( 1 \leq j \leq r \ \mathrm { o r } \ j = s$ )$} $ 与 $ k $ 的选取无关，故记 $ \text{$A _ { k j } $\equiv A$ _ { j }$} $。因此，将式 (6) 分别写为 $ \text{$k  $= 1 , 2 , \ldots , m , } $ 的情形，即得  

$$
A _ { * 1 } A _ { 1 } + A _ { * 2 } A _ { 2 } + \cdot \cdot \cdot + A _ { * r } A _ { r } + A _ { * s } A _ { s } = 0 .\tag{7}
$$

其中，$A _ { * j } \left( 1 \leq j \leq r \mathrm { o r } j = s \right)$ 表示将矩阵 $ A $ 的第 $ j $ 列视作来自 $ \mathbb{C}^n $（或 $ \mathbb{R}^n $）的向量；但 $A _ { s }$ 是 $ A $ 的一个非零子式。因此，方程 (7) 表明列向量组 $A _ { * 1 } , A _ { * 2 } , \ldots , A _ { * r } , A _ { * s }$ 线性相关，从而 $ A $ 的所有列向量亦线性相关。

现注意到列向量组 $A _ { * j } ( j = 1 , 2 , \ldots , r )$ 是线性无关的。事实上，由  

$$
\alpha _ { 1 } { \cal A } _ { \ast 1 } + \alpha _ { 2 } { \cal A } _ { \ast 2 } + \cdot \cdot \cdot + \alpha _ { r } { \cal A } _ { \ast r } = \theta , \qquad \alpha _ { j } \in \mathcal { F } , ~ j = 1 , 2 , \ldots , r ,
$$  

可得 $\hat { A } \mathbf { \hat { a } } = \pmb { \theta } ,$，其中 $\pmb { \alpha } = [ \alpha _ { 1 } \quad \alpha _ { 2 } \quad \cdots \quad \alpha _ { r } ] ^ { \mathbf { T } }$ 且 $\hat { A } = [ a _ { i j } ] _ { i , j = 1 } ^ { r }$。由于 $ \det\, \text{$\hat { A } = A _ { s } $\neq 0 , } \ne 0 $，根据定理 2.9.2 可知 ${ \pmb q } = { \pmb 0 }$，从而 $\{ A _ { * 1 } , \ldots , A _ { * r } \}$ 的线性无关性得以确立。故有  

$$
\dim ( \operatorname { s p a n } \{ A _ { * 1 } , A _ { * 2 } , \dots , A _ { * n } \} ) = r = \operatorname { r a n k } A
$$  

命题得证。

若将定理 1 的证明改述为关于 $ A $ 的行向量，则易见  

$$
\dim { \mathcal { R } } _ { A } = { \mathrm { r a n k } } A ,
$$  

其中 $\mathcal { R } _ { A }$ 表示 $ A $ 的行空间（参见第 3.3 节）。

注意到：对 $ i = 1,2,\dots,n $，条件 $A \mathbf { x } = \pmb { \theta }$ 成立（此处 ${ \pmb x } \neq { \pmb \theta }$）等价于 $ A $ 的列向量线性相关；再结合定理 2.9.2，即可得到定理 1 的一个推论。
