定理 2（柯朗–费希尔定理）：在前述记号下，对 $ j = 1, 2, \dots, n $，有  

$$
\lambda _ { j } = \operatorname* { m a x } _ { \mathcal { S } _ { j } } \operatorname* { m i n } _ { \mathfrak { p } \neq \pmb { x } \in \mathcal { S } _ { j } } R ( \pmb { x } )\tag{8}
$$  

或等价地，以对偶形式表示为  

$$
\lambda _ { n - j + 1 } = \operatorname* { m i n } _ { \mathcal { S } _ { j } } \operatorname* { m a x } _ { \mathfrak { v } \in \mathcal { S } _ { j } } R ( \mathfrak { x } ) .\tag{9}
$$  

换言之，式 (8) 表明：对 $ \mathbb{C}^n $ 的任一 $ j $ 维子空间，先取  R ( x )  在该子空间所有非零向量上的最小值，再对 $ \mathbb{C}^n $ 中所有 $ j $ 维子空间取这些最小值的最大值，所得结果即为 $ H $ 的第 $ j $ 个特征值。

$\mathbf { \delta x } _ { 0 } \mathcal { S } _ { j } ( n - j + 1 ) \mathbb { C } ^ { n } ; \mathbb { C } ^ { n }$



**证明**．为证等式 (8)，根据等式 (6) 的第一部分，只需证明存在一个  ( n - j + 1 ) -维子空间，使得当 $ x $ 取遍该子空间中所有非零向量时，$ \min $R ( x )  等于 $\lambda$ _ { j } 。取 $\mathcal { C }$ _ { j } $= \operatorname { s p a n } \{ \boldsymbol { x }$ _ { j } $, \boldsymbol { x }$ _ { j + 1 } $, \ldots , \boldsymbol { x }$ _ { n } \} ，即可得到这样一个子空间。事实上，由 (6) 可得  

$$
\operatorname* { m i n } _ { \mathbf { \theta } _ { 0 } \neq x \in \mathcal { C } _ { j } } R ( \pmb { x } ) \leq \lambda _ { j } ,
$$  

而由定理 1 得  

$$
\operatorname* { m i n } _ { \mathbf { \theta } _ { 0 } \neq x \in \mathcal { C } _ { j } } R ( \pmb { x } ) = \lambda _ { j } .
$$  

这表明等式 (8) 成立。等式 (9) 可类似地予以证明。

**习题 2**．验证：当  H  $\in \mathbb { R } ^ { 3 \times 3 } , H > 0 ,$ 与  j = 2 ,  时，等式 (8) 的几何解释（如习题 5.10.5 与 5.10.6 中所展开）如下：椭球体的任一中心截面（该截面为一椭圆）的长轴长度不小于该椭球体的第二主轴长度；且存在某个中心截面，其长轴长度恰好等于该椭球体的第二主轴长度。
