## 5.13 可容许的矩阵对

当一个  r  $\times p$ 阶矩阵 $ X $ 在右侧乘以一个 $p \times p$ 阶矩阵  T ,  时，所得矩阵 $\pmb { \chi } T$ 仍为 $r \times p .$ 阶矩阵。事实上，序列  X , X T , X T ^ { 2 } $, \ldots$ 中的所有矩阵均为 $r \times p .  $ 阶。此类序列在矩阵论的一些现代应用中——尤其是系统理论中——频繁出现。本节将简要介绍其若干基本性质。

首先，设  ( X , T )  是一对矩阵，其阶数分别为 $r \times p$ 和 $p \times p ,$ ，若满足 $ \operatorname{Ker} $X  $\neq \{ 0 \}$ ，则称该对矩阵为 $ p $ 阶容许对（admissible pair）。当然，$ r $ 与 $\pmb { p }$ 可取任意正整数；但在实际应用中，通常有 $r \leq p$ _ { 1 } ；且若  r < p , ，则必有 $ \operatorname{Ker} $X  $\neq \{ 0 \} （$ 参见命题 3.8.1）。事实上，情形  r = 1  具有相当重要的意义。

令  K _ { 1 } = { $\sf K }$ 表示 $ X $ 的零空间（即 $ \operatorname{Ker} X $），并令  K _ { 2 }  表示同时属于 $ \operatorname{Ker} X $ 与 $ \operatorname{Ker} X^\top $ 的所有向量构成的集合。显然有  K _ { 2 } $\subset K$ _ { 1 } ，但可能有  K _ { 2 } = K _ { 1 } 。（例如，当  p = 1  且 $T \neq O$ 时即如此。）此外，我们显然可将  K _ { 2 }  表示为  

$$
K _ { 2 } = \mathop { \mathrm { K e r } } \left[ { X \atop X T } \right] .
$$  

更一般地，对  l  $= 1 , 2 , \ldots ,  $，定义  

$$
K _ { \iota } = { \bf K } { \bf e r } \left[ \begin{array} { c } { { X } } \\ { { X T } } \\ { { X T ^ { 2 } } } \\ { { \vdots } } \\ { { X T ^ { l - 1 } } } \end{array} \right] ,
$$  

于是可见，我们在  \mathbb { C } ^ { p }  中得到一个“嵌套”的子空间序列：  

$$
K _ { 1 } \supset K _ { 2 } \supset K _ { 3 } \supset \cdots .
$$  

该序列的一个基本性质由下述引理给出。
