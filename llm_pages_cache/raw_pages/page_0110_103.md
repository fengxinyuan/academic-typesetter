解．易见，矩阵 $ A $ 的最后两行是其前两行（线性无关）的线性组合，故 $ \operatorname{rank} $A = 2 。又因向量 $ \mathbf{b} $ 是 $ A $ 的第一列与第三列的线性组合，故 $ \operatorname{rank} $[ $A \quad b ] = 2$ 同样成立；因此，由定理 1 可知，所给方程组相容（有解）。进一步观察可知， { $\bf x }$ _ { 0 } = [ 1 0 - 1$\, 0] $ 是该方程组的一个特解，而齐次方程组 $A \mathbf { x } ^ { \prime } = { \pmb \theta }$ 具有  n - r = 2  个线性无关的解。为求出这些解，首先注意到：$ A $ 左上角的 $2 \times 2$ 阶子式非零，因此我们考虑方程组 $A \mathbf { x } ^ { \prime } = { \pmb \theta }  $ 的前两个方程：



$$
\begin{array}{c} \begin{array} { r } { \Big [ 1 - 2 \Big ] \Big [ \begin{array} { r } { x _ { 1 } ^ { \prime } } \\ { x _ { 2 } ^ { \prime } } \end{array} \Big ] + \Big [ \begin{array} { r r } { 1 } & { 1 } \\ { 3 } & { - 1 } \end{array} \Big ] \Big [ \begin{array} { r } { x _ { 3 } ^ { \prime } } \\ { x _ { 4 } ^ { \prime } } \end{array} \Big ] = \Big [ 0 } \\ { 0 } \end{array} \Big ] ,  \end{array}
$$



或

$$
 \begin{array} { r } { \left[ 1 \ - 2 \right] \left[ { x _ { 1 } ^ { \prime } } \right] = \left[ { - x _ { 3 } ^ { \prime } - x _ { 4 } ^ { \prime } } \right] . } \\ { 2 \ \quad 0 \end{array} }
$$  

因此，对左侧的 $2 \times 2$ 矩阵求逆，可得  

$$
{ \begin{array} { r } { \left[ x _ { 1 } ^ { \prime } \right] = { \frac { 1 } { 4 } } { \biggl [ } { - } 6 x _ { 3 } ^ { \prime } + 2 x _ { 4 } ^ { \prime } { \biggr ] } . } \\ { \left[ x _ { 2 } ^ { \prime } \right] } \end{array} }
$$  

令 $x _ { 3 } ^ { \prime } = u , x _ { 4 } ^ { \prime } = v$（以表明它们将作为自由参数），则有 $\begin{array} { r } { x _ { 1 } ^ { \prime } = \frac 1 4 ( - 6 u + 2 v ) , x _ { 2 } ^ { \prime } = \frac 1 4 ( - u + 3 v ) , x _ { 3 } ^ { \prime } = u , x _ { 4 } ^ { \prime } = v . } \end{array}$。  

首先取 $v = 0 \mathrm { \ a n d \ } u = 1$，再分别取 $u = 0$ 和 $v = 1$，易得 $[ - \frac { 3 } { 2 } - \frac { 1 } { 4 } - 1 0 ] ^ { \mathtt { T } }$ 与 $[ { \frac { 1 } { 2 } } \quad { \frac { 3 } { 4 } } \quad 0 \quad 1 ] ^ { \boldsymbol { \mathsf { T } } }$ 是方程组 $A \mathbf { x } = \pmb { \theta } .$ 的两个线性无关的解向量。于是，该非齐次线性方程组的通解可表为  

$$
\begin{array} { r } { x = x _ { 0 } + x ^ { \prime } = [ 1 \quad 0 \quad - 1 \quad 0 ] ^ { \mathrm { T } } + u [ - \frac { 3 } { 2 } \quad - \frac { 1 } { 4 } \quad 1 \quad 0 ] ^ { \mathrm { T } } + v [ \frac { 1 } { 2 } \quad \frac { 3 } { 4 } \quad 0 \quad 1 ] ^ { \mathrm { T } } } \end{array}
$$  

其中 $ u $ 与 $ v $ 为任意标量。  

注意：通解中自由（且彼此线性无关）参数的个数（如定理 3 所指出）恰为 $n - r = 2$。
