定理 4．C 上任一非零次数的多项式在 C 中至少有一个零点。

利用定理 1 对 $p ( \lambda )$ 除以 $( \lambda - \lambda _ { 1 } )$，可立即推出下述习题。

习题 5．证明：$\lambda _ { 1 }$ 是 $p ( \lambda )$ 的零点，当且仅当 $\lambda - \lambda _ { 1 }$ 是 $p ( \lambda )$ 的一个（一次）因式。换言之，存在某个定义在 ${ \mathcal { F } } ,$ 上的多项式 $p _ { 1 } ( \lambda )$，使得

$$
p ( \lambda ) = p _ { 1 } ( \lambda ) ( \lambda - \lambda _ { 1 } ) . ~ \varTheta\tag{4}
$$  

设 λ₁ 是 p(λ) 的一个零点。可能出现如下情形：除 $\lambda _ { 1 }$、$p ( \lambda )$、$\lambda - \lambda _ { 1 }$ 外，更高次幂 $( \lambda - \lambda _ { 1 } ) ^ { 2 } , ( \lambda - \lambda _ { 1 } ) ^ { 3 } , \ldots ,$ 也整除 $p ( \lambda )$。若 $( \lambda - \lambda _ { 1 } ) ^ { k }$ 整除 $p ( \lambda )$，但 $( \lambda - \lambda _ { 1 } ) ^ { k + 1 }$ 不整除 $p ( \lambda )$，则称标量 $\lambda _ { 1 } \in \mathcal { F }$ 为多项式 $p ( \lambda )$ 的 k 重零点。重数为 1 的零点称为单零点；其余零点则称为该多项式的多重零点。

习题 6．验证：λ₁ 是 p(λ) 的 k 重零点，当且仅当 $\lambda _ { 1 }$、$p ( \lambda )$、$p ( \lambda _ { 1 } ) = p ^ { \prime } ( \lambda _ { 1 } ) = \cdot \cdot \cdot = p ^ { ( k - 1 ) } ( \lambda _ { 1 } ) = 0$，但 $p ^ { ( k ) } ( \bar { \lambda } _ { 1 } ) \neq 0$。 □  

再次考虑等式 (4)，并假设 $p _ { 1 } ( \lambda )$ 的次数非零。根据定理 4，多项式 $p _ { 1 } ( \lambda )$ 在 ℂ 中必有一零点 $\lambda _ { 2 }$。利用习题 5，可得 $p ( \lambda ) = p _ { 2 } ( \lambda ) ( \lambda - \lambda _ { 2 } ) ( \lambda - \lambda _ { 1 } )$。接着对 ${ \pmb p } _ { 2 } ( \lambda )$ 进行因式分解，并重复此过程，即得如下定理。

定理 5．任一定义在 ℂ 上、次数为 $l \ ( l \geq 1 )$ 的多项式，在 ℂ 中恰有 l 个零点 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { l }$（计入重数）。此外，该多项式具有如下表示：  

$$
p ( \lambda ) = p _ { l } ( \lambda - \lambda _ { l } ) ( \lambda - \lambda _ { l - 1 } ) \cdots ( \lambda - \lambda _ { 1 } ) ,\tag{5}
$$

其中，当多项式  p  $( \lambda$ )为首一多项式时， p _ { l } = 1 。

将式 (5) 中相等的零点合并并重新编号后，我们得到  

$$

p ( \lambda ) = p _ { l } ( \lambda - \lambda _ { 1 } ) ^ { k _ { 1 } } ( \lambda - \lambda _ { 2 } ) ^ { k _ { 2 } } \cdot \cdot \cdot ( \lambda - \lambda _ { s } ) ^ { k _ { s } } ,\tag{6}
$$
  

其中  \lambda _ { i } $\neq \lambda$ _ { j } $( i \neq j$ )，且  k _ { 1 } + k _ { 2 } $+ \cdots + k$ _ { s } = l . 。

给定一组多项式  p _ { 1 } $( \lambda ) , p$ _ { 2 } $( \lambda ) , \ldots , p$ _ { k } $( \lambda$ )，若多项式 $p ( \lambda$ )能被其中每一个多项式整除，则称 $p ( \lambda$ )为这些给定多项式的一个公倍式，即对每个 $ i = 1,2,\dots,k $，均有  

$$

p ( \lambda ) = q _ { i } ( \lambda ) p _ { i } ( \lambda ) , \quad \quad 1 \leq i \leq k ,\tag{7}
$$
  

其中  q _ { i } $( \lambda$ )  是定义在同一数域上的多项式。若某一公倍式能整除任意其他公倍式，则称其为这些多项式的最小公倍式（least common multiple）。

**定理 6.** 对于任意一组首一多项式，存在唯一的一个首一最小公倍式。
