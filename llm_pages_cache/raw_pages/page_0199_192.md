在证明定理 1 时所采用的方法可进一步推广，以证明另一重要结果：  

**定理 2.** 设 $ A $ 为 ${ \mathcal { F } } ^ { m \times n }$ 中的任一矩阵，且 $\left\{ s _ { i } \right\} _ { i = 1 } ^ { r }$ 为 $ A $ 的非零奇异值。则 $ A $ 可表为如下形式：  

$$
A = U D V ^ { * } ,\tag{7}
$$

其中，$U \in \mathcal { F } ^ { m \times m }$ 和 $V \in \mathcal { F } ^ { n \times n }$ 是酉矩阵，而 $ m \times n $ 矩阵 $ D $ 的第 $ i,i $ 个位置为 $s _ { i }$（当 $ i = 1,2,\dots,r $ 时），其余位置均为零。

表示式 (7) 称为矩阵 $ A $ 的**奇异值分解**（singular-value decomposition）。

**证明**．我们沿用定理 1 之证明中所引入的记号。仅需注意：此处矩阵 $ A $ 一般为矩形矩阵，而  A ^ { * } A  的特征向量组 $\{ { \pmb x } _ { i } \} _ { i = 1 } ^ { n }$ 与  A A ^ { * }  的特征向量组 $\{ y _ { j } \} _ { j = 1 } ^ { m }$，现在分别构成空间 ${ \mathcal { F } } ^ { n }$ 与 ${ \mathcal { F } } ^ { m }$ 中的标准正交基。我们有［参见式 (2)］

$$
A { \pmb x } _ { i } = \sqrt { \lambda _ { i } } { \pmb y } _ { i } , \qquad i = 1 , 2 , \ldots , r ,\tag{8}
$$

且由 $\pmb { x } _ { i }$ 的定义（参见习题 5.3.6），可知 $A x _ { i } = \theta \left( r + 1 \leq i \leq n \right)$。

接下来，我们构造如下矩阵：

$$
V = \left[ \ b { x } _ { 1 } \quad \ b { x } _ { 2 } \quad \cdots \quad \ b { x } _ { n } \right] \qquad \mathrm { a n d } \qquad \ b { U } = \left[ \ b { y } _ { 1 } \quad \ b { y } _ { 2 } \quad \cdots \quad \ b { y } _ { m } \right]\tag{9}
$$

并注意到：根据推论 5.6.2，这两个矩阵均为酉矩阵。又因按定义有 $s _ { i } = \sqrt { \lambda _ { i } } ( i = 1 , 2 , \ldots , n )$，故关系式 (8) 推出

$$
A V = [ s _ { 1 } y _ { 1 } s _ { 2 } y _ { 2 } \dotsm s _ { r } y _ { r } \theta \dotsm \theta ] = U D ,
$$

其中 $ D $ 即为式 (7) 中所出现的矩阵。因此，表示式 (7) 得证。
