$$
\omega _ { i } = - \lambda _ { n - r + 1 - i } \qquad \mathrm { f o r } \quad i = 1 , 2 , \ldots , n - r .
$$  

将前述关于 $H$ 所证得的结果应用于矩阵 $-H$，即得  

$$
\nu _ { i + r } \geq \omega _ { i } ,

$$
- \mu _ { n + 1 - i - r } \geq - \lambda _ { n - r + 1 - i } .
$$
