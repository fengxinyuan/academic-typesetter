## 5.9 实数域上的矩阵

设 $A \in \mathbb { R } ^ { n \times n }$。显然，前述关于任意域 $\mathcal { F }$ 的所有命题，在特例 ${ \mathcal { F } } = \mathbb { R }$ 下依然成立。然而，ℝ 并非代数闭域，因此 $\mathbb { R } ^ { n \times n }$ 中的矩阵可能丧失某些关键性质。例如，一个实元素矩阵可能没有（实）特征值。此类矩阵的一个例子是  

$$
\left[ - \frac { \mu } { \nu } \quad \frac { \nu } { \mu } \right] , \qquad , \nu \in \mathbb { R } , \quad \nu \neq 0 .\tag{1}
$$  

（另见例 4.1.2 中的矩阵，其中 $\gamma$ 并非 $\pi . )$ 的整数倍。）另一方面，若一个实矩阵的谱完全由实数组成，则实情形与复情形之间并不存在本质差异。

接下来我们讨论一种称为**复化方法**（complexification）的过程，该方法可将实矩阵的研究归约为具有复元素的矩阵之研究。

首先，我们回顾熟知的笛卡尔分解 ${ \pmb z } = { \pmb x } + i { \pmb y } _ { \mathrm { : } }$，其中 $z \in \mathbb { C } ^ { n }$ 且 $x , y \in \mathbb { R } ^ { n }$。因此，若 $\{ a _ { 1 } , a _ { 2 } , \ldots , a _ { n } \}$ 是 $\mathbb { R } ^ { n }$ 中的一组基，

$$
\boldsymbol { x } = \sum _ { j = 1 } ^ { n } \alpha _ { j } \boldsymbol { a } _ { j } \qquad \mathrm { a n d } \qquad \boldsymbol { y } = \sum _ { j = 1 } ^ { n } \beta _ { j } \boldsymbol { a } _ { j } \qquad ( \alpha _ { j } , \beta _ { j } \in \mathbb { R } , j = 1 , 2 , \ldots , n ) ,
$$  

于是  

$$
z = x + i y = \sum _ { j = 1 } ^ { n } { \bigl ( } \alpha _ { j } + i \beta _ { j } { \bigr ) } \pmb { a } _ { j } .
$$  

因此，$\mathbb { C } ^ { n }$ 可视为在此基底下具有复坐标的所有向量构成的集合，而 $\mathbb { R } ^ { n }$ 则是相对于同一基底具有实坐标的全部向量所构成的集合。若 $\mathbb { R } ^ { n }$ 中的基为标准基，则上述最后一点便显而易见。注意：$\mathbb { R } ^ { n }$ 中的向量 $ \mathbf{x} $ 可视作 $ \mathbb{C}^n $ 中形如 $x + i 0$ 的向量。  

接下来考虑一个矩阵 $A \in \mathbb { R } ^ { n \times n } ,$，我们按如下规则将其作用延拓至 $\mathbb { C } ^ { n }$ 中的向量：  

$$
\tilde { A } \mathbf { z } = A \mathbf { x } + i A \mathbf { y }\tag{2}
$$  

其中 $z = x + i y , x , y \in \mathbb { R } ^ { n }$。需指出，矩阵 $A$ 与 $\tilde { A }$ 实际上完全相同，因而具有相同的特征多项式，且该特征多项式的系数均为实数。还须特别强调：$A _ { i }$ 的特征值仅限于实数；同样地，$A$ 的特征向量亦仅限于实向量（即各分量均为实数的向量）。
