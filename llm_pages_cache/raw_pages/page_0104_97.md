命题 3．设 A 是 ${ \mathcal { F } } ^ { m \times n }$ 中一个 m × n 矩阵，且 rank A = $r \ ( r \geq 1 )$，则 A 可表为如下乘积  

$$
A = P _ { 1 } Q _ { 1 } ,\tag{3}
$$  

其中 $P _ { 1 } \in \mathcal { F } ^ { m \times r } , Q _ { 1 } \in \mathcal { F } ^ { r \times n }$，且这两个矩阵的秩均为 r。

**证明．** 设 P 与 Q 为如式 (2) 所定义的两个非奇异矩阵。记  

$$
P = [ P _ { 1 } \quad P _ { 2 } ] \qquad \mathrm { a n d } \qquad Q = \left[ Q _ { 1 } \right] ,
$$

其中，$P _ { 1 } \in \mathcal { F } ^ { m \times r } , P _ { 2 } \in \mathcal { F } ^ { m \times ( m - r ) } , Q _ { 1 } \in \mathcal { F } ^ { r \times n } , Q _ { 2 } \in \mathcal { F } ^ { ( n - r ) \times n } ;$，容易看出，分块 $P _ { 2 }$ 与 $Q _ { 2 }$ 并不出现在最终结果中：  

$$
\begin{array}{c} A = P { \binom { I _ { r } } { 0 } } \quad { \boldsymbol { 0 } } \end{array}  ] Q = P _ { 1 } I _ { r } Q _ { 1 } = P _ { 1 } Q _ { 1 } .
$$  

矩阵 $P _ { 1 }$ 与 $Q _ { 1 }$ 所需的性质由习题 1 提供。  

注意，式 (3) 被称为矩阵 $ A $ 的秩分解（rank decomposition）。  

**习题 4.** 证明：任一秩为 $ r $ 的矩阵均可表示为 $ r $ 个秩为 1 的矩阵之和。  

**习题 5.** 若 $ A $ 与 $ B $ 是两个矩阵，且乘积 $ AB $ 有定义，证明  

$$
\operatorname { r a n k } ( A B ) \leq \operatorname* { m i n } ( \operatorname { r a n k } \ A , \operatorname { r a n k } \ B ) .
$$  

**解.** $ AB $ 的每一列均为 $ A $ 的各列的线性组合，因此 $ \operatorname{rank}(AB) \le \operatorname{rank}(A) $；再结合习题 3.5.5 中的不等式及定理 3.7.1，即得不等式 $ \operatorname{rank}(AB) \le \operatorname{rank}(B) $。对两边取转置，并利用习题 2.8.5，第二个不等式可立即得出。  

**习题 6.** 设 $ A $ 是 $\mathcal { F } ^ { n \times n }$ 中的一个非奇异矩阵。证明：对任意 $B \in \mathcal { F } ^ { n \times k }$ 与 $C \in \mathcal { F } ^ { l \times n }  $，均有  

$$
\operatorname { r a n k } ( A B ) = \operatorname { r a n k } B , \qquad \operatorname { r a n k } ( C A ) = \operatorname { r a n k } C .
