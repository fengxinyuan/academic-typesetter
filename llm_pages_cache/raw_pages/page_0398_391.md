## 11.3 解析扰动

我们现在采用一种截然不同的方法来处理扰动问题。设 $A \in \mathbb { C } ^ { n \times n }$ 为未受扰动的矩阵，其特征值为 $\lambda _ { 1 } , \ldots , \lambda _ { n }$。再设 $A ( \zeta )$ 是一个 $n \times n$ 矩阵，其各元素均为变量 $\zeta$ 在 $\zeta _ { 0 }$ 的某个邻域内的解析函数，且满足 $A ( \zeta _ { 0 } ) = A$。为方便起见，且不失一般性，我们可假设 $\zeta _ { 0 } = 0 ,$，从而有 $A ( 0 ) = A$。记 $\lambda _ { 1 } ( \zeta ) , \ldots , \lambda _ { n } ( \zeta )$ 为 $A ( \zeta )$ 的特征值；于是（参见第 10.6 节），由于 $A ( \zeta )$ 的特征值关于其元素连续依赖，我们可以假定 $\lambda _ { j } ( \zeta ) \to \lambda _ { j } \mathrm { a s } \zeta \to 0 \mathrm { f o r } j = 1 , 2 , \ldots , n .$。
