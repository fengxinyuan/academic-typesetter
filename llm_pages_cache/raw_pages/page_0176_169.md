为定义伴随算子，我们取  { $\pmb u } .$ 的一个标准正交基 $\pmb { u }$ _ { 1 } $, \ldots , \pmb { u }$ _ { n } ，然后依据  T  定义一个映射  T ^ { * } { $\colon } \mathcal { V }  \mathcal { U }  $，其定义如下：  

$$
T ^ { * } ( y ) = \sum _ { j = 1 } ^ { n } { ( y , T ( u _ { j } ) ) _ { 2 } } { u _ { j } }\tag{2}
$$  

对任意  \pmb { y } $\in \mathcal { V } .$ 成立。我们首先验证  T ^ { * } $\in \mathcal { L } ( \mathcal { V } , \mathcal { U }$ )确为线性映射。设  { $\pmb y } , { \pmb z } \in \mathcal { V }$ 、 $\alpha , \beta \in \mathcal { F }  $，则利用内积的线性性（第 3.11 节），有  

$$
\begin{array} { c } { { T ^ { * } ( \alpha y + \beta z ) = \displaystyle \alpha \sum _ { j = 1 } ^ { n } ( y , T ( u _ { j } ) ) _ { 2 } u _ { j } + \displaystyle \beta \sum _ { j = 1 } ^ { n } ( z , T ( u _ { j } ) ) _ { 2 } u _ { j } } } \\ { { { } } } \\ { { { } = \alpha T ^ { * } ( y ) + \beta T ^ { * } ( z ) , } } \end{array}
$$  

此式由  T ^ { * }  的定义（2）直接得出。因此  T ^ { * } $\in \mathcal { L } ( \mathcal { V } , \mathcal { U }$ )。我们的第一个定理将证明：如此定义的  T ^ { * } { } _ { ; }  确实具有我们所要求的性质（1）；此外，该定理还将表明， T ^ { * }  的定义实际上与  { $\pmb u } .  $ 所选取的标准正交基无关。

首先，我们应指出本讨论中一个重要的特例：即  \mathcal { U } $= \mathcal { V }  $，且两个空间上的内积亦完全一致。在此情形下，定义（2）化为

$$
T ^ { * } ( x ) = \sum _ { j = 1 } ^ { n } { ( x , T ( u _ { j } ) ) u _ { j } } ,\tag{3}
$$  

且 $T ^ { * } ,$ 以及 $ T $ 均属于 $ \mathcal{L}(U,V) $。  

**定理 1.** 设 $ T \in \mathcal{L}(U,V) $，其中 $ U $ 是具有内积 $ \langle \cdot,\cdot \rangle_U $ 的酉空间，$ V $ 是具有内积 $ \langle \cdot,\cdot \rangle_V $ 的酉空间。则 $ T $ 的伴随变换 $ T^* \in \mathcal{L}(V,U) $ 满足如下条件：  

$$
( T ( \mathbf { x } ) , \mathbf { y } ) _ { 2 } = ( \mathbf { x } , T ^ { * } ( \mathbf { y } ) ) _ { 1 }\tag{4}
$$  

对所有 $ u \in U $、$ v \in V $ 成立；且 $ T^* $ 是 $ \mathcal{L}(V,U) $ 中唯一满足式 (4) 的元素。反之，若式 (4) 成立，则 $ T^* $ 即为 $ T $ 的伴随变换。
