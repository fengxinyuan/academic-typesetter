习题 1．证明初等矩阵是幺模矩阵，且其逆矩阵也是初等矩阵。

现在我们可以对等价变换作出形式定义：设  A  $( \lambda$ )与 $B ( \lambda$ )是定义在  { $\mathcal F } ,$ 上的两个矩阵多项式，若 $ B(\lambda) $ 可由 $A ( \lambda$ )经有限次初等运算得到，则称二者等价，或称二者通过一个等价变换相互关联。由于初等运算与左乘或右乘初等矩阵的运算等价，因此 $A ( \lambda$ )与 $ B(\lambda) $ 等价当且仅当存在初等矩阵  E _ { 1 } $( \lambda ) , E$ _ { 2 } $( \lambda ) , \dots , E$ _ { k } $( \lambda ) , E$ _ { k + 1 } $( \lambda ) , \dots , E$ _ { s } $( \lambda$ ) ，使得  

$$

B ( \lambda ) = E _ { k } ( \lambda ) \cdot \cdot \cdot E _ { 1 } ( \lambda ) A ( \lambda ) E _ { k + 1 } ( \lambda ) \cdot \cdot \cdot E _ { s } ( \lambda )
$$
  

或者等价地，  

$$

B ( \lambda ) = P ( \lambda ) A ( \lambda ) Q ( \lambda ) ,\tag{1}
$$
  

其中  P  $( \lambda ) = E$ _ { k } $( \lambda ) \cdots E$ _ { 1 } $( \lambda$ )与 $Q ( \lambda ) = E$ _ { k + 1 } $( \lambda ) \cdot \cdot \cdot E$ _ { s } $( \lambda$ )是定义在域 $ F $ 上的矩阵多项式。习题 1 表明：矩阵 $ P(\lambda) $ 与 $Q ( \lambda$ )  均为幺模矩阵，从而可得如下命题。

**命题 1．** 矩阵多项式  A  $( \lambda$ )与 $ B(\lambda) $ 等价，当且仅当存在幺模矩阵 $ P(\lambda) $ 与 $ Q(\lambda) $，使得式 (1) 成立。

最后这一事实立即表明：矩阵多项式之间的等价关系是一种等价关系。

**习题 2．** 记 $ A(\lambda) $ 与 $ B(\lambda) $ 等价为 $A \sim B ,  $，试证明：

(b)  A  $\sim B$ 蕴含 $B \sim A  $；  
(c) 若 $ A \sim B $ 且 $ B \sim C $，则 $A \sim C  $。

习题 3．证明：任一幺模矩阵均等价于单位矩阵。

【解】若 $ A(\lambda) $ 是幺模矩阵，则 $A ( \lambda ) [ A ( \lambda ) ] ^ { - 1 } = I$，因此关系式 (1) 在取 $ P(\lambda) = I $ 且 $ Q(\lambda) = [A(\lambda)]^{-1} $ 时成立。□
