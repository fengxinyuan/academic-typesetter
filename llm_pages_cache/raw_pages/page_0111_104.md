## 3.11 酉空间与欧几里得空间

我们在第 3 章开头形式化了 $\mathbb { R } _ { 3 }$ 中一些熟知的概念，并进而将其推广以定义线性空间。现在我们沿此方向再进一步，将 $\mathbb { R } _ { 3 }$ 中内积（标量积）这一重要概念（参见第 1.3 节）推广至一大类线性空间。由此，我们便可将长度、夹角等熟知的概念加以推广。

设  \mathcal { S }  是域 $\mathcal { F } （$ 实数域或复数域）上的（有限维）线性空间，且设 $\pmb { x } , \pmb { y } \in \mathcal { S } . \pmb { A }$ 。从 $\mathcal { S } \times \mathcal { S }$ 到 $\mathcal { F }$ 的二元运算  ( { $\pmb x } , { \pmb y }$ )称为 $\mathcal { S }$ 上的一个**内积**（或**标量积**），若对所有 $\mathbf { \boldsymbol { x } } , \mathbf { \boldsymbol { y } } , z \in \mathcal { S }$ 与 $\alpha , \beta \in \mathcal { F }  $，下列性质成立：

11  ( { $\pmb x } , { \pmb x } ) \geq 0$ 且  ( { $\pmb x } , { \pmb x } ) = { \pmb 0 }$ 当且仅当 $\begin{array} { r } { \pmb { x } = \pmb { \theta } ; } \end{array}  $。

$$

\begin{array} { r l } { { \bf { I } } 2 } & { { } ( \alpha { \bf { x } } + \beta y , z ) = \alpha ( { \bf { x } } , z ) + \beta ( y , z ) , } \end{array}
$$


13  ( { $\pmb x } , { \pmb y } ) = ( \overline { { { \pmb y } , { \pmb x } } }$ ) （其中上划线表示复共轭）。

这三条性质分别称为**正定性**、**关于第一变元的线性性**以及**共轭对称性**（注：原文中“antisymmetry”系笔误；在复内积定义中，第三条实为 conjugate symmetry，即共轭对称性；若为实空间，则退化为对称性。标准中文教材术语应作“共轭对称性”，而非“反对称性”）。容易验证，我们所熟知的 $ \mathbb{R}^3 $ 中的标量积满足全部三条性质。下一个例子是 $\mathbb { R }$ _ { 3 } ：将前述情形自然推广至 $\mathbb { C } ^ { n } .  $。

**习题 1.** 验证：对任意一对元素，如下定义的二元运算  

$$

( { \pmb x } , { \pmb y } ) = x _ { 1 } { \bar { y } } _ { 1 } + x _ { 2 } { \bar { y } } _ { 2 } + \dots + x _ { n } { \bar { y } } _ { n } = { \pmb y } ^ { * } { \pmb x } ,\tag{1}
$$
  

满足内积的全部三条公理。

$$
\pmb { x } = [ \pmb { x } _ { 1 } \quad \pmb { x } _ { 2 } \quad \cdots \quad \pmb { x } _ { n } ] ^ { \mathsf { T } } , \quad \pmb { y } = [ \pmb { y } _ { 1 } \quad \pmb { y } _ { 2 } \quad \cdots \quad \pmb { y } _ { n } ] ^ { \mathsf { T } }
$$  

由 $\mathbb { C } ^ { n } ,$ 所定义的映射是 $\mathbb{C}^n$ 上的一个标量积。□  

由式 (1) 所给出的内积称为 $ \mathbb{C}^n $ 上的标准内积；若无特别说明，所采用的即为此内积。$ \mathbb{R}^n $ 上的标准内积亦由式 (1) 定义，此时共轭符号（即上划线）显然可以省略。因此，在此情形下，该内积是双线性的，即对两个变元均呈线性。  

下一习题说明：如何在任意一个有限维空间 $ V $（其基域为 $ \mathbb{F} $，且 $ \mathbb{F} $ 中可定义复共轭运算）上定义一个内积。  

习题 2．(a) 设 $ \{v_1, v_2, \dots, v_n\} $ 是 $ V $ 在 $ \mathbb{F} $ 上的一组基。验证如下二元运算  

$$
( { \pmb x } , { \pmb y } ) = \sum _ { i = 1 } ^ { n } x _ { i } { \overline { { y } } } _ { i }\tag{2}
$$  

构成 $ V $ 上的一个内积，其中 $ x = \sum_{i=1}^n \alpha_i v_i $，$ y = \sum_{i=1}^n \beta_i v_i $，且 $ \alpha_i, \beta_i \in \mathbb{F} $。
