将范数与复数的模或  \mathbb { R } _ { 3 }  中向量的通常长度作类比，是很有启发性的。公理 1–3 正是对这些直观概念的直接推广；因此，特别地，公理 3 被称为**三角不等式**。  

首先需注意，在酉空间  \boldsymbol { $\mathcal U } （$ 参见第 3.11 节）中，内积自然诱导出一个范数。具体而言，对任意向量 $\pmb { x } \in \mathcal { U }$ ，定义  \| { $\pmb x } \| = ( { \pmb x } , { \pmb x } ) ^ { 1 / 2 }  $；上述范数公理可直接由内积公理推出。然而可以证明，并非所有范数函数都可由某个内积诱导生成；由于若干此类范数在应用中极为重要，本章的大部分分析均在不依赖内积的前提下完成。  

接下来的一组习题至关重要。第一题指出了范数公理所蕴含的一些直接且常用的推论；第二题介绍了在 $ n $ 元组空间 $\textstyle \mathbb { R } ^ { n }$ 与 $\mathbb { C } ^ { n }  $ 上最重要的一类范数；第三题则特别表明：**任意抽象的有限维线性空间上总可定义范数**。配备了一个范数的线性空间称为**赋范线性空间**。
