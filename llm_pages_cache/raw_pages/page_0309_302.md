## 8.8 小振动理论中的应用

我们现在回到第5.12节所讨论的问题。在该节中，我们将一个物理振动问题归结为求解矩阵微分方程 $A { \ddot { p } } + C p = 0$，其中 $ A $ 是正定矩阵，而 $ C $ 要么是正定矩阵，要么是半正定矩阵。进而，该问题又简化为一个纯代数问题：通过合同变换，将 $ A $ 与 $ C $ 同时化为对角矩阵。而这一问题又被进一步归结为：利用正交合同变换将矩阵 $B = A ^ { - 1 / 2 } C A ^ { - 1 / 2 }$ 化为对角形式。

该系统的固有频率由多项式 $ \det $( $A \lambda - C$ )的非负零点的平方根给出，这些零点也恰好是矩阵 $ B $ 的特征值。因此，我们现已知道，最大的固有频率 $\omega$ _ { n } $= \lambda$ _ { n } ^ { 1 / 2 }  可表示为 $\lambda$ _ { n } $= \operatorname* { m a x } R$ _ { 1 } ( { $\pmb x }$ )，其中  R _ { 1 }  是 $ B $ 的瑞利商（Rayleigh quotient），而 $\pmb { x } \neq \pmb { \theta }$ 遍历 $\mathbb { R } ^ { n } （$ 参见习题8.2.1）。定理8.2.1与8.2.2表明，所有固有频率均可借助  R _ { 1 }  的极值来定义。然而需注意，若令 $\pmb { x } = A ^ { 1 / 2 } \pmb { q }  $，则有  

$$
