## 矩阵代数

由 $mn$ 个元素构成的有序数组 $a _ { i j } ( i = 1 , 2 , . . . , m ; j = 1 , 2 , . . . , n )$，以如下形式书写：

$$
A = { \left[ \begin{array} { l l l l } { a _ { 1 1 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 n } } \\ { a _ { 2 1 } } & { a _ { 2 2 } } & { \cdots } & { a _ { 2 n } } \\ { \vdots } & { \vdots } & & { \vdots } \\ { a _ { m 1 } } & { a _ { m 2 } } & { \cdots } & { a _ { m n } } \end{array} \right] }
$$  

被称为一个矩形 $m \times n$ 矩阵。这些元素可取自任意一个域 $\mathcal { F }$。然而，就本书的目的而言，$\mathcal { F }$ 恒指全体实数集或全体复数集，分别记为 ℝ 和 ℂ。

矩阵 A 可更简略地以其元素表示为  

$$
A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } , \qquad \mathrm { o r } \qquad A = [ a _ { i j } ] ,
$$  

其中 $a _ { i j } ( 1 \leq i \leq m , 1 \leq j \leq n )$ 表示矩阵 A 中位于第 i 行与第 j 列交点处的元素。

具有相同行数（m）与相同列数（n）的两个矩阵称为同型矩阵（即大小相同的矩阵）。两个同型矩阵  

$$
A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } \qquad \mathrm { a n d } \qquad B = [ b _ { i j } ] _ { i , j = 1 } ^ { m , n }
$$  

相等，当且仅当其所有对应元素均相同，即对所有 $1 \leq i \leq$ ≤ m 与 $1 \leq j \leq n .$ ≤ n，均有 $a _ { i j } = b _ { i j }$。

全体 m × n 实矩阵构成的集合记为 $\mathbb { R } ^ { m \times \prime }$；类似地，$\mathbb { C } ^ { m \times n }$ 表示全体 m × n 复矩阵构成的集合。
