## 稳定性问题

在第 12.3 节中，我们定义了稳定矩阵。此类矩阵在常微分方程理论的研究中具有特殊重要性，如下命题所示：矩阵 $ A $ 是稳定的，当且仅当对微分方程  { $\dot { \pmb { x } } } = { \pmb { A } } { \pmb { x } } ,$ 的每一个解向量  { $\pmb x } ( t$ )，均有  { $\pmb x } ( t )  { \pmb \theta } （$ 当 $t \to \infty$ ）。该结论在考察方程 $\dot { \pmb { x } } = \pmb { A } \pmb { x }$ 的解  { $\bf x } ( t ) = e ^ { A t } { \bf x$ _ { 0 } } （见定理 9.10.3）时即显而易见，其论证方式与定理 12.3.3 的证明一致（另参见习题 10.9.14）。

就惯性而言，矩阵  A  $\in \mathbb { C } ^ { n \times n }$ 是稳定的，当且仅当其惯性（参见第 5.5 节）为  ( 0 , n , 0 ) 。本章所介绍的李雅普诺夫方法，将任意给定矩阵的惯性表示为某一相关埃尔米特矩阵的惯性，并在理论上具有重要意义。

特别地，李雅普诺夫（Lyapunov）理论为判断矩阵的稳定性提供了一个判据，该判据无需直接计算矩阵 $ A $ 的特征多项式及其零点。此外，对于给定的一个实系数标量多项式，其零点关于虚轴的分布问题（即劳斯–赫尔维茨（Routh–Hurwitz）问题）亦可通过李雅普诺夫方法予以解决。同样，关于单位圆周的舒尔–科恩（Schur–Cohn）零点定位问题，以及其他涉及实系数多项式零点位置的问题，也将在本节中予以讨论。

## 13.1 李雅普诺夫稳定性理论及其推广

为阐明李雅普诺夫在稳定性理论中的研究思路，本节开头将首先关注二次型。记 $ v $ 为以实对称矩阵 $ V $ 为矩阵的二次型（参见第 5.10 节）；类似地，记 $ w $ 为以实对称矩阵 $ W $ 为矩阵的二次型。$ V $（或 $ W $）的正定性将记作  $v > 0$ （或  $w > 0 )$ ），而半正定二次型的表示方式类似。

设  $\pmb { A } \in \mathbb { R } ^ { n \times n }$ ，并考虑如下微分方程：

$$
{ \dot { \mathbf { x } } } ( t ) = A { \mathbf { x } } ( t ) .\tag{1}
$$

将二次型 $ v $ 沿方程 (1) 的解  $\pmb { x } ( t )$  进行求值，其中对每个 $ t $ 均有  $\ b { x } ( t ) \in \mathbb { R } ^ { n }$ 。于是有  $v ( { \boldsymbol { \mathbf { x } } } ) = { \boldsymbol { \mathbf { \mathit { x } } } } ^ { \mathbf { T } } V { \boldsymbol { \mathbf { \mathit { x } } } }$ ，从而

$$
\dot { v } ( { \pmb x } ) = \dot { { \pmb x } } ^ { \operatorname { T } } V { \pmb x } + { \pmb x } ^ { \operatorname { T } } V \dot { \pmb x } = { \pmb x } ^ { \operatorname { T } } ( A ^ { \operatorname { T } } V + V A ) { \pmb x } .
$$  

若我们记  

$$
\begin{array} { r } { \boldsymbol { A } ^ { \mathrm { T } } \boldsymbol { V } + \boldsymbol { V } \boldsymbol { A } = - \boldsymbol { W } , } \end{array}\tag{2}
$$  

则显然 $ W $ 是实对称矩阵，且满足 $ \mathrm{${ $\dot { v } } ( { \bf x } ) = - w ( { \bf x }$ )$} $，其中 $ \mathrm{$w ( { $\pmb x } ) = } $，$ \mathrm{$\mathbf { x } ^ { $\mathrm { { T } } } W \mathbf { x } } $。  

李雅普诺夫指出：给定一个正定二次型 $ w $，矩阵 $ A $ 的稳定性可由方程 (2) 是否存在正定解矩阵 $ V $ 来刻画；因为此时 $ \mathrm{$v ( { $\pmb x }$ )$} $ 可作为向量 $ x $ 的模长的一个可行度量。因此，方程 $ \mathrm{${ $\dot { \pmb { x } } } = A { \pmb { x } } } $ 具有如下性质：对任一解向量 $ x(t) $，均有 $ \mathrm{$\begin{array} { r } { $\operatorname* { l i m }$ _ { $t \to \infty } \pmb { x } ( t ) = 0 } \end{array} } $，当且仅当存在正定二次型 $ w $ 与 $ v $，使得  
$$
\mathrm{${ \dot { v } } ( { \pmb x } ) =$}, \quad \mathrm{$- w ( { \pmb x } )$}.
$$  
此外，方程 (2) 中的正定矩阵 $ W $ 可任意选取，故一种自然的选择常取为 $ \mathrm{$W = I .$} $。  

为直观理解这一结论的意义，设 $ A $ 为 $ \mathrm{$2  $\times 2 } $，并考虑其解  

$$
{ \pmb x } ( t ) = \left[ { \pmb x } _ { 1 } ( t ) \right] ,
$$

其中，$x _ { 1 } ( t )$ 和 ${ \boldsymbol x } _ { 2 } ( t )$ 是关于变量 $ t $ 的实值函数。正定型 $ v $ 的等位线（参见习题 5.10.6）在 $\mathbf { { x } _ { 1 } } , \mathbf { { x } _ { 2 } }$ 平面上为椭圆（图 1），且当 ${ \pmb x } _ { 0 } = { \pmb x } ( t _ { 0 } )$ 时，我们可在椭圆 $v ( { \bf { x } } ) = v ( { \bf { x } } _ { 0 } )$ 上确定对应于 ${ \bf \mathfrak { x } } ( t _ { 0 } )$ 的一点。现考虑解 ${ \pmb x } ( t )$ 在 $( x _ { 1 } ( t _ { 0 } ) , x _ { 2 } ( t _ { 0 } ) )$ 附近所形成的连续路径（即轨迹）。若 $w > 0$，则 $\dot { v } < 0 .$，因而当 $ t $ 增大时，该路径必进入椭圆 $v ( { \bf { x } } ) = v ( { \bf { x } } _ { 0 } )$ 内部；进一步地，对充分大的 $ t $，该路径必可任意接近原点（即与原点的距离可小于任意给定的正数）。

回到更精确、更一般的讨论，我们现在陈述经典李雅普诺夫（Lyapunov）定理的一个代数版本。本节后续还将证明更为一般的惯性定理，以及一个更普遍的稳定性定理（定理 5）。
