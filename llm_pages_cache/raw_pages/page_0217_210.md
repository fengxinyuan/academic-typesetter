或者  

$$
( \lambda I - A ^ { - 1 } C ) q = \pmb { \theta } .\tag{4}
$$  

参数 λ 的容许取值（即定义振动固有频率的值）恰为矩阵 $A ^ { - 1 } C$ 的 n 个特征值。相应的振动模态则由对应的右特征向量确定。然而，为使我们的解具有所需形式（即 ω 取实数值），我们必须首先保证这些特征值均为实数且非负。

方程 (3) 所提出的代数问题，仅仅是方程 (5.5.5) 的一个特例；利用该节中的论证可知，矩阵 $A ^ { - 1 } C$ 的特征值恰好与矩阵 $\bar { A } ^ { - 1 / 2 } C \bar { A } ^ { - 1 / 2 }$ 的特征值相同。而后者矩阵显然与矩阵 C 一样，是半正定（或正定）的。因此，方程 (4) 的所有特征值均为实数且非负（若 C 是正定矩阵，则所有特征值均为正数）。记第 j 个特征值为 $\lambda _ { i } = \omega _ { j } ^ { 2 } , ( \omega _ { j } \geq 0 )$，并令 $W = \mathrm { d i a g } [ \omega _ { 1 } , . . . , \omega _ { n } ]$。

定理 5.5.2 的证明表明：若我们在 $\mathbb { C } ^ { n }$ 中通过 $\overset { \cdot } { \pmb { q } } = \pmb { A } ^ { - 1 / 2 } \pmb { U } \overset { \cdot } { \pmb { s } }$ 引入新的坐标系，其中 $U ^ { * } U = I$，且  

$$
U ^ { * } ( A ^ { - 1 / 2 } C A ^ { - 1 / 2 } ) U = \Lambda = W ^ { 2 } ,
$$

此时，矩阵 $ A $ 与 $ C $ 可被同时对角化。（事实上，此处的 $ U $ 是一个（实）正交矩阵。）回到含时方程，这提示我们为该系统引入一组新的广义坐标：  
$\xi _ { 1 } , \ldots , \xi _ { n } ,$  
由下式给出：  
$p ( t ) = A ^ { - 1 / 2 } U \xi ( t )$  
，从而有  
$\ddot { p } = A ^ { - 1 / 2 } U \ddot { \xi } .$  
将其代入方程 (2)，并在左端乘以  
$U ^ { * } A ^ { - 1 / 2 }$  
，即得“解耦”的方程：  

$$
\ddot { \pmb { \xi } } + W ^ { 2 } \pmb { \xi } = \pmb { \theta } ,
$$  

或等价地  

$$
\ddot { \zeta } _ { i } + \omega _ { i } ^ { 2 } \xi _ { i } = 0 , \qquad i = 1 , 2 , \ldots , n .
$$  

由此可得  

$$
\xi _ { i } ( t ) = \alpha _ { i } \cos ( \omega _ { i } t + \varepsilon _ { i } ) \qquad \mathrm { i f } \quad \omega _ { i } \neq 0 .
$$  

上述方程中的  
${ \pmb { \alpha } } { \bf \dot { s } }$  
与  
${ \pmb \varepsilon } { \pmb s }$  
为任意常数，通常由给定的初始条件确定。当仅  
$\xi _ { i }$  
按此方式变化，而其余所有  
$\xi \mathbf { \hat { s } }$  
均为零时，称该系统正以第 $ i $ 个正则模态（或简正模态）振动。坐标  
$\xi _ { 1 } , \xi _ { 2 } , \ldots , \xi _ { n }$  
即为该系统的正则坐标（或简正坐标）。注意  

$$
\begin{array} { r l } & { T = \frac { 1 } { 2 } \dot { p } ^ { \mathrm { T } } A \dot { p } = \frac { 1 } { 2 } \dot { \xi } ^ { \mathrm { T } } \dot { \xi } } \\ & { \phantom { T = } = \frac { 1 } { 2 } ( \dot { \xi } _ { 1 } ^ { 2 } + \dot { \xi } _ { 2 } ^ { 2 } + \cdot \cdot \cdot + \dot { \xi } _ { n } ^ { 2 } ) } \end{array}
$$  

且

$$
\begin{array} { l } { { V = \frac { 1 } { 2 } p ^ { \mathrm { T } } C p = \frac { 1 } { 2 } \xi ^ { \mathrm { T } } W ^ { 2 } \xi } } \\ { { \mathrm { } } } \\ { { = \frac { 1 } { 2 } ( \omega _ { 1 } ^ { 2 } \xi _ { 1 } ^ { 2 } + \cdot \cdot \cdot + \omega _ { n } ^ { 2 } \xi _ { n } ^ { 2 } ) . } } \end{array}
$$
