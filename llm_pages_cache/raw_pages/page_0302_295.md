$$
0 < \mu _ { 1 } \leq \lambda _ { 1 } \leq \lambda _ { 2 } \leq \cdot \cdot \cdot \leq \lambda _ { n - r } ,
$$  

其中，$\mu _ { 1 }$ 表示正定矩阵 $ H $ 的最小特征值。于是，行列式 det $H _ { n - r } = \lambda _ { 1 } \lambda _ { 2 } \dotsm \lambda _ { n - r }$ 为正，所断言之结论即得证。□  

我们现在可发展一种刻画定矩阵（definite matrices）的新途径，即通过其行列式性质来表征它们。

**定理 2（G. Frobenius†）**．一个 $ n \times n $ 阶埃尔米特矩阵 $ H $ 是正定的，当且仅当它的所有顺序主子式  

$$
H { \binom { 1 } { 1 } } , \qquad H { \binom { 1 } { 1 } } , \quad 2 \biggr ) , \qquad \ldots , \qquad H { \binom { 1 } { 1 } } \quad 2 \quad \cdots \quad n \biggr ) ,\tag{2}
$$  

均为正数。

**证明**．若 $ H $ 正定，则由习题 1 可知，$ H $ 的所有主子式——特别地，其顺序主子式——均为正数。

$n \times n H > 0$



反之，设子式 (2) 均为正数。记  H _ { k } $\left( 1 \leq k \leq n \right$ )为 $ H $ 的 $k \times k$ 阶顺序主子矩阵；我们对 $ k $ 进行数学归纳法，证明矩阵  H _ { n } = H  是正定的。

首先，当  k = 1  时， $1 \times 1$ 阶矩阵  H _ { 1 }  显然是正定的。接着假设矩阵  H _ { k } \  $( 1 \leq k \leq n - 1$ )是正定的，并证明  H _ { k + 1 }  也是正定的。注意，假设  H _ { k } > 0  意味着  H _ { k }  的特征值 $\lambda$ _ { 1 } ^ { ( k ) } $\leq \lambda$ _ { 2 } ^ { ( k ) } $\leq \cdots \leq \lambda$ _ { k } ^ { ( k ) }  全为正数。若 $\hat { \nearrow }$ _ { $\times$ _ { 1 } } ^ { ( k + 1 ) } $\le \lambda$ _ { 2 } ^ { ( k ^ { - } + 1 ) } $\le \cdots \le \lambda$ _ { k + 1 } ^ { ( k + 1 ) }  是  H _ { k + 1 }  的特征值，则由定理 1 可得  

$$
\lambda _ { 1 } ^ { ( k + 1 ) } \leq \lambda _ { 1 } ^ { ( k ) } \leq \lambda _ { 2 } ^ { ( k + 1 ) } \leq \cdots \leq \lambda _ { k } ^ { ( k + 1 ) } \leq \lambda _ { k } ^ { ( k ) } \leq \lambda _ { k + 1 } ^ { ( k + 1 ) } ,
$$  

且特征值  \lambda _ { i } ^ { ( k ) } $\left( i = 1 , 2 , \ldots , k \right$ )的正性蕴含了数 $\lambda$ _ { 2 } ^ { ( k + 1 ) } , \  $\lambda$ _ { 3 } ^ { $( k \mp 1 ) } , \ \dots , \ \lambda$ _ { k + 1 } ^ { ( k + 1 ) }  的正性。此外， $\lambda$ _ { 1 } ^ { ( k + 1 ) }  亦为正数，这是因为子式 (2) 的正性意味着  

$$
\operatorname* { d e t } H _ { k + 1 } = \lambda _ { 1 } ^ { ( k + 1 ) } \lambda _ { 2 } ^ { ( k + 1 ) } \dots \lambda _ { k + 1 } ^ { ( k + 1 ) } > 0 .
$$  

因此， H _ { k + 1 }  的所有特征值均为正数，即  H _ { k + 1 }  是正定矩阵。

注意，事实上，正定矩阵的所有顺序主子矩阵都是正定的。
