习题 5．验证：元素 $\pmb { x } \in \mathcal { S }$ 关于空间 $\mathcal { S }$ 的一组基 $\{ a _ { 1 } , \ldots , a _ { n } \}$ 的表示为 $[ { \alpha } _ { 1 } \quad { \alpha } _ { 2 } \quad \ldots \quad { \alpha } _ { n } ] ^ { \mathrm { { T } } }$ 时，其长度（范数）在 $\mathcal { S } . \sqsupset$ 上的标准内积下由下式给出：

$$
\| { \pmb x } \| ^ { 2 } = \sum _ { j , k = 1 } ^ { n } \alpha _ { j } \bar { \alpha } _ { k } ( { \pmb a } _ { j } , { \pmb a } _ { k } )\tag{4}
$$

长度（即范数）为 1 的元素 $\pmb { x } \in \pmb { \mathcal { U } }$ 称为**归一化元素**（或单位元素）。显然，任一非零元素 $ x $ 均可通过过渡到元素 $ \lambda x $ 实现归一化，其中 $\lambda = 1 / \| { \pmb x } \|$。

如下不等式刻画了酉空间中任意两个元素的范数与内积之间的关系，称为**（广义）柯西–施瓦茨不等式**（Cauchy–Schwarz inequality），习题 2.5.4 即为其在实欧几里得空间 $ \mathbb{R}^n $ 中的特例。

**定理 1．** 若 $ x, y $ 是一个酉空间中的元素，则

$$
| ( \mathbf { x } , \mathbf { y } ) | \leq \| \mathbf { x } \| \ \| \mathbf { y } \| .\tag{5}
$$

**证明．** 令 $\alpha = - ( y , x ) , \beta = ( x , x )$，且 ${ \pmb z } = { \pmb { \alpha } } { \pmb x } + { \pmb \beta } { \pmb y }$。为证等价不等式 $| \alpha | ^ { 2 } . \le \beta ( y , y ) .$，我们利用性质 12 进行计算：

$$
( z , z ) = \alpha ( { \bf x } , \alpha x + \beta y ) + \beta ( y , \alpha x + \beta y ) .
$$

再结合性质 I1 及习题 3(a)，可得

$$
0 \leq \lvert \alpha \rvert ^ { 2 } ( x , x ) + \alpha \bar { \beta } ( x , y ) + \bar { \alpha } \beta ( y , x ) + \lvert \beta \rvert ^ { 2 } ( y , y ) .
$$

回代 $ \alpha $ 与 $\beta ,$ 的定义，上式即化为

$$
0 \leq \beta ( - | \alpha | ^ { 2 } + \beta ( y , y ) ) .
$$  

若  \beta = 0 . ，则  { $\pmb x } = { \pmb \theta }$ ，且式 (5) 显然成立。若 $\beta > 0$ ，则 $| \alpha | ^ { 2 } \le \beta ( y , y$ ) 。  

**习题 6.** 验证：当 $ \mathbf{x} $ 与 $ \mathbf{y} $ 均非零时，式 (5) 中等号成立当且仅当 $\pmb { x } = \lambda \mathbf { y }$ ，其中 $\lambda \in \mathbb { C }  $。 □  

接下来定义欧几里得空间  \pmb { $\mathcal { O } } ,$ 中两个非零元素 $ \mathbf{x} $ 与 $ \mathbf{y} $ 之间的夹角 $ \theta $。我们首先回顾：在具有通常标量积（即内积）的 $\mathcal { E } = \mathbb { R } ^ { 3 }  $ 中，有  

$$
\cos \theta = { \frac { ( \mathbf { x } , \mathbf { y } ) } { \left\| \mathbf { x } \right\| \left\| \mathbf { y } \right\| } } , \qquad 0 \leq \theta \leq \pi .\tag{6}
$$  

将此推广，我们定义欧几里得空间  \pmb { $\mathcal { E } } = \mathcal { S } ( \mathbf { \theta } , \mathbf { \alpha }$ )中任意两个非零向量 $ \mathbf{x} $ 与 $ \mathbf{y} $ 之间的夹角 $\pmb \theta$ 由式 (6) 给出。注意，由于柯西–施瓦茨不等式，式 (6) 右端表达式的绝对值不超过 1，因此该余弦值存在。此外，该定义是唯一的；特别地，若将 $\theta$ 中的 $ \mathbf{x} $、$ \mathbf{y} $ 分别替换为 $ \alpha \mathbf{x} $ 与 $\beta \mathbf { y }$ ，其中 $ \alpha $ 为任意正实数 $\alpha , \beta .$ ，则 $ \cos $\theta  的值保持不变。
