**定理 1（A. M. 李雅普诺夫†）**：设 $ A $、$W \in \mathbb { C } ^ { n \times n }$，且 $ W $ 为正定矩阵。

（a）若 $ A $ 是稳定的，则方程  

$$
A H + H A ^ { * } = W\tag{3}
$$  

存在唯一解矩阵 $ H $，且 $ H $ 为负定矩阵。

（b）若存在负定矩阵 $ H $ 满足方程（3），则 $ A $ 是稳定的。

证明. (a) 设 $ A $ 是稳定的。则 $ A $ 与 $ \text{$- A ^ { * }$} $ 显然没有公共特征值，因此定理 12.3.2 推出方程 (3) 的解存在且唯一。我们可利用定理 12.3.3 将方程 (1) 的解 $ H $ 显式地表为如下形式：  

$$
\text{$$
 $H = - \int$ _ { 0 } ^ { $\infty } e ^ { A t } W e ^ { A ^ { \ast } t } d t .$ 
$$}
$$
