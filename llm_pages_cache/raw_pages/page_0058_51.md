注意：这些矩阵在仅使用初等行变换的前提下，无法进一步化简为更简单的形式。然而，若同时允许初等列变换，则可能实现进一步的化简，如下一命题所示。此处仍略去详细证明。

**定理 2**．任一非零的 $ m \times n $ 矩阵，均可通过一系列初等行变换与初等列变换，化为如下形式之一的 $ m \times n $ 矩阵：

$$

[ I _ { m } 0 ] , \quad { \binom { I _ { n } } { 0 } } , \quad { \binom { I _ { r } } { 0 } } , \quad I _ { n }\tag{8}
$$


回顾初等变换与初等矩阵之间的对应关系，并结合式（6）与式（7），我们由定理 2 可推出下述结论：

**定理 3**．设 $ A $ 为一个 $ m \times n $ 矩阵，则存在有限个初等矩阵  E _ { 1 } , E _ { 2 } $, \dots , E$ _ { k + s } ，使得

$$
E _ { k } E _ { k - 1 } \cdots E _ { 1 } A E _ { k + 1 } E _ { k + 2 } \cdots E _ { k + s }\tag{9}
$$  

是式 (8) 中的矩阵之一。

由于初等矩阵均为非奇异矩阵（参见习题 1），其乘积亦为非奇异矩阵；因此，式 (9) 中的矩阵可表为  P A Q  的形式，其中 $ P $ 与  Q  均为非奇异矩阵。这一观点的重要性足以使其成为一个正式命题。

**推论 1.** 对任意 $ m \times n $ 矩阵 $ A $，均存在一个 $ m \times m $ 非奇异矩阵  P  与一个 $ n \times n $ 非奇异矩阵  Q ，使得 $ PAQ $ 是式 (8) 中的某一个矩阵。

现在考虑所有非零的 $ m \times n $ 矩阵所构成的集合（其中 $ m $ 与 $ n $ 固定）。由于式 (8) 所列各类矩阵的总数严格有限，故必存在大量互不相同的矩阵，它们均以式 (8) 中的同一个矩阵为其相抵标准形（即“约化形式”）。
