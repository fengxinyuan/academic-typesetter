推论 1．多项式 $a ( \lambda )$ 关于单位圆是稳定的，当且仅当矩阵 $\check { B }$ 是正定的（即 $i f$）。

## 13.6 实多项式的摄动

设 $a ( \lambda )$ 是一个次数为 $ l $ 的实系数多项式。本节关注的是：将 $a ( \lambda )$ 的系数施以纯虚数形式的微小扰动后所产生的影响。特别地，我们将研究原多项式与扰动后多项式关于实轴的惯性之间的关系。这些结果将在后续章节中用于导出实多项式稳定性的判据。

本节的主要结果首先给出，随后被用来为若干经典稳定性判据提供一种统一的处理方法。

定理 1（P. Lancaster 与 M. Tismenetsky†）．设 $\begin{array} { r } { a ( \lambda ) = \sum _ { i = 0 } ^ { l } a _ { i } \lambda ^ { i } } \end{array}$、$( a _ { l } \neq 0 )$ 与 $\begin{array} { r } { \dot { b } ( \lambda ) = \sum _ { i = 0 } ^ { l - 1 } b _ { i } \lambda ^ { i } } \end{array}$ 均为实系数多项式。记 $\tilde { a } ( \lambda ) = a ( \lambda ) + i b ( \lambda )$。若 Bezout 矩阵 $\pmb { { \cal B } } = \mathbf { B e z } ( a , b )$ 非奇异，即 $i f a ( \lambda )$，且 $ b(\lambda) $ 与 $ a(\lambda) $ 互素，则

$$
\delta ^ { \prime } ( \tilde { a } ) = 0\tag{1}
$$  

以及  

$$
\pi ^ { \prime } ( a ) \leq \pi ^ { \prime } ( { \tilde { a } } ) = \nu ( B ) , \qquad \nu ^ { \prime } ( a ) \leq \nu ^ { \prime } ( { \tilde { a } } ) = \pi ( B ) .\tag{2}
$$  

此外，式 (2) 中各处的等号均成立：$i f \delta ^ { \prime } ( a ) = 0 .$。  

该定理表明，扰动 $b ( \lambda )$ 的作用是将多项式 $a ( \lambda )$ 的所有实零点移出实轴；而扰动后多项式的特征值中，位于实轴上方与下方的个数（分别记为 $\pi ^ { \prime } ( \tilde { a } )$ 与 $\nu ^ { \prime } ( \tilde { a } )$）可通过矩阵 B 的惯性性质予以确定。  

**证明**：设 $\tilde { a } ( \lambda _ { 0 } ) = 0$，且 $\lambda _ { 0 }$ 为实数。则 $a ( \lambda _ { 0 } ) , b ( \lambda _ { 0 } )$ 均为实数，因而由 $\tilde { a } ( \lambda _ { 0 } ) = a ( \lambda _ { 0 } ) + i b ( \lambda _ { 0 } ) = 0$ 可得 $a ( \lambda _ { 0 } ) = b ( \lambda _ { 0 } ) = 0$。于是 $a ( \lambda )$ 与 $ b(\lambda) $ 具有公共零点，这与假设“B 非奇异”相矛盾。故关系式 (1) 成立。  

如前所述，贝祖矩阵 $ B $ 满足式 (13.3.22)；当 $\tilde { a } ( \lambda ) = a ( \lambda )$ 时，该式可写为 $C _ { a } ^ { * } B = B C _ { a }$，其中 $C _ { a }$ 是与 $a ( \lambda )$ 相关联的友矩阵；等价地，亦可表示为  

$$
( i C _ { a } ) ^ { * } B + B ( i C _ { a } ) = 0 .\tag{3}
$$  

此外，我们还知道（参见习题 13.3.1），$ B $ 是实对称矩阵。
