$$

$$

其中，$D = \mathrm { d i a g } [ b _ { 0 } , b _ { 1 } , . . . , b _ { l - 1 } ]$ 且  

$$
F = \left[ \begin{array} { l l l } { 0 } & { \cdots } & { 0 } \\ { \vdots } & { } & { \vdots } \\ { 0 } & { \cdots } & { 0 } \\ { i a _ { l } ^ { - 1 } } & { \cdots } & { i a _ { l } ^ { - 1 } } \end{array} \right]

将式 (4) 代入式 (3)，可得  

$$

$$

$$
