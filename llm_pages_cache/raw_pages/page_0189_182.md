后续讨论中，正半定（或正定）矩阵 $ H $ 的唯一正半定（或正定）平方根记作  H ^ { 1 / 2 } 。综上所述，我们注意到： $\lambda \in \sigma ( H ^ { 1 / 2 }$ )当且仅当 $\lambda ^ { 2 } \in \sigma ( H$ )，且  H ^ { 1 / 2 }  与 $ H $ 的相应特征子空间重合。正半定矩阵平方根的概念使我们得以引入矩形矩阵的一种谱刻画。

考虑任意一个 $ m \times n $ 矩阵 $ A $。$ n \times n $ 矩阵 $A ^ { * } A$ （通常）是半正定的（参见习题 5.3.5）。因此，由定理 1 可知，矩阵 $A ^ { * } A$ 存在一个半正定平方根 $H _ { 1 }$，使得 $A ^ { * } A = H _ { 1 } ^ { 2 }$。矩阵 $H _ { 1 } = ( A ^ { * } A ) ^ { 1 / 2 }$ 的特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ 称为（一般为长方的）矩阵 $ A $ 的奇异值 $s _ { 1 } , s _ { 2 } , \ldots , s _ { n }$。于是，对 $i = 1 , 2 , \ldots , n ,$  

$$
s _ { i } ( A ) \triangleq \lambda _ { i } ( ( A ^ { * } A ) ^ { 1 / 2 } ) .
$$  

显然，一个矩阵的奇异值是非负实数。

定理 2．矩阵 $( A ^ { * } A ) ^ { 1 / 2 }$ 与 $( A A ^ { * } ) ^ { 1 / 2 }$ 的非零特征值完全相同。

证明．首先我们注意到，只需对矩阵 $A ^ { * } A$ 与 $A A ^ { * }$ 验证本定理的断言即可。此外，我们选取 $A ^ { * } A$ 关于特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ 的一组特征向量 ${ \mathfrak { x } } _ { 1 } , { \mathfrak { x } } _ { 2 } , \ldots , { \mathfrak { x } } _ { n }$，使得 $\{ \pmb { x } _ { 1 } , \pmb { x } _ { 2 } , \ldots , \pmb { x } _ { n } \}$ 构成 ${ \mathcal { F } } ^ { n }$ 中的一组标准正交基。于是有  

$$
( A ^ { * } A { \bf x } _ { i } , { \bf x } _ { j } ) = \lambda _ { i } ( { \bf x } _ { i } , { \bf x } _ { j } ) = \lambda _ { i } \delta _ { i j } , \qquad 1 \leq i , j \leq n .
$$  

另一方面，$( A ^ { * } A x _ { i } , x _ { j } ) = ( A x _ { i } , A x _ { j } )$，比较可知 $( A x _ { i } , A x _ { i } ) = \lambda _ { i } , i = 1 , 2 , . . . , \dot { n } .$。因此，$A { \boldsymbol { \mathbf { \mathit { x } } } } _ { i } = \theta \left( 1 \leq i \leq n \right)$ 当且仅当 $\lambda _ { i } = 0$。由于  

$$
A A ^ { * } ( A x _ { i } ) = A ( A ^ { * } A x _ { i } ) = \lambda _ { i } ( A x _ { i } ) , \qquad 1 \leq i \leq n ,
$$

前述评注表明：对于 $\lambda _ { i } \neq 0$，向量 $A \mathbf { x } _ { i }$ 是 $A A ^ { * }$ 的一个特征向量。因此，若非零标量 $\lambda _ { i } \in \sigma ( A ^ { * } A )$ 与特征向量 $\mathbf { \lambda } _ { \mathbf { \lambda } _ { \mathbf { \lambda } } } \mathbf { \hat { x } } _ { i } ,$ 相关联，则 $\lambda _ { i } \in \sigma ( A A ^ { * } )$，且该特征值与特征向量 Ax 相关联。特别地，有 $A { \mathfrak { x } } _ { i }$ ⊆ $\sigma ( A ^ { * } A ) \subset \sigma ( A A ^ { * } )$。反向包含关系可通过交换 A 与 $A ^ { * }$ 的角色而得到。
