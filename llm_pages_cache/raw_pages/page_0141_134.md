**习题 1.** 描述习题 4.2.1 中定义的变换 $ T $ 的像，并确定其秩。

**解.** 将 $ T $ 表示为

$$

{ \begin{array} { r } { \left[ x _ { 2 } + x _ { 3 } \right] } \\ { x _ { 1 } + x _ { 2 } } \\ { x _ { 1 } } \\ { x _ { 1 } - x _ { 2 } } \end{array} } = x _ { 1 } { \left[ \begin{array} { l } { 0 } \\ { 1 } \\ { 1 } \\ { 1 } \\ { 1 } \end{array} \right] } + x _ { 2 } { \left[ \begin{array} { l } { 1 } \\ { 1 } \\ { 0 } \\ { - 1 } \end{array} \right] } + x _ { 3 } { \left[ \begin{array} { l } { 1 } \\ { 0 } \\ { 0 } \\ { 0 } \end{array} \right] } ,
$$


$$
\operatorname { r a n k } T \triangleq \mathrm { d i m } ( \operatorname { I m } T ) .
$$

$T ( \mathcal { S } _ { 1 } ) \mathcal { S } _ { 1 } T \mathcal { S } _ { 2 } \mathcal { F } T _ { A } { \mathcal { F } } ^ { n } { \mathcal { F } } ^ { m } T _ { A } { \mathcal { F } } ^ { m } T \in \mathcal { L } ( \mathbb { R } ^ { 3 } , \mathbb { R } ^ { 4 } ) _ T$



不难看出，$\operatorname{Im} \text{ $T$ }$ 与 $\operatorname{span} \text{ $\{ $\mathfrak { v }$ _ { 1 } $, \mathfrak { v }$ _ { 2 } $, \mathfrak { v }$ _ { 3 } \}$ }$ 重合，其中 $\text{$\mathfrak { v } _ { 3 } $= [ 0 \mathrm { ~  ~ \mathsf ~ { ~ 1 ~ } ~ } 1 \mathrm { ~  ~ \mathsf ~ { ~ 1 ~ } ~ } ] ^ { \mathrm { T } } , \ \mathfrak { v }$ _ { 2 } $= [ 1 \mathrm { ~  ~ \mathsf ~ { ~ 1 ~ } ~ } 0 \mathrm { ~  ~ \mathsf ~ { ~ - ~ 1 ~ } ~ } ] ^ { \mathrm { T } } , \ \mathfrak { v }$ _ { 3 } $= [ 1 \mathrm { ~  ~ \mathsf ~ { ~ 0 ~ } ~ } 0 \mathrm { ~  ~ \mathsf ~ { ~ 0 ~ } ~ } ] ^ { \mathrm { T } } . }$。向量组 $\text{${ $\mathfrak { v } }$ _ { i } ( i = 1 , 2 , 3 )$}$ 线性无关，因此 $\operatorname{rank} \text{ $T = 3$ }$。

**习题 3.** 验证：对任意 $\text{$T _ { 1 } , T _ { 2 } $\in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } ) .$}$，

$$
\mathrm { I m } ( T _ { 1 } + T _ { 2 } ) \subset \mathrm { I m } T _ { 1 } + \mathrm { I m } T _ { 2 } .
$$

然后证明如下不等式：

$$
\lvert \mathrm { r a n k } \ T _ { 1 } - \mathrm { r a n k } \ T _ { 2 } \rvert \leq \mathrm { r a n k } ( T _ { 1 } + { T _ { 2 } } ) \leq \mathrm { r a n k } \ T _ { 1 } + \mathrm { r a n k } \ T _ { 2 } .
$$

**提示：** 利用习题 3.6.2；并将该结论与命题 3.8.2 的断言作比较。

**习题 4.** 设 $\text{$T _ { 1 } $\in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } )$}$ 且 $\text{$T _ { 2 } $\in \mathcal { L } ( \mathcal { S }$ _ { 2 } $, \mathcal { S }$ _ { 3 } )$}$。证明：

$$
\mathrm { I m } ( T _ { 2 } T _ { 1 } ) = T _ { 2 } ( \mathrm { I m } T _ { 1 } )
$$  

且  

$$
\mathrm { r a n k } ( T _ { 2 } T _ { 1 } ) \leq \mathrm { m i n } ( \mathrm { r a n k } T _ { 1 } , \mathrm { r a n k } T _ { 2 } ) .
$$  

提示：利用公式 (1)。将此结果与习题 3.8.5 的结论进行比较。  

线性变换的秩这一概念可采用另一种方式定义。回顾（第 4.3 节），等价类 $\mathcal { A } _ { T }$ 中的所有矩阵具有相同的秩，因此该秩可视为变换 $ T $ 本身的特征量。于是，将此特征量定义为 $ T $ 的秩是自然的。注意，这两种定义是等价的。
