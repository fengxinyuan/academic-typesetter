定理 2．任一方阵都酉相似于一个上三角矩阵。

证明．设 $ \text{$A  $\in { \mathcal { F } } ^ { n \times n } } $，并令 $ \mathcal{V} $ 为装备标准内积的 $ \text{${ $\mathcal { F } } ^ { n } } $ 维酉空间。于是，$ A $ 自然地确定了一个线性变换 $ \text{$T  $\in { \mathcal { L } } ( { \mathcal { U } }$ )$} $。由习题 4.14.6 可知，存在一条关于 $ T $ 不变的子空间链：

$$
\{ \mathbf { 0 } \} = \mathcal { U } _ { 0 } \subset \mathcal { U } _ { 1 } \subset \cdots \subset \mathcal { U } _ { n } = \mathcal { U }
$$

使得对每个 $ i $，$ \text{${ $\pmb q }$ _ { i }$} $ 的维数为 $ i $。由此可知，利用格拉姆–施密特正交化过程，可在 $ \text{${ $\mathcal { F } } ^ { n } } $ 中构造一组标准正交基 $ \text{$\{ u _ { 1 } $, \ldots , u$ _ { n } \}$} $，满足性质：$ \text{${ $\pmb u }$ _ { i } $\in \mathcal { U }$ _ { i }$} $ 且 $ \text{$\pmb { u } _ { i } $\notin \pmb { \mathcal { U } }$ _ { i - 1 }$} $ 对所有 $ \text{$i  $= 1 , 2 , \ldots , n } $ 成立。于是，该子空间链的 $ T $-不变性意味着：线性算子 $ T $ 关于这组标准正交基的矩阵表示必为上三角矩阵，记作 $ B $（参见第 4.8 节）。

但矩阵 $ A $ 恰是 $ T $ 关于 $ \text{${ $\mathcal { F } } ^ { n } } $ 的标准基（该基亦为标准正交基）的矩阵表示，因此 $ A $ 与 $ B $ 必为酉相似矩阵。

舒尔–托普利茨定理（Schur–Toeplitz theorem）在证明下一个关于正规矩阵的优美刻画中起着关键作用；事实上，它常被用作正规矩阵的定义。

**定理 3.** 一个 $ n \times n $ 矩阵 $ A $ 是正规矩阵，当且仅当  

$$
\text{$$
A A ^ { * } = A ^ { * } $A .\tag{2}$ 
$$}
$$

**证明.** 若 $ A $ 是正规矩阵，则由式 (1) 可知，存在酉矩阵 $ U $ 和对角矩阵 $ D $，使得  
$$
\text{$A = U D U ^ { \star }$}.
$$  
于是  
$$
\text{$$
A A ^ { * } = ( U D U ^ { * } ) ( U { $\bar { D } } U ^ { * } ) = U D { \bar { D } } U ^ { * } = U { \bar { D } } D U ^ { * } = ( U { \bar { D } } U ^ { * } ) ( U D U ^ { * } ) = A ^ { * } A ,$ 
$$},
$$  
故 $ A $ 满足式 (2)。

反之，设 $ \text{$A A ^ { * } = A ^ { * } A$} $，并应用定理 2。于是存在酉矩阵 $ U $ 和上三角矩阵 $ \text{$S = [ s _ { i j } ] _ { i , j = 1 } ^ { n }$} $，使得  
$$
\text{$A = U S U ^ { * }$}.
$$  
易见，$ \text{$A A ^ { * } = A ^ { * } A$} $ 当且仅当 $ \text{$S S ^ { * } = S ^ { * } S$} $。将上述等式两端取 $ (1,1) $ 元素，得

$$
| s _ { 1 1 } | ^ { 2 } + | s _ { 1 2 } | ^ { 2 } + \cdot \cdot \cdot + | s _ { 1 n } | ^ { 2 } = | s _ { 1 1 } | ^ { 2 } .
$$
