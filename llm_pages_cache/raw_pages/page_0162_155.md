习题 1．设矩阵 $\pmb { A } \in \mathcal { F } ^ { n \times n }$ 的特征向量为 $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$，分别对应于特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$。证明：由 A 的一组特征向量  

$$
x _ { j _ { 1 } } , x _ { j _ { 2 } } , \dotsc , x _ { j _ { k } } ( 1 \leq j _ { 1 } < j _ { 2 } < \dots < j _ { k } \leq n )
$$  

所生成的 $\mathcal { F } ^ { n }$ 的任一子空间都是 A-不变子空间。

习题 2．证明：分块上三角方阵  

$$
A = { \left[ \begin{array} { l l } { A _ { 1 } } & { A _ { 3 } } \\ { 0 } & { A _ { 2 } } \end{array} \right] } ,
$$  

的谱（即全体特征值构成的集合），其中 $A _ { 1 }$ 与 $A _ { 2 }$ 均为方阵，等于 $\pmb { A } _ { 1 }$ 的谱与 $A _ { 2 }$ 的谱的并集。

习题 3．验证：矩阵 $\pmb { A } \in \mathcal { F } ^ { n \times n }$ 是奇异矩阵当且仅当它具有零特征值。

习题 4．设 $\lambda \in \sigma ( A ) .$，A 为非奇异矩阵，且 $A \mathbf { x } = \lambda \mathbf { x } , \mathbf { x } \neq \pmb { 0 } .$。证明：$\lambda ^ { - 1 }$ 是 $A ^ { - 1 }$ 的一个特征值，对应的特征向量为 x。□

## 4.11 特征多项式

我们现在将行列式理论的相关概念应用于求解 n 阶方阵 $A \in { \mathcal { F } } ^ { n \times n }$ 的特征值问题。正如线性变换情形下（参见习题 4.9.3）所示，容易证明：$\lambda \in \sigma ( A )$ 当且仅当矩阵 $\lambda I - A$ 不可逆；等价地（定理 2.6.2），

$n \times n$



$$
\operatorname* { d e t } ( \lambda I - A ) = 0 .\tag{1}
$$  

现在注意到，式 (1) 左端的表达式是关于 $\lambda$ 的一个 n 次首一多项式。  

$$
\operatorname* { d e t } ( \lambda I - A ) = c _ { 0 } + c _ { 1 } \lambda + \cdot \cdot \cdot + c _ { n - 1 } \lambda ^ { n - 1 } + c _ { n } \lambda ^ { n } , \qquad c _ { n } = 1 .\tag{2}
$$  

式 (2) 中的多项式 $\begin{array} { r } { c ( \lambda ) \triangleq \sum _ { i = 0 } ^ { n } c _ { i } \lambda ^ { i } } \end{array}$ 称为矩阵 A 的特征多项式。将上述概念整合，即得定理 1。  

**定理 1.** 标量 $\lambda \in \mathcal { F }$ 是矩阵 $\pmb { A } \in \mathcal { F } ^ { n \times n }$ 的一个特征值，当且仅当 λ 是 A 的特征多项式的零点。  

该结果的意义在于：求矩阵的特征值这一问题，被归约为求一个标量多项式的零点，从而与（同时）求其特征向量的问题相分离。
