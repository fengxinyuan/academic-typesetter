鉴于习题 3，自然会提出如下问题：$\mathcal { S }$ 的所有基是否均含有相同数目的元素？答案是肯定的。  

**定理 1.** 任一有限维线性空间 $\mathcal { S }$ 的所有基均含有相同数目的元素。  

**证明.** 设 $\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \}$ 与 $\{ \pmb { c } _ { 1 } , \pmb { c } _ { 2 } , \dots , \pmb { c } _ { m } \}$ 是 $\mathcal { S }$ 中的两个基。我们的目标是证明 $n = m .$。反设 $n < m$。  

首先，由于 $\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \}$ 构成 $\mathcal { S }$ 的一个基，故该组向量线性无关；其次，$\mathcal { S }$ 中的每个元素（特别地，每个 $\mathfrak { c } _ { j } ( 1 \le j \le m )$）均可表为 ${ \bf b } _ { i } ( i = 1 , 2 ,$、$\cdots , n )$ 的线性组合，即  

$$
\pmb { c } _ { j } = \sum _ { i = 1 } ^ { n } \beta _ { i j } \pmb { b } _ { i } , 1 \leq j \leq m .\tag{4}
$$
