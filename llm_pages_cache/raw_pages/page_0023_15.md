转置运算与复共轭运算结合，引出矩阵 $ A $ 的一个重要概念——共轭转置矩阵 $A ^ { * }$，其定义为 $\mathbf { \bar { \Sigma } } _ { A ^ { * } } \triangleq \mathbf { \bar { A } } ^ { \mathsf { T } }$。更具体地，对 $A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n }$，

$$
A ^ { * } \triangleq \left[ \begin{array} { c c c c } { \overline { { a } } _ { 1 1 } } & { \overline { { a } } _ { 2 1 } } & { \cdot \cdot \cdot } & { \overline { { a } } _ { m 1 } } \\ { \overline { { a } } _ { 1 2 } } & { \overline { { a } } _ { 2 2 } } & { \cdot \cdot \cdot } & { \overline { { a } } _ { m 2 } } \\ { \vdots } & { \vdots } & & { \vdots } \\ { \overline { { a } } _ { 1 n } } & { \overline { { a } } _ { 2 n } } & { \cdot \cdot \cdot } & { \overline { { a } } _ { m n } } \end{array} \right] .
$$  

显然，对任一实矩阵 $ A $，转置与共轭转置这两个概念是等价的。

习题 9．验证下列矩阵  

$$
A = { \left[ \begin{array} { l l } { 2 \ - 3 } \\ { 0 } & { 1 } \\ { 1 } & { 0 } \end{array} \right] } \qquad { \mathrm { a n d } } \qquad B = { \left[ \begin{array} { l l } { i } & { \quad - 3 } \\ { 0 } & { 2 i + 1 } \end{array} \right] }
$$  

的共轭转置分别为  

$$
A ^ { * } = { \left[ \begin{array} { l l l } { 2 } & { 0 } & { 1 } \\ { - 3 } & { 1 } & { 0 } \end{array} \right] } = A ^ { \operatorname { T } } \qquad { \mathrm { a n d } } \qquad B ^ { * } = { \left[ \begin{array} { l l } { - i } & { 0 } \\ { - 3 } & { - 2 i + 1 } \end{array} \right] } ,
$$  

（依次对应）。

习题 10．（参见习题 2。）证明：$( A ^ { * } ) ^ { * } = A , ( \alpha A ) ^ { * } = \bar { x } A ^ { * } , ( A + B ) ^ { * } = A ^ { * } + B ^ { * } , ( A B ) ^ { * } = B ^ { * } A ^ { * }$  □  

借助共轭转置的概念，可对埃尔米特矩阵给出一个优美的刻画。

习题 11．证明：一个方阵 $ A $ 是埃尔米特矩阵（定义见第 1.1 节），当且仅当 $A = A ^ { * }$。

习题 12．证明：对任意矩阵 $ A $，矩阵 $A A ^ { * }$ 与 $A ^ { * } A$ 均为埃尔米特矩阵。

习题 13．验证：对任意方阵 $ A $，矩阵 $A + A ^ { * }$ 与 $\mathfrak { i } ( A - A ^ { * } )$ 均为埃尔米特矩阵。

注意：所有 $ 1 \times 1 $ 复矩阵（即仅含一个标量元素的矩阵）恰好一一对应于全体复数集合。进一步地，在该对应关系下，$1 \times 1$ 类埃尔米特矩阵恰好对应于实数集。更一般地，将埃尔米特矩阵嵌入到 $\mathbb { C } ^ { n \times n }$ 中，可视为实数集 $ \mathbb{R} $ 自然嵌入复数集 $ \mathbb{C} $ 的推广。特别地，请注意如下复方阵的表示形式与复数熟知的笛卡尔分解之间的类比关系。
