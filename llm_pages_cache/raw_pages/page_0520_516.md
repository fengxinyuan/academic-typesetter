## 14.7 一个表示定理  

前文（定理 14.2.2）已指出：对任一矩阵多项式 $L ( \lambda )$（满足 $\det $L _ { l } $\neq 0$ )$$），其任意标准三元组均可用于显式地表示其（有理）预解函数 $L ( \lambda ) ^ { - 1 }$。本节则进一步寻求 $L ( \lambda )$ 本身的表示，即系数矩阵 $L _ { 0 } , L _ { 1 } , \ldots , L _ { t }$ 关于某一标准三元组的表达式。我们将证明：特别地，本节所给出的这些表示，实质上推广了方阵经相似变换化为若尔当标准形这一经典结果。

**定理 1.** 设 $ (U, T, V) $ 是矩阵多项式 $L ( \lambda )$ 的一个标准三元组（定义见 $E q .$（14.1.2））。则 $L ( \lambda )$ 的各系数具有如下表示：  

$$
L _ { l } = ( U T ^ { l - 1 } V ) ^ { - 1 } $,\tag{1}$ 
$$
$$


$$
[ L _ { 0 } \quad L _ { 1 } \quad \cdots \quad L _ { l - 1 } ] = - L _ { l } U T ^ { l } \left[ \begin{array} { c } { { U } } \\ { { U T } } \\ { { \vdots } } \\ { { U T ^ { l - 1 } } } \end{array} \right] ^ { - 1 } ,\tag{2}
$$  

以及  

$$
\left[ \begin{array} { c } { L _ { 0 } } \\ { L _ { 1 } } \\ { \vdots } \\ { L _ { l - 1 } } \end{array} \right] = - \left[ V \quad T V \quad . . . \quad T ^ { l - 1 } V \right] ^ { - 1 } T ^ { l } V L _ { l } .\tag{3}
