于是，依据定理 7.5.1，$ A $ 与 $ B $ 相似当且仅当 $ \lambda I - A $ 与 $ \lambda I - B $ 具有相同的不变因子（invariant polynomials）。

**证明.** 首先假设 $ A $ 与 $ B $ 相似。则存在一个非奇异矩阵 $\pmb { S } \in \mathcal { F } ^ { n \times n }$，使得 $A = S B S ^ { - 1 }$；从而  

$$
\lambda I - A = S ( \lambda I - B ) S ^ { - 1 } ,
$$  

这表明 $\lambda I - A$ 与 $\lambda I - B$ 等价。再由定理 7.5.1 的推论可知，$ \lambda I - A $ 与 $ \lambda I - B $ 具有相同的不变因子。

反之，假设 $ \lambda I - A $ 与 $ \lambda I - B $ 具有相同的不变因子，则它们等价，故存在两个幺模矩阵多项式 $ P(\lambda) $ 与 $ Q(\lambda) $，使得  

$$
P ( \lambda ) ( \lambda I - A ) Q ( \lambda ) = \lambda I - B .
$$  

于是，定义 $M ( \lambda ) = [ P ( \lambda ) ] ^ { - 1 }$，我们注意到 $ M(\lambda) $ 是一个矩阵多项式，且  

$$
M ( \lambda ) ( \lambda I - B ) = ( \lambda I - A ) Q ( \lambda ) .
$$

现在，将 $ M(\lambda) $ 在左侧除以 $\lambda I - A$，将 $ Q(\lambda) $ 在右侧除以 $\lambda I - B$，得到  

$$
\begin{array} { r } { M ( \lambda ) = ( \lambda I - A ) S ( \lambda ) + M _ { 0 } , } \\ { Q ( \lambda ) = R ( \lambda ) ( \lambda I - B ) + Q _ { 0 } , } \end{array}\tag{1}
$$  

其中 ${ \bf \nabla } \cdot { \cal M } _ { 0 } , { \cal Q } _ { 0 }$ 与 $ \lambda $ 无关。接着，将上述结果代入前一方程，可得  

$$
( ( \lambda I - \mathit { A } ) S ( \lambda ) + M _ { 0 } ) ( \lambda I - \mathit { B } ) = ( \lambda I - \mathit { A } ) ( R ( \lambda ) ( \lambda I - \mathit { B } ) + \mathcal { Q } _ { 0 } ) ,
$$  

从而  

$$
( \lambda I - { \cal A } ) \{ S ( \lambda ) - R ( \lambda ) \} ( \lambda I - { \cal B } ) = ( \lambda I + { \cal A } ) Q _ { 0 } - M _ { 0 } ( \lambda I - \dot { \cal B } ) .
$$  

但这是一个矩阵多项式恒等式；而右边多项式的次数为 1，因此必有 $S ( \lambda ) \equiv R ( \lambda )$。（否则左边矩阵多项式的次数至少为 2。）于是  

$$
M _ { 0 } ( \lambda I - B ) = ( \lambda I - A ) Q _ { 0 } ,\tag{2}
$$  

从而  

$$
M _ { 0 } = Q _ { 0 } , \qquad M _ { 0 } B = A Q _ { 0 } , \qquad \mathrm { a n d } \qquad M _ { 0 } B = A M _ { 0 } .\tag{3}
$$  

现在我们只需证明 $M _ { 0 }$ 是非奇异的，即可完成证明。
