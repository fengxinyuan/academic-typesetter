习题 1. 求多项式 $p ( \lambda )$ 除以 $= \lambda ^ { 3 } + \lambda + 2  { \mathbf { b } }  { \mathbf { y } } q ( \lambda ) = \lambda ^ { 2 } + \lambda + 1$ 所得的商与余式。  

答：商为 $d ( \lambda ) = \lambda - 1 , r ( \lambda ) = \lambda + 3 .$。  

习题 2. 证明：$p ( \lambda )$ 整除 $q ( \lambda )$，且同时 $q ( \lambda )$ 整除 $p ( \lambda )$，当且仅当 $p ( \lambda ) = c q ( \lambda )$，其中 $c \in { \mathcal { F } } , \ \sqsupset$。  

设 $p _ { 1 } ( \lambda ) , p _ { 2 } ( \lambda ) , \ldots , p _ { k } ( \lambda ) .$ 与 $ q(\lambda) $ 是定义在 ${ \mathcal { F } } ,$ 上的多项式，则称多项式 $q ( \lambda )$ 为 $p _ { i } ( \lambda ) ( i = 1 , 2 , \ldots , k )$ 的一个公因式，若它整除每一个多项式 $p _ { i } ( \lambda )$。$p _ { i } ( \lambda ) ( i = 1 , 2 , \ldots , k )$ 的一个最大公因式（greatest common divisor），记作 $d ( \lambda )$，简记为 ${ \bf g . c . d . } \{ p _ { i } ( \lambda ) \}$，是指满足如下条件的公因式：任何其他公因式均整除该多项式。为避免不必要的复杂性，在本节余下部分（除非另有说明），我们总假设所考虑多项式的首项系数（即其最高次幂前的系数）等于 1；这类多项式称为首一多项式（monic polynomial）。  

定理 2. 对任意一组定义在 $\mathcal { F } ,$ 上的非零多项式，存在唯一的一个最大公因式。  

该结论可直接由最大公因式的定义推出。若一组多项式的最大公因式为 1，则称这些多项式互素（relatively prime）。  

习题 3. 验证多项式 $p ( \lambda ) = \lambda ^ { 2 } + 1$ 与 $q ( \lambda ) = \lambda ^ { 3 } + 1$ 互素。

习题 4．构造一组三个两两互素的多项式，使得其中任意两个均不互素。□

定理 3．若 $d ( \lambda )$ 是 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda ) _ { : }$ 的最大公因式，则存在多项式 $c _ { 1 } ( \lambda )$ 和 $c _ { 2 } ( \lambda )$，使得  

$$
c _ { 1 } ( \lambda ) p _ { 1 } ( \lambda ) + c _ { 2 } ( \lambda ) p _ { 2 } ( \lambda ) = d ( \lambda ) .
$$  

特别地，若 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda )$ 互素，则存在多项式 $c _ { 1 } ( \lambda )$ 和 $c _ { 2 } ( \lambda )$，使得  

$$
c _ { 1 } ( \lambda ) p _ { 1 } ( \lambda ) + c _ { 2 } ( \lambda ) p _ { 2 } ( \lambda ) = 1\tag{3}
$$  

该重要定理需更详尽的证明；为简洁起见，此处略去论证过程。

设 $\begin{array} { r } { \lambda _ { 1 } \in \mathcal { F } . \mathrm { ~ H f ~ } p ( \lambda _ { 1 } ) = \sum _ { i = 0 } ^ { l } p _ { i } \lambda _ { 1 } ^ { i } = 0 , } \end{array}$，则 $\lambda _ { 1 }$ 是 $p ( \lambda )$ 的一个零点，亦即方程 $\begin{array} { r } { p ( \lambda ) = 0 . } \end{array}$ 的一个根。代数学基本定理刻画了复数域 C 上多项式的零点。
