**定理 2（格拉姆判据，Gram’s criterion）**：设  \mathbf { x } _ { 1 } $, \ldots , \mathbf { x }$ _ { r }  是一个酉空间（unitary space）中的向量，则它们线性无关当且仅当其格拉姆行列式 $g ( \pmb { x }$ _ { 1 } $, \ldots , \pmb { x }$ _ { r } )  为正；线性相关当且仅当该格拉姆行列式为零。
