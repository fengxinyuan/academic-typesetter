习题 5．设 $ (X, T) $ 如习题 4 所定义，且 $ R $、$ S $ 分别为尺寸为 $ p \times p $ 与 $ n \times n $ 的非奇异矩阵。证明：数对

$$
( X , T ) \qquad \mathrm { a n d } \qquad ( R X S , S ^ { - 1 } T S )
$$

具有相同的指数，且其不可观子空间维数相同（在可观测数对的情形下，该维数可为零）。注意：利用定理 4.3.1 与 4.3.2 可知，本习题表明可观测性可被理解为一对线性变换所具有的性质，而 $ X $ 与 $ T $ 正是这对线性变换在某组基下的矩阵表示。

下一个结果是 $ (X, T) $ 可观测性通常采用的表述形式。注意：该命题中并未显式出现数对 $ (X, T) $ 的指数值。

定理 1．阶数为 $ p $ 的容许数对 $ (X, T) $ 是可观测的，当且仅当

$\mathbf { x ^ { \mathrm { { T } } } } T , ( \mathbf { x } ^ { \mathrm { { T } } } , T ) s = 1 p s , { \boldsymbol { \rho } } \neq \mathbf { 0 } . ( X , T ) p r \times p . p \times r , ( X , T ) r \times r p \times p , T ( X , T ) ( X , T ) ( X , T )$



$$
{ \mathrm { r a n k } } { \left[ \begin{array} { c } { X } \\ { X T } \\ { \vdots } \\ { X T ^ { p - 1 } } \end{array} \right] } = p .\tag{3}
$$  

**证明**．若条件 (3) 成立，则在上述记号下，核空间为  \operatorname{ker}$ 

$$
\begin{bmatrix} C^\top & (A^\top C^\top)^\top & \cdots & ((A^\top)^{n-1} C^\top)^\top \end{bmatrix}
$$

^ $\top = \{0\} 。因此，不可观子空间是平凡的，故 $ (C, A) $ 是一个可观测对。

反之，若 $ (C, A) $ 可观测，则由习题 3 可知，指数 $ s $ 不可能超过 $ n $。于是  \operatorname{rank}$ 

$$
\begin{bmatrix} C^\top & (A^\top C^\top)^\top & \cdots & ((A^\top)^{n-1} C^\top)^\top \end{bmatrix}
$$

^ $\top = n $$ ，而这正意味着秩条件 (3) 成立。■  

本节迄今所述结果具有对偶形式。讨论本可始于考察 $ \mathbb{R}^n $（或 $ \mathbb{C}^n $）中的子空间族  

$$
R _ { 1 } = { \mathrm { I m ~ } } X ^ { * } , \qquad R _ { 2 } = { \mathrm { I m ~ } } X ^ { * } + { \mathrm { I m ~ } } T ^ { * } X ^ { * } ,
$$  

并注意到一个平凡事实：  

$R _ { 1 } \subset R _ { 2 } \subset \mathbb { C } ^ { p } .$  

但存在一种更简洁的方式。定义  

$\begin{array} { r } { R _ { j } = \sum _ { k = 1 } ^ { j } \operatorname { I m } ( ( T ^ { * } ) ^ { k - 1 } X ^ { * } ) } \end{array}$  

并观察到  

$$
R _ { j } = \operatorname { I m } [ X ^ { * } \quad T ^ { * } X ^ { * } . \cdot T ^ { * j - 1 } X ^ { * } ] .\tag{4}
$$  

于是命题 5.8.1 表明  

$$
\begin{array} { r } { \ker \left[ \begin{array} { c } { X } \\ { X T } \\ { \vdots } \\ { X T ^ { j - 1 } } \end{array} \right] \oplus \mathrm { I m } [ X ^ { * } \quad T ^ { * } X ^ { * } \cdot \cdot \cdot T ^ { * j - 1 } X ^ { * } ] = \mathbb { C } ^ { p } . } \end{array}
$$  

从而我们得到如下关系：  

$$
K _ { j } \oplus R _ { j } = \mathbb { C } ^ { p }\tag{5}
