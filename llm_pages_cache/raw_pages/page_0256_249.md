此外，乘积  

$$
A ( \lambda ) B ( \lambda ) = A _ { 0 } B _ { 0 } + \lambda ( A _ { 1 } B _ { 0 } + A _ { 0 } B _ { 1 } ) + \dots + \lambda ^ { l + m } A _ { l } B _ { m }
$$  

的次数不超过 $l + m$。显然，若 $A ( \lambda )$ 或 $B ( \lambda )$ 中至少有一个是首项系数可逆的矩阵多项式，则该乘积的次数恰好为 $l + m$。

设 $B ( \lambda )$ 是一个 $ m $ 次矩阵多项式，且其首项系数可逆；又设存在矩阵多项式 $Q ( \lambda ) , R ( \lambda )$，使得 $R ( \lambda ) \equiv 0$，或 $R ( \lambda )$ 的次数小于 $ m $，且满足  

$$
A ( \lambda ) = Q ( \lambda ) B ( \lambda ) + R ( \lambda ) .
$$  

在此情形下，称 $Q ( \lambda )$ 为 $A ( \lambda )$ 除以 $ B(\lambda) $ 所得的右商，而 $R ( \lambda )$ 则为 $A ( \lambda )$ 除以 $B ( \lambda )$ 所得的右余式。类似地，若  

$$
A ( \lambda ) = B ( \lambda ) { \widetilde Q } ( \lambda ) + { \widetilde R } ( \lambda )
$$  

且 $\widetilde { R } ( \lambda ) \equiv 0$，或 $R ( \lambda )$ 的次数小于 $ m $，则称 $\tilde { Q } ( \lambda )$ 与 $\widetilde { R } ( \lambda )$ 分别为 $A ( \lambda )$ 除以 $B ( \lambda )$ 所得的左商与左余式。

若 $A ( \lambda )$ 除以 $B ( \lambda )$ 所得的右余式为零矩阵，则称 $Q ( \lambda )$ 为 $A ( \lambda )$ 关于 $B ( \lambda )$ 的右因子。类似地，可定义 $A ( \lambda )$ 关于 $B ( \lambda )$ 的左因子。

为了使这些形式化定义具有实际意义，我们必须证明：给定此 $A ( \lambda )$ 与 $B ( \lambda )$，确实存在如上所定义的商与余式。完成这一存在性证明后，我们还将进一步证明该商与余式亦是唯一的。下一判定理的证明，是标量多项式除法算法的一个推广。

**定理 1.** 设 $\begin{array} { r } { A ( \lambda ) = \sum _ { i = 0 } ^ { l } \lambda ^ { i } A _ { i } , B ( \lambda ) = \sum _ { i = 0 } ^ { m } \lambda ^ { i } B _ { i } } \end{array}$ 分别为次数为 $ l $ 与 $ m $ 的 $n \times n$ 矩阵多项式，且满足 $ \det $B _ { m } $\neq 0$ 。则在以 $B ( \lambda )$ 为除式的右除法下，$A ( \lambda )$ 存在右商与右余式；类似地，在左除法下亦存在左商与左余式。

**证明.** 若 $l < m$，则只需取 $Q ( \lambda ) = \theta$ 与 $R ( \lambda ) = A ( \lambda )$，即可得所求结果。

若 $l \geq m ,$，则我们首先“用”$B ( \lambda )$ 的首项（即 $B _ { m } \lambda ^ { m }$）进行除法。注意，λ-矩阵 $A _ { l } B _ { m } ^ { - 1 } \lambda ^ { l - m } B ( \lambda )$ 的最高次项恰为 $A _ { l } \lambda ^ { l }$。因此，

$$
A ( \lambda ) = A _ { l } B _ { m } ^ { - 1 } \lambda ^ { l - m } B ( \lambda ) + A ^ { ( 1 ) } ( \lambda ) ,
$$

其中 $A ^ { ( 1 ) } ( \lambda )$ 是一个矩阵多项式，其次数 $l _ { 1 }$ 不超过 ${ l - 1 }$。将 $A ^ { ( 1 ) } ( \lambda )$ 按 λ 的降幂展开，令

$$
A ^ { ( 1 ) } ( \lambda ) = A _ { l _ { 1 } } ^ { ( 1 ) } \lambda ^ { l _ { 1 } } + \cdot \cdot \cdot + A _ { 0 } ^ { ( 1 ) } , \qquad A _ { l _ { 1 } } ^ { ( 1 ) } \neq 0 , \qquad l _ { 1 } < l .
$$
