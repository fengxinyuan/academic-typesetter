下述习题中列举了秩的一些性质：

习题 4．证明：对任一矩形矩阵 $ A $ 及任意适当维数的可逆矩阵 $P , Q$，均有  

$$
\operatorname { r a n k } ( P A Q ) = \operatorname { r a n k } A .
$$  

习题 5．证明：对任一矩形矩阵 $ A $，有  

$$
\operatorname { r a n k } A = \operatorname { r a n k } A ^ { \mathrm { \scriptscriptstyle T } } = \operatorname { r a n k } A ^ { * } .
$$  

习题 6．证明：对一分块对角矩阵，其秩满足  

$$
\operatorname{rank} \operatorname{diag}[ $A _ { 1 1 } , A _ { 2 2 } , \ldots , A _ { k k } ] = \sum _ { i = 1 } ^ { k } \operatorname { r a n k } A _ { i i } .$ ] = \sum_{i=1}^k \operatorname{rank} A_i.
$$
