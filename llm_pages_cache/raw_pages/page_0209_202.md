## 5.10 双线性型、二次型与埃尔米特型  

设 $A \in { \mathcal { F } } ^ { n \times n }$ 与 $\pmb { x } , \pmb { y } \in \mathcal { F } ^ { n }$。考虑定义在 $\mathcal { F } ^ { n } \times \mathcal { F } ^ { n }$ 上的函数 $f _ { A }$：  

$$
f _ { A } ( x , y ) \triangleq ( A x , y ) .\tag{1}
$$  

回顾内积的相应性质可知：对固定的矩阵 $ A $，式 (1) 中的函数 $f _ { A }$ 关于两个向量变量均为可加的（下标 $ A $ 此处省略）。

$\mathbb { C } ^ { n \times n } \mathbb { R } ^ { n \times n }$



$$
\begin{array} { r } { f ( x _ { 1 } + x _ { 2 } , y ) = f ( x _ { 1 } , y ) + f ( x _ { 2 } , y ) , } \\ { f ( x , y _ { 1 } + y _ { 2 } ) = f ( x , y _ { 1 } ) + f ( x , y _ { 2 } ) , } \end{array}\tag{2}
$$  

且关于第一个向量变量是齐次的：  

$$
f ( \alpha x , y ) = \alpha f ( x , y ) , \qquad \alpha \in { \mathcal { F } } .\tag{3}
$$  

若 ${ \mathcal { F } } = \mathbb { R }$，则该函数关于第二个向量变量也是齐次的：  

$$
f ( x , { \boldsymbol { \beta } } { \boldsymbol { y } } ) = \beta f ( x , \boldsymbol { y } ) , \qquad \beta \in \mathbb { R } ,\tag{4}
$$  

而在 ${ \mathcal { F } } = \mathbb { C } .$ 的情形下，函数 $f \equiv f _ { A }$ 关于第二个自变量是共轭齐次的：  

$$
f ( \mathbf { x } , \beta \mathbf { y } ) = \bar { \beta } f ( \mathbf { x } , \mathbf { y } ) , \qquad \beta \in \mathbb { C } .\tag{4'}
$$  

现在我们形式地定义：设函数 $f ( x , y )$ 定义在 ${ \mathcal { F } } ^ { n }$ 中向量对的集合上，若它满足条件 (1) 至 (4)（相应地，(1) 至 (3) 及 (4')），则称其为双线性函数（相应地，共轭双线性函数）。考虑由式 (1) 在 $\mathbb { C } ^ { n } \times \mathbb { C } ^ { n }$ 上定义的共轭双线性函数 $f _ { A } ( { \boldsymbol { \mathbf { x } } } , { \boldsymbol { \mathbf { y } } } )$。若 $\mathcal { E } = \{ \boldsymbol { x } _ { 1 } , \boldsymbol { x } _ { 2 } , \ldots , \boldsymbol { x } _ { n } \}$ 是 $\mathbb { C } ^ { n }$ 中的一组基，且 $\begin{array} { r } { { \pmb x } = \sum _ { i = 1 } ^ { n } \alpha _ { i } { \pmb x } _ { i } , { \pmb y } = \sum _ { j = 1 } ^ { n } \beta _ { j } { \pmb x } _ { j } } \end{array}$，那么

$$
f _ { A } ( { \pmb x } , { \pmb y } ) = ( A { \pmb x } , { \pmb y } ) = \sum _ { i , j = 1 } ^ { n } ( A { \pmb x } _ { i } , { \pmb x } _ { j } ) \alpha _ { i } \overline { { \beta } } _ { j } = \sum _ { i , j = 1 } ^ { n } \gamma _ { i j } \alpha _ { i } \overline { { \beta } } _ { j } ,\tag{5}
$$  

其中  

$$
\gamma _ { i j } = ( A x _ { i } , x _ { j } ) , \qquad i , j = 1 , 2 , \ldots , n .\tag{6}
$$  

当如式 (5) 所示以坐标形式表达时，$f _ { A }$ 通常分别称为共轭双线性型（conjugate bilinear form）或简称为双线性型（bilinear form），对应于 $\mathcal F = \mathbb C$ 或 $\mathcal { F } = \mathbb { R }$ 的情形。该型被称为由矩阵 $A ,$ 所生成；而矩阵 $\tilde { A } = [ \gamma _ { i j } ] _ { i , j = 1 } ^ { n }$ 则称为双线性型 $f _ { A }$ 关于该基的矩阵。我们的首要目标是研究双线性型 (1) 关于不同基的矩阵之间的联系，特别是这些矩阵与生成矩阵 A 之间的关系。
