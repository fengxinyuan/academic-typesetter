## 4.8 直和与矩阵

设  T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )，并令 $\mathcal { A }$ _ { $\mathrm { ~ T ~ } } ^ { 0 }$ 表示与线性变换 $ T $ 相关联的相似矩阵等价类。在该等价类中寻求最简矩阵时，我们首先研究当空间 $\mathcal { S }$ 分解为若干子空间的直和（其中至少有一个子空间是 $ T $-不变的）情形下 $ T $ 的表示。

设  \mathcal { S } $= \mathcal { S }$ _ { 1 } \ : $+ \mathcal { S }$ _ { 2 } ，其中 $\mathcal { S }$ _ { 1 }  是 $ T $-不变子空间；此处暂且假定此类分解总可行。现在，我们构造  T  的一个表示，使其对给定的空间分解“最为适配”：即，我们选取如下基来建立 $ T $ 的矩阵表示：

$$

\left\{ { \bf { x } } _ { 1 } , { \bf { x } } _ { 2 } , \ldots , { \bf { x } } _ { k } , { \bf { x } } _ { k + 1 } , \ldots , { \bf { x } } _ { n } \right\}\tag{1}
$$


该基位于  { $\mathcal { S } } ,$ 中，其中 $ k = \dim $\mathcal { S } _ { 1 } ，且前 $ k $ 个向量构成 $\mathcal { S }$ _ { 1 }  的一组基。由于 $\mathcal { S }$ _ { 1 }  是 $ T $-不变的，故有 $T ( \mathbf { x }$ _ { i } $) \in \mathcal { S }$ _ { 1 } $\left( j = 1 , 2 , \ldots , k \right$ ) ，于是由式 (4.2.1) 可得：

$$

T ( { \pmb x } _ { j } ) = \sum _ { i = 1 } ^ { k } \alpha _ { i j } { \pmb x } _ { i } , \qquad j = 1 , 2 , \ldots , k .\tag{2}
$$


因此，矩阵  A  $= [ \alpha$ _ { i j } ] _ { i , j = 1 } ^ { n } （其中各块 $\alpha$ _ { i j } $( 1 \leq i , j \leq n$ )由方程 $\begin{array} { r } { T ( \pmb { x }$ _ { j } $) = \sum$ _ { i = 1 } ^ { n } $\alpha$ _ { i j } $\pmb { x }$ _ { i } $( j = 1 , 2 , \ldots , n ) } \end{array}  $ 确定）具有如下分块形式：

$$
A = { \left[ \begin{array} { l l } { A _ { 1 } } & { A _ { 3 } } \\ { 0 } & { A _ { 2 } } \end{array} \right] } ,\tag{3}
$$  

其中  A _ { 1 } $\in { \mathcal { F } } ^ { k \times k }$ 且  A _ { 2 } $\in \mathcal { F } ^ { ( n - k ) \times ( n - k ) }$ 。根据定义，矩阵 (3) 是线性变换 $ T $ 关于基 (1) 的表示。因此，若空间可分解为若干子空间的直和，且其中至少有一个子空间是 $ T $-不变的，则 $ T $ 可表示为块三角形形式 (3)。

$$
