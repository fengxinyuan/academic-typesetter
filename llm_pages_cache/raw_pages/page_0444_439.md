7. 设  A  $\in \mathcal { F } ^ { m \times n }$ 是一个左（或右）可逆矩阵。证明：存在 $\varepsilon > 0$ ，使得对任意满足条件  \| A - B \| $< \varepsilon$ 的矩阵 $B \in \mathcal { F } ^ { m \times n }$ ，该矩阵 $B \in \mathcal { F } ^ { m \times n }  $ 同样是左（或右）可逆的。

换言之，单侧可逆性在小扰动下是“稳定的”。

提示：在左可逆情形下，取  \varepsilon  $< \lVert A$ _ { $\mathrm { L } } ^ { - 1 } \rVert ^ { - 1 }$ ，并证明  ( I + C ) ^ { - 1 } A _ { $\mathbf { L } } ^ { - 1 } B = I ,$ ，其中  C = A _ { $\mathrm { L } } ^ { - 1 } ( B - A$ ) 。
