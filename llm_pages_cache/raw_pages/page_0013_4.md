例如，在三维欧几里得空间中，一点 $ P $ 的笛卡尔坐标为 $( x _ { 0 } , y _ { 0 } , z _ { 0 } ) ,$，其所对应的向量为 ${ \overrightarrow { \mathbf { O P } } } ,$，二者均与 $ 1 \times n $ 行矩阵 $1 \times 3$（即 $[ x _ { 0 } y _ { 0 } z _ { 0 } ]$）相关联。点 $\mathbf { P } ,$ 的位置，以及向量 $\overrightarrow { \mathbf { O P } } ,$ 的位置，均由该（位置）向量完全确定。

借用若干几何术语，向量（或位置向量）的长度由欧几里得几何的自然推广来定义：对元素为 $b _ { 1 } , b _ { 2 } , \ldots , b _ { n }$ 的向量 $\blacktriangleright$，其长度为  

$$
| b | \triangleq ( | b _ { 1 } | ^ { 2 } + | b _ { 2 } | ^ { 2 } + \cdots + | b _ { n } | ^ { 2 } ) ^ { 1 / 2 } .
$$

注意：本书中，符号 $\triangleq$ 在用作定义关系时始终采用。

## 1.2 加法与标量乘法运算

由于向量是矩阵的特例，因此矩阵上的运算将被定义为：在列矩阵与行矩阵这两种特殊情形下，其运算恰好对应于位置向量上所熟知的运算。回顾可知，在三维欧几里得空间中，两个位置向量之和定义为  

$$
[ x _ { 1 } \quad y _ { 1 } \quad z _ { 1 } ] + [ x _ { 2 } \quad y _ { 2 } \quad z _ { 2 } ] \triangleq [ x _ { 1 } + x _ { 2 } \quad y _ { 1 } + y _ { 2 } \quad z _ { 1 } + z _ { 2 } ] .
$$
