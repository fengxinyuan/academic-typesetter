## 1.3 矩阵乘法

矩阵的乘法与加法可直接由其定义及数的相应运算性质推出。

习题 2．验证：对任意两个同型矩阵以及任意标量 α，有  
$\beta$  

$$
\begin{array} { c } { 0 A = 0 , } \\ { \left( \alpha + \beta \right) A = \alpha A + \beta A , } \\ { \alpha ( A + B ) = \alpha A + \alpha B , } \\ { \alpha ( \beta A ) = ( \alpha \beta ) A . \quad \Gamma } \end{array}
$$  

注意，通过记号 $( - 1 ) B \triangleq - B$，我们亦可将差 $A - B$ 定义为矩阵 A 与 −B 的和。

## 1.3 矩阵乘法  

与其他矩阵运算一样，两个矩阵乘积的概念亦可由向量代数中的某些概念引出。回顾三维欧几里得空间中，（位置）向量 a 与 b 的标量积（又称点积或内积）是一个重要且实用的概念。它定义为  

$$
a \cdot b \triangleq | a | | b | \cos \alpha ,\tag{1}
$$  

其中 α 表示给定向量之间的夹角。显然，对非零向量 a 与 $\mathbf { \delta } _ { \mathbf { \delta } }$，其标量积为零当且仅当 a 与 b 正交。

若向量 a 与 $\mathbf { \delta } _ { \mathbf { \delta } }$ 的坐标分别为 $a _ { 1 } , a _ { 2 } , a _ { 3 }$ 与 $b _ { 1 } , b _ { 2 } , b _ { 3 }$，则标量积的计算十分简单：  

$$
a \cdot b = a _ { 1 } b _ { 1 } + a _ { 2 } b _ { 2 } + a _ { 3 } b _ { 3 } .\tag{2}
$$  

矩阵乘法定义的关键在于如下约定：将行向量 ${ \pmb a } ^ { \dagger }$ 与列向量 $\pmb { b }$（按此顺序）的乘积定义为式 (2) 右端的和。

$$
\begin{array} { r } { \pmb { a } ^ { \operatorname { T } } \pmb { b } = [ a _ { 1 } \quad a _ { 2 } \quad a _ { 3 } ] \Bigg [ b _ { 1 } \Bigg ] \triangleq a _ { 1 } b _ { 1 } + a _ { 2 } b _ { 2 } + a _ { 3 } b _ { 3 } , } \\ { \pmb { b } _ { 3 } \Bigg ] } \end{array}\tag{3}
$$  

且此定义现将取代式 (1) 或式 (2) 中所用的“点积”记号。毫不意外地，该运算被描述为“行乘列”（row-into-column）乘法。
