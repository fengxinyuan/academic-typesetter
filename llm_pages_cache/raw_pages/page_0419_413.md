习题 3．若 $\pmb { x } = [ \alpha _ { 1 } \quad \alpha _ { 2 } \quad \cdot \cdot \cdot \quad \alpha _ { m } ] ^ { \mathsf { T } } \in \mathbb { C } ^ { m }$ 是矩阵 $A \in \mathbb { C } ^ { m ^ { \times } }$ 的属于特征值 λ 的特征向量，且 $\pmb { y } \in \mathbb { C } ^ { n }$ 是矩阵 $\pmb { { \cal B } } \in \mathbb { C } ^ { n \times n }$ 的属于特征值 $\mu ,$ 的特征向量，则 A ⊗ B 的属于特征值 $\lambda \mu$ 的一个特征向量 z 为  

$$
\boldsymbol { z } = [ { \alpha _ { 1 } } { y } ^ { \mathrm { T } } \quad { \alpha _ { 2 } } { y } ^ { \mathrm { T } } \quad \cdot \cdot \cdot \quad { \alpha _ { m } } { y } ^ { \mathrm { T } } ] ^ { \mathrm { T } } .\tag{1}
$$  

习题 4．证明：若 A 与 B 均为正定矩阵，则 $A \otimes B$ 亦为正定矩阵。  

定义两个矩形矩阵 $A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , l } \in \mathcal { F } ^ { m \times l }$ 与 $B \in \mathcal { F } ^ { n \times k }$ 的（右）克罗内克积为如下矩阵：  

$$
A \otimes B \triangleq [ a _ { i j } B ] _ { i , j = 1 } ^ { m , l } \in \mathcal { F } ^ { m n \times l k } .\tag{2}
$$  

习题 5．将命题 12.1.1 与 12.1.2 中的断言推广至矩形矩阵情形并予以验证。  

习题 6．设 x、$y \in \mathbb { C } ^ { m }$ 及 u、$\pmb { v } \in \mathbb { C } ^ { n }$。证明：若方程 $\pmb { x } \circledast$ u $= \textbf { y } \otimes$ v 成立，则必有 $\boldsymbol { y } = \lambda \boldsymbol { x }$ 且 ${ \mathfrak { v } } = \lambda { \mathfrak { u } }$，其中 $\lambda \in \mathbb { C }$。 □

注意，利用矩形矩阵的克罗内克积的一般定义（参见式 (2)），我们可以将式 (1) 中的 $ z $ 表示为 ${ \pmb z } = { \pmb x } \otimes { \pmb y }$，并利用推广后的命题 12.1.1（参见习题 5）来证明习题 3。此外，若 $ A $ 与 $ B $ 均为可对角化矩阵，则 $A \otimes B$ 亦为可对角化矩阵（习题 12.1.6），因而关于 $ A \otimes B $ 存在一个由纯量积向量构成的特征基，即形如 $x _ { i } \otimes y _ { j }$ 的向量全体，其中 $\left\{ x _ { i } \right\} _ { i = 1 } ^ { m } , \left\{ y _ { j } \right\} _ { j = 1 } ^ { n }$ 分别是 $ A $ 和 $ B $ 在空间 $\mathbb { C } ^ { m }$ 和 $\mathbb { C } ^ { n }$ 中的特征基。在一般情形下，情况则更为复杂。

## 12.3 克罗内克积在矩阵方程中的应用

我们首先研究一般的线性矩阵方程  

$$
A _ { 1 } X B _ { 1 } + A _ { 2 } X B _ { 2 } + \cdots + A _ { p } X B _ { p } = C ,\tag{1}
$$  

其中 $A _ { j } \in \mathbb { C } ^ { m \times m } , B _ { j } \in \mathbb { C } ^ { n \times n } ( j = 1 , 2 , . . . , p ) , X , C \in \mathbb { C } ^ { m \times n }$，以及它的若干特殊情形。我们所采用的方法依赖于命题 12.1.4 的断言，并将式 (1) 化归为一个矩阵–向量方程，其形式为 $G x = \pmb { c } ,$，其中 $G \in \mathbb { C } ^ { m n \times m n }$ 且 $\pmb { x } , \pmb { c } \in \mathbb { C } ^ { m n }$。
