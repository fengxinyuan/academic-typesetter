## 6.7 实若尔当标准形

设 $ \text{$A  $\in \mathbb { R } ^ { n \times n } } $。若将 $ A $ 视为复矩阵，则由定理 6.5.1 可知，$ \text{$A$} $ 相似于式 (6.5.4) 与 (6.5.5) 所定义的若尔当矩阵。然而，该若尔当矩阵 $ \text{$J ,$} $ 以及满足 $ \text{$P ^ { - 1 } A P = J ,$} $ 的矩阵 $ P $，通常均为复矩阵。本节中，我们将描述一种适用于 $ A $ 的规范形式——它可通过限定仅使用实可逆变换矩阵 $ P $ 而实现，从而得到一个**实典范形式**（real canonical form）。为达成此目标，我们将利用前述已导出的（复）若尔当标准形，并借助一个基本事实（参见第 5.9 节）：$ \text{$A$} $ 的特征值要么为实数，要么以共轭复数对的形式成对出现。

我们将利用前几节中为 $ A $ 构造（复）若尔当基的方法，来构造一组实基。该实基的向量将构成我们所需的实变换矩阵 $ P $ 的各列。

首先，若 $ \lambda $ 是矩阵 $A ,$ 的一个实特征值，则如 (6.4.1) 节所述，其对应的广义特征子空间存在一组实约当基；这些向量将构成我们为 $\mathbb { R } ^ { n } .$ 所构造的新实基的一部分。若 $ \lambda $ 满足 $\lambda \in \sigma ( A )$ 且非实数，则 $ \overline{\lambda} $ 亦非实数（即 $\bar { \lambda } \in \sigma ( A )$）。此时，按 (6.4.1) 节所述方法，构造（必为非实的）约当链，以张成 $ \lambda $ 对应的广义特征子空间（即 $\lambda$）；于是，该生成集中的每条链均满足形如 (6.3.3) 的关系式（其中线性算子 $ T $ 替换为 $A ) .$）。对这些关系式取复共轭，可知其复共轭向量构成另一条链，张成 $ \overline{\lambda} $ 对应的广义特征子空间。
