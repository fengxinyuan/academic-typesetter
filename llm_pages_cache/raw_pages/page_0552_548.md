在下一个定理中我们将看到，一大类非负矩阵可通过一个简单变换化为随机矩阵。

定理 2．设 $ A $ 是一个 $ n \times n $ 非负矩阵，其最大的实特征值为 $ r $。若存在一个与 $ r $ 相关联的正（右）特征向量 $\mathbf { x } = [ x _ { 1 } \quad x _ { 2 } \quad \cdot \cdot \cdot \quad x _ { n } ] ^ { \mathrm { T } }$，且记 $X = \operatorname { d i a g } [ x _ { 1 } , \ldots , x _ { n } ]$，则  

$$
\begin{array} { r } { \pmb { { \cal A } } = r { \pmb { X } } { \pmb { P } } { \pmb { X } } ^ { - 1 } , } \end{array}
$$  

其中 $ P $ 是一个随机矩阵。  

注意：定理 2 的假设要求该特征向量 $ \mathbf{x} $ 为正向量，因此某些非负矩阵被排除在外（参见定理 15.5.1）。  

**证明．** 令 $P = r ^ { - 1 } X ^ { - 1 } A X$。我们只需证明 $ P $ 是随机矩阵。由于 $A { \boldsymbol { \mathbf { x } } } = r { \boldsymbol { \mathbf { x } } }$，故有  

$$
\sum _ { j = 1 } ^ { n } a _ { i j } x _ { j } = r x _ { i } , \qquad i = 1 , 2 , \ldots , n .
$$  

由定义，$p _ { i j } = r ^ { - 1 } x _ { i } ^ { - 1 } a _ { i j } x _ { j }$，因而  

$$
\sum _ { j \mathop { = } 1 } ^ { n } p _ { i j } = r ^ { - 1 } x _ { i } ^ { - 1 } \sum _ { j \mathop { = } 1 } ^ { n } a _ { i j } x _ { j } \mathop { = } 1 .
$$  

于是 $ P $ 是随机矩阵，定理得证。■  

最后，我们考虑非负矩阵序列 $P , P ^ { 2 } , P ^ { 3 } , \ldots ,$，其中 $ P $ 是随机矩阵。我们关心的是极限  

$$
P ^ { \infty } = \operatorname* { l i m } _ { p \to \infty } P ^ { p }
$$  

存在的条件。我们已知：对任意随机矩阵 $ P $，其必有一个特征值等于 $ 1 $；且当且仅当 $ P $ 的所有其余特征值的模均小于 $ 1 $ 时，有 $P ^ { \infty } \neq \theta ,$，并且 $P ^ { r }  0$（参见习题 11.1.8）。

$P ^ { \infty } = \operatorname* { l i m } _ { p \to \infty } P ^ { p }$  
存在当且仅当 $ P $ 是本原的。

**证明．** 我们已知 $ P $ 的最大实特征值 $\lambda _ { 1 }$ 等于 1。回忆可知：由于 $ P $ 不可约，特征值 1 是单重的（见定理 15.3.1(c)）。因此，设 $\lambda _ { 2 } , \ldots , \lambda _ { k }$ 为 $ P $ 的其余模为 1 的特征值，而 $\lambda _ { k + 1 } , \ldots , \lambda _ { s }$ 为 $ P $ 的所有模小于 1 的互异特征值。我们用 $f ( \lambda ) = \lambda ^ { p }$ 和 $f _ { l , . }$ 分别表示函数 $ f $ 在点 $\lambda _ { l }$ 处的第 $ j $ 阶导数；再次应用定理 9.5.1，可得
