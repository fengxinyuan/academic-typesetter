习题 2．验证与矩阵  

$$
\left[ { \begin{array} { r r r } { 2 } & { 0 } & { 0 } \\ { 3 } & { 1 } & { 0 } \\ { 0 } & { 4 } & { - 1 } \end{array} } \right]
$$  

相关联的有向图不是强连通的。

习题 3．证明：若矩阵 $ A $ 的某一行（或某一列）的所有非对角元均为零，则 $ A $ 的有向图不是强连通的。

**解**．考虑 $ A $ 的第 $ i $ 行的情形：此时不存在从节点 $ i $ 出发的有向边 $\overrightarrow { P _ { i } P _ { j } }$，因此节点 $ i $ 无法到达任何其他节点，故该有向图不是强连通的。□

接下来的两个习题构成下一命题证明的一部分。

习题 4．设矩阵 $A \in \mathbb { C } ^ { n \times n }$ 具有分块形式  

$$
A = { \left[ \begin{array} { l l } { A _ { 1 1 } } & { A _ { 1 2 } } \\ { 0 } & { A _ { 2 2 } } \end{array} \right] } ,
$$  

其中 $A _ { 1 1 }$ 是 $k \times k$ 阶矩阵，$1 \leq k \leq n - 1$ 是 $k \times k$ 阶矩阵（因而 $ A $ 显然是可约的）。  
证明：$ A $ 的有向图不是强连通的。

解．考虑从某个节点 $ i $ 出发的任意一条有向路径，其中  i > k . 。该路径的第一段由矩阵 $ A $ 的第 $ i $ 行中非零元  a _ { i j }  的存在所决定。由于该行的前 $ k $ 个位置均为零，因此仅当 $\operatorname { i f } j > k .$ 时，才可能从节点 $ i $ 连接到节点 $ j $。类似地，该路径只能从节点 $ j $ 延伸至另一个大于 $ k $ 的节点。依此类推可知：从满足  i > k  的节点 $ i $ 出发的任意有向路径，均无法连接到小于  k + 1  的节点。故该有向图不是强连通的。

习题 5．设  A  $\in \mathbb { C } ^ { n \times n }$ ，且 $ P $ 是一个 $n \times n$ 阶置换矩阵。证明：$ A $ 的有向图是强连通的，当且仅当  P A P ^ { $\mathrm { \bf T } }  $ 的有向图是强连通的。

解．注意到  P A P ^ { $\mathrm { \bf T } }$ 的图仅是通过对 $ A $ 的图重新编号节点而得到，而这一操作不改变图的连通性。□

定理 1．一个方阵不可约，当且仅当其对应的有向图是强连通的。

证明．习题 4 表明：若 $ A $ 可约，则对某个置换矩阵 $ P $，矩阵  P A P ^ { $\mathrm { \bf T } }$ 的有向图不是强连通的；习题 5 进一步说明，这等价于 $ A $ 本身的有向图不是强连通的。因此，若其有向图是强连通的，则该矩阵必为不可约。其逆命题的证明留待习题 15.3.3。
