$$
\mathbf{$$
A ^ { $\prime } = D ^ { - 1 } A ^ { * } D ,\tag{8}$ 
$$}
$$  

其中 $ \mathbf{$D  $= \mathrm { d i a g } \{ ( u$ _ { i } , u _ { i } ) \} _ { i = 1 } ^ { n } $. \quad \bigsqcup } $。  

特别地，关系式 (8) 表明：当基 $ \mathbf{$\pmb { $\delta } } $ 是标准正交基时，有 $ \mathbf{$A ^ { $\prime } = A ^ { * } } $。然而事实上，若 $ \mathbf{$\pmb { $\mathcal { U } } = \pmb { \mathcal { V } } } $，且两组基向量在内积 $ u $ 下构成双正交系（参见第 3.13 节），则定理 2 的结论仍然成立。

**定理 3．** 设 $ \mathbf{$T  $\in { \mathcal { L } } ( { \mathcal { U } }$ )$} $，并设 $ \mathbf{$( $\mathcal { E } , \mathcal { E } ^ { \prime }$ )$} $ 是空间 $ U $ 中的一对双正交基。若 $ A $ 是 $ \mathbf{$T$} $ 关于基 $ \mathbf{$\begin{array} { r } { $\pmb { \mathcal { E } } , } \end{array} } $ 的表示矩阵，则 $ \mathbf{$A ^ { * }$} $ 即为 $ \mathbf{$T ^ { * }$} $ 关于基 $ \mathbf{$\clubsuit ^ { $\prime } } $ 的表示矩阵。

**证明**．设  \boldsymbol { $\mathcal { E } } = \{ u$ _ { 1 } , u _ { 2 } , . . . , u _ { n } \} $, \boldsymbol { \mathcal { E } } ^ { \prime } = \{ u$ _ { 1 } ^ { $\prime } , u$ _ { 2 } ^ { $\prime } , . . . , u$ _ { n } ^ { $\prime } \}$ ，且  A = [ a _ { i j } ] _ { i , j = 1 } ^ { n } 。由于 $\begin{array} { r } { T ( u$ _ { j } $) = \sum$ _ { i = 1 } ^ { n } a _ { i j } u _ { i } $( 1 \leq j \leq n ) } \end{array}$ 且  ( { $\pmb u }$ _ { k } , { $\pmb u }$ _ { i } ^ { $\prime } ) = \delta$ _ { k i } $( 1 \leq i , k \leq n ) .$ ，故有 $( T ( \pmb { u }$ _ { j } $) , \pmb { u }$ _ { i } ^ { $\prime } ) = a$ _ { i j } 。以类似方式计算线性变换  T ^ { * }  关于基 $\clubsuit ^ { \prime }$ 的表示矩阵  B  的各项  b _ { i j } ，可得 $\begin{array} { r } { \pmb { b }$ _ { i j } = ( T ^ { * } $( \pmb { u }$ _ { j } ^ { $\prime } ) , \pmb { u }$ _ { i } ) } $\end{array}$ 、 $( 1 \leq i , j \leq n$ )。因此，对所有可能的 $ i $ 与 $ j $，均有  

$$

b _ { i j } = ( { \pmb u } _ { j } ^ { \prime } , T ( { \pmb u } _ { i } ) ) = ( \overline { { T ( { \pmb u } _ { i } ) , { \pmb u } _ { j } ^ { \prime } } } ) = \overline { { a _ { j i } } } ,
$$
  

从而  B = A ^ { * } 。
