**命题 2**． 对任一矩阵 $A$，有  
$$
\begin{array} { r } { \operatorname { K e r } A ^ { + } = \operatorname { K e r } A ^ { * } , \qquad \operatorname { I m } A ^ { + } = \operatorname { I m } A ^ { * } . } \end{array}
$$  

可通过直接计算由 $A$ 确定 $$A ^ { + }$$。令 $r = \operatorname{rank} A$，并设  

$$
A = F R ^ { * } , \qquad F \in { \mathcal { F } } ^ { m \times r } , \qquad R ^ { * } \in { \mathcal { F } } ^ { r \times n }\tag{8}
$$  

为 $A$ 的一个秩分解，即 $\operatorname{rank} F = \operatorname{rank} $R ^ { * } = r .$$。注意到 $$r  $\times r$ $$ 阶矩阵 $$F ^ { * } F$$ 与 $$R ^ { * } R$$ 均为满秩矩阵，因而可逆；我们定义 $$n  $\times n$ $$ 阶矩阵  

$$
X = R ( R ^ { * } R ) ^ { - 1 } ( F ^ { * } F ) ^ { - 1 } F ^ { * } $.\tag{9}$ 
$$
$$


容易验证，这是矩阵 $A ,$ 的摩尔–彭罗斯广义逆，记为 $X = A ^ { + }$。注意，A 的线性无关列可选取为式 (8) 中矩阵 F 的各列。这一选择将导出下一习题中所述的若干有用推论。
