以下特殊情形经常出现：若 det $L _ { l } \neq \mathbf { 0 }$ ≠ 0，且特别地，若 $L ( \lambda )$ 是首一多项式，则方程 (1) 的解空间维数为 $ ln $。这一结论可直接由如下显然事实推出：det $L ( \lambda )$ 的首项系数恰好等于 det $L _ { l }$。其中一种特殊情形极为重要，值得单独陈述如下：  

**推论 1.** 若 $A \in \mathbb { C } ^ { n \times n }$，则 ${ \dot { \mathbf { x } } } ( t ) = A { \mathbf { x } } ( t )$ 的解空间维数为 $ n $。  

我们现在转向研究一组含 $ n $ 个齐次标量线性差分方程的系统，其系数为复常数，阶数为 $ l $。此类系统可写成矩阵形式：  

$$
L _ { l } { \bf { \Psi } } _ { l } + L _ { l - 1 } { \bf { \Psi } } _ { x _ { j + l - 1 } } + \cdot \cdot \cdot + L _ { 1 } { \bf { \Psi } } _ { x _ { j + 1 } } + L _ { 0 } { \bf { \Psi } } _ { x _ { j } } = 0\tag{6}
$$

对于  j  $= 0 , 1 , 2 , \ldots$ ，其中  L _ { 0 } , L _ { 1 } $, \dots , L$ _ { l } $\in \mathbb { C } ^ { n \times n } \left( L$ _ { l } $\neq O \right$ )，一个解是指满足所有关系式 (6) 的向量序列  ( { $\pmb x }$ _ { 0 } , { $\pmb x }$ _ { 1 } , { $\pmb x }$ _ { 2 } $, \ldots$ )，且对所有 $j = 0 , 1 , 2 , \ldots$ 均成立。此时，我们引入线性空间  { $\mathcal { S } } ( \mathbb { C } ^ { n }$ )，它由所有取值于 $\mathbb { C } ^ { n } .$ 的无穷向量序列构成，并按分量自然定义向量加法与标量乘法。容易验证，方程组 (6) 的解集是  { $\mathcal { S } } ( \mathbb { C } ^ { n }$ )  的一个子空间。

为便于讨论，我们引入作用在  { $\mathcal { S } } ( \mathbb { C } ^ { n }$ )上的一个变换 $ E $，其定义为  

$$

E ( \boldsymbol { u } _ { 0 } , \boldsymbol { u } _ { 1 } , \ldots ) = ( \boldsymbol { u } _ { 1 } , \boldsymbol { u } _ { 2 } , \ldots )
$$
  

对任意  ( $\pmb { u }$ _ { 0 } $, \pmb { u }$ _ { 1 } $, . . . ) \in \mathcal { S } ( \mathbb { C } ^ { n }$ )成立。显然，$ E $ 是线性的。该变换称为**移位算子（shift operator）**，将在差分方程理论中扮演类似于  d / d t  在微分方程理论中所起的作用。

对于  r  $= 1 , 2 , 3 , \ldots ,$ ， E  的幂按如下方式递归定义：  

$$

E ^ { r } u = E ( E ^ { r - 1 } u ) , \qquad r = 1 , 2 , \ldots , \qquad u \in { \mathcal { S } } ( \mathbb { C } ^ { n } ) ,
$$
  

其中  E ^ { 0 }  是  { $\mathcal { S } } ( \mathbb { C } ^ { n }$ )  上的恒等变换。因此，  

$$

E ^ { r } ( u _ { 0 } , u _ { 1 } , . . . ) = ( u _ { r } , u _ { r + 1 } , . . . ) .
$$


此外，若 $\ b { A } \in \mathbb { C } ^ { n \times n }$ 与 $( \pmb { u } _ { 0 } , \pmb { u } _ { 1 } , \dots ) \in \mathcal { S } ( \mathbb { C } ^ { n } )$，则我们定义  

$$
A ( \boldsymbol { u } _ { 0 } , \boldsymbol { u } _ { 1 } , \ldots ) \triangleq ( A \boldsymbol { u } _ { 0 } , A \boldsymbol { u } _ { 1 } , \ldots ) \in \mathcal { S } ( \mathbb { C } ^ { n } ) .
$$  

于是容易验证：若记 ${ \pmb x } = ( { \pmb x } _ { 0 } , { \pmb x } _ { 1 } , \dots )$，则式 (6) 可写为如下形式  

$$
L ( E ) \pmb { x } \triangleq L _ { l } ( E ^ { l } \pmb { x } ) + \cdots + L _ { 1 } ( E \pmb { x } ) + L _ { 0 } \pmb { x } = 0 ,\tag{7}
$$  

其中式 (7) 右端的零是 ${ \mathcal { S } } ( \mathbb { C } ^ { n } )$ 中的零元素。
