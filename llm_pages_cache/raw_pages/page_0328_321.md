**定理1**：设 $A \in \mathbb { C } ^ { n \times n }$ 的一个特征值为 $\lambda _ { k }$，则与其关联的分量矩阵 $Z _ { k 0 }$ 是到 $\lambda _ { k }$ 的广义特征子空间上的投影算子，且沿所有异于 $\lambda _ { k }$ 的 A 的特征值所对应的广义特征子空间之和进行投影。

第4.8节的讨论表明：若我们在 $\operatorname{Im} \text{$Z _ { k 0 }$}$ 与 $\ker \text{$Z _ { k 0 }$}$ 中分别选取基，则它们共同确定了 $ \text{$\mathbb { C } ^ { n }$} $ 的一个基，在该基下，矩阵 $ A $ 具有分块对角形式 $ \operatorname{diag}\left( \text{$\left[ A _ { 1 } , A _ { 2 } $\right$ ]$},\, \text{$A _ { 1 }$} \right) $，其中 $ \text{$A _ { 1 }$} $ 与 $ \text{$A _ { 2 }$} $ 的阶数恰好分别为 $ \operatorname{Im} \text{$Z _ { k 0 }$} $ 与 $ \ker \text{$Z _ { k 0 }$} $ 的维数。特别地，若这些基均由 $ A $ 的若尔当链构成（如第6.4节所述），则 $ \text{$A _ { 1 }$} $ 与 $ \text{$A _ { 2 }$} $ 均具有若尔当标准形。

对任意 $ \text{$A  $\in \mathbb { C } ^ { n \times n } } $ 及任意 $ \text{$z  $\not \in \sigma ( A$ )$} $，函数 $ \text{$f  $( \lambda ) = ( z - \lambda ) ^ { - 1 } } $ 在 $ \text{$\sigma ( A )$} $ 上有定义；因此，$ \text{$A , ( z I - A ) ^ { - 1 }$} $ 的预解式（resolvent）存在。固定 $ A $ 后，该预解式可视为复变量 $ z $ 的函数，其定义域为复平面 $ \mathbb{C} $ 中不包含 $ \text{$\sigma ( A )$} $ 中任何点的任意区域；这一观点在矩阵分析中起着重要作用。事实上，我们将在第9.9节中进一步发展该理论，并在第11章引入摄动理论时对其作实质性应用。

预解式的一个显式表达式已在习题9.5.2中得到：  

$$
( z I - A ) ^ { - 1 } = \sum _ { k = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } \frac { j ! } { ( z - \lambda _ { k } ) ^ { j + 1 } } Z _ { k j } .
$$  

利用矩阵 $ \text{$Z _ { k j }$} $ 的正交性，可立即推出  

$$
( z I - { \cal A } ) ^ { - 1 } ( I - { \cal Z } _ { 1 0 } ) = \sum _ { k = 2 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } \frac { j ! } { ( z - \lambda _ { k } ) ^ { j + 1 } } { \cal Z } _ { k j }
$$

并利用式 (1) 及习题 9.5.6，可知预解式（resolvent）的值域为 $\operatorname{Im} \, \text{$( I - Z _ { 1 0 } )$}$。现在，当 $ \text{$z  $\lambda$ _ { 1 }$} $ 时，$ \text{$( z I - A ) ^ { - 1 }$} $ 中的元素将趋于无界。但由于该等式右侧的极限存在，我们看出：将预解式乘以 $ \text{$I - Z _ { 1 0 }$} $ 的效果，正是消除了 $ \text{$( z I - A ) ^ { - 1 }$} $ 在 $ \text{$z  $= \lambda$ _ { 1 }$} $ 处的奇异部分。换言之，预解式在子空间  

$$
\mathrm { I m } ( I - Z _ { 1 0 } ) = \sum _ { j = 2 } ^ { s } \mathrm { I m } Z _ { j 0 }
$$  

上的限制在 $ \text{$z  $= \lambda$ _ { 1 }$} $ 处无奇异性。
