若 λ-矩阵 $A ( \lambda )$ 的行列式 det $A ( \lambda )$ 不恒等于零，则称该 λ-矩阵为**正则的**（regular）。需注意：det $A ( \lambda )$ 本身是一个以 ${ \mathcal F } ,$ 中元素为系数的多项式，因此 $A ( \lambda )$ 非正则当且仅当 det $A ( \lambda )$ 的每一项系数均为 $\mathcal { F } .$ 中的零元。λ-矩阵 $A ( \lambda )$ 的**次数**（degree）定义为其所有元素中出现的多项式的最高次数，并记作 deg $A ( \lambda )$。于是有：deg($\lambda I - A ) = 1$)，且对任意非零的 $A \in { \mathcal { F } } ^ { n \times n }$，均有 deg $A = 0$。

同阶的 λ-矩阵可以按通常方式相加与相乘，且在每种情形下，结果仍为一个 λ-矩阵。特别地，若存在一个 λ-矩阵 $B ( \lambda )$，使得 $A ( \lambda ) B ( \lambda ) = B ( \lambda ) A ( \lambda ) = I .$，则称 λ-矩阵 $A ( \lambda )$ 是可逆的。换言之，$A ( \lambda )$ 是可逆的，当且仅当 $B ( \lambda ) = [ A ( \lambda ) ] ^ { - 1 }$ 存在且本身也是一个 λ-矩阵。

**命题 1.** 一个 λ-矩阵 $A ( \lambda )$ 是可逆的，当且仅当 det $A ( \lambda )$ 是一个非零常数。

**证明.** 若 det $A ( \lambda ) = c \neq 0 ;$，则其逆矩阵的各个元素等于 $A ( \lambda )$ 的 (n−1) 阶子式（即阶数为 $n - 1$ 的子式）除以 $c \neq 0$，因此均为关于 λ 的多项式。于是 $[ A ( \lambda ) ] ^ { - 1 }$ 是一个 λ-矩阵。反之，若 $A ( \lambda )$ 可逆，则由等式 $A ( \lambda ) B ( \lambda ) = I$ 可得  

$$
\operatorname* { d e t } A ( \lambda ) \operatorname* { d e t } B ( \lambda ) = 1 .
$$  

因此，多项式 det $A ( \lambda )$ 与 det $B ( \lambda )$ 的乘积是一个非零常数。而两个多项式的乘积为非零常数，当且仅当它们各自均为非零常数。■

具有非零常数行列式的 λ-矩阵亦称为**幺模 λ-矩阵**（unimodular λ-matrix）。借助这一概念，命题 1 可重述为：一个 λ-矩阵是可逆的，当且仅当它是幺模的。注意，幺模矩阵的次数（即其元素中 λ 的最高次数）可以是任意的。
