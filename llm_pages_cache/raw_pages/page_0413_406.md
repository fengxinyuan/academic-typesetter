# 线性矩阵方程与广义逆

本章我们研究一般的线性矩阵方程  

$$
A _ { 1 } X B _ { 1 } + A _ { 2 } X B _ { 2 } + \cdots + A _ { p } X B _ { p } = C ,
$$  

其中未知量为矩阵 $ X $；我们还将考察它的若干特殊情形，尤其是具有重大理论与实际意义的方程：  

$$
A X + X B = C .
$$  

对上述矩阵方程的研究将依赖于“克罗内克积”（Kronecker product）这一概念——这是一个十分有用的概念，具有若干重要应用。

在本章后半部分，我们将发展方阵逆矩阵概念的一些推广形式。我们首先从“单侧逆”（one-sided inverses）出发，进而引入一种适用范围极广的广义逆定义：该定义适用于任意矩阵（无论其为方阵或长方阵）。摩尔–彭罗斯逆（Moore–Penrose inverse）即为此类分析中的一个特例；本章最后将阐述摩尔–彭罗斯逆在求解方程 $A \mathbf { x } = \pmb { b } ,$ 中的应用，其中 $ A $ 与 $ \mathbf{b} $ 分别为任意（矩形）矩阵与向量。

## 12.1 克罗内克积的概念

本节中，我们引入并考察一种新的运算；该运算在最一般的情形下是从 $\mathcal { F } ^ { m \times l } \times \mathcal { F } ^ { n \times k }$ 到 $\mathcal { F } ^ { m n } \times l k$ 的二元运算；然而，我们将仅限于讨论情形 $l = m , k = n .$。此情形在应用中最为常用，且能导出关于积矩阵特征值的优美结果——这些特征值可由因子矩阵的特征值完全确定。克罗内克积的概念自然地出现在群论中，因而它在粒子物理学中具有重要应用。
