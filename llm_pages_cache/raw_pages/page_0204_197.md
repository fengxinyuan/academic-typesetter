**定理 4.** 设 $A \in { \mathcal { F } } ^ { n \times n }$。$ \mathbb{C}^n $（或 $ \mathbb{R}^n $）的一个子空间 $\mathcal { S }$ 是 $ A $-不变的，当且仅当 $P A P = A P$ 对任意将 ${ \mathcal { F } } ^ { n }$ 投影到 $ S $ 上的投影算子 $ P $ 成立。
