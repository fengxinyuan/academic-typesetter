现在考虑一个定义在开集 ${ \mathcal { S } } \subseteq \mathbb { C } ^ { n }$ 上、取值于 $\mathbb { C } ^ { m }$ 的函数 $f$。我们称 $f$ 在点 $\pmb { x } \in \mathcal { S }$ 处连续，是指：对任意给定的 $\varepsilon > 0 ,$，存在 $\delta > 0$，使得当 $\mathbf { \boldsymbol { y } } \in \mathcal { N } _ { \delta } ( \mathbf { \boldsymbol { x } } )$ 时，有  

$$
\| f ( \mathbf { y } ) - f ( \mathbf { x } ) \| < \varepsilon .
$$  

我们称 $f$ 在 $\mathcal { S }$ 上连续，是指 $ f $ 在 ${ \mathcal { S } } .$ 的每一点处均连续；若 $\mathbf { I f } \mathbf { \mathcal { S } }$ 是闭集，则称 $f$ 在 $\mathcal { S }$ 上连续，是指存在某个包含 $\mathcal { S } .$ 的开集，使得 $ f $ 在该开集上连续。函数 $f$ 的像集（range）$f ( \mathcal S )$ 是 $\mathbb { C } ^ { m }$ 的一个子集，其定义如下：${ \pmb a } \in f ( { \mathcal { S } } )$ 当且仅当存在向量 $\pmb { b } \in \mathbb { C } ^ { n }$，使得 $a = f ( b )$ 成立。

定理 2．设 $ f $ 如上所定义。若 $I f { \mathcal { S } }$ 是 $\mathbb { C } ^ { n }$ 中的一个闭且有界集合，且 $ f $ 在 ${ \mathcal { S } } ,$ 上连续，则 $f ( \mathcal S )$ 是 $o f \mathbb { C } ^ { m } ,$ 的一个闭且有界子集。

在定理 2 及下一个定理中，我们可以将 $\mathbb { C } ^ { n }$ 替换为 $\mathbb { R } ^ { n }$，或将 $\mathbb { C } ^ { m }$ 替换为 $\mathbb { R } ^ { m }$，或二者同时替换。下一个定理是通过综合定理 1 与定理 2 得到的。

**定理 3.** 设 $ f $ 是定义在 $ \mathbb{C}^n $ 的某个闭且有界子集 $\mathcal { S }$ 上的连续实值函数。若  

$$
M = \operatorname* { s u p } _ { \mathbf { x } \in \mathcal { S } } f ( \mathbf { x } ) , \qquad m = \operatorname* { i n f } _ { \mathbf { x } \in \mathcal { S } } f ( \mathbf { x } ) ,
$$  

则存在向量 $ y $、$\pmb { z } \in \mathcal { S }$，使得  

$$
M = f ( { \pmb y } ) , ~ { \pmb m } = f ( { \pmb z } ) .
$$  

在此陈述中，$\operatorname { s u p } _ { x \in \mathcal { S } } f ( x )$ 读作“当 $\pmb { x } \in \mathcal { S } . ^ { \pmb { \mathscr { s } } }$ 时，所有数 $f ( x )$ 的上确界（即最小上界）”。类似地，$\operatorname { i n f } _ { x \in \mathcal { S } } f ( x )$ 表示下确界（即最大下界）。

定理 2 告诉我们：在定理 3 的假设条件下，$f ( \mathcal S )$ 是一个闭且有界的实数集合；于是该结论可直接由定理 1 推出。我们亦可表述为：在定理 3 的假设条件下，$ f $ 在 $\mathcal { S }$ 上取得最大值与最小值，且可记为  

$$
\operatorname* { s u p } _ { x \in \mathcal { S } } f ( { \pmb x } ) = \operatorname* { m a x } _ { { \pmb x } \in \mathcal { S } } f ( { \pmb x } ) , \qquad \operatorname* { i n f } _ { { \pmb x } \in \mathcal { S } } f ( { \pmb x } ) = \operatorname* { m i n } _ { { \pmb x } \in \mathcal { S } } f ( { \pmb x } ) .
$$

我们现在通过下面的例子说明：定理 $3 - f$ 的三个条件——${ \mathcal { S } } , { \mathcal { S } }$ 上连续、$\mathcal { S }$ 有界、$\mathcal { S }$ 闭——全都是必不可少的。

习题 1. （a）令 $f ( x ) = x ,$，令 $\mathcal { S }$ 为开区间 $( 0 , 1 )$。此时 $\mathcal { S }$ 有界但不闭，且 $f$ 在 $\mathcal { S } .$ 上连续。显然，$M = 1$，$m = 0 ,$，而 $f$ 在 ${ \mathcal { S } } .$ 上取不到这两个值。

（b）取 $f ( x ) = 1 / x$，$\mathcal { S }$ 为所有不小于 1 的实数构成的集合，则 $f$ 在 $\mathcal { S }$ 上连续，且 $\mathcal { S }$ 是闭集但无界。此时 $f ( \mathcal S )$ 为半开区间 $( 0 , 1 ]$，而 $\operatorname { f } _ { x \in { \mathcal { S } } } f ( x ) = 0$ 在该区间上取不到。
