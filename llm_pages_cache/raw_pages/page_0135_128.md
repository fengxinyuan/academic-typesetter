事实上，若 α 和 $\pmb { \alpha } ^ { \prime }$ 分别表示线性变换 $\mathbf { x } \in \mathcal { S } _ { 1 }$ 关于基 $\pmb { \delta }$ 与基 $\pmb { \mathcal { E } } ^ { \prime } { } _ { \mathrm { i } }$ 的矩阵表示，则根据定理 3.9.1，有  

$$
{ \pmb { \alpha } } ^ { \prime } = Q { \pmb { \alpha } } .\tag{3}
$$  

令 $y = T ( x )$，且令 $\pmb { \beta }$ 表示向量 y 关于基 $\mathcal { G } ^ { \prime }$ 的坐标向量。由定理 4.2.2 可得  

$$
\ B = A _ { \varepsilon , \mathbf { g } , \mathbf { \mathcal { A } } } \qquad \mathrm { a n d } \qquad \ B = A _ { \varepsilon ^ { \prime } , \mathbf { g } ^ { \prime } } \mathbf { \mathcal { A } } ^ { \prime } .\tag{4}
$$  

因此，利用式 (3)，式 (4) 中的第二个关系式推出 $\beta = A _ { \delta ^ { \prime } , \mathcal { G } ^ { \prime } } Q \alpha .$。将此式与式 $( 4 )$ 中的第一个关系式比较，并注意到 $\pmb { x } \in \mathcal { S } _ { 1 }$ 是任意的，即可得出所要求的等式 (2)。  

将式 (1) 与式 (2) 结合，并回顾习题 3.7.2 的结论（即过渡矩阵是非奇异的），我们得到如下定理。  

**定理 1.** 设 $T \in { \mathcal { L } } ( { \mathcal { S } } _ { 1 } \ { \mathcal { S } } _ { 2 } ) . I f A _ { { \boldsymbol { \varepsilon } } , { \boldsymbol { \ s } } }$ 与 $A _ { \mathcal { E } ^ { \prime } , \mathcal { G } ^ { \prime } }$ 分别表示线性变换 $T$ 关于基对 $( \pmb { \mathscr { E } } , \pmb { \mathscr { G } } )$ 与 $( \pmb { \mathcal { E } } ^ { \prime } , \pmb { \mathcal { G } } ^ { \prime } )$ 的矩阵表示，则  

$$
A _ { \delta ^ { \prime } , \lessgtr ^ { \prime } } = P A _ { \delta , \lessgtr } Q ^ { - 1 } ,\tag{5}
$$

其中，$ P $ 与 $Q$ 分别表示从 $\mathscr { G }$ 到 $\mathcal { G } ^ { \prime }$、以及从 $\pmb { \delta }$ 到 ${ \pmb \mathcal { O } } ^ { \prime } ,$ 的过渡矩阵。
