我们已证明如下结果：

**定理 1.** 若 $ Q $ 是齐次马尔可夫链的转移矩阵，且 $Q$ 不可约，则极限绝对概率 $p _ { i } ( t _ { \infty } )$ 存在当且仅当 $ Q $ 是本原矩阵。进一步地，当 $\boldsymbol { Q }$ 为本原矩阵时，对所有 $ i = 1,2,\dots,n $，均有 $p _ { i } ( t _ { \infty } ) > 0$，且这些概率恰为 $ Q $ 的（适当归一化的）右特征向量的各个分量，该右特征向量对应于特征值 1。
