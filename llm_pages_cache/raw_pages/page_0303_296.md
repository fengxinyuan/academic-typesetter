习题 2．验证如下关于 $ n \times n $ 埃尔米特矩阵负定性的判据：  
$H < 0$  
当且仅当 $ H $ 的顺序主子式 $ \det $H _ { k } $\left( k = 1 , 2 , \ldots , n \right$ )满足条件 $ \det $H _ { 1 } < 0 ，且  

$$
( \operatorname* { d e t } H _ { k } ) ( \operatorname* { d e t } H _ { k + 1 } ) < 0
$$  

对所有  k  $= 1 , 2 , \ldots , n - 1 . \quad \bigsqcup  $ 成立。  

因此，一个埃尔米特矩阵  H = [ h _ { i j } ] _ { i , j = 1 } ^ { n }  是负定的，当且仅当  h _ { 1 1 } < 0 ，且其顺序主子式的符号交替变化。

本节所给出的正定性与负定性判据在实际中常被采用，因为从计算角度看，它们易于实现。这些结果的一些推广将在下一节中讨论。

## 8.6 雅可比–贡德芬格–弗罗贝尼乌斯方法

以下结果是西尔维斯特定理的一个推广。对于一般的埃尔米特矩阵 $ H $，它给出了第 5.5 节所定义的 $ H $ 的惯性（inertia）的一个判据。

定理 1（G. Jacobi†）．设  H _ { 1 } , \ H _ { 2 } $, \ldots , H$ _ { n }  是秩为 $ r $ 的埃尔米特矩阵 $H \in \mathbb { C } ^ { n \times n }$ 的顺序主子矩阵，并假定  d _ { k } $= \operatorname* { d e t } H$ _ { k } $\neq 0 , k = 1 , 2 , \ldots , r .$ 。则 $ H $ 的负特征值（相应地，正特征值）的个数等于序列  

$$
1 , d _ { 1 } , d _ { 2 } , \ldots , d _ { r } .\tag{1}
$$  

中符号改变（相应地，符号保持不变）的次数。

证明．我们用数学归纳法证明该结论。若 $k = 1$，则 $d _ { 1 }$ 是 $H _ { 1 }$ 的（唯一）特征值，且显然 $d _ { 1 }$ 为负或正，取决于序列 $1 , d _ { 1 }$ 中符号的变号或不变号。

假设该命题对首主子矩阵 $H _ { k }$ 成立，即：$H _ { k }$ 的负（相应地，正）特征值个数等于序列 $1,\, \text{$d _ { 1 } , d _ { 2 } $, \ldots , d$ _ { k }$}$ 中符号变号（相应地，不变号）的次数。过渡到 $H _ { k + 1 }$ 时，该序列新增一项非零数 $d _ { k + 1 } = \det H _ { k + 1 }$。若 $d _ { k + 1 } > 0$，则（参见式 (4.11.3)）$H _ { k + 1 }$ 的所有特征值之积为正。此外，$d _ { k } = \lambda _ { 1 } ^ { ( k ) } \lambda _ { 2 } ^ { ( k ) } \cdot \cdot \cdot \lambda _ { k } ^ { ( k ) }$。考虑情形 $d _ { k } > 0 .$。此时，在序列 $1,\, \text{$d _ { 1 } $, \ldots , d$ _ { k } , d _ { k + 1 }$}$ 中符号变号的次数与在序列 $1,\, \text{$d _ { 1 } $, \ldots , d$ _ { k }$}$ 中相同；因此，我们的目标是证明：$H _ { k + 1 }$ 比 $H _ { k }$ 具有相同数目的负特征值，但正特征值多一个。

事实上，设 $H _ { k }$ 有 $m$ 个 $( 1 \leq m \leq k )$ 负特征值和 $$k - m$$ 个正特征值：

$$
\lambda _ { 1 } ^ { ( k ) } \leq \cdot \cdot \cdot \leq \lambda _ { m } ^ { ( k ) } < 0 < \lambda _ { m + 1 } ^ { ( k ) } \leq \cdot \cdot \cdot \leq \lambda _ { k } ^ { ( k ) } .
$$
