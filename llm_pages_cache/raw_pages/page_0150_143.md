现在假设 $\mathcal { S } _ { 1 } = \mathcal { S } _ { 2 }$。于是我们研究形如 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 的线性变换。以下这一概念本身即具重要性，在当前背景下尤为有用。

设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，子空间 $\mathcal { S } _ { 0 } \subset \mathcal { S }$ 称为在 $T$ 下不变的（或简称为 $T \cdot$-不变的），若对任一 $\pmb { x } \in \mathcal { S } _ { 0 }$，其像 $T ( { \pmb x } )$ 也属于 $\mathcal { S } _ { 0 }$。

$$
T ( x ) \in \mathcal { S } _ { 0 } \qquad \mathrm { f o r ~ a l l ~ } x \in \mathcal { S } _ { 0 } .\tag{2}
$$

换言之，若 $\mathcal { S } _ { 0 }$ 是 T-不变的，则对任意 $\pmb { x } \in \mathcal { S } _ { 0 }$，T 将 x 变换为同一子空间 $\mathcal { S } _ { 0 }$ 中的一个元素。因此，在此情形下，T 在 $T | _ { \mathcal { S } _ { 0 } }$ 上的限制是一个作用于 $\mathcal { S } _ { 0 }$ 的线性变换，从而可视为 T 在 $\mathcal { S } _ { 0 }$ 中的一个“部分”。

显然，零子空间 $\{ \pmb { \theta } \}$ 与整个空间本身在任何线性变换下均是不变的。这类子空间被称为平凡不变子空间，通常在后续讨论中被排除在外。

下一习题表明：非可逆的线性变换必存在非平凡的不变子空间。

习题 3．设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$。证明：Ker T 与 Im T 均为 T-不变子空间。  
并进一步证明：任何包含 Im T 的子空间也是 T-不变的。

解．对第一个子空间，设 $\pmb { x } \in \mathbf { K }$ ∈ Ker T。则 $T ( \pmb { x } ) = \pmb { \theta }$，且由于 $\pmb { \theta } \in \mathbf { K }$ ∈ Ker T，故条件 (2) 成立。Im T 的 T-不变性可类似证明。

习题 4．证明：子空间  \mathcal { S } _ { 0 }  是 $ T $-不变的，当且仅当 $T ( \mathbf { x }$ _ { i } $) \in \mathcal { S }$ _ { 0 } \ ( i = 1$ \, $2  $, \ldots , k$ )，其中  \{ $\pmb { x }$ _ { 1 } $, \pmb { x }$ _ { 2 } $, \ldots , \pmb { x }$ _ { k } \}  是 $\mathcal { S }$ _ { 0 }  的一组基。

习题 5．验证：若  T _ { 1 } T _ { 2 } = T _ { 2 } T _ { 1 } ，则 $ \operatorname{Ker} \, $T _ { 2 }  与 $ \operatorname{Im} \, $T _ { 2 }  均为  T _ { 1 } $\cdot  $-不变子空间。
