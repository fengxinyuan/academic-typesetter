设 $ \mathbf{$b _ { 1 } , b _ { 2 } $, \ldots , b$ _ { n }$} $ 属于某线性空间。由这些元素在基 $ \mathbf{$\left\{ a _ { i } $\right\}$ _ { i = 1 } ^ { m } ,$} $ 下的坐标表示，我们构造一个 $ m \times n $ 矩阵  

$$
\mathbf{$$
A _ { a } $= [ \alpha$ _ { i j } ] _ { i , j = 1 } ^ { m , n } $,\tag{1}$ 
$$}
$$  

其中  

$$
\mathbf{$$
b _ { j } $= \sum$ _ { i = 1 } ^ { m } $\alpha$ _ { i j } a _ { i } $\qquad 1 \leq j \leq n .\tag{2}$ 
$$}
$$  

该矩阵（1）称为有序组 $ \mathbf{$\left\{ b _ { 1 } , b _ { 2 } $, \ldots , b$ _ { n } $\right\} } $ 关于基 $ \mathbf{$\{ a _ { 1 } , a _ { 2 } $, \ldots , a$ _ { m } \}$} $ 的（矩阵）表示。显然，任意向量组关于给定基的（矩阵）表示是唯一的；但同一向量组在不同基下的表示通常互不相同。

习题 1．利用习题 3.5.2 和 3.5.3 验证：下列矩阵  

$$
\mathbf{$$
A _ { $\mathfrak { e } } = \left[$ 

$$
\begin{array} { r r } { 1 } & { 0 } \\ { 2 } & { 1 } \\ { - 1 } & { 2 } \end{array}
$$
 $\right] \quad \quad \mathrm { a n d } \quad \quad A$ _ { $\mathfrak { s } } = \left[$ 

$$
\begin{array} { r r } { 2 \ - \frac { 1 } { 2 } } \\ { 0 } & { \frac { 3 } { 2 } } \\ { - 1 } & { \frac { 1 } { 2 } } \end{array}
$$
 $\right$ ]
$$}
$$

分别是线性系统 $\pmb { b } _ { 1 } = [ 1 \quad 2 \quad - 1 ] ^ { \mathrm { T } } , \pmb { b } _ { 2 } = [ 0 \quad 1 \quad 2 ] ^ { \mathrm { T } }$ 关于基 $\{ e _ { 1 } , e _ { 2 } , e _ { 3 } \}$ 与基 $\left\{ a _ { 1 } , \ a _ { 2 } , \ a _ { 3 } \right\}$ 的表示，其中 $\mathbf { a } _ { 1 } = [ 1 \quad 1 \quad 0 ] ^ { \mathrm { T } } , \mathbf { a } _ { 2 } = [ 0 \quad 1 \quad 1 ] ^ { \mathrm { T } } , \mathbf { a } _ { 3 } = [ 1 \quad 0 \quad 1 ] ^ { \mathrm { T } } . \quad \mathsf { U }$。

正如习题 1 所示，任一矩阵均可视为其列向量关于标准基的表示。事实上，当矩阵 $ A $ 是线性映射 $b _ { 1 } , b _ { 2 } , \ldots , b _ { n }$ 关于某一基的表示时，$ A $ 的列空间（或行空间）的维数——即 $ \dim(\operatorname{Im} A) $（参见第 3.3 节）——与 $ \operatorname{span} \, \text{$\{ b _ { 1 } , b _ { 2 } , . . . , b _ { n } \}$} $ 的维数之间存在紧密联系。

我们首先注意到：向量组 $b _ { 1 } , . . . , b _ { p } \left( 1 \leq p \leq n \right)$ 线性相关，当且仅当它们在该基下的表示 $\pmb { \alpha } _ { j } = [ { \pmb { \alpha } } _ { 1 j } \pmb { \alpha } _ { 2 j } \cdots \pmb { \alpha } _ { m j } ] ^ { \mathrm { T } } ,$、$( j = 1 , 2 , \ldots , p )$ 线性相关。事实上，等式  

$$
\sum _ { j \mathop { = } 1 } ^ { p } \beta _ { j } b _ { j } \mathop { = } 0\tag{3}
$$  

结合 (2) 式可得  

$$
\sum _ { j = 1 } ^ { p } \beta _ { j } \biggl ( \sum _ { i = 1 } ^ { m } \alpha _ { i j } a _ { i } \biggr ) = \sum _ { i = 1 } ^ { m } \Bigg ( \sum _ { j = 1 } ^ { p } \alpha _ { i j } \beta _ { j } \Bigg ) a _ { i } = \theta ,
$$

其中，$\{ a _ { i } \} _ { i = 1 } ^ { m }$ 是所依据的基。因此，$\{ { \pmb a } \} _ { i = 1 } ^ { m }$ 的线性无关性推出：对所有 $i = 1 , 2 , \dots , m ,$，有 $\sum _ { j = 1 } ^ { p } { \alpha _ { i j } \beta _ { j } } = \mathrm { { \bar { 0 } } }$；或者说，等价地，

$$
\sum _ { j = 1 } ^ { p } \beta _ { j } { \pmb a } _ { j } = \sum _ { j = 1 } ^ { p } \beta _ { j } [ { \pmb \alpha } _ { 1 j } \quad { \pmb \alpha } _ { 2 j } \quad \cdots \quad { \pmb \alpha } _ { m j } ] ^ { \mathrm { T } } = { \pmb \theta } .\tag{4}
$$

于是，$b _ { 1 } , b _ { 2 } , \ldots , b _ { p }$ 的线性相关性蕴含 $\mathfrak { a } _ { 1 } , \mathfrak { a } _ { 2 } , \ldots , \mathfrak { a } _ { p }$ 的线性相关性。反之，若从式 (4) 出发并重复上述论证，则可轻易推出关系式 (3)。因此，系统 $\{ b _ { j } \} _ { j = 1 } ^ { p }$ 与 $\{ \alpha _ { j } \} _ { j = 1 } ^ { p }$ 或者同时线性相关，或者同时线性无关。通过调整元素的顺序，该结论可直接推广至 $\{ b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \}$ 中任意 p 个元素及其表示 $( 1 \leq p \leq n )$。
