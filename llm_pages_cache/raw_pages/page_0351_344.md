**定理 2 的证明**．若状态 $z$ 可在时间 $t$ 内从状态 $y$ 到达，则利用 $t ,$ 及式 (5)，有  

$$
z - e ^ { A t } y = \int _ { 0 } ^ { t } e ^ { ( t - s ) A } B u ( s ) d s
$$  

对某个 $\pmb { u } \in \mathcal { U } _ { m }$ 成立。应用引理 1，可将上式写为  

$$
z - e ^ { A t } y = \sum _ { j = 1 } ^ { n } A ^ { j - 1 } B \int _ { 0 } ^ { t } \psi _ { j } ( t - s ) u ( s ) d s ,
$$  

再结合定义 (6)，立即可知 $\mathbf { \delta } \mathbf { z } \mathrm { ~ - ~ } e ^ { \boldsymbol { A } t } \mathbf { y } \in \mathcal { C } _ { \boldsymbol { A } , \boldsymbol { B } }$。  

对于其逆命题，设 $\mathbf { \delta } \mathbf { z } \mathrm { ~ - ~ } e ^ { \boldsymbol { A } t } \mathbf { y } \in \mathcal { C } _ { \boldsymbol { A } , \boldsymbol { B } }$。我们需要构造一个输入（即控制函数）$u(t)$，使得系统能从初始状态 $y$ 被“驱动”至终态 $z$。利用引理 2，可将 ${ \pmb u } ( t )$ 表示为  

$$
z - e ^ { A t } y = W ( t ) w = \int _ { 0 } ^ { t } e ^ { A s } B B ^ { * } e ^ { A ^ { * } s } w ~ d s
$$  

其中 $\pmb { w } \in \mathbb { C } ^ { n } ,$。令 $s = t - \tau$，便得到  

$$
z - e ^ { A t } y = \int _ { 0 } ^ { t } e ^ { A ( t - \tau ) } B B ^ { * } e ^ { A ^ { * } ( t - \tau ) } w d \tau = \int _ { 0 } ^ { t } e ^ { A ( t - \tau ) } B u ( \tau ) d \tau ,
$$

其中我们定义  u  $( \tau ) = B ^ { * } e ^ { A ^ { * } ( t - \tau ) } w \in \mathcal { U }$ _ { m } 。将此式与式 (5) 比较，可知状态 $ z $ 在时刻 $ t $ 可由状态 $ y $ 达到。

**推论 1.** 数对  ( A , B )  是可控的，当且仅当系统  { $\dot { \mathbf { x } } } = A { \mathbf { x } } + B { \mathbf { \mathfrak { u } } } , { \mathbf { \mathfrak { x } } } ( 0 ) = { \mathbf { \mathfrak { x } } }$ _ { 0 }  是可控的。

**证明.** 若数对  ( A , B )  是可控的，则 $\mathcal { C }$ _ { A , B } $= \mathbb { C } ^ { n }$ 。因此，对任意向量 $y , z \in \mathbb { C } ^ { n } ,$ ，平凡地有 $\mathbf { \delta } \mathbf { z } \mathrm { ~ - ~ } e ^ { \mathbf { { \cal A } } t } \mathbf { y } \in \mathcal { C }$ _ { { $\cal A } , { \cal B } }  $。于是，由定理 2 可知该系统是可控的。

反之，若该系统是可控的，则特别地，任意向量  z  $\in \mathcal { C } ^ { n }$ 均可从零向量出发达到；再由定理 2，可知 $\mathcal { C }$ _ { A , B } $= \mathbb { C } ^ { n }$ 。因此，数对  ( A , B )  是可控的。

当系统可控时，事实上任意状态  z  $\in \mathbb { C } ^ { n }$ 均可从任意初态 $\pmb { y } \in \mathbb { C } ^ { n }$ 出发，在任意给定时刻  t > 0  达到。为说明这一点，我们构造一个显式的控制函数  u ( s ) ，使得对应解在任意指定时间 $ t $ 内由 $ y $ 转移到 $ z $。因此，在可控情形下，引理 2 中的矩阵  W ( t )  是正定的，从而我们可以定义函数  

$$

\pmb { u } ( s ) = B ^ { * } e ^ { \pmb { A } ^ { * } ( t - s ) } W ( t ) ^ { - 1 } ( \pmb { z } - e ^ { \pmb { A } t } \pmb { y } ) .\tag{8}
$$
  

于是式 (5) 给出

$$
x ( t ; y , u ) = e ^ { A t } y + \left( \int _ { 0 } ^ { t } e ^ { A ( t - s ) } B B ^ { * } e ^ { A ^ { * } ( t - s ) } d s \right) W ( t ) ^ { - 1 } ( z - e ^ { A t } y ) .
