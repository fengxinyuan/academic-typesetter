## 5.14 杂项习题

1. 对于哪些实数 α，下列矩阵是正定的：

(a)  

$$
{ \left[ \begin{array} { l l l } { 1 } & { \alpha } & { \alpha } \\ { \alpha } & { 1 } & { \alpha } \\ { \alpha } & { \alpha } & { 1 } \end{array} \right] } ,
$$  

(b)  

$$
{ \left[ \begin{array} { l l l } { 1 } & { 1 } & { \alpha } \\ { 1 } & { 1 } & { 1 } \\ { \alpha } & { 1 } & { 1 } \end{array} \right] } .
$$  

答：(a) $- \frac { 1 } { 2 } < \alpha < 1$；(b) 无解。

2. 设 $A \in \mathbb { C } ^ { n \times n }$，且假设 $A { \boldsymbol { \mathbf { x } } } = \lambda { \boldsymbol { \mathbf { x } } }$ 与 $A ^ { * } y = \mu { \bf { y } } \left( { \bf { x } } , { \bf { y } } \neq 0 \right)$。证明：若 $\lambda \neq \mu$，则 $\pmb { x } \perp \mathbf { y } .$；若 $\mathbf { \nabla } x = y ;$，则 $\lambda = \bar { \mu }$。

3. 验证矩阵 $H \geq \theta$ 是正定的当且仅当 det $H \neq 0 .$。

4. 设 $A , B \in \mathbb { C } ^ { n \times n }$，并定义  

$$
R = { \left[ \begin{array} { l l } { A } & { B } \\ { B } & { - A } \end{array} \right] }
$$  

试证：λ 是 R 的特征值，仅当 −λ 是 R 的特征值。

提示：注意到 $P R + R P = 0$，其中  

$$
P = \left[ { \begin{array} { r r } { 0 } & { I } \\ { - I } & { 0 } \end{array} } \right] .
$$

5. 验证：埃尔米特酉矩阵的特征值只能是 $+1$ 和 $-1$。

6. 若 $P$ 是一个正交投影矩阵，且 $$\alpha _ { 1 } , \alpha _ { 2 }$$ 为非零实数，则证明矩阵 $$\alpha _ { 1 } ^ { 2 } P + \alpha _ { 2 } ^ { 2 } ( I - P )$$ 是正定矩阵。  
提示：利用定理 5.2.1。

7. 证明：一个既非零矩阵又非单位矩阵的正交投影矩阵是半正定矩阵。
