## 9.5 $ f(A) $ 的谱分解

如下所述的分解，即 $ f(A) $ 的**谱分解**（spectral resolution），具有重要意义，且显然与我们此前已在定理 4.10.3 和习题 4.14.3 中讨论过的**单矩阵的谱定理**密切相关。该分解以矩阵 $ A $ 的基本性质为依据，给出了  f ( A )  的一种有用而显式的表达式。

**定理 1.** 设  A  $\in \mathbb { C } ^ { n \times n } , \ f ( \lambda$ )在 $ A $ 的谱  \{ $\lambda$ _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { s } \}  上有定义；记  o f A , f _ { k , j }  为函数 $f ( \lambda$ )在特征值 $\lambda$ _ { k } $\left( k = 1 , 2 , \right.$ 处的第 $ j $ 阶导数值； $\dots , s , j = 0 , 1 , \dots , m$ _ { k } - 1 )  为  m _ { k }  的指标（index），即 $\lambda$ _ { k }  的指标；则存在一组与 $ f(\lambda) $ 无关的矩阵  Z _ { k j } ，使得  

$$
f ( A ) = \sum _ { k = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } f _ { k , j } Z _ { k j } .\tag{1}
$$

此外，矩阵  Z _ { k j }  是 $\mathbb { C } ^ { n \times n }$ 中线性无关的元素，且它们彼此之间以及与 $ A $ 均可交换。

**证明**：回顾函数  f  $( \lambda$ )与由式 (9.2.8) 所定义的多项式 $p ( \lambda$ )，二者在 $ A $ 的谱上取值相同。因此有  f ( A ) = p ( A ) ，而将  Z _ { k j } $= \varphi$ _ { k j } ( A )  代入即得式 (1)。由此亦立即可知，$ A $ 与所有  Z _ { k j }  彼此两两可交换。

$$
