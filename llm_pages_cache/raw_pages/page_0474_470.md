## 13.7 利纳尔–希帕尔特判据  

A. 利纳尔（A. Liénard）与 M. 希帕尔特（M. Chipart）的名字与实系数多项式零点的稳定性判据紧密关联。借助前一节的结果，我们现在可借助贝祖矩阵（Bezoutian）给出原始利纳尔–希帕尔特†稳定性判据的一个修正版本。  

考虑一个多项式 $\begin{array} { r } { a ( \lambda ) = \sum _ { j = 0 } ^ { l } a _ { j } \lambda ^ { j } . } \end{array}$，其中 $a _ { \imath } \neq 0$，且其系数均为实数。若 $ l $ 为偶数，定义  

$$
h ( \lambda ) = \sum _ { j = 0 } ^ { l / 2 } a _ { 2 j } \lambda ^ { j } , \qquad g ( \lambda ) = \sum _ { j = 0 } ^ { ( l / 2 ) - 1 } a _ { 2 j + 1 } \lambda ^ { j } .
$$  

若 $ l $ 为奇数，则令  

$$
h ( \lambda ) = \sum _ { j = 0 } ^ { 1 / 2 ( l - 1 ) } a _ { 2 j } \lambda ^ { j } , \qquad g ( \lambda ) = \sum _ { j = 0 } ^ { 1 / 2 ( l - 1 ) } a _ { 2 j + 1 } \lambda ^ { j } .
$$  

为简洁起见，我们将 $h ( \lambda )$ 与 $g ( \lambda )$，以及显然成立的表示式  

$$
a ( \lambda ) = h ( \lambda ^ { 2 } ) + \lambda g ( \lambda ^ { 2 } ) ,\tag{1}
$$  

统称为 $L { - } C$ 对 $a ( \lambda )$ 的分裂（splitting）。
