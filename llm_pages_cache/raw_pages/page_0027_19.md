习题 7．设矩阵 $ A $ 与 $ B $ 的对应分块  A _ { i j }  与  B _ { i j }  均具有相同尺寸，则  

$$
A + B = [ A _ { i j } + B _ { i j } ] _ { i , j = 1 } ^ { m , n } , \qquad A - B = [ A _ { i j } - B _ { i j } ] _ { i , j = 1 } ^ { m , n } .
$$  

习题 8．设  m  $\times l$ 阶矩阵 $ A $ 的分块为  A _ { i k } ，其尺寸为  m _ { i } $\times l$ _ { k } ，其中 $1 \leq i \leq r$ 且 $1 \leq k \leq \alpha ,$ ；又设 $l \times n$ 阶矩阵 $ B $ 的分块为  B _ { k j } ，其尺寸为  l _ { k } $\times n$ _ { j } ，其中 $1 \leq j \leq s ,  $；则 [参见式 (1.3.5)]  

$$
A B = \left[ \sum _ { k = 1 } ^ { \alpha } A _ { i k } B _ { k j } \right] _ { i , j = 1 } ^ { r , s } . \sqsupset
$$

注意：对分块矩阵进行乘法运算时，需满足两个“相容性”条件。首先，矩阵 $ A $ 的每一行所含的子块个数必须等于矩阵 $ B $ 的每一列所含的子块个数；其次，$ A $ 的列数必须等于每个 $ B_k $ 的行数，其中 $\pmb { A }$ _ { i k } 、 B _ { k j } 、 $1 \leq k \leq \alpha$ ，且对所有可能的 $ i $ 和  j .  均成立。

## 1.7 矩阵的多项式

设 $ A $ 为一个方阵，并设  

$$

p ( \lambda ) = a _ { 0 } + a _ { 1 } \lambda + \cdot \cdot \cdot + a _ { \mathrm { I } } \lambda ^ { l } \qquad ( a _ { l } \neq 0 )
$$
  

为一个次数为 $ l $、系数为标量的多项式。借助第 1.2 节与第 1.3 节中引入的矩阵运算，可定义如下矩阵：  

$$

p ( A ) \triangleq a _ { 0 } I + a _ { 1 } A + \cdot \cdot \cdot + a _ { l } A ^ { l }
$$
  

称此矩阵为关于 $ A $ 的一个多项式。

**习题 1.** 验证：若  p  $( \lambda ) = 2 - \lambda + \lambda ^ { 2 }  $，且  

$$

A = { \left[ \begin{array} { l l l } { 0 } & { 1 } & { 0 } \\ { 0 } & { 1 } & { 0 } \\ { 1 } & { 0 } & { 1 } \end{array} \right] } ,
$$
  

则  

$$

p ( A ) = 2 I - A + A ^ { 2 } = { \left[ \begin{array} { l l l } { 2 } & { 0 } & { 0 } \\ { 0 } & { 2 } & { 0 } \\ { 0 } & { 1 } & { 2 } \end{array} \right] } . \quad \boxed { 1 }
$$
  

由于任一 方阵均与自身可交换，故同一矩阵的所有多项式彼此之间均可交换。这一事实是将下列标量多项式的熟知性质推广至矩阵多项式时所必需的。
