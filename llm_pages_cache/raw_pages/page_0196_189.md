**定理 2**：若正规矩阵  A  $\in { \mathcal { F } } ^ { n \times n }$ 的所有特征值均位于单位圆上，则 $ A $ 是酉矩阵。

证明．设  A  $\mathbf { x }$ _ { i } $= \lambda$ _ { i } $\mathbf { x }$ _ { i } ，其中 $| \lambda$ _ { i } | = 1  且  ( x _ { i } , x _ { j } $) = \delta$ _ { i j } \  $( 1 \leq i , j \leq n$ )。对任意向量  \ b { x } $\in \mathcal { F } ^ { n }$ ，记 $\begin{array} { r } { { \pmb x } = \sum$ _ { i = 1 } ^ { n } { $\pmb \alpha }$ _ { i } { $\pmb x }$ _ { i } } $\end{array}  $；则可得  

$$

A ^ { * } A { \boldsymbol { \mathbf { \mathit { x } } } } = A ^ { * } { \biggl ( } \sum _ { i = 1 } ^ { n } \alpha _ { i } A x _ { i } { \biggr ) } = A ^ { * } { \biggl ( } \sum _ { i = 1 } ^ { n } \alpha _ { i } \lambda _ { i } x _ { i } { \biggr ) } .\tag{1}
$$
  

由习题 5.2.7 可知  A ^ { * } x _ { i } $= \bar { \lambda }$ _ { i } $\mathbf { x }$ _ { i } $( i = 1 , 2 , \ldots , n$ ) ，因此式 (1) 化为  

$$

A ^ { * } A x = \sum _ { i = 1 } ^ { n } \alpha _ { i } \lambda _ { i } A ^ { * } x _ { i } = \sum _ { i = 1 } ^ { n } \alpha _ { i } \vert \lambda _ { i } \vert ^ { 2 } \mathbf { x } _ { i } = \sum _ { i = 1 } ^ { n } \alpha _ { i } \mathbf { x } _ { i } = \mathbf { x } .
$$
  

于是对每个  \pmb { x } $\in \mathcal { F } ^ { n }$ ，均有  A ^ { * } A { $\mathbf { x } } = { \mathbf { x } }$ ，从而  A ^ { * } A = I 。关系式  A A ^ { * } = I  现在随之成立，因为左逆矩阵同时也是右逆矩阵（参见第 2.6 节）。故矩阵 $ A $ 是酉矩阵。

因此，一个正规矩阵是酉矩阵当且仅当其特征值均位于单位圆周上。酉矩阵亦可用标准内积来刻画。特别地，下一个定理表明：若 $ U $ 是酉矩阵，则对任意向量 $ x $，向量 $ x $ 与 $ Ux $ 具有相同的欧几里得长度（即范数）。

定理 3．矩阵  U  $\in \mathcal { F } ^ { n \times n }  $ 是酉矩阵当且仅当

$$
( U \mathbf { x } , U \mathbf { y } ) = ( \mathbf { x } , y )\tag{2}
$$  

对所有 $x , y \in { \mathcal { F } } ^ { n } .$ 成立。  

**证明**：若 $U ^ { * } U = I ,$，则  

$$
( U \pmb { x } , U y ) = ( U ^ { * } U \pmb { x } , y ) = ( \pmb { x } , \pmb { y } )
$$  

且式 (2) 成立。反之，由式 (2) 可得 $( U ^ { * } U x , y ) = ( { \boldsymbol { x } } , { \boldsymbol { y } } )$，等价地，$( ( U ^ { * } U - I ) x , y ) = 0$ 对所有 $\mathbf { x } , \mathbf { y } \in \mathcal { F } ^ { n } ,$ 成立。参见习题 3.13.2，我们立即得到 $U ^ { * } U = I$。从而亦有 $U U ^ { * } = I$，故 $ U $ 是一个酉矩阵（unitary matrix）。  

注意：式 (2) 对 $ \mathbb{C}^n $ 中每一个向量 $ x $、$y \in { \mathcal { F } } ^ { n }$ 成立，当且仅当它对 $ \mathbb{C}^n $ 中某组基的向量成立。（请将下一条推论的陈述与习题 3.14.12 的内容对照。）  

**推论 1**：矩阵 $U \in { \mathcal { F } } ^ { n \times n }$ 是酉矩阵，当且仅当它将 $ \mathbb{C}^n $ 的一组标准正交基映射为 $ \mathbb{C}^n $ 的另一组标准正交基。
