## 2.2 行列式的性质  

以下记号中，$ A $ 表示任意一个 $ n \times n $ 矩阵。首先，我们指出若干由行列式定义直接导出的基本性质。

习题 1．证明：若  \tilde { A }  是由方阵 $ A $ 的某一行（或某一列）乘以标量  k ,  所得的矩阵，则  

$$
\operatorname* { d e t } { \tilde { A } } = k \operatorname* { d e t } A . \quad \bigsqcup
$$  

回顾：若函数  f  满足对域  { $\mathcal { F } } \operatorname { i f } f ( k x ) = k f ( x$ )中任意 $k \in \mathcal { F }$ 均有 $ f(kx) = k f(x) $，则称该函数在域  { $\mathcal { F } } \operatorname { i f } f ( k x ) = k f ( x$ )上是齐次的。因此，习题 1 的结论表明：行列式关于矩阵 $ A $ 的第 $ i $ 行（或第 $ i $ 列）是一个齐次函数。将此性质重复应用 $ n $ 次，易见：对任意标量 $ k $ 及任意 $ n \times n $ 矩阵 $ A $，均有  

$$
\operatorname* { d e t } ( k A ) = k ^ { n } \operatorname* { d e t } A .\tag{1}
$$
