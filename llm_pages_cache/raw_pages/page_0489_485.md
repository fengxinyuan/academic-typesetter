命题 2．若实系数多项式 $a ( \lambda ) = a _ { 0 } + a _ { 1 } \lambda + \cdot \cdot \cdot + a _ { l } \lambda ^ { l }$（其中 $a _ { l } > 0$）是稳定的，则  

$$
a _ { 0 } > 0 , a _ { 1 } > 0 , \ldots , a _ { l - 1 } > 0 , a _ { l } > 0 .\tag{6}
$$  

证明．任一 $ l $ 次实系数多项式 $a ( \lambda )$ 均可表示为  

$$
a ( \lambda ) = a _ { l } \prod _ { i = 1 } ^ { s } { ( \lambda + \lambda _ { i } ) \prod _ { j = 1 } ^ { k } { ( \lambda ^ { 2 } + \mu _ { j } \lambda + \nu _ { j } ) } } ,\tag{7}
$$

其中，$s + 2 k = n$，且数 $\lambda _ { i } , \mu _ { j } , \nu _ { j }$ 均为实数。显然，$a ( \lambda )$ 的所有零点均具有负实部这一条件，意味着 $\lambda _ { i } > 0 ,$ 与 $i = 1 , \ 2 , \ldots , \ s ,$，同时也意味着二次多项式 $\lambda ^ { 2 } + \mu _ { j } \lambda + \nu _ { j } ,$ 与 $j = 1 , 2 , \dots , k$ 的零点均位于开左半平面。最后这一要求推出：对所有 $ j $，均有 $\mu _ { j } > 0 , \nu _ { j } > 0$。现在由式 (7) 显然可知，由于 $a ( \lambda )$ 的系数均为正数之积的和，故它们均为正数。■

需注意，条件 (6) 并不足以保证 $a ( \lambda ) .$ 的稳定性，反例即多项式 $\lambda ^ { 2 } + 1$。

因此，在研究稳定性判据时，我们可首先假定 $ a(\lambda) $ 的各项系数均为正数。此时可以证明，(13.9.11) 中的行列式不等式并非相互独立：具体而言，偶阶胡尔维茨行列式 $\Delta _ { i }$ 的正定性蕴含奇阶胡尔维茨行列式的正定性，反之亦然。这一事实将由定理 4 推出。我们首先对李纳尔–希帕特（Liénard–Chipart）与马尔可夫（Markov）稳定性判据作简化处理，该简化借助柯西指标（Cauchy index）完成。
