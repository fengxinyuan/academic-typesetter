因此，每个幂等矩阵 $ P $ 均生成两个唯一确定、彼此互补的子空间 $ \mathrm{$\mathcal { S } _ { 1 } $= \mathop { \mathrm { K e r } } \ P } $ 与 $ \mathrm{$\mathcal { S } _ { 2 } $= \mathrm { I m } ~ P } $，使得它们的直和等于整个空间。其逆命题亦成立：若 $ \mathrm{$\mathcal { S } _ { 1 } $+ \mathcal { S }$ _ { 2 } $= \mathcal { F } ^ { n } , } $，则存在唯一的幂等矩阵 $ P $，使得 $ \mathrm{$\mathcal { S } _ { 1 } $= \mathrm { K e r } } $ 且 $ \mathrm{$\mathcal { S } _ { 2 } =$} = \operatorname{Im} P $。为验证这一点，只需如下定义† $ P $ 在 $ \mathrm{${ $\mathcal { F } } ^ { n } } $ 上的作用：对任意向量 $ \mathbf{x} \in \mathrm{${ $\mathcal { F } } ^ { n } } $，令 $ \mathrm{$P { $\mathbf { x } } = { \mathbf { x } }$ _ { 2 }$} $，其中 $ \mathrm{${ $\pmb x } = { \pmb x }$ _ { 1 } + { $\pmb x }$ _ { 2 }$} $ 且 $ \mathrm{$\pmb { x } _ { 1 } $\in \mathcal { S }$ _ { 1 }$} \in \mathrm{$\pmb { x } _ { 2 } $\in \mathcal { S }$ _ { 2 }$} $。由此显然可得 $ \mathrm{$P ^ { 2 } = P$} $ 且 $ \mathrm{$\mathcal { S } _ { 1 } $= \mathrm { K } } = \ker P $、$ \mathrm{$P  $, \mathcal { S }$ _ { 2 } =$} = \operatorname{Im} P $。此外，$ P $ 的唯一性亦直接由该定义推出。因此，在 $ \mathrm{${ $\mathcal { F } } ^ { n \times n } } $ 中的幂等矩阵与满足 $ \mathrm{$\mathcal { S } _ { 1 } $, \mathcal { S }$ _ { 2 }$} $ 且 $ \mathrm{$\mathcal { S } _ { 1 } $\dot { + } \mathcal { S }$ _ { 2 } $= \mathcal { F } ^ { n } } $ 的子空间对之间，存在一一对应关系。

鉴于这一结果，我们称幂等矩阵 $ P $ 实现了空间 $ \mathrm{${ $\mathcal { F } } ^ { n } } $ 到子空间 $ \mathrm{$\mathcal { S } _ { 2 }$} $ 上沿 $ \mathrm{$\mathcal { S } _ { 1 }$} $ 方向（或平行于 $ \mathrm{$\mathcal { S } _ { 1 }$} $）的投影，亦即沿 $ \mathrm{$\mathcal { S } _ { 1 }$} $ 投影到 $ \mathrm{$\mathcal { S } _ { 2 }$} $ 上。故“投影矩阵”（projector）可作为“幂等矩阵”的另一标准称谓。

接下来，我们将研究投影矩阵的谱性质。

## 定理 3．幂等矩阵是可对角化的。

**证明**．我们在习题 4.11.7 中已指出：幂等矩阵的特征值全为 1 或 0。由此可知，$ P $ 的所有特征向量均属于 $ \operatorname{Im} \, \text{$P  $\left( \lambda = 1 \right$ )$} $ 或 $ \operatorname{Ker} \, \text{$P  $\left( \lambda = 0 \right$ )$} $。根据定理 2，$ P $ 的特征向量必张成 $ \text{${ $\mathcal { F } } ^ { n } } $，故 $ P $ 是一个可对角化矩阵（即单矩阵）。

此时可应用谱定理（定理 4.10.3）：

**推论 1**．任一 $ \text{$n  $\times n } $ 阶投影矩阵 $ P $ 具有如下表示形式：

$$
\text{$$
 $P = \sum$ _ { j = 1 } ^ { r } x _ { j } y _ { j } ^ { * } $,\tag{1}$ 
$$}
$$

其中 $ \text{$r  $= \operatorname { r a n k } P } $ 与 $ \text{$\{ $\boldsymbol { x }$ _ { 1 } $, \ldots , \boldsymbol { x }$ _ { r } \} , \{ $\boldsymbol { y }$ _ { 1 } $, \ldots , \boldsymbol { y }$ _ { r } \}$} $ 是 $ \text{$\mathcal { F } _ { n }$} $ 中的一组双正交系。

注意，直接计算 $ \text{$P ^ { 2 }$} $ 可知：反之，任何形如 (1) 的矩阵均为幂等矩阵。

一个重要的特例是 $ P $ 同时为幂等矩阵与埃尔米特矩阵，即满足  
$$
\text{$P ^ { 2 } = P$} \quad \text{且} \quad \text{$P ^ { * } = P .$}.
$$  
此时子空间 $ \text{$\mathcal { S } _ { 1 } $= \mathop { \mathrm { K e r } } P } $ 与 $ \text{$\mathcal { S } _ { 2 } $= \operatorname { I m } P } $ 彼此正交。事实上，若 $ \text{$\pmb { x } $\in \mathcal { S }$ _ { 1 }$} $ 且 $ \text{$\pmb { y } $\in \mathcal { S }$ _ { 2 }$} $，则  

$$
\text{$$
( { $\pmb x } , { \pmb y } ) = ( { \pmb x } , P { \pmb y } ) = ( P ^ { * } { \pmb x } , { \pmb y } ) = ( P { \pmb x } , { \pmb y } ) = 0$ 
$$}
$$  

因而 $ \text{${ $\mathcal { S } }$ _ { 1 } $\oplus { \mathcal { S } }$ _ { 2 } = { $\mathcal { F } } ^ { n } } $。这种既是埃尔米特矩阵又是幂等矩阵的 $ P $ 称为**正交投影矩阵**：它实现了将 $ \text{${ $\mathcal { F } } ^ { n } } $ 沿其正交补空间 $ \text{$\mathcal { S } _ { 1 } $= \mathop { \mathrm { K e r } } P } $ 投影到子空间 $ \text{$\mathcal { S } _ { 2 } $= \operatorname { I m } P } $ 上的线性映射。
