## 6.6 若尔当矩阵的参数

设  A  $\in \mathbb { C } ^ { n \times n }$ ，且令 $ J $（由式 (6.5.4) 与 (6.5.5) 给出）为 $ A $ 的一个若尔当标准形，即存在可逆矩阵 $ P $，使得 $\bar { A } = P J \bar { P } ^ { - 1 }$ 。本节将阐明：某一特征值的代数重数与几何重数等重数性质，和该特征值所对应的若尔当块（即 $ J $ 的子矩阵 $J ( \lambda$ _ { i } ) ）的参数之间存在若干关系。

命题 1．矩阵 $\ b { A } \in \mathbb { C } ^ { n \times n }$ 关于特征值 $\lambda _ { i } \in \sigma ( A )$ 的广义特征子空间的维数（即：$J ( \lambda _ { i } )$ 在 $E q$（6.5.4）中的阶数）等于 $\lambda _ { i }$ 的代数重数。

**证明．** 设 $A = P J P ^ { - 1 }$，其中 J 由式 (6.5.4) 给出。A 与 J 的特征多项式相同（见第 4.11 节），因此  

$$
c ( \lambda ) = { \operatorname * { d e t } ( \lambda I - J ) } = \prod _ { i = 1 } ^ { s } { \operatorname * { d e t } ( \lambda I - J ( \lambda _ { i } ) ) } .
$$  

根据式 (6.5.5) 与 (6.5.3)，有  

$$
c ( \lambda ) = \prod _ { i = 1 } ^ { s } ( \lambda - \lambda _ { i } ) ^ { q _ { i } } ,\tag{1}
$$  

其中 $q _ { i }$ 是 $J ( \lambda _ { i } ) \left( 1 \leq i \leq s \right)$ 的阶数。最后只需回顾：式 (1) 中的 $q _ { i }$ 按定义即为 $\lambda _ { i }$ 的代数重数。■  

注意：$J ( \lambda _ { i } )$ 中约当块的个数等于 (6.4.1) 式中行数，亦即特征值 $\lambda _ { i }$ 的几何重数；因此，由 (6.4.1) 式及命题 1 可立即推出：任一特征值的几何重数不超过其代数重数（即 (6.4.1) 式中所有元素的总数）。然而，仅在接下来所讨论的特殊情形下，这两个量才能唯一确定与 $\lambda _ { i }$ 相关联的约当子矩阵 $J ( \lambda _ { i } )$。

命题 2．矩阵 A 是可对角化的（即“简单矩阵”），当且仅当它的每个特征值的几何重数均等于其代数重数。等价地，A 是简单矩阵当且仅当 A 的极小多项式仅有单重零点。
