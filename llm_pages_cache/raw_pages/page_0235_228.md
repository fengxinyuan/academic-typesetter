推论 2．任一复方阵 $ B $ 均相似于一个形如 (6) 的矩阵 $ A $，其中 $\begin{array} { r } { \dot { A } _ { i } \in \mathcal { F } ^ { q _ { i } \times q _ { i } } , \sigma ( A _ { i } ) = \{ \lambda _ { i } \} , 1 \leq i \leq s , } \end{array}$，且诸数 $q _ { i }$ 由 $ B $ 唯一确定。

习题 2．设 $ \lambda $ 是两个相似矩阵 $ A $ 与 $ B $ 的一个共同特征值。证明：$ \lambda $ 关于 $ A $ 的指数与关于 $ B $ 的指数相等。

本节的最后一个定理称为凯莱–哈密顿定理（Cayley–Hamilton theorem），它在矩阵理论中占据重要地位。另一种基于矩阵而非线性变换的证明将在第 7.2 节给出。

定理 5．$T \in { \mathcal { L } } ( { \mathcal { S } } )$ 的特征多项式 $ c(\lambda) $ 是它的一个零化多项式：$c ( T ) = 0 .$

**证明**．首先回顾：线性变换的特征多项式即为其任一矩阵表示的特征多项式（参见第 4.11 节）。参考式 (6)，可知 $ c(T) $ 恰为 $ \text{$A _ { 1 } , A _ { 2 } $, \ldots , A$ _ { s }$} $ 的特征多项式的乘积。对 $ \text{$j  $= 1 , 2 , \dots , s , } $，方阵 $ \text{$A _ { j }$} $ 的阶数恰为 $ \text{$q _ { j } $= \dim \mathcal { G }$ _ { j }$} $，且 $ \text{$\sigma ( A _ { j } ) = \{ $\lambda$ _ { j } \}$} $。因此，$ \text{$A _ { j }$} $ 的特征多项式为 $ \text{$( $\lambda - \lambda$ _ { j } ) ^ { q _ { j } }$} $。于是，由命题 1 可得 $ \text{$q _ { j } $\geq m$ _ { j }$} $。最后，由于  

$$
\text{$$
 $c ( T ) = c ( A ) = \prod$ _ { j = 1 } ^ { s } $( \lambda - \lambda$ _ { j } ) ^ { q _ { j } }
$$}
$$  

且  

$$
\text{$$
 $m ( T ) = \sum$ _ { j = 1 } ^ { s } { $( \lambda - \lambda$ _ { j } ) ^ { m _ { j } } } ,
$$}
$$  

显然 $ c(T) $ 可被 $ m(T) $ 整除。再由定理 1 的推论 2，即得 $ \text{$c ( T )$} $ 的结论。
