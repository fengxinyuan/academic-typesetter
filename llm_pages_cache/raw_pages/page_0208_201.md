我们将上述讨论归纳如下：  

**定理 1.** 任一实矩阵  A  $\in \mathbb { R } ^ { n \times n }$ ，在其特征多项式的每个实零点（复零点）处，均在 $\mathbb { R } ^ { n }  $ 中对应一个一维（二维）的不变子空间。  
在前一种情形下，该不变子空间由  A ,  的一个（实）特征向量张成；而在后一种情形下，该矩阵在这一不变子空间中不含有任何特征向量。

满足条件 $U ^ { \mathrm { T } } U = U U ^ { \mathrm { T } } = I$ 的矩阵 $U \in \mathbb { R } ^ { n \times n }$ 称为正交矩阵。将正交矩阵视为 $ \mathbb{R}^{n\times n} $ 中的矩阵时，其性质可由酉矩阵的相应性质导出。特别地，由于任一酉矩阵都是可对角化的（即单的），故它相似于以其特征值为对角元的对角矩阵。其中某些特征值可能是复数，因而当把 $U$ 视为 $ \mathbb{R}^{n\times n} $ 中的矩阵时，这些复数便不再是它的特征值。因此，如下结论具有重要意义。
