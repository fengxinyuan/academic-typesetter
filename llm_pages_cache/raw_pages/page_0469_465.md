定理 2．采用前一段的记号，矩阵 $\widetilde { B } = \widehat { B } D$ 是埃尔米特矩阵。若 $I f \widetilde { B }$ 同时是非奇异的，则  

$$
\begin{array} { l } { { \pi ( a ) = v ( \widetilde { B } ) , } } \\ { { \nu ( a ) = \pi ( \widetilde { B } ) , } } \\ { { \delta ( a ) = \delta ( \widetilde { B } ) = 0 . } } \end{array}
$$  

**证明．** 该定理的断言由定理 1 及如下易验证的关系式推出：  

$$
F \biggl ( \frac { 1 } { i } B \biggr ) F ^ { * } = - \widetilde { B } ,
$$  

其中 $F = \mathrm { d i a g } [ i ^ { l - 1 } , i ^ { l - 2 } , \ldots , i , 1 ]$，而 $ B $ 是与 $a _ { 1 } ( \lambda ) = a ( - i \lambda )$ 和 $\overline { { { a } } } _ { 1 } ( \lambda ) = \overline { { { a } } } ( i \lambda )$ 相关联的贝祖矩阵（Bezoutian）。■  

**推论 1．** 一个多项式 $a ( \lambda )$ 是稳定的，当且仅当矩阵 $\widetilde { B }$ 是正定的。  

**例 2．** 考虑多项式 $a ( \lambda ) = \lambda ^ { 2 } - 2 \lambda + 5$ 与 $a ( - \lambda ) =$，$\lambda ^ { 2 } + 2 \lambda + 5$。其对应的贝祖矩阵为  

$$
{ \widehat { B } } = { \left[ \begin{array} { l l } { - 2 } & { 1 } \\ { 1 } & { 0 } \end{array} \right] } { \left[ \begin{array} { l l } { 5 } & { 2 } \\ { 0 } & { 5 } \end{array} \right] } - { \left[ \begin{array} { l l } { 2 } & { 1 } \\ { 1 } & { 0 } \end{array} \right] } { \left[ \begin{array} { l l } { 5 } & { - 2 } \\ { 0 } & { 5 } \end{array} \right] } = { \left[ \begin{array} { l l } { - 2 0 } & { 0 } \\ { 0 } & { 4 } \end{array} \right] } ,
$$  

因而该矩阵为  

$$
\widetilde { B } = \left[ \begin{array} { r r } { { - 2 0 } } & { { 0 } } \\ { { 0 } } & { { - 4 } } \end{array} \right]
$$

是负定的。因此，该多项式的两个零点 $\lambda _ { 1 }$ 和 $\lambda _ { 2 }$ 均位于开右半平面，符合要求，因为 $\lambda _ { 1 } = 1 + 2 i$ 且 $\lambda _ { 2 } = 1 - 2 i$ □

若定理 2 中的 $a ( \lambda )$ 是一个实系数多项式，则矩阵 $ B $ 中所有满足 $i + j$ 为奇数的第 $ i $ 行第 $ j $ 列元素均为零。以下习题对此予以说明。
