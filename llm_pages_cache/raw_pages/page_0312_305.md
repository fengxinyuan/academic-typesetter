## 9.1 定义在矩阵谱上的函数

设 $A \in \mathbb { C } ^ { n \times n }$，并假定 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 是 A 的互异特征值，于是  

$$
m ( \lambda ) = ( \lambda - \lambda _ { 1 } ) ^ { m _ { 1 } } ( \lambda - \lambda _ { 2 } ) ^ { m _ { 2 } } \cdot \cdot \cdot ( \lambda - \lambda _ { s } ) ^ { m _ { s } }\tag{1}
$$  

即为 A 的极小多项式，其次数为 $m = m _ { 1 } + m _ { 2 } + \cdot \cdot \cdot + m _ { s }$。回顾一下：$\lambda _ { k }$ 作为极小多项式零点的重数 $m _ { k }$ 称为特征值 $\lambda _ { k }$ 的**指数**（见第 6.2 节），它等于与 $\lambda _ { k } \left( 1 \leq k \leq s \right)$ 相关联的初等因子的最高次数。

对任一函数 $f ( \lambda )$，若下列诸数  

$$
f ( \lambda _ { k } ) , f ^ { \prime } ( \lambda _ { k } ) , \ldots , f ^ { ( m _ { k } - 1 ) } ( \lambda _ { k } ) , \qquad k = 1 , 2 , \ldots , s ,\tag{2}
$$  

均有定义，则称该函数**定义在 A 的谱上**。

称为 $ f(\lambda) $ 在矩阵 $ A $ 的谱上的取值，是存在的。显然，任一复系数多项式在任意 $ \mathbb{C}^{n\times n} $ 中矩阵的谱上均有定义。关于极小多项式，还可作进一步阐述：$\mathbb { C } ^ { n \times n }$。

习题 1．验证：矩阵 $ A $ 的极小多项式在其谱上的所有取值均为零。

下一个结果给出了两个标量多项式 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda )$ 生成同一矩阵 $p _ { 1 } ( A ) = p _ { 2 } ( A )$ 的判别准则。此处所述矩阵的定义见第 1.7 节。

命题 1．设 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda )$ 是复系数多项式，且 $\ b { A } \in \mathbb { C } ^ { n \times n }$，则 $p _ { 1 } ( A ) = p _ { 2 } ( A )$ 当且仅当多项式 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda )$ 在 $ A $ 的谱上取值相同。

**证明**．若 $p _ { 1 } ( A ) = p _ { 2 } ( A )$ 且 $p _ { 0 } ( \lambda ) = p _ { 1 } ( \lambda ) - p _ { 2 } ( \lambda )$，则显然有 $p _ { 0 } ( A ) = 0$，从而 $p _ { 0 } ( \lambda )$ 是 $ A $ 的一个零化多项式。因此（由定理 $6 . 2 . 1 ) p _ { 0 } ( \lambda )$ 可知），该多项式可被 $ A $ 的极小多项式 $ m(\lambda) $（由式 (1) 给出）整除；故存在某个多项式 $q ( \lambda )$，使得 $p _ { 0 } ( \lambda ) = q ( \lambda ) m ( \lambda )$。对 $p _ { 0 } ( \lambda )$ 在 $ A $ 的谱上取值，并利用习题 1，易得

$$
p _ { 1 } ^ { ( j ) } ( \lambda _ { k } ) - p _ { 2 } ^ { ( j ) } ( \lambda _ { k } ) = p _ { 0 } ^ { ( j ) } ( \lambda _ { k } ) = 0\tag{3}
$$

对于 $j = 0 , 1 , \ldots , m _ { k } - 1 , 1 \leq k \leq s$。因此，只要满足 $p _ { 1 } ( A ) = p _ { 2 } ( A )$，则两个多项式 $p _ { 1 } ( \lambda )$ 与 $p _ { 2 } ( \lambda )$ 在矩阵 $ A $ 的谱上取值相同。

反之，若条件 (3) 成立，则对每个 $k = 1 , 2 , \ldots , s .$，函数 $p _ { 0 } ( \lambda )$ 在点 $\dot { \iota } _ { \ast k }$ 处具有重数为 $m _ { k }$ 的零点。因此，$p _ { 0 } ( \lambda )$ 必须被 (1) 中的 $m ( \lambda )$ 整除；从而可得 $p _ { 0 } ( A ) = 0$（参见定理 6.2.2 的推论 1），等价地，$p _ { 1 } ( A ) = p _ { 2 } ( A )$。
