此外，由习题 12.1.5 可知，$J _ { \textbf { 1 } } ^ { i } \otimes J _ { 2 } ^ { j }$ 也是一个上三角矩阵。容易验证，它的对角线元素为 $\lambda _ { r } ^ { i } \mu _ { s } ^ { j }$，其中 $r = 1 , 2 , \ldots , m , s = 1 , 2 , \ldots , n .$。因此，矩阵 $p ( J _ { 1 } ; J _ { 2 } )$ 是上三角矩阵，且其对角线元素为 $p ( \lambda _ { r } , \mu _ { s } )$。但上三角矩阵的对角线元素即为其特征值；故 $p ( J _ { 1 } ; J _ { 2 } )$ 的特征值为 $p ( \lambda _ { r } , \mu _ { s } )$，其中 $r = 1 , 2 , \ldots , m , s = 1 , 2 , \ldots , n .$。

现在我们只需证明 $p ( J _ { 1 } ; J _ { 2 } )$ 与 $p ( A ; B )$ 具有相同的特征值。将命题 12.1.2 的推论 2 应用于该情形，可得

$$
\begin{array} { c } { { J _ { 1 } ^ { i } \otimes J _ { 2 } ^ { j } = P A ^ { i } P ^ { - 1 } \otimes Q B ^ { j } Q ^ { - 1 } } } \\ { { = ( P \otimes Q ) ( A ^ { i } \otimes B ^ { j } ) ( P ^ { - 1 } \otimes Q ^ { - 1 } ) , } } \end{array}
$$

又由命题 12.1.2 的推论 1，有 $P ^ { - 1 } \otimes Q ^ { - 1 } = ( P \otimes Q ) ^ { - 1 }$。因此，

$$
J _ { 1 } ^ { i } \otimes J _ { 2 } ^ { j } = ( P \otimes Q ) ( A ^ { i } \otimes B ^ { j } ) ( P \otimes Q ) ^ { - 1 } ,
$$

从而

$$
p ( J _ { 1 } ; J _ { 2 } ) = ( P \otimes Q ) p ( A ; B ) ( P \otimes Q ) ^ { - 1 } .
$$

这表明 $p ( J _ { 1 } ; J _ { 2 } )$ 与 $p ( A ; B )$ 相似，因而它们必具有相同的特征值（第 4.10 节）。■

以下两个特殊情形（分别对应于 $p ( x , y ) = x y$ 和 $p ( x , y ) = x + y )$）可能是最常被使用的。

推论 1．矩阵 $A \otimes B$ 的特征值为 $mn$ 个数：$\lambda _ { r } \mu _ { s } , r = 1$ 与 $2 , \ldots , m , s = 1 , 2 , \ldots , n .$。

推论 2．矩阵 $( I _ { n } \otimes A ) + ( B \otimes I _ { m } )$ 的特征值（或者，等价地——依据习题 4.11.9——矩阵 $( I _ { n } \otimes A ^ { \mathsf { T } } ) + ( B ^ { \mathsf { T } } \otimes I _ { m } ) )$ 的特征值）为 $mn$ 个数：$\lambda _ { r } + \mu _ { s } , r = 1 , 2 , \ldots , m , s = 1 , 2 , \ldots , n .$。

矩阵 $( I _ { n } \otimes A ) + ( B \otimes I _ { m } )$ 常被称为 $A$ 与 $B$ 的克罗内克和（Kronecker sum）。
