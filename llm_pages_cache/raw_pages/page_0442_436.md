其中 $A \in \mathcal { F } ^ { m \times n }$ 且 $\pmb { b } \in \mathcal { F } ^ { m }$，我们希望求解 $\pmb { x } \in \mathcal { F } ^ { n } ,$。我们已知：方程 (1) 存在解当且仅当 $\pmb { b } \in$ ∈ Im A。一般地，解集构成一个由 Ker A 经“平移”所得的向量“流形”，如定理 3.10.2 所述。利用习题 12.8.3 可知，向量 ${ \pmb x } _ { 0 } = { \pmb A } ^ { + } { \pmb b }$ 是该流形中一个解：



$$
\pmb { A x } _ { 0 } = \pmb { A } \pmb { A } ^ { + } \pmb { b } = \pmb { b } ,
$$



并且，${ \pmb x } _ { 0 } = { \pmb A } ^ { + } { \pmb b }$ 是方程 (1) 的唯一解当且仅当 A 非奇异；此时有 $A ^ { + } = A ^ { - 1 }$。

此外，向量 $\pmb { x } \in \mathcal { F } ^ { n }$ 是方程 $\mathbf { E q . } \left( 1 \right)$ 的解当且仅当对 ${ \mathcal { F } } ^ { m }$ 中任意向量范数 ∥·∥，均有 $\| A \pmb { x } - \pmb { b } \| = 0$。

考虑 $\Delta \notin$ ∉ Im A 的情形。此时方程 (1) 无解；但鉴于前述讨论，我们可以将 $A \mathbf { x } = \mathbf { b }$ 的一个近似解定义为使 $\| A \mathbf { x } - \mathbf { b } \|$ 达到最小的向量 $\pmb { x _ { 0 } }$：



$$
\| A \mathbf { x } _ { 0 } - b \| = \operatorname* { m i n } _ { \mathbf { x } \in \mathcal { F } ^ { n } } \| A \mathbf { x } - b \|\tag{2}
$$

在欧几里得向量范数 $\|\cdot\|$ 下。（此时，$\pmb { x _ { 0 } }$ 也被称为不相容（或超定）线性方程组 $\pmb { A } \pmb { x } = \pmb { b }$ 的最小二乘解。注意：若 $\pmb { x _ { 0 } }$ 是这样一个向量，则形如 $\pmb { x } _ { 0 } + \pmb { u }$ 的任意向量也是，其中 $u \in \mathrm { K e r } A . )$。）

现在，对任意 $A \in \mathcal { F } ^ { m \times n }$ 和任意 $\pmb { b } \in \mathcal { F } ^ { m }$，方程 (1) 的最佳近似解是满足方程 (2) 且具有最小欧几里得长度的向量 $\pmb { x _ { 0 } } \in \mathcal { F } ^ { n }$。我们将证明 ${ \pmb x } _ { 0 } = { \pmb A } ^ { + } { \pmb b }$ 即为这样的向量。因此，若 $\pmb { b } \in$ ∈ Im A，则 $A ^ { + } b$ 将是方程 (1) 解流形（或该方程的唯一解）中范数最小的向量；而若 $\Delta \notin$ ∉ Im $A ,$，则 $A ^ { + } b$ 是唯一一个既使 (2) 取得最小值、又具有最小范数的向量。

**定理 1.** 向量 ${ \pmb x } _ { 0 } = A ^ { + } { \pmb b }$ 是方程 $A \pmb { x } = \pmb { b }$ 的最佳近似解。

**证明.** 对任意 $\pmb { x } \in \mathcal { F } ^ { n }$，将其写为  

$$
A { \bf x } - { \bf b } = A ( { \bf x } - A ^ { + } { \bf b } ) + ( I - A A ^ { + } ) ( - { \bf b } ) ,
$$  

并注意到：由于 $I - A A ^ { + }$ 是到子空间 $( \operatorname { I m } A ) ^ { \perp }$ 上的正交投影算子（参见推论 12.7.1），故右侧各项为彼此正交的向量：  

$$
A ( { \bf x } - A ^ { + } b ) \in \mathrm { I m } \ A , \qquad ( I - A A ^ { + } ) ( - b ) \in ( \mathrm { I m } \ A ) ^ { \bot } .
$$  

于是，勾股定理的推广形式即得

$$
\begin{array} { c } { { \| A { \mathbf { x } } - { \pmb { b } } \| ^ { 2 } = \| A ( { \pmb x } - { \pmb A } ^ { + } { \pmb b } ) \| ^ { 2 } + \| ( { \pmb I } - A { \pmb A } ^ { + } ) ( - { \pmb b } ) \| ^ { 2 } } } \\ { { = \| A ( { \pmb x } - { \pmb x } _ { 0 } ) \| ^ { 2 } + \| A { \pmb x } _ { 0 } - { \pmb b } \| ^ { 2 } } } \end{array}\tag{3}
$$  

因而，关系式 (2) 成立。
