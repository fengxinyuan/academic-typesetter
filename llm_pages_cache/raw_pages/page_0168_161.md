## 4.13 微分方程的初步应用

考虑如下形式的常系数常微分方程组：

$$

{ \begin{array} { r l } & { { \dot { x } } _ { 1 } = a _ { 1 1 } x _ { 1 } + a _ { 1 2 } x _ { 2 } + \cdot \cdot \cdot + a _ { 1 n } x _ { n } , } \\ & { } \\ & { { \dot { x } } _ { 2 } = a _ { 2 1 } x _ { 1 } + a _ { 2 2 } x _ { 2 } + \cdot \cdot \cdot + a _ { 2 n } x _ { n } , } \\ & { } \\ & { \quad \vdots } \\ & { { \dot { x } } _ { n } = a _ { n 1 } x _ { 1 } + a _ { n 2 } x _ { 2 } + \cdot \cdot \cdot + a _ { n n } x _ { n } , } \end{array} }
$$


其中，$x _ { 1 } , \ldots , x _ { n }$ 是自变量 $t ,$ 的函数；符号 $\dot { x } _ { j }$ 表示 $\boldsymbol { x } _ { j }$ 关于 $t ;$ 的导数；而系数 $a _ { i j }$ 与 $ t $ 无关。显然，我们可以将这组方程简写为一个矩阵方程：

$$
{ \dot { { \mathbf { x } } } } ( t ) = A { \mathbf { x } } ( t ) ,\tag{1}
$$

其中 $\pmb { x } ( t ) = [ \pmb { x } _ { 1 } \quad \pmb { x } _ { 2 } \quad \cdot \cdot \cdot \quad \pmb { x } _ { n } ] ^ { \mathrm { T } }$，且 $\begin{array} { r } { A = [ a _ { i j } ] _ { i , j = 1 } ^ { n } . } \end{array}$。注意：若变量对 $ t $ 的依赖关系在上下文中已明确，则可简记 $ \mathbf{x} $ 或 $ x $，而不必写作 $\pmb { x } ( t )$ 或 ${ \dot { \mathbf { x } } } ( t )$。

若矩阵 $ A $ 至少有一个特征值，则我们可轻易证明方程 ${ \dot { \pmb { x } } } = A { \pmb { x } }$ 存在解。我们尝试寻找形如 $\begin{array} { r } { { \bf x } ( t ) = { \bf x } _ { 0 } e ^ { \lambda _ { 0 } t } , } \end{array}$ 的解，其中 $\pmb { x _ { 0 } }$ 与 $\lambda _ { 0 }$ 均与 $ t $ 无关。此时有 ${ \dot { \pmb x } } = \lambda _ { 0 } { \pmb x }$，于是方程 (1) 可改写为 $( A - \lambda _ { 0 } I ) \mathbf { x } _ { 0 } = \pmb { 0 }$。因此，若取 $\pmb { x } _ { 0 }$ 为 $ A $ 的一个（右）特征向量，对应特征值 $\lambda _ { 0 }$，则 ${ \pmb x } ( t )$ 确为该方程的一个解。进一步地，若 $A \in \mathbb { C } ^ { n , \times n } ,$，则此类解恒存在，因为此时每个 $ A $ 至少拥有一个特征值及其相应的（右）特征向量。

命题 1．向量值函数 $x ( t ) = x _ { 0 } e ^ { \lambda _ { 0 } t }$ 是微分方程组 $E q .$（1）的解，当且仅当 $i f$，且 $i f \lambda _ { 0 }$ 是矩阵 $ A $ 的一个特征值，对应于特征向量 $\pmb { x _ { 0 } }$。

因此，确定一个矩阵的特征值与特征向量的问题，与求解相应的常系数线性微分方程组密切相关。我们能否刻画方程（1）的所有解构成的解集 $\mathcal { S }$？容易验证，$\mathcal { S }$ 构成一个线性空间；后文将证明该空间的维数为 $ n $（参见第 7.10 节）。此处，我们仅对可对角化矩阵（即“简单矩阵”）证明该结论。第一个习题则说明：如何总能生成 $\mathcal { S }$ 的一个子空间。

习题 1．设 $A \in \mathbb { C } ^ { n \times n }$，记 $\mathcal { S }$ 为方程（1）的解空间。若 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 是矩阵 $ A $ 的互异特征值，分别对应于特征向量 $\pmb { x } _ { 1 } , \pmb { x } _ { 2 } , \dots , \pmb { x } _ { s }$，则证明集合  

$$
\mathcal { S } _ { 0 } = \mathtt { s p a n } \{ \mathbf { x } _ { 1 } e ^ { \lambda _ { 1 } t } , \mathbf { x } _ { 2 } e ^ { \lambda _ { 2 } t } , \dots , \mathbf { x } _ { s } e ^ { \lambda _ { s } t } \}
$$  

是 $\mathcal { S }$ 中的一个线性子空间，其维数为 $ s $。
