## 5.12 小振动理论

本节我们将介绍一个重要的物理问题，其求解依赖于定理 5.5.2 所解决的问题：两个埃尔米特矩阵（或埃尔米特型）的**同时化简**。我们将以力学系统的小振动为例进行阐述；尽管由此导出的方程及其解法亦出现在许多截然不同的场合中，例如电路中电流与电压的振荡。

考虑一个弹性力学系统的运动，该系统偏离某一稳定平衡位置的位移可用 $ n $ 个坐标来描述。设这些坐标为 $p _ { 1 } , p _ { 2 } , \ldots , p _ { n }$。若系统在平衡位置附近作小振动，则其动能 $ T $ 可表示为坐标的**时间变化率**的二次型，即 $T$；记为 $\dot { p } _ { 1 } , \dots , \dot { p } _ { n }$。因此，存在一个实对称矩阵 $ A $，使得  

$$
\begin{array} { r } { T = \frac 1 2 \displaystyle \sum _ { j = 1 } ^ { n } \sum _ { k = 1 } ^ { n } a _ { j k } \dot { p } _ { j } \dot { p } _ { k } = \frac 1 2 \dot { p } ^ { \mathrm { T } } A \dot { p } , } \end{array}
$$  

其中 $\pmb { p } = [ \pmb { p } _ { 1 } \quad p _ { 2 } \quad \cdots \quad p _ { n } ] ^ { \mathrm { T } }$ 且 $\pmb { \dot { p } } = [ \pmb { \dot { p } } _ { 1 } \quad \pmb { \dot { p } } _ { 2 } \quad \dotsb \ \dot { p } _ { n } ] ^ { \mathtt { T } }$。此外，对任意可能的运动，均有 $\pmb { \dot { p } } \in \mathbb { R } ^ { n }$；并且基于物理原因，动能 $ T $ 恒为正。故 $ A $ 是一个实的正定矩阵（参见习题 5.10.4）。
