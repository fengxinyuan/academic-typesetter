## 3.14 若干补充习题

10. 证明弗雷德霍姆定理：方程 $A { \boldsymbol { \mathfrak { x } } } = b \ ( A \in \mathbb { C } ^ { m \times n } )$ 有解当且仅当向量 $\pmb { b } \in \mathbb { C } ^ { m }$ 与齐次方程 $A ^ { * } y = \cdot \pmb { \theta }$ 的所有解正交。

提示：利用习题 8 的结论。

11. 验证对称矩阵（或斜对称矩阵）的秩等于其最大的非零主子式的阶数。特别地，证明斜对称矩阵的秩不可能为奇数。

12. 证明从一个标准正交基到另一个标准正交基的过渡矩阵 $P _ { n }$ 是酉矩阵，即满足 $P _ { n } ^ { * } P _ { n } = I _ { n }$。

提示：注意到将 $ P $ 的列视作 $ \mathbb{C}^n $（或 $ \mathbb{R}^n $）中的元素时，它们关于标准内积构成一个标准正交系。
