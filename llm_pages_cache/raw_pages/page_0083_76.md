因此，线性空间  \mathcal { S } （定义在域 $\mathcal { F }$ 上）的一个非空子集 $\mathcal { S }$ _ { $\mathfrak { d } }$ ，若对任意 $ a \in $\pmb { b } $\in \mathcal { S }$ _ { 0 }  及任意 $\alpha \in \mathcal { F }  $，均满足：

(1)  \pmb { a } $+ \pmb { b } \in \mathcal { S }$ _ { $\mathfrak { o } }  $；

(2)  \alpha { $\pmb a } \in \mathcal { S }$ _ { 0 } ，

则  \mathcal { S } _ { $\mathfrak { d } }$ 是 $\mathcal { S }  $ 的一个子空间。

（注意：此处及一般情形下，若无其他既定记号，则用粗体字母表示线性空间中的元素。）

不难看出， \mathcal { S } _ { $\mathfrak { d } }$ 在 $\mathcal { S }  $ 所定义的运算下自身构成一个线性空间，故称之为“子空间”。

若  \mathcal { S }  是一个线性空间，则易见：若 $ 0 $ 是  { $\mathcal { S } } ,$ 的零元素，则单元素集  \{ $\pmb { \theta } \}$ 与整个空间 $\mathcal { S }$ 均为  { $\mathcal { S } } .$ 的子空间。这些子空间被称为**平凡子空间**（trivial subspaces），而其余任意子空间则称为**非平凡子空间**（nontrivial subspace）。还需特别指出： $\mathcal { S }$ 的零元素必然是其任一子空间 $\mathcal { S }$ _ { $\mathfrak { d } } （$ 其中 $\mathcal { S }$ _ { $\mathfrak { d } }$ 是 $\mathcal { S }  $ 的子空间）的零元素。（此结论可由习题 3.1.2(a) 推出。）

不难验证，子空间定义中的条件 (1) 和 (2) 可合并为一条等价刻画子空间的单一陈述。具体而言，设  \mathcal { S } _ { $\mathfrak { d } }$ 是域 $\mathcal { F }$ 上线性空间 $\mathcal { S }$ 的一个非空子集，则 $\mathcal { S }$ _ { $\mathfrak { d } }$ 是 $\mathcal { S }$ 的子空间，当且仅当对任意 $ a \in $\mathcal { F } 、任意 $ x, y \in $\mathcal { S } _ { $\mathfrak { d } }  $，均有  
$$
ax + y \in $\mathcal { S } _ { \mathfrak { d } }$.
$$  
（注：原文此处表述不完整，依据标准定义补全为上述常见等价形式；原文中 “for every a, $\pmb { b } \in \mathcal { S } _ { \pmb { \rho } }$ and ever $\alpha , \beta \in \mathcal { F } , \alpha \pmb { a } + \beta \pmb { b } \in \mathcal { S } _ { 0 }$” 显系排版遗漏，结合上下文及线性空间子空间的标准判据，应理解为“对任意 $ a \in $\mathcal { F }  及任意 $ x, y \in $\mathcal { S } _ { $\mathfrak { d } }  $”。）

**例 1.**  
(a) 任何过原点的直线，即形如

\{ x = ( x _ { 1 } , x _ { 2 } , x _ { 3 } ) \colon x _ { 1 } = a t , x _ { 2 } = b t , x _ { 3 } = c t , ( - \infty < t < \infty ) \} ,
$$
  
的三元组集合，是  \mathbb { R } _ { 3 }  的一个子空间。  

(b)  \mathbb { R } _ { 3 }  中任何过原点的平面，即形如  
$$

\{ \mathbf { x } = ( x _ { 1 } , x _ { 2 } , x _ { 3 } ) : a x _ { 1 } + b x _ { 2 } + c x _ { 3 } = 0 , a ^ { 2 } + b ^ { 2 } + c ^ { 2 } > 0 \} ,
$$
  
的三元组集合（其中  a , b , c ,  为给定的实数），是 $\mathbb { R }$ _ { 3 }  的一个子空间。  

(c) 所有元素取自 $ \mathbb{R} $ 的 $n \times n$ 阶上（下）三角矩阵构成的集合，是 $\mathbb { R } ^ { n \times n }  $ 的一个子空间。

(d) 所有主对角线元素为零的实 $ n \times n $ 矩阵构成的集合是 $ \mathbf{$\mathbb { R } ^ { $n \times n } } $ 的一个子空间。  

(e) 所有实对称 $ n \times n $ 矩阵构成的集合是 $ \mathbf{$\mathbb { R } ^ { $n \times n } } $ 的一个子空间。 □  

再次注意：任一子空间本身即为一线性空间，因此必包含零元素。正因如此，$ \mathbf{$\mathbb { R } _ { 3 }$} $ 中任何不经过原点的平面均不能成为 $ \mathbf{$\mathbb { R } _ { 3 }$} $ 的子空间。
