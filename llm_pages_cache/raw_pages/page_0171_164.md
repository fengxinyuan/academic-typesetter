## 4.14 杂项习题

1. 设 ${ \mathcal { S } } = { \mathcal { S } } _ { 1 } + { \mathcal { S } } _ { 2 }$。在 $\mathcal { S }$ 上定义一个变换 $T$，如下：

$$
T ( { \boldsymbol { \mathbf { x } } } ) = { \boldsymbol { \mathbf { \mathit { x } } } } _ { 1 } ,
$$

其中 ${ \pmb x } = { \pmb x } _ { 1 } + { \pmb x } _ { 2 }$ 且 $\pmb { x } _ { 1 } \in \mathcal { S } _ { 1 } , \pmb { x } _ { 2 } \in \mathcal { S } _ { 2 }$。证明：

(a) $T \in { \mathcal { L } } ( { \mathcal { S } } )$；

(b) $\mathcal { S } _ { 1 }$ 与 $\mathcal { S } _ { 2 }$ 均为 $T$-不变子空间；

(c) $T$ 满足条件 $T ^ { 2 } = T ( \mathrm { i } . \mathrm { e } . , T$（即 $T$ 是幂等变换）。

该变换 $T$ 称为沿 $\mathcal { S } _ { 2 }$ 方向将 $\mathcal { S }$ 投影到 $\mathcal { S } _ { 1 }$ 上的投影算子。注意：$T | _ { \mathcal { S } _ { 1 } }$ 是 $\mathcal { S } _ { 1 }$ 上的恒等变换。

2. 考虑一个简单的线性变换  T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )，其中 $ \dim ${ $\mathcal { S } } = n ,$ ， $\lambda$ _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { n }  是它的特征值，而  { $\mathfrak { x } }$ _ { 1 } , { $\mathfrak { x } }$ _ { 2 } $, \ldots , { \mathfrak { x } }$ _ { n }  是对应的一组特征向量，且张成 $\mathcal { S }$ 。对 $i = 1 , 2 , \ldots , n .$ ，定义  { $\mathcal { S } }$ _ { 1 } $= \operatorname { s p a n } ( x$ _ { i } ) 。证明： $\begin{array} { r } { T = \sum$ _ { i = 1 } ^ { n } $\cdot \lambda$ _ { i } I _ { i } } $\end{array}$ ，其中  I _ { i }  是 $\mathcal { S }$ _ { i } $\left( 1 \leq i \leq n \right$ )上的恒等变换，且 $\begin{array} { r } { \mathcal { S } = \sum$ _ { i = 1 } ^ { n } $\cdot \mathcal { S }$ _ { i } } $\end{array}  $；此即简单变换的谱定理。

3. 考虑作为定理 4.10.3 给出的谱分解。设  

$$
G _ { j } = { \pmb x } _ { j } { \pmb y } _ { j } ^ { \operatorname { T } } \operatorname { f o r } j = 1 , 2 , \ldots , n , \operatorname { s o } \operatorname { t h a t } A = \sum _ { j = 1 } ^ { n } \lambda _ { j } G _ { j } .
$$  

(a) 证明：每个  G _ { j }  的秩为一，且  G _ { 1 } $, \ldots , G$ _ { n }  彼此正交，即对所有 $1 \leq j , k \leq n$ ，有  G _ { k } G _ { j } $= \delta$ _ { k j } G _ { k } ；  

(b) 若  p  $( \lambda$ )是任意一个标量多项式，则证明  p ( A )  是简单的，且 $\begin{array} { r } { p ( A ) = \sum$ _ { j = 1 } ^ { n } $p ( \lambda$ _ { j } ) G _ { j } } $\end{array}  $。  

矩阵  G _ { j } $, 1 \le j \le n ,$ 称为矩阵 $ A $ 关于 $\lambda$ _ { j }  的成分矩阵（constituent matrix）。

4. 矩阵 $\ b { R _ { \lambda } } = ( \lambda \ b { I } - \lambda ) ^ { - 1 }$（称为 $ A $ 的预解矩阵）在点 $\lambda \not \in \sigma ( A )$ 处有定义。验证下列命题：

(a) $R _ { \lambda } - R _ { \mu } = ( \mu - \lambda ) R _ { \lambda } R _ { \mu }  \mathbf{u} $；

(b) 若 $ A $ 是可对角化的（即单重的），且 $G _ { 1 } , G _ { 2 } , \ldots , G _ { n }$ 如习题 3 中所定义，则  

$$
R _ { \lambda } = \sum _ { i = 1 } ^ { n } \frac { 1 } { \lambda - \lambda _ { i } } G _ { i } , \qquad \lambda \notin \sigma ( { \cal A } ) .
$$  

提示：首先利用公式 (4.13.3) 与 (4.13.4)，将 $R _ { \lambda } = P ( \lambda I - D ) ^ { - 1 } Q ^ { \mathbf { T } }$ 表示为相应形式。

5. 证明：若 $ \dim\,V = n $，则对任一线性变换 $ T \in \mathcal{L}(V) $，均存在一个维数为 $ k $ 的 $ T $-不变子空间。

提示：令 $\lambda \in \sigma ( T )$，并对 $T - \lambda I$ 应用公式 (4.5.2)，以确认像空间  \operatorname{Im}\,$ $$( T - \lambda I )$ 是一个 $ k $ 维的、在 $ T $ 下不变的子空间。
