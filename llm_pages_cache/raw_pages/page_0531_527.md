# 非负矩阵

一个矩阵 $A \in \mathbb { R } ^ { m \times n }$ 称为**非负矩阵**，若其所有元素均非负；若其所有元素均为正数，则称该矩阵为**正矩阵**。此类方阵出现在多种问题中，而令人惊讶的是，仅凭这一定义性条件，竟可推出关于其结构的一些强有力结论。著名的**佩龙–弗罗贝尼乌斯定理**（Perron–Frobenius theorem）是非负矩阵理论的核心结果，它将在定理 15.3.1 与定理 15.4.2 中予以确立。

其逆矩阵为非负矩阵（或正矩阵）的矩阵，在应用中亦具有重要作用；本章亦将对此类矩阵作简要介绍。

若 $A = [ a _ { i j } ]$ 与 $B = [ b _ { i j } ]$ 是来自 $\mathbb { R } ^ { m \times n }$ 的矩阵，则我们记 $A \geq B$（相应地，记 $A > B )$），当且仅当对所有满足 $1 \leq i \leq m , 1 \leq j \leq n .$ 的指标对 $( i , j )$，均有 $a _ { i j } \geq b _ { i j }$（相应地，$a _ { i j } > b _ { i j } )$）。在此记号下，A 为非负矩阵当且仅当 $A \geq 0 .$。需注意：$A \geq 0$ 与 $A \neq 0$ 并不蕴含 $A > 0$。此外，若 $A \ge 0 , B \ge C$ 且 AB 有定义，则 $A B \geq A C$；若 $A \ge 0 , B > 0$ 且 $A B = 0 ,$，则 $A = 0$。须指出，上述大多数论述对向量同样成立。

此处所用记号与**正定矩阵**及**半正定矩阵**的记号发生重复，实属不便。然而，由于后两类概念在本章中并不起重要作用，故不会引起混淆。
