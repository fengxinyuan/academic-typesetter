**定理 1.** 采用前一段所设定的记号，  

$$
\begin{array} { r } { c ( \lambda ) = \delta ( \lambda ) m ( \lambda ) . } \end{array}\tag{1}
$$  

**证明.** 首先，我们引入矩阵多项式  

$$
C ( \lambda ) = { \frac { 1 } { \delta ( \lambda ) } } B ( \lambda ) ,
$$

称为  A ,  的**约化伴随矩阵**，并注意到 $C ( \lambda$ )  的各元素互素。  
由式 (7.2.1) 可得  
$$
$c ( \lambda ) I = \delta ( \lambda ) ( \lambda I - A ) C ( \lambda )$
$$  
该等式表明  c  $( \lambda$ )可被 $\delta ( \lambda$ )整除；又因二者均为首一多项式，故存在唯一的首一多项式 $\tilde { m } ( \lambda$ ) ，使得  
$$
$c ( \lambda ) = \delta ( \lambda ) \tilde { m } ( \lambda )$
$$  
因此  

$$

\tilde { m } ( \lambda ) I = ( \lambda I - A ) C ( \lambda ) .\tag{2}
$$
  

我们的目标是证明  \tilde { m } $( \lambda ) = m ( \lambda$ )，即 $\tilde { m } ( \lambda$ )是矩阵 $ A $ 的最小多项式。  
事实上，关系式 (2) 表明 $ m_{\tilde{n}}(\lambda)I $ 可被 $\lambda I - A  $ 整除，从而根据定理 7.2.3 的推论，有  
$$
$\tilde { m } ( A ) = O$
$$  
于是 $ \tilde{n}(\lambda) $ 是 $ A $ 的一个零化多项式；接下来只需验证它确实是 $ A $ 的次数最低的零化多项式。  
为此，假设存在某个次数更小的零化多项式  \tilde { m } $( \lambda ) = \theta ( \lambda ) m ( \lambda$ )。由于  m ( A ) = 0 ; ，依据同一推论可知  

$$

m ( \lambda ) I = ( \lambda I - A ) \tilde { C } ( \lambda )
$$
  

其中  \widetilde { C } $( \lambda$ )  是某个矩阵多项式，进而可得  

$$

\tilde { m } ( \lambda ) I = ( \lambda I - A ) \theta ( \lambda ) \tilde { C } ( \lambda ) .
$$
  

将此式与  \mathbf { E q } . ( 2 )  比较，并利用左商的唯一性，我们推出 $C ( \lambda ) = \theta ( \lambda ) \widetilde C ( \lambda$ )。但这就意味着 $( \mathrm { i f } \theta ( \lambda ) \not \equiv 1$ )，即 $\theta ( \lambda$ )是 $C ( \lambda$ )各元素的一个公因式，这与 $ \delta(\lambda) $ 的定义相矛盾。  
因此必有  \theta  $( \lambda ) \equiv 1$ ，且 $\tilde { m } ( \lambda ) = m ( \lambda$ ) 。

该结果蕴含了极小多项式的另一种有用刻画。

**定理 2.** 矩阵 $A \in { \mathcal { F } } ^ { n \times n }$ 的极小多项式等于其友矩阵 $\lambda I - A$ 的最高次数的不变因子（即首一不变多项式）。

**证明.** 注意到 $\lambda I - A$ 的秩为 $ n $，且由命题 7.3.1 与定理 7.5.1 可知，

$$
\operatorname* { d e t } ( \lambda I - A ) = \alpha i _ { 1 } ( \lambda ) i _ { 2 } ( \lambda ) \cdot \cdot \cdot i _ { n } ( \lambda ) ,\tag{3}
$$

其中所有 $i _ { 1 } ( \lambda ) , \ldots , i _ { n } ( \lambda )$ 均不恒等于零。

此外，$\alpha = 1$，这是因为所有不变因子以及 $\operatorname* { d e t } ( \lambda I - A )$ 均为首一多项式。回顾式 (7.5.3)，由式 (3) 可推出

$$
c ( \lambda ) = \operatorname * { d e t } ( \lambda I - A ) = d _ { n - 1 } ( \lambda ) i _ { n } ( \lambda ) ,\tag{4}
