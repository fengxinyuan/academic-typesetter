命题 1．设  \begin{array} { r } { $b ( \lambda ) = \sum$ _ { j = 0 } ^ { l } b _ { j } $\lambda ^ { j } } \end{array}$ 与 $\begin{array} { r } { c ( \lambda ) = \sum$ _ { j = 0 } ^ { l } c _ { j } $\lambda ^ { j } } \end{array}$ 是两个实系数多项式，且满足  c _ { $\iota } \neq 0$ 。若 $B = \mathbf { B e z } ( c , b$ )表示与 $c ( \lambda$ )和 $ b(\lambda) $ 相关联的贝祖矩阵，则  

$$

B = S ( c ) H S ( c ) ,\tag{1}
$$


其中 $ H $ 表示有理函数 $R ( \lambda ) = b ( \lambda ) / c ( \lambda )$ 的马尔可夫参数所构成的汉克尔矩阵。

**证明**．令 $H = [ h _ { i + j - 1 } ] _ { i , j = 1 } ^ { l }$，其中 $h _ { 1 } , h _ { 2 } , \ldots , h _ { 2 l - 1 }$ 由下式定义：

$$
b ( \lambda ) = ( h _ { 0 } + h _ { 1 } \lambda ^ { - 1 } + h _ { 2 } \lambda ^ { - 2 } + \cdots ) c ( \lambda ) .\tag{2}
$$

通过比较等式 (2) 两端对应幂次的系数，易得

$$
\begin{array} { r } { \pmb { b } ^ { \operatorname { \cal T } } = \pmb { h } _ { 1 } ^ { \operatorname { \cal T } } S ( c ) , } \end{array}\tag{3}
$$

其中 $\pmb { b } ^ { \mathrm { r } } = [ \tilde { b } _ { \pmb { 0 } } \quad \tilde { b } _ { 1 } \quad \cdots \quad \tilde { b } _ { l - 1 } ] , \tilde { b } _ { j } = b _ { j } - b _ { l } c _ { j } c _ { l } ^ { - 1 } , j = 0 , 1 , \ldots , l - 1 ,$，且 $\pmb { h } _ { 1 } ^ { \operatorname { T } } = [ h _ { 1 } \quad h _ { 2 } \quad \cdots \quad h _ { l } ] .$。

此外，利用式 (13.3.5)，可得

$$
\boldsymbol { b } ^ { \boldsymbol { \mathsf { T } } } C _ { c } ^ { j } = \boldsymbol { h } _ { 1 } ^ { \boldsymbol { \mathsf { T } } } \operatorname { d i a g } \left[ - \left[ \begin{array} { c c c c } & & { c _ { 0 } } \\ & & { c _ { 1 } } \\ & & { \ddots } \\ { c _ { 0 } } & { c _ { 1 } } & { \cdots } & { c _ { j - 1 } } \end{array} \right] , \left[ \begin{array} { l l l } { c _ { j + 1 } } & { \cdots } & { c _ { l } } \\ { \vdots } & { \ddots } & \\ { c _ { l } } & & \end{array} \right] \right] = \boldsymbol { h } _ { j + 1 } ^ { \boldsymbol { \mathsf { T } } } S ( c ) ,
$$

其中  \pmb { h } _ { j + 1 } ^ { $\mathsf { T } } = [ h$ _ { j + 1 } $\quad h$ _ { j + 2 } $\quad \cdots \quad h$ _ { j + l } ]  且 $j = 1 , 2 , \dots , l - 1  $。将此式与式 (3) 结合，可得  

$$

\begin{array} { r } { \left[ \begin{array} { l } { b ^ { \operatorname { T } } } \\ { b ^ { \operatorname { T } } C _ { c } } \\ { \vdots } \\ { b ^ { \operatorname { T } } C _ { c } ^ { l - 1 } } \end{array} \right] = H S ( c ) . } \end{array}
$$
  

最后只需利用式 (13.3.20) 即可导出式 (1)。  

现在我们可陈述一个修正后的马尔可夫稳定性判据。  

**定理 1.** 设 $ H $ 为多项式 $ a(\lambda) $ 的马尔可夫参数所构成的汉克尔矩阵，并假设 $ \det $H  $\neq 0 .  $。则  

$$

\pi ( a ) = \pi ( H ) , \qquad \nu ( a ) = \nu ( H ) , \qquad \delta ( a ) = 0 .\tag{5}
$$
  

**证明.** 该定理的断言可直接由定理 13.7.1、命题 1 及西尔维斯特惯性定律平凡推出。
