## 10.6 盖尔施戈林定理（Geršgorin 定理）

本节给出矩阵 $ A $ 的特征值 $ \lambda $ 在复平面上所处区域的一种刻画。回忆一下，此类结果的首个版本已在定理 10.3.1 中给出（另见习题 10.5.2）。

在深入细节之前，我们先指出一个关键事实：矩阵 $ A $ 的特征值关于其元素是连续依赖的。由于特征值恰好是其特征多项式的零点，因此该结论可立即由“多项式的零点关于其系数连续依赖”这一事实推出。这是代数函数初等理论中的一个结果，此处不再详述。

下面我们证明一个最为实用且易于应用的特征值界估计定理——即盖尔施戈林定理（Geršgorin’s theorem），该定理最早发表于 1931 年†。

**定理 1**．若 $ A = (a_{ij}) $，且 $ a_{ij} $ 表示矩阵 $ A $ 的元素，并设  

$$
\rho _ { j } = \sum _ { k } | a _ { j k } | ,
$$  

其中 $ \sum_{k=1}^{n} $ 表示从 $ k = 1 $ 到 $ n $ 的求和，$ a_{ik} $ 为 $ A $ 的第 $ i $ 行第 $ k $ 列元素，则 $ A $ 的每一个特征值必位于复 $ z $-平面上如下至少一个圆盘之内：  

$$
\{ z : | z - a _ { j j } | \leq \rho _ { j } \} , ~ j = 1 , 2 , \ldots , n ,\tag{1}
$$  

此外，若某 $ m $ 个圆盘构成的集合与其余 $ n - m $ 个圆盘无公共点，则该集合中恰包含 $ A $ 的 $ m $ 个（且仅 $ m $ 个）特征值。

$\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n } A \in \mathbb { C } ^ { n \times n } A \in \mathbb { C } ^ { n \times n } a _ { j k } A , j , k = 1 , \ldots , n , \sum \limits _ { k } ^ { \prime } k \neq j ,$



证明．设 λ 是矩阵 A 的一个特征值，x 为其对应的特征向量。则有  
$A { \boldsymbol { \mathbf { x } } } = \lambda { \boldsymbol { \mathbf { x } } }$  
或将其展开为 n 个标量方程：  

$$
\sum _ { k = 1 } ^ { n } a _ { j k } x _ { k } = \lambda x _ { j } , \qquad j = 1 , 2 , \ldots , n .
$$  

令 $\vert x _ { p } \vert = \mathrm { m a x } _ { j } \vert x _ { j } \vert$；则第 p 个方程给出  

$$
| \lambda - a _ { p p } | | x _ { p } | = \left| \sum _ { k = 1 } ^ { n } a _ { p k } x _ { k } \right| \leq \sum _ { k = 1 } ^ { n } | a _ { p k } | | x _ { k } | \leq | x _ { p } | \sum _ { k = 1 } ^ { n } | a _ { p k } | .
$$  

由于 $\pmb { x } \neq \pmb { \theta }$，必有 $| x _ { p } | \neq 0 .$，从而得到 $| \lambda - a _ { p p } | \leq \rho _ { p }$。第一个结论得证。
