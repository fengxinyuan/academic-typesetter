**习题 1.** 验证矩阵  

$$
A = \left[ { \begin{array} { r r r } { 2 } & { 0 } & { 0 } \\ { 1 1 } & { 4 } & { 5 } \\ { 7 } & { - 1 } & { - 2 } \end{array} } \right]
$$  

的特征值为 $\lambda _ { 1 } = 2 , \lambda _ { 2 } = 3 , \lambda _ { 3 } = - 1$。  

**习题 2.** 证明：三角矩阵的对角元即为其特征值。□

注意，若域 $\mathcal { F }$ 是代数闭域（其定义与相关讨论见附录 1），则标量多项式 $c ( \lambda )$ 的所有零点均属于 F。因此，任一 $A \in { \mathcal { F } } ^ { n \times n }$ 的谱非空，且至多包含 n 个点；这些性质我们早已熟悉。它们在定理 4.10.5 中得到确立；此外，如定理 4.10.1 所指出的，这些性质同样适用于该矩阵所对应的底层线性变换。

还须注意，若 $A = P B P ^ { - 1 }$，则  

$$
c _ { A } ( \lambda ) = \operatorname * { d e t } ( \lambda I - A ) = \operatorname * { d e t } ( P ( \lambda I - B ) P ^ { - 1 } ) = \operatorname * { d e t } ( \lambda I - B ) = c _ { B } ( \lambda ) .
$$  

于是，特征多项式在相似变换下保持不变，因而等价类 $\mathcal { A } _ { T } ^ { 0 }$ 中的所有矩阵均具有相同的特征多项式。换言之，该多项式本质上刻画了线性变换 T 本身的特性，故可称之为该变换的特征多项式。

接下来，我们考察矩阵 A（或等价地，考察以 A 为其表示的线性变换 T）的特征多项式的系数。为此，首先陈述并证明如下引理：

引理 1．若 $A \in { \mathcal { F } } ^ { n \times n }$，且 A 的若干互异列 $i _ { 1 } , i _ { 2 } , \ldots , i _ { r } ( 1 \leq r < n )$ 恰为单位向量 $e _ { i _ { 1 } } , e _ { i _ { 2 } } , \ldots , e _ { i _ { r } }$，则 det A 等于从 A 中删去行与列 $i _ { 1 } , i _ { 2 } , \ldots , i _ { r }$ 后所得的主子式。

证明．将 det A 按列 $i _ { 1 } ,$ 展开，即得

$$
\begin{array} { r l } { \operatorname* { d e t } A = ( - 1 ) ^ { i _ { 1 } + i _ { 1 } } A \binom { 1 } { 1 } \quad 2 \quad \cdots } & { i _ { 1 } - 1 \quad i _ { 1 } + 1 \quad \cdots \quad n } \\ { \qquad 2 \quad \cdots } & { i _ { 1 } - 1 \quad i _ { 1 } + 1 \quad \cdots } & { n } \end{array} ,
$$  

现在按编号为 $i _ { 2 }$ 的列展开该子式。可得：det A 是矩阵 A 的一个主子式，它由删去第 $i _ { 1 }$ 行与第 $i _ { 2 }$ 列后所得。依此方式继续对列 $i _ { 3 } , i _ { 4 } , \dots , i _ { r } ,$ 进行类似操作，即可得到所求结果。
