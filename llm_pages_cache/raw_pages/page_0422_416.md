然而，我们目前更倾向于放弃利用克罗内克积（Kronecker product）来研究方程 (3) 的可解性及其线性无关解的个数。我们的分析思路将重新展开：首先在第 12.4 节中考察特例 $A X = X A$；继而在第 12.5 节中考察特例 $A X +$ 和 $X B = O$；在此过程中，前述关于一般方程 $A X + X B = C$ 所提出的诸问题将得以解决。

**习题 1.** 设 A 是一个稳定矩阵，且假设 $W \geq 0 .$。证明李雅普诺夫方程 $A X + X A ^ { * } = - W$ 存在唯一解 X，且满足 $X \geq O$。（另参见第 13.1 节。）

**习题 2.** 设 $A \in \mathbb { C } ^ { m \times m } , B \in \mathbb { C } ^ { n \times n }$，$C \in \mathbb { C } ^ { m \times n }$。若 A 与 B 的谱半径分别为 $\mu _ { A }$ 和 $\mu _ { B }$，且 $\mu _ { A } \mu _ { B } < 1$，则证明方程  

$$
X = A X B + C\tag{8}
$$  

存在唯一解 X，且该解由下式给出：  

$$
X = \sum _ { j = 0 } ^ { \infty } A ^ { j } C B ^ { j } .
$$  

**习题 3.** 证明：若对所有 $\lambda \in \sigma ( A )$ 和 $\mu \in \sigma ( B )$ 均有 $\lambda \mu \neq 1$，则方程 (8) 存在唯一解。

**习题 4.** 设 A、$C \in \mathbb { C } ^ { n \times n }$ 和 $C ^ { * } = C$。若方程  

$$
X = \leavevmode { A ^ { * } X A + C }
$$  

存在唯一解 X，证明 X 是埃尔米特矩阵。此外，若 $\mu _ { A } < 1$，则 $( X - C ) \geq 0$。特别地，若 $C \geq 0 ,$，则 $X \geq 0$。

**习题 5.** 若 $A > 0 , C > 0 .$ 且 $X = A X A + C$，则 $\mu _ { A } < 1$。□

## 12.4 可交换矩阵

方程 (12.3.3) 的一个重要特殊情形出现在 $C = O$ 且 $B = - A$ 时：  

$$
A X = X A , \quad \ A , X \in \mathbb { C } ^ { n \times n } .\tag{1}
$$

显然，求出方程 (1) 的所有解 $ X $，等价于确定所有与给定矩阵 $ A $ 可交换的矩阵。为此，我们首先注意到：若  A = P J P ^ { - 1 } ，其中 $ J $ 是 $ A $ 的一个若尔当标准形，则方程 (1) 等价于如下方程：

$$

J Y = Y J ,\tag{2}
$$


其中  Y = P ^ { - 1 } X P  。
