## 摄动理论  

本章的大部分内容致力于研究矩阵元素发生摄动时，其特征值的变化行为。在正式展开这一主题之前，考察线性方程 $A { \boldsymbol { \mathbf { x } } } = \mathbf { \boldsymbol { b } }$ 的解 $ \mathbf{x} $ 在系数矩阵 $ A $ 与右端项 $\pmb { b }$ 同时受到摄动时所受影响，是富有启发性的（对数值分析工作者而言尤为关键）。

## 11.1 线性方程组解的摄动

给定 $A \in \mathbb { C } ^ { n \times n }$，考虑方程 $A { \pmb x } = b \left( { \pmb x } , { \pmb b } \in \mathbb { C } ^ { n } \right)$，并假设 det $A \neq 0 ,$，从而 x 是该方程的唯一解。

一般而言，若“微小”的原因（即矩阵 A 或向量 b 的扰动）仅导致“微小”的结果（即解向量 x 的扰动），则称该问题为**稳定的**（stable）或**良态的**（well conditioned）。所谓“微小”，其程度通常相对于未受扰动状态下的相应量的大小来衡量。因此，若 $x + y$ 是扰动后问题的解，则我们用某个向量范数 $\Vert \big | \big | \big | _ { \mathbf { v } }$ 来度量解向量的扰动大小，即以比值 $\| \mathbf { y } \| _ { \mathbf { v } } / \| \mathbf { x } \| ,$ 作为度量标准；我们称此比值为 **x 的相对扰动**（relative perturbation of x）。
