在所有位置向量构成的集合中，加法运算按第 1.2 节所定义的方式进行。换言之，对任意两个位置向量，依照某一特定规则，均对应于另一个位置向量。这种具体的对应关系是所谓二元运算的一个特例；我们将为此类运算建立严格的定义。

设  \mathcal { A } $, \mathcal { B } ,$ 与 $\mathcal { S }$ 为任意集合，记  { $\mathcal { A } } \times { \mathcal { B } }$ 为所有有序对  ( a , b )  构成的集合，其中 $\pmb { a }$ ，且 $ b $ 分别属于 $\mathcal { A }$ 与  { $\mathcal { B } } ,$ 。从  { $\mathcal { A } } \times { \mathcal { B } }$ 到 $\mathcal { S }$ 的一个二元运算，是指这样一条规则：它将  { $\mathcal { A } } \times { \mathcal { B } }$ 中的每一个有序对唯一地对应到 $\mathcal { S }  $ 中的一个元素。

**例 1.**  
(a) 若  \mathcal { A } $, \mathcal { B } ,$ 与 $\mathcal { S }$ 均表示全体实数构成的集合，则实数的加法、减法与乘法均为从 $\mathcal { A } \times \mathcal { A }$ 到  { $\mathcal { A } } .  $ 的二元运算。  

(b) 若取  \mathcal { A } _ { 1 }  为除去零以外的所有实数构成的集合，则除法是从 $\mathcal { A } \ \times \mathcal { A }$ _ { 1 }  到 $\mathcal { A } .  $ 的一个二元运算。  

(c) 记全体位置向量（其坐标为实数）构成的集合为  \mathbb { R } _ { 3 } $, \quad \mathrm { w e }$ ，则可知向量加法是从 $\mathbb { R }$ _ { 3 } $\times \mathbb { R }$ _ { 3 }  到 $\mathbb { R }$ _ { 3 }  的一个二元运算。
