## 15.5 可约矩阵

我们现在考虑从定理 15.3.1 的假设中去掉“$ A $ 是不可约的”这一条件的可能性。该定理的结论 (a) 与 (b) 对可约矩阵仍给出相应结果，因为任一可约矩阵均可视为一列正矩阵（从而是不可约矩阵）的极限。于是，我们的结论将由主特征值（及其归一化右特征向量）关于矩阵元素的连续依赖性导出。

与此相反，我们在第11章关于摄动理论的经验表明：矩阵的结构（由其初等因子所确定）并不依赖于矩阵元的连续函数。正因如此，定理15.3.1的结论(c)在可约情形下无法给出任何有用的结果。

**定理1**．若矩阵 $A \in \mathbb { R } ^ { n \times n }$ 是非负矩阵，则  

(a) 矩阵 $ A $ 有一个实特征值 $ r $，且该特征值等于 $ A $ 的谱半径；  

(b) 存在一个与特征值 $ r $ 相关联的非负（右）特征向量。

**证明**．定义矩阵 $D ( t ) \in \mathbb { R } ^ { n \times n }$，其元素 $d _ { i j } ( t )$ 按如下方式给出：  

$$
d _ { i j } ( t ) = \left\{ { a _ { i j } } \begin{array} { l l } { \quad { \mathrm { i f } } \quad a _ { i j } > 0 , } \\ { t \quad } & { { \mathrm { i f } } \quad a _ { i j } = 0 . } \end{array} \right.
$$  

于是，对所有 $t > 0$，有 $D ( t ) > 0$；且对所有 $D ( 0 ) = A$，有 $D ( t ) > 0$。令 $\rho ( t )$ 表示矩阵 $D ( t )$ 在 $t > 0$ 时的最大实特征值。则 $D ( t )$ 的所有特征值均为 $ t $ 的连续函数（参见第11.3节）；又因 $\rho ( t )$ 等于 $D ( t )$ 的谱半径（对所有 $t > 0 ,$），故 ${ \mathrm { i m } } _ { t  0 + } \rho ( t ) = r$ 是 $D ( 0 ) = A$ 的一个特征值。进一步地，该特征值即为 $ A $ 的谱半径。

我们还知道（参见习题11.7.6）：存在一个可与 $\rho ( t )$ 关联的右特征向量 $\pmb { x } ( t )$，且该向量关于 $ t $ 在 $t \geq 0$ 上连续依赖。由定理15.3.1可知，对所有 $t > 0$，有 $\mathbf { \boldsymbol { x } } ( t ) > \mathbf { \boldsymbol { \theta } }$；因此，在 $t = 0 .$ 处有 $\mathbf { \boldsymbol { x } } ( t ) \geq \mathbf { \boldsymbol { \theta } }$。
