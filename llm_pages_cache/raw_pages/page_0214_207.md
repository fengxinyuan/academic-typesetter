## 5.11 寻求标准形

因此，我们已证明：任一实埃尔米特型均可经合同变换化为形式 (2)。将同一过程依次应用于 $f _ { 2 } ( { \pmb x } _ { 1 } )$，依此类推，至多经过 $n - 1$ 步，即可完成该化简。

习题 1．求二次型 $f ( \pmb { x } ) = 2 \alpha _ { 1 } \alpha _ { 2 } + 2 \alpha _ { 2 } \alpha _ { 3 } + \alpha _ { 3 } ^ { 2 }$ 的秩与惯性指数，并确定一组坐标变换 $a _ { 1 } , a _ { 2 } , a _ { 3 }$，使其将 $ f $ 化为平方和形式。

解．施行变换 $\alpha _ { 1 } = \beta _ { 3 } , \alpha _ { 2 } = \beta _ { 2 } , \alpha _ { 3 } = \beta _ { 1 }$，得

$$
f ( x ) = ( \beta _ { 1 } ^ { 2 } + 2 \beta _ { 1 } \beta _ { 2 } ) + 2 \beta _ { 2 } \beta _ { 3 } = ( \beta _ { 1 } + \beta _ { 2 } ) ^ { 2 } - \beta _ { 2 } ^ { 2 } + 2 \beta _ { 2 } \beta _ { 3 } .
$$  

现在令 $\gamma _ { 1 } = \beta _ { 1 } + \beta _ { 2 } , \gamma _ { 2 } = \beta _ { 2 } , \gamma _ { 3 } = \beta _ { 3 }$，并得到  

$$
f ( x ) = \gamma _ { 1 } ^ { 2 } - \gamma _ { 2 } ^ { 2 } + 2 \gamma _ { 2 } \gamma _ { 3 } = \delta _ { 1 } ^ { 2 } - \delta _ { 2 } ^ { 2 } + \delta _ { 3 } ^ { 2 }
$$  

其中 $\delta _ { 1 } = \gamma _ { 1 } , \delta _ { 2 } = \gamma _ { 2 } - \gamma _ { 3 } , \delta _ { 3 } = \gamma _ { 3 }$。因此，该二次型的秩为 $r = 3 ,$，正平方项的个数为 $\pi = 2 ,$，符号差为 $\pi - \nu = 2 - 1 = 1$。注意，实现该化简的变换矩阵 $ P $ 是由前述各次变换复合而成的：  

$$
\left[ \begin{array} { c } { \delta _ { 1 } } \\ { \delta _ { 2 } } \\ { \delta _ { 3 } } \end{array} \right] = \left[ \begin{array} { r r r } { 0 } & { 1 } & { 1 } \\ { - 1 } & { 1 } & { 0 } \\ { 1 } & { 0 } & { 0 } \end{array} \right] \left[ \begin{array} { c } { \alpha _ { 1 } } \\ { \alpha _ { 2 } } \\ { \alpha _ { 3 } } \end{array} \right] .
$$  

对变换矩阵求逆后可知，将 $f ( \mathbf { x } )$ 化为平方和所对应的变量代换为  

$$
\begin{array} { r } { \left[ \alpha _ { 1 } \right] = \left[ \begin{array} { c c c } { 0 } & { 0 } & { 1 } \\ { 0 } & { 1 } & { 1 } \\ { 1 } & { - 1 } & { - 1 } \end{array} \right] \left[ \begin{array} { c c c } { \delta _ { 1 } } \\ { \delta _ { 2 } } \\ { \delta _ { 3 } } \end{array} \right] . } \end{array}
$$  

还需指出的是，借助拉格朗日配方法，我们避免了计算该矩阵特征值的过程。

$$
A = { \left[ \begin{array} { l l l } { 0 } & { 1 } & { 0 } \\ { 1 } & { 0 } & { 1 } \\ { 0 } & { 1 } & { 1 } \end{array} \right] }
$$  

生成该二次型的矩阵。此类计算需解出特征方程 $\lambda ^ { 3 } - \lambda ^ { 2 } - 2 \lambda + 1 = 0$ 的全部根。如我们已知，其中必有两个正根与一个负根。

另一种确定矩阵 $ A $（或等价地，确定相应埃尔米特型）惯性指数的方法（由雅可比提出）将在第 8.6 节中讨论。
