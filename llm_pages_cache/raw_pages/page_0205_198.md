**定理 5.** 设 $A \in { \mathcal { F } } ^ { n \times n }$。子空间对 ${ \mathcal { S } } _ { 1 } , { \mathcal { S } } _ { 2 } \subset { \mathcal { F } } ^ { n }$ 是 $A$-约化子空间，当且仅当 $A P = P A ,$，其中 $P$ 是沿 $\mathcal { S } _ { 1 }$ 到 $\mathcal { S } _ { 2 }$ 上的投影算子（projector）。

${ \mathcal { F } } ^ { n }$



**证明**．设  \mathcal { F } ^ { n } $= \mathcal { S }$ _ { 1 } $\dot { + } \mathcal { S }$ _ { 2 } ，且 $A ( \mathcal { S }$ _ { 1 } $) \subset \mathcal { S }$ _ { 1 } $, A ( \mathcal { S }$ _ { 2 } $) \subset \mathcal { S }$ _ { 2 } 。对任意 $\pmb { x } \in \mathcal { F } ^ { n }$ ，记  { $\pmb x } = { \pmb x }$ _ { 1 } + { $\pmb x }$ _ { 2 } ，其中 $\mathbf { x }$ _ { 1 } $\in \mathcal { S }$ _ { 1 } , ~ $\mathbf { x }$ _ { 2 } $\in \mathcal { S }$ _ { 2 } 。于是  A P x = A x _ { 2 } ，又因 $\begin{array} { r } { A { \boldsymbol { x } }$ _ { 1 } $\in \mathcal { S }$ _ { 1 } $= \operatorname { K e r } P , } \end{array}  $，  

$$

P A x = P A x _ { 1 } + P A x _ { 2 } = P A x _ { 2 } .
$$
  

但  A { $\boldsymbol { x } }$ _ { 2 } $\in \mathcal { S }$ _ { 2 } $= \operatorname { I m } P ;  $，故  

$$

P A x = P A x _ { 2 } = A x _ { 2 } = A P x
$$
  

对所有  \pmb { x } $\in \mathcal { F } ^ { n }$ 成立。因此  P A = A P 。  

现设 $ P $ 是沿 $\mathcal { S }$ _ { 1 }  到 $\mathcal { S }$ _ { 2 }  上的投影算子，且假设  A P = P A . 。我们需证： $\mathcal { S }$ _ { 1 }  与 $\mathcal { S }$ _ { 2 }  均为 $ A $-不变子空间。  

若  \pmb { x } _ { 2 } $\in \mathcal { S }$ _ { 2 } ，则  P x _ { 2 } = x _ { 2 } ，且  

$$

A x _ { 2 } = A P x _ { 2 } = P A x _ { 2 } \in \mathcal { S } _ { 2 } ,
$$
  

从而  A  $( \mathcal { S }$ _ { 2 } $) \subset \mathcal { S }$ _ { 2 } 。其次，若 $\pmb { x }$ _ { 1 } $\in \mathcal { S }$ _ { 1 } ，则  

$$

A x _ { 1 } = A ( I - P ) x _ { 1 } = ( I - P ) A x _ { 1 } \in \mathcal { S } _ { 1 } ,
$$
  

故  A  $( \mathcal { S }$ _ { 1 } $) \subset \mathcal { S }$ _ { 1 } ，证明完毕。

让我们借此机会归纳若干有关矩阵的像（image）与核（kernel）的重要事实。为清晰起见并便于后续使用，我们将矩阵 $A \in \mathbb { C } ^ { m \times n }$ 视为从 $\mathbb { C } ^ { n }$ 到 $\mathbb { C } ^ { m }$ 的一个线性变换；尽管相关讨论亦可置于抽象线性变换的框架下进行。首先回顾：Im $A \subset \mathbb { C } ^ { m }$ 与 Ker $A \subset \mathbb { C } ^ { n }$。接着，由定理 4.5.5 可得：

$$
\dim ( \operatorname { I m } A ) + \dim ( \operatorname { K e r } A ) = n .\tag{3}
$$

特别地，若 $m = n$，则该等式有时可加强为：

$$
\operatorname { I m } A \ + \operatorname { K e r } A = \mathbb { C } ^ { n } .\tag{4}
$$

定理 2 指出：当 $A ^ { 2 } = A _ { \mathrm { { } } }$ 时——即当 A 是一个投影矩阵（projector）时——该加强式成立；且易见，当 A 是正规矩阵（normal matrix）时（尤其是当 A 为埃尔米特矩阵（Hermitian matrix）或酉矩阵（unitary matrix）时），该式亦成立。在后一情形下，结论还可进一步加强：当 A 为正规矩阵时，该直和分解是正交的，即

$$
\mathbf { I m } ~ A ~ \oplus ~ \mathbf { K e r } ~ A = \mathbb { C } ^ { n } .\tag{5}
$$
