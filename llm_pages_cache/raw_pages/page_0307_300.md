例 3．埃尔米特矩阵  

$$
H = { \left[ \begin{array} { l l l l } { 0 } & { 0 } & { 0 } & { b } \\ { 0 } & { a } & { 0 } & { 0 } \\ { 0 } & { 0 } & { a } & { 0 } \\ { b } & { 0 } & { 0 } & { 0 } \end{array} \right] } , \qquad a , b \neq 0 ,
$$  

的各阶顺序主子式为  

$$
d _ { 1 } = d _ { 2 } = d _ { 3 } = 0 , d _ { 4 } = a ^ { 2 } b ^ { 2 } < 0 .
$$  

另一方面，H 的特征多项式为 $( \lambda ^ { 2 } - b ^ { 2 } ) ( \lambda - a ) ^ { 2 }$，因而有 $\sigma ( H ) = \{ b , - b , a , a \}$。于是，当 $a > 0$ 时，$\pi ( H ) = 3 , \nu ( H ) = 1$；而当 $a < 0$ 时，$\pi ( H ) = 1 , \nu ( H ) = 3$。因此，H 的惯性不能仅由其顺序主子式的符号唯一确定。□  

还需注意：若 H 的秩 r 并未在 H 的某个顺序主子矩阵 $H _ { r }$ 上实现，即 $d _ { r } = 0 ,$，则雅可比定理不适用。

习题 4．观察如下埃尔米特矩阵  

$$
H = { \left[ \begin{array} { l l l } { 1 } & { 1 } & { 1 } \\ { 1 } & { 1 } & { 1 } \\ { 1 } & { 1 } & { a } \end{array} \right] }
$$  

其中 $a \neq 1$，其秩为 2，而 $d _ { 2 } = \operatorname* { d e t } \ H _ { 2 } = 0 .$。此外，其各阶顺序主子式 $d _ { 1 } = 1 , d _ { 2 } = d _ { 3 } = 0$ 的值与 $^ { a , }$ 所取的具体数值无关；然而，H 的惯性却依赖于 $^ { a , }$ 的取值：

$$
\operatorname* { d e t } ( \lambda I - H ) = \lambda [ \lambda ^ { 2 } - ( a + 2 ) \lambda + ( 2 a - 2 ) ] .
$$  

由于 $ H $ 的非零特征值 $\lambda$ _ { 1 } $, \lambda$ _ { 2 }  满足 $\lambda$ _ { 1 } $\lambda$ _ { 2 } = 2 a - 2  与 $\lambda$ _ { 1 } $+ \dot { \iota }$ _ { 2 } = a + 2 ，因此对所有  a < 1 ，均有 $\pi ( H ) = 2 \mathrm { i f } a > 1$ 与 $\pi ( H ) = 1  $。□  

## 8.7 Courant–Fischer 理论的一个应用  

考虑两个  n  $\times n$ 阶埃尔米特矩阵  H _ { 1 }  与  H _ { 2 } 。我们称  H _ { 2 }  不大于  H _ { 1 : } ，记作  H _ { 1 } $\geq H$ _ { 2 }  或  H _ { 2 } $\leq H$ _ { 1 } , ，若差矩阵  H _ { 1 } $\mathrm { ~ - ~ } H$ _ { 2 }  是半正定矩阵。类似地，若  H _ { 1 } - H _ { 2 } > 0 ，则记作  H _ { 1 } > H _ { 2 }  或  H _ { 2 } < H _ { 1 } 。这些关系在一定程度上保持了实数自然序所具有的某些性质（参见习题 5.14.21）。然而，数值不等式中成立的若干性质，在埃尔米特矩阵情形下并不普遍成立。例如，由  H _ { 1 } $\geq H$ _ { 2 } $\geq 0$ 并不能一般地推出不等式  H _ { 1 } ^ { 2 } $\geq H$ _ { 2 } ^ { 2 } 。
