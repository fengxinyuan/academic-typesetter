## 12.8 摩尔–彭罗斯广义逆

命题 12.7.3 与 12.7.4 已指出：一个  m  $\times n$ 矩阵的广义逆由且仅由 $ \operatorname{Im} A $ 在  { $\mathcal { F } } ^ { m }$ 中的一对直和补子空间、以及 $ \operatorname{Ker} A $ 在  { $\mathcal { F } } ^ { n } .$ 中的一对直和补子空间所确定。一个重要的特例是选取正交补子空间的情形。为确保这一点，只需要求投影算子  A A ^ { 1 }  与  A ^ { 1 } A  均为埃尔米特矩阵（参见第 5.8 节）。事实上，在此条件下， A A ^ { $\boldsymbol { \mathsf { I } } }$ 是沿 $ \operatorname{Ker} $A ^ { $\mathbf { I } }$ 到 $ \operatorname{Im} A $ 上的正交投影算子（推论 12.7.1），从而有



$$
\mathrm { I m } ~ { \cal A } \oplus \mathrm { K e r } ~ { \cal A } ^ { \mathrm { I } } = \mathcal { F } ^ { m } ,\tag{1}
$$



类似地，还有



$$
\ker A \oplus \operatorname { I m } A ^ { \mathbf { I } } = { \mathcal { F } } ^ { n } .\tag{2}
$$

$y \in { \boldsymbol { y } } = A { \boldsymbol { x } } \pmb { x } \in \mathcal { F } ^ { m }$



因此，我们定义矩阵 $ A $ 的摩尔–彭罗斯广义逆†（Moore–Penrose inverse），记作 $ A^+ $，为满足如下附加条件的 $ A $ 的一个广义逆：

$$
AA^+A = A,
$$

A^+AA^+ = A^+,
$$

(AA^+)^* = AA^+,
$$

(A^+A)^* = A^+A.
$$

显然，子空间正交补的存在性与命题 12.7.4 共同保证了对任一矩阵 $ A $，其摩尔–彭罗斯广义逆 $ A^+ $ 必然存在。此外，该广义逆还是唯一的。

$$
