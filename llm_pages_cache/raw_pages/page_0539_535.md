考虑闭集 $\mathcal { M }$，即满足 ${ \pmb x } \geq { \pmb \theta }$ 且 $\sum _ { i } x _ { i } ^ { 2 } = 1$ 的向量 $ \mathbf{x} $ 所构成的集合。于是，${ \mathcal { M } } \subset { \mathcal { L } }$，且

$$
r = \operatorname* { s u p } _ { \mathbf { x } \in \mathcal { M } } r ( \mathbf { x } ) .
$$

倘若函数 $r ( x )$ 在 ${ \mathcal { M } } ,$ 上连续，则该上确界可等同于最大值 $ \max_{\mathbf{x} \in S} \, \text{$r ( { $\pmb x }$ )$} $（参见附录 2）。然而，$r ( { \pmb x } )$ 在向量 $ \mathbf{x} $ 的某些分量为零的点处可能出现不连续性。因此，我们转而考虑由下式定义的向量 $ \mathbf{y} $ 的集合 $\mathcal { N }$：

$$
\mathbf { y } = ( I + A ) ^ { n - 1 } \pmb { x } , \qquad \pmb { x } \in \mathcal { M } .
$$

$\boldsymbol { x } \in \mathcal { M }$



根据命题 1，集合 $\mathcal { N }$ 中的每个元素均为正向量，因此 ${ \mathcal { N } } \subset { \mathcal { L } } . \operatorname { N o w } , \mathcal { N }$ 是闭且有界集 $\mathcal { M }$ 在连续函数下的像，故其本身亦为闭且有界集。此外，$r ( \mathbf { y } )$ 在 $\mathcal { N }$ 上连续。

对任意 $\pmb { x } \in \mathcal { M }$ 及其对应的 y，有  

$$
r ( { \pmb x } ) { \pmb y } = r ( { \pmb x } ) ( { \pmb I } + { \pmb A } ) ^ { n - 1 } { \pmb x } \leq ( { \pmb I } + { \pmb A } ) ^ { n - 1 } { \pmb A } { \pmb x } ,
$$  

这是因为 $r ( { \pmb x } ) { \pmb x } \leq A { \pmb x }$，从而对每个 $\mathbf { \boldsymbol { y } } \in \mathcal { N } .$ 均有 $r ( { \mathfrak { x } } ) { \mathfrak { y } } \leq A { \mathfrak { y } }$。现在，$r ( \boldsymbol { \mathbf { y } } )$ 是满足 $\rho \mathbf { y } \leq A \mathbf { y }$ 的最大数 $\rho$，因此 $r ( \mathbf { x } ) \leq r ( \mathbf { y } )$。于是，  

$$
r = \operatorname* { s u p } _ { \mathbf { x } \in \mathcal { M } } r ( \mathbf { x } ) \leq \operatorname* { m a x } _ { \mathbf { y } \in \mathcal { N } } r ( \mathbf { y } ) .
$$  

但又因 ${ \mathcal { N } } \subset { \mathcal { L } } ,$，故  

$$
\operatorname* { m a x } _ { \pmb { y } \in \mathcal { N } } r ( \mathbf { y } ) \leq \operatorname* { s u p } _ { \pmb { x } \in \mathcal { L } } r ( \pmb { x } ) = \operatorname* { s u p } _ { \pmb { x } \in \mathcal { M } } r ( \pmb { x } ) .
$$  

因而  

$$
r = \operatorname* { m a x } _ { \mathbf { y } \in \mathcal { N } } r ( \mathbf { y } ) ,\tag{6}
$$  

且存在某个 $\mathbf { y } > \pmb { \theta }$，使得 $r = r ( \mathbf { y } )$。

可能存在其他属于  \mathcal { L }  的向量，使得  r ( x )  取到值 $ r $。任何这样的向量均称为矩阵 $ A $ 的极值向量（extremal vector）。因此，一个非零向量 $z \geq \theta$ 是 $ A $ 的极值向量，当且仅当 $r ( z ) = r \mathrm { o r }$ ，这等价于 $r z \leq A z  $。

我们之所以关注数值 $ r $，其原因将在下一个结论中得以阐明。
