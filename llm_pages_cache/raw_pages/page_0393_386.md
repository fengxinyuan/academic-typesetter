习题 3．证明：对任意可逆矩阵  A  $\in \mathbb { C } ^ { n \times n }$ 及任一矩阵范数，其条件数 $\kappa ( A$ )  满足不等式  

$$
$\kappa ( A ) \geq 1$
$$  

习题 4．若  \kappa ( A )  表示矩阵 $ A $ 的谱条件数，即采用谱范数所定义的条件数；而  s _ { 1 }  与  s _ { n }  分别为矩阵  A ,  的最大与最小奇异值，试证明  

$$
$\kappa ( A ) = s _ { 1 } / s _ { n }$
$$

习题 5．若 $\kappa ( A )$ 是一个正规非奇异矩阵 $A \in \mathbb { C } ^ { n \times n }$ 的谱条件数，且 $\lambda _ { 1 }$ 与 $\lambda _ { n }$ 分别为 A 的模最大与模最小的特征值（取绝对值），证明：$\kappa ( A ) = \vert \lambda _ { 1 } \vert / \vert \lambda _ { n } \vert$。

习题 6．证明：谱条件数 $\kappa ( A )$ 等于 1 当且仅当 $\alpha A$ 是某个 $\alpha \neq 0$ 的酉矩阵。

习题 7．若线性方程 $A \mathbf { x } = \mathbf { b } $ 的行列式为 $A \neq 0 ,$，将其替换为等价方程 $B x = A ^ { * } b$，其中 $B = A ^ { * } A$，则证明该替换将以条件数为代价；即，证明：$\kappa ( B ) \geq \kappa ( A )$。

习题 8．利用定理 1 证明：当 $p  \infty$ 时，有 $M ^ { p }  0$。更精确地，证明：当且仅当矩阵 M 的谱半径小于 1 时，有 $M ^ { p }  0$ 成立（其中 $p  \infty$）。

习题 9．若矩阵 $A \in \mathbb { C } ^ { n \times n }$ 满足如下条件：对某个矩阵范数 |·|、所有非负整数 $p ,$ 及某个与 $p ,$ 无关的常数 k，均有 $\| A \| ^ { p } < k$，试证明：A 同样满足预解条件：对所有满足 $| z | > 1$ 的复数 z，矩阵 $z I - A$ 非奇异，且  

$$
\lVert ( z I - A ) ^ { - 1 } \rVert \leq { \frac { k } { | z | - 1 } } .
$$
