设约束特征值为 $\lambda _ { 1 } \leq \lambda _ { 2 } \leq \cdots \leq \lambda _ { n - }$，并令

$$
y _ { 1 } , y _ { 2 } , \ldots , y _ { n - r }
$$

为 $B ^ { * } H B$ 的一组相应的标准正交特征向量。则 $\pmb { x } _ { 1 } = B \pmb { y } _ { 1 } , \dots , \pmb { x } _ { n - r } =$ 与 $B y _ { n - 1 }$ 即为对应的约束特征向量。它们亦构成标准正交向量组，这是因为：对任意 $i , j = 1 , 2 , \dots , n - r ,$，有

$$
\delta _ { i j } = ( \pmb { x _ { i } } , \pmb { x _ { j } } ) = ( B \pmb { y _ { i } } , B \pmb { y _ { j } } ) = ( B ^ { * } B \pmb { y _ { i } } , \pmb { y _ { j } } ) = ( \pmb { y _ { i } } , \pmb { y _ { j } } ) .
$$  

对于  i  $= 1 , 2 , \ldots , n - r ,$ ，令  X _ { i }  为 $\mathbb { C } ^ { n }$ 中由向量组 $\mathbf { { x } }$ _ { i } , { $\mathbf { { x } } }$ _ { i + 1 } $, \ldots , { \mathbf { { x } } }$ _ { n - r }  所生成的子空间。首先将定理 8.2.1 应用于  B ^ { * } H B  在 $\mathbb { C } ^ { n - r }$ 中的情形，再将所得结果变换至 $\mathbb { C } ^ { n }  $，并结合式 (3)，我们可直接导出如下结论。

**命题 1**．若  \lambda _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n - }  是约束特征值问题 (2) 的特征值，其对应的规范正交特征向量为 $\mathbf { x }$ _ { 1 } $, \mathbf { x }$ _ { 2 } $, \ldots , \mathbf { x }$ _ { n - r } , ，则对任意 $i = 1 , 2 , \ldots , n - r ,  $，有  

$$
\lambda _ { i } = \operatorname* { m i n } _ { \pmb { \theta } \neq \pmb { x } \in X _ { i } } R ( \pmb { x } ) ,
$$  

其中  X _ { i }  是由 $\mathbf { x }$ _ { i } $, \mathbf { x }$ _ { i + 1 } $, \ldots , \mathbf { x }$ _ { n - r }  所生成的子空间。  

类似地，利用习题 8.2.1，我们还可得到另一结论。  

**命题 2**．在命题 1 的记号下，  

$$
\lambda _ { i } = \operatorname* { m a x } _ { \substack { \theta \neq x \in X _ { n - r - i + 1 } } } R ( { \pmb x } ) , \qquad i = 1 , 2 , \ldots , n - r ,
$$  

其中  X _ { n - r - i + 1 }  是由 $\pmb { x }$ _ { n - r - i + 1 } $, \ldots , \pmb { x }$ _ { n - r } .  所生成的子空间。

我们现在考察约束特征值问题的特征值与原始无约束问题的特征值之间的关系。这一方向上的主要结果有时被称为**瑞利定理（Rayleigh’s theorem）**†，尽管瑞利本人将其归功于鲁斯（Routh），而柯西（Cauchy）更早便已使用过该结果。借助**柯朗–费希尔定理（Courant–Fischer theorem）**，该定理可简洁地予以证明。

**定理 1.** 若  \lambda _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n - r }  是埃尔米特矩阵 $H \in \mathbb { C } ^ { n \times n }$ 在施加 $ r $ 个约束条件下的特征值问题（2）的特征值，则  

$$

\mu _ { i } \leq \lambda _ { i } \leq \mu _ { i + r } , \qquad i = 1 , 2 , \ldots , n - r ,
$$
  

其中  \mu _ { 1 } $\leq \mu$ _ { 2 } $\leq \cdots \leq \mu$ _ { n }  是相应无约束问题 $H \mathbf { x } = \mu \mathbf { x } , \mathbf { x } \neq \pmb { \theta } .  $ 的特征值。
