提示：设给定元素 $ a $ 与 $\begin{array} { r } { \pmb { b } , } \end{array}$ 之间有 $ k $ 个数，则为交换 $ a $ 与 $ b $，需进行  2 k + 1  次相邻元素的对换。

习题 5．证明：排列 $ j $ 的奇偶性可通过计算将其变为自然顺序序列  j _ { 0 }  所需的元素对换次数来判定，即变为  j _ { 0 } $= ( 1 , 2 , \ldots , n$ )。 （一般而言，这种变换可经由多种方式实现，但所需对换次数的奇偶性恒与  t ( j )  的奇偶性一致。） □

现在我们已具备给出 $ n $ 阶矩阵行列式定义的条件。设 $ A $ 是一个 $ n $ 阶方阵。$ A $ 的行列式，记作 $ \det A $，定义为  

$$
\operatorname* { d e t } A \triangleq \sum _ { j } ( - 1 ) ^ { t ( j ) } a _ { 1 j _ { 1 } } a _ { 2 j _ { 2 } } \cdot \cdot \cdot a _ { n j _ { n } } ,\tag{8}
$$  

其中  t ( j )  表示排列  j = ( j _ { 1 } , j _ { 2 } $, \dots , j$ _ { n } )  的逆序数，而 $ j $ 取遍  n !  个 $1 , 2 , \ldots , n .  $ 的所有排列。

$n \times n A ,$



换言之，det A 是 n! 个乘积项的和。每一项均由属于同一主对角线（更准确地说，属于由某个排列所确定的广义对角线）的 A 的 n 个元素相乘而得；该乘积前冠以 +1 或 −1 号，取决于定义该对角线的排列 $( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } )$ 是偶排列还是奇排列。
