斜埃尔米特矩阵（skew-Hermitian matrix）$ A $ 是指满足  A ^ { * } = - A  的矩阵（此处 $ A^* $ 表示 $ A $ 的共轭转置）。

习题 15．验证矩阵  

$$
\begin{array} { r } { A = \bigg [ \frac { i } { i } \begin{array} { c c } { i } \\ { i } \end{array} \bigg ] } \end{array}
$$  

为斜埃尔米特矩阵。

## 1.6 子矩阵与矩阵的分块

给定矩阵 $\begin{array} { r } { A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } } \end{array}$，若从中删去若干完整的行或若干完整的列，或同时删去若干完整的行与若干完整的列，则所得的新矩阵称为 $ A $ 的一个子矩阵。  

例 1．若

$$
A = { \left[ \begin{array} { l l l l } { 2 } & { 3 } & { - 2 } & { 4 } \\ { 0 } & { 1 } & { 1 } & { 0 } \\ { 2 } & { - 1 } & { 0 } & { 0 } \end{array} \right] } ,
$$  

那么，如下矩阵  

$$
{ \left[ \begin{array} { l l } { 2 } & { 3 } \\ { 0 } & { 1 } \end{array} \right] } , \qquad [ 1 1 ] , \qquad [ 2 \quad 3 \ - 2 \quad 4 ] , \qquad { \left[ \begin{array} { l l } { 2 } & { 4 } \\ { 2 } & { 0 } \end{array} \right] }
$$  

即为矩阵 $ A $ 的若干子矩阵。  

有一种特殊方式可将矩阵划分为子矩阵：在指定的行之间及指定的列之间插入分隔线（每条分隔线贯穿整个矩阵阵列的宽度或高度）。这种划分称为矩阵的一个**分块**（partition）。  

**例 2.** 矩阵  

$$
A = { \left[ \begin{array} { l l l l } { 2 } & { 3 } & { - 2 } & { 4 } \\ { 0 } & { 1 } & { 1 } & { 0 } \\ { 2 } & { - 1 } & { 0 } & { 0 } \end{array} \right] }
$$
