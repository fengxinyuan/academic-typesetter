## 13.3 贝祖矩阵与结式

后续各节中给出的稳定性结果之证明，依赖于两个方向的发展：其一是矩阵惯性理论的发展，我们此前已予介绍；其二是关于一对标量多项式的贝祖矩阵（Bezout matrix）性质的较新进展，这将在本节中予以讨论。

设  \begin{array} { r } { $a ( \lambda ) = \sum$ _ { j = 0 } ^ { l } a _ { j } $\lambda ^ { j } } \end{array}$ 与 $\begin{array} { r } { b ( \lambda ) = \sum$ _ { i = 0 } ^ { m } b _ { i } $\lambda ^ { j } ( a$ _ { i } $\neq 0 , b$ _ { m } $\neq 0 , l \ge m ) } \end{array}$ 为任意复系数多项式。由于 $b ( \lambda$ )可视为 $\sum$ _ { j = 0 } ^ { l } b _ { j } $\lambda ^ { j }$ ，其中  b _ { m + 1 } $= \cdots = b$ _ { l } = 0 _ { ! } ，故在不丧失一般性的前提下，可设这两个多项式具有如下形式： $\dot { \sum$ _ { j = 0 } ^ { l } } a _ { j } $\lambda ^ { j } , a$ _ { l } $\neq 0 .$ 与 $\sum$ _ { j = 0 } ^ { l } b _ { j } $\lambda ^ { j } .  $。  

表达式  

$$

\frac { a ( \lambda ) b ( \mu ) - b ( \lambda ) a ( \mu ) } { \lambda - \mu }
$$
  

易验证为关于两个变量 $ \lambda $ 与 $\mu { : }  $ 的多项式。  

$$

\frac { a ( \lambda ) b ( \mu ) - b ( \lambda ) a ( \mu ) } { \lambda - \mu } = \sum _ { i , j = 0 } ^ { l - 1 } \gamma _ { i j } \lambda ^ { i } \mu ^ { j } .\tag{1}
$$
  

此时，矩阵  B  $= [ \gamma$ _ { i j } ] _ { i , j = 0 } ^ { l - 1 }  称为与多项式 $a ( \lambda$ )和 $b ( \lambda$ )相关联的贝祖矩阵（或贝祖型，Bezout matrix / Bezoutian）。为突出这一关联，我们亦记作 $B = \operatorname { \mathbf { B e z } } ( a , b$ ) 。  

本节的主要目标有三：  
（i）导出将  \mathtt { B e z } ( a , b )  表示为多项式 $ a $ 与 $ b $ 的系数之函数的公式（特别是公式 (7)、(17) 与 (20)）；  
（ii）建立其与  a  $( \lambda$ )和 $b ( \lambda$ )  的结式（resultant）之间的联系（见公式 (24)）；  
（iii）由此得出关于  a  $( \lambda$ )与 $b ( \lambda$ )  的最大公因式的若干初步结论，并以定理 1 与定理 2 的形式予以陈述。  

习题 1．验证：

$$
\operatorname { B e z } ( a , b ) = - \operatorname { B e z } ( b , a ) ,
$$  

对任意两个多项式 $a ( \lambda )$ 与 $b ( \lambda )$ 均成立，且 $\mathtt { B e z } ( a , b )$ 是对称矩阵。  

习题 2．证明矩阵  

$$
B = \left[ { \begin{array} { r r r } { 0 } & { - 1 } & { 4 } \\ { - 1 } & { 4 } & { 0 } \\ { 4 } & { 0 } & { - 2 } \end{array} } \right]
$$  

是与多项式 $a ( \lambda ) = 1 - \lambda ^ { 2 } + 2 \lambda ^ { 3 }$ 和 $b ( \lambda ) = 2 - \lambda ^ { 2 } = 2 - \lambda ^ { 2 } + 0 \lambda ^ { 3 }$ 相关联的贝祖矩阵。□
