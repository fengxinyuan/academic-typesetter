下一个结果给出了本原矩阵的一种颇为不同的刻画。

**定理 1.** 一个方的非负矩阵 $ A $ 是本原矩阵，当且仅当存在某个正整数 $ p $，使得 $A ^ { p } \ > 0$。

**证明.** 首先假设 $A ^ { p } > 0$，从而 $A ^ { p }$ 是不可约的。我们已知（习题 10.7.1）：若 $ A $ 可约，则 $A ^ { p }$ 亦可约；因此，$A ^ { p } > 0$ 蕴含 $ A $ 不可约。若 $ A $ 的非本原指数为 $k > 1$，则由于 $A ^ { p }$ 的特征值恰为 $ A $ 的特征值的 $ p $ 次幂，故矩阵 $A ^ { p }$ 的非本原指数也为 $k > 1$。但这与将 Perron 定理应用于正矩阵 $A ^ { p }$ 所得结论相矛盾。因此必有 $k = 1$，即 $ A $ 是本原矩阵。

反之，设 $ A $ 是本原矩阵；于是 $ A $ 具有一个重数为 1 的主实特征值 $r$（参见定理 15.3.1 与 15.4.2）。利用定理 9.5.1，并记 $r = \lambda _ { 1 }$，我们有

$$
A ^ { p } = r ^ { p } Z _ { 1 0 } + \sum _ { l = 2 } ^ { s } \sum _ { j = 0 } ^ { m _ { l } - 1 } \ f _ { l , j } Z _ { l j } ,
$$

其中 $f ( \lambda ) = \lambda ^ { p }$，且 $f _ { l , j }$ 是函数 $ f $ 在 $\lambda _ { l }$ 处的第 $ j $ 阶导数。由该式易见，因 $ r $ 是主特征值，故有

$$
\operatorname * { l i m } _ { p  \infty } { \frac { A ^ { p } } { r ^ { p } } } = Z _ { 1 0 } .\tag{2}
$$

此外，由习题 9.9.7 还可知

$$
Z _ { 1 0 } = \frac { C ( r ) } { m ^ { ( 1 ) } ( r ) } ,
$$

且其极小多项式 $ m $ 由下式给出：

$$
m ( \lambda ) = ( \lambda - r ) \prod _ { l = 2 } ^ { s } ( \lambda - \lambda _ { l } ) ^ { m _ { l } } .
$$

由于 $ r $ 是多项式 $m ( \lambda )$ 的最大实零点，且 $m ( \lambda )$ 是首一多项式，因此必有 $m ^ { ( 1 ) } ( r ) > 0$。又因 $C ( r ) > 0$（习题 15.3.10），故得 $Z _ { 1 0 } > 0 .$。由此再结合式 (2)，可知从某个正整数 $ p $ 开始，恒有 $A ^ { p } > 0$。
