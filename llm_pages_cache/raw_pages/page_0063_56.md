## 2.9 线性方程组与矩阵  

考虑如下 $ m $ 个线性代数方程（即一个线性方程组）：  

$$
\begin{array} { r l r } & { } & { a _ { 1 1 } x _ { 1 } + a _ { 1 2 } x _ { 2 } + \dots + a _ { 1 n } x _ { n } = b _ { 1 } , } \\ & { } & { a _ { 2 1 } x _ { 1 } + a _ { 2 2 } x _ { 2 } + \dots + a _ { 2 n } x _ { n } = b _ { 2 } , } \\ & { } & { \vdots } \\ & { } & { a _ { m 1 } x _ { 1 } + a _ { m 2 } x _ { 2 } + \dots + a _ { m n } x _ { n } = b _ { m } . } \end{array}\tag{1}
$$  

其中含有 $ n $ 个未知量 $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$

一个 $ n $ 元组 $ \mathbf{x} = $( x _ { 1 } ^ { 0 } , x _ { 2 } ^ { 0 } $, \ldots , x$ _ { n } ^ { 0 } )  称为方程组 (1) 的一个解，若将 $\pmb { x }$ _ { i } ^ { 0 }  代入 (1) 中  x _ { i } $( i = 1 , 2 , \ldots , n$ )的位置后，所得均为恒等式。此时我们也称  x _ { i } ^ { 0 } $( i = 1 , 2 , \ldots , n$ )  满足 (1) 中的每一个方程。若方程组 (1) 无解，则称其为不相容的（inconsistent）；若它至少有一个解，则称其为相容的（consistent）。在许多实际应用中，需要求解此类方程组，即：求出它的全部解，或证明其不相容。本节首先介绍求解线性方程组的高斯消元法（Gauss reduction method），然后介绍若干其他方法，这些方法均借助前文已建立的矩阵技巧。关于线性方程组及其解的进一步研究见第 3.10 节。

回到方程组 (1)，注意到其左端各项的系数构成一个 $ m \times n $ 矩阵  

$$
\begin{array} { r } { A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } , } \end{array}\tag{2}
$$  

该矩阵称为 (1) 的**系数矩阵**。此外，$ n $ 个未知量与右端的 $ m $ 个常数可分别写成（列）向量：  

$$
\begin{array} { r } { \boldsymbol { x } = \left[ \begin{array} { c } { x _ { 1 } } \\ { x _ { 2 } } \\ { \vdots } \\ { x _ { n } } \end{array} \right] , \qquad \boldsymbol { b } = \left[ \begin{array} { c } { b _ { 1 } } \\ { b _ { 2 } } \\ { \vdots } \\ { b _ { m } } \end{array} \right] , } \end{array}\tag{3}
$$
