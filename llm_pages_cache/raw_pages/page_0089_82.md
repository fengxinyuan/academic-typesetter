至此，我们已获得线性相关元素组的另一种刻画方式。

**定理 1.** 子空间 $\operatorname{span}\{$\{ a _ { 1 } , a _ { 2 } $, \ldots , a$ _ { n } \}$\}$ 可由 $$\left\{ { \pmb a } _ { i } \right\} _ { i } ^ { n } = 1$$ 的某个真子集张成，当且仅当元素 $${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { n }$$ 线性相关。

线性无关集则定义为非线性相关的集合。因此，若 $$\mathcal { S }$$ 是一个线性空间，则元素组 $${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , \dots , { \pmb a } _ { n } \in \mathcal { S }$$ 线性无关，是指方程  

$$
\sum _ { i \mathop { = } 1 } ^ { n } \gamma _ { i } \pmb { a } _ { i } = \pmb { \mathscr { 0 } } ,
$$  

对 $$\gamma _ { 1 } , \gamma _ { 2 } , \ldots , \gamma _ { n } \in \mathcal { F } ,$$ 成立时，必有  

$$
\gamma _ { 1 } = \gamma _ { 2 } = \cdot \cdot \cdot = \gamma _ { n } = 0 .
$$  

由此可见，在此情形下，无法再从集合 $$\{ a _ { 1 } , a _ { 2 } , \ldots , a _ { n } \}$$ 中删去任一元素，而仍保持其张成子空间 $\operatorname{span}\{$\{ a _ { 1 } , a _ { 2 } $, \ldots , a$ _ { n } \}$\}$ 不变。  

因此，在此情形下，$n$ 即为所考虑的线性包（linear hull）的最小生成元个数。与此相关的一系列问题将在下一节中更详细地讨论；而本节余下部分将用于若干示例说明。
