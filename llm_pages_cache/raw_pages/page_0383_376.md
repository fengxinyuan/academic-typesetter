下一个结果表明：对于一个不可约矩阵 $ A $，其所有特征值要么全部位于盖尔圆盘（Geršgorin disks）之并集的内部，要么某个特征值 $ \lambda $ 是全部 $ n $ 个盖尔圆盘的公共边界点。

**定理 2（O. Taussky）**：设  \begin{array} { r } { A = [ a _ { j k } ] _ { j , k = 1 } ^ { n } } $\end{array}$ 是一个复不可约矩阵，且 $ \lambda $ 是 $ A $ 的一个特征值，并位于盖尔圆盘之并集的边界上。则 $ \lambda $ 必位于每一个盖尔圆盘的边界上。

**证明**：在定理假设下，存在某个 $ i $，使得 $| \lambda - a$ _ { i i } $| = \rho$ _ { i } ，且 $1 \leq i \leq n .$ 。若 $ \lambda $ 位于其余 $ n-1 $ 个盖尔圆盘之外，则对所有 $j \neq i .$ ，均有 $| \lambda - a$ _ { j j } $| > \rho$ _ { j } 。因此，由定理 1 可知，矩阵 $\lambda I - A$ 必为非奇异矩阵。但这与 $ \lambda $ 是 $ A $ 的特征值这一假设相矛盾。于是，由于 $ \lambda $ 必须位于这些圆盘之并集的边界上，它必为 $ m $ 个圆周的交点，其中 $2 \leq m \leq n$ 。因此，在如下方程组中恰有 $ m $ 个等式成立：

$$
| \lambda - a _ { j j } | \geq \sum _ { k = 1 , k \neq j } ^ { n } | a _ { j k } | , \qquad 1 \leq j \leq n ,
$$
