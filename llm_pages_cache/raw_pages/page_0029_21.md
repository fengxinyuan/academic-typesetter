## 1.8 杂项习题  

1. 设 $\pmb { A } \in \mathbb { R } ^ { n \times n }$ 是一个元素均非负的方阵，且其每一行的所有元素之和（即每行行和）均等于 1。这样的矩阵称为随机矩阵（stochastic matrix）。证明：两个随机矩阵的乘积仍是随机矩阵。  

2. 若矩阵 $\pmb { A } \in \mathbb { R } ^ { n \times n }$ 满足 A 与 $A ^ { \boldsymbol { \mathsf { T } } }$ 均为随机矩阵，则称 A 为双随机矩阵（doubly stochastic matrix）。证明：两个双随机矩阵的乘积仍是双随机矩阵。
