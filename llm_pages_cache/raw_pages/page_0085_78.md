习题 5．该集合

$$
\left\{ \left[ \begin{array} { l } { \alpha } \\ { 0 } \end{array} \right] : \alpha \in \mathcal { F } \right\}
$$  

是矩阵  

$$
A = { \left[ \begin{array} { l l l } { 1 } & { 0 } & { 0 } \\ { 0 } & { 0 } & { 0 } \end{array} \right] } .
$$  

的值域（像空间）。  

习题 6．验证：任意矩阵 $A \in \mathcal { F } ^ { m \times n }$ 的值域是 ${ \mathcal { F } } ^ { m }$ 的一个子空间。  

习题 7．证明：若矩阵乘积 $ AB $ 有定义，则  

$$
\mathbf { K e r } ( A B ) \supset \mathbf { K e r } \ B ,
$$  

且当 $ A $ 可逆时等号成立；又  

$$
\mathbf { I m } ( A B ) \subset \mathbf { I m } A ,
$$  

且当 $ B $ 可逆时等号成立。 □  

注意：符号 $\mathbf { \Sigma } = \left. \left( \mathbf { o r \Sigma } \supset \right) \right.$ 始终一致地表示**严格包含或相等**（即“⊆”关系，而非真包含“⊂”）。  

## 3.3 线性组合  

我们从如下问题出发：设 ${ a } _ { 1 } , \ { a } _ { 2 } , \ldots , \ { a } _ { n }$ 是域 $\mathcal { F } .$ 上线性空间 $\mathcal { S }$ 中的元素。我们希望找出包含这些给定元素的、$\mathcal { S }$ 中最小的子空间 $\mathcal { S } _ { 0 }$。此处“最小”的含义是：若 $\mathcal { S } _ { 1 }$ 是 $\mathcal { S }$ 的一个子空间，且满足 ${ \pmb a } _ { 1 } , { \pmb a } _ { 2 }$、$\dots , a _ { n }$ ∈ $\mathcal { S } _ { 1 }$，则必有 $\mathcal { S } _ { \mathfrak { I } } \supset \mathcal { S } _ { 0 }$。

为了解决该问题，我们首先注意到：根据子空间的定义，集合 $\mathcal { S } _ { 0 }$ 在包含 $a _ { i } ( i = 1 , 2 , \dots , n )$ 的同时，还必须包含所有形如 $\alpha _ { i } \pmb { a } _ { i } ( \alpha _ { i } \in \mathscr { F } , i = 1 , 2 , \dots , n )$ 的元素；此外，属于 $\mathcal { S } _ { 0 }$ 的元素之和也必须属于 $\mathcal { S } _ { 0 }$。

因此，任何包含元素 ${ a } _ { 1 } , { a } _ { 2 } , \ldots , { a } _ { n }$ 的子空间，都必须包含所有形如  

$$
\alpha _ { 1 } \pmb { a } _ { 1 } + \alpha _ { 2 } \pmb { a } _ { 2 } + \dots + \alpha _ { n } \pmb { a } _ { n }\tag{1}
$$  

的元素，其中 $\alpha _ { i } \in \mathcal { F } \left( i = 1 , 2 , . . . , n \right)$ 为任意标量。形如 (1) 的表达式称为元素 ${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { n }$ 在域 $\mathcal { F } .$ 上的线性组合。
