提示：注意  \mathbf { x } _ { 1 } $, \mathbf { x }$ _ { 2 } $, \ldots , \mathbf { x }$ _ { s }  的线性无关性蕴含了 $\pmb { x }$ _ { 1 } e ^ { $\lambda$ _ { 1 } t } $, \pmb { x }$ _ { 2 } e ^ { $\lambda$ _ { 2 } t } $, \dots , \pmb { x }$ _ { s } e ^ { $\lambda$ _ { s } t }  的线性无关性，并利用命题 1。

对于一个可对角化矩阵 $ A $，我们能比习题 1 的结论说得更深入：此时， $\mathbb { C } ^ { n }$ 存在一组由 $ A $ 的特征向量构成的基。事实上，若 $\mathbf { { \dot { x } } }$ _ { 1 } $, \dots , \mathbf { { \dot { x } }$ _ { n } }  是这样一组基，其对应的特征值分别为 $\lambda$ _ { 1 } $, \ldots , \lambda$ _ { n } ，则易验证，$ n $ 个向量值函数  x _ { j } e ^ { $\lambda$ _ { j } t } ;  均为方程的解，即 $j = 1 , 2 , \dots , n ,$ ，且它们生成一个 $ n $ 维的解子空间 $\mathcal { S }$ _ { 0 } 。我们将证明：该子空间 $\mathcal { S }$ _ { 0 }  实际上就是整个解空间 $\mathcal { S }  $。

更一般地，我们首先考虑非齐次方程组  

$$
{ \dot { \mathbf { x } } } ( t ) = A { \mathbf { x } } ( t ) + f ( t )\tag{2}
$$  

（其中  \pmb { f } ( t )  是一个给定的可积函数）。将证明：方程 (2) 可约化为 $ n $ 个相互独立的标量方程。为此，设 $ A $ 的右特征向量 $\pmb { x }$ _ { 1 } $, \ldots , \pmb { x }$ _ { n }  与左特征向量  y _ { 1 } $, \ldots , y$ _ { n }  按照定理 4.10.3 的要求予以定义。若令  P = [ { $\pmb x }$ _ { 1 } $\quad \cdots \quad { \pmb x }$ _ { n } ]  且  Q = [ { $\mathfrak { y } }$ _ { 1 } $\quad \cdots \quad { \mathfrak { y } }$ _ { n } ] . ，则特征向量的双正交性（参见式 (4.10.6)）可概括为如下关系：  

$$
Q ^ { \boldsymbol { \mathsf { T } } } \ P = I ,\tag{3}
$$

且矩阵 $ A $ 本身的表示式（参见公式 (4.10.7)）为  

$$
A = P D Q ^ { \mathbf { T } } ,\tag{4}
$$  

其中  $D = \mathrm { d i a g } [ \lambda _ { 1 } , . . . , \lambda _ { n } ] ,$  

现在，若将公式 (4) 代入系统 (2)，再在等式左边同乘以  $Q ^ { \boldsymbol { \mathsf { T } } } .$，并利用公式 (3)，即可将系统 (2) 约化为一组标量方程：  

$$
Q ^ { \mathsf { T } } \dot { \mathbf { x } } ( t ) = D Q ^ { \mathsf { T } } \mathbf { x } ( t ) + Q ^ { \mathsf { T } } f ( t ) .
$$  

引入新变量  $z _ { j } ( t ) = y _ { j } ^ { \mathrm { T } } x ( t )$（其中  $j = 1 , 2 , \dots , n$），以及经变换后的给定函数  $\phi _ { j } ( t ) \stackrel { \cdot } { = } y _ { j } ^ { \operatorname { T } } f ( t )$，则方程化为  $\dot { z } ( t ) = D z ( t ) + \varphi ( t )$，其中  

$$
\begin{array} { r } { z ( t ) = [ z _ { 1 } ( t ) \quad z _ { 2 } ( t ) \quad \cdot \cdot \quad z _ { n } ( t ) ] ^ { \mathrm { T } } , \ : \ : \ : \ : \varphi ( t ) = [ \varphi _ { 1 } ( t ) \quad \varphi _ { 2 } ( t ) \quad \cdot \cdot \cdot \quad \varphi _ { n } ( t ) ] ^ { \mathrm { T } } . } \end{array}
$$  

等价地，我们得到  $n ^ { ~ 6 6 }$ 个“解耦的”标量方程  

$$
\dot { z } _ { j } ( t ) = \lambda _ { j } z _ { j } ( t ) + \varphi _ { j } ( t ) ,\tag{5}
$$  

其中  $j = 1 , 2 , \dots , n .$。这些方程可用初等方法求解；而原系统 (2) 的解则可通过下述关系复原：首先注意到  $z ( t ) = Q ^ { \mathrm { { r } } } x ( t )$，再结合公式 (3) 得  ${ \bf { \boldsymbol { x } } } ( t ) = P { \boldsymbol { \boldsymbol { z } } } ( t )$。

对于齐次方程 (1)（即当式 (2) 中对所有 $ t $ 均有 $\pmb { f } ( t ) = \pmb { \theta }$ 时），式 (5) 中直接有 $\varphi _ { j } ( t ) = 0$，且式 (5) 的解为 $z _ { j } ( t ) = c _ { j } e ^ { \dot { a } _ { j } t }$，其中 $c _ { j }$ 为某个常数。
