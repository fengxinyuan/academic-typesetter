## 5.4 正定矩阵的平方根与奇异值

埃尔米特矩阵与实数之间存在一种类比关系，以下结果即体现了这一点：它断言，任一正半定矩阵 $ H $ 存在平方根 $ \text{$H _ { 0 }$} $，即存在一个矩阵 $ \text{$H _ { 0 }$} $，使得 $ \text{$H _ { 0 } ^ { 2 } = H ,$} $。
