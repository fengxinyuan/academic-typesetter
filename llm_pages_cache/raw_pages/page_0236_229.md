## 6.3 广义特征子空间

在前一节中已指出：若 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，则线性变换 $T$ 在空间 $\mathcal { S }$ 上的作用可分解为研究更基本的变换 $T _ { i } = \left. T \right| _ { \mathfrak { s } _ { i } }$ 在式 (6.2.4) 所定义的 T-不变子空间 ${ \pmb { \mathscr { G } } } _ { i }$ 上的作用。为持续推进对 $T ,$ 的“分解”，我们接下来将更细致地考察这些子空间的结构。此外，第 9.5 节将发展一种技术，用以构造一族投影算子，其像空间恰为子空间 $\mathcal { G } _ { 1 } , \ldots , \mathcal { G } _ { s }$。

设 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，其中 $\mathcal { F } = \mathbb { C } , \ \lambda \in \sigma ( T )$，且 $\mathcal { S } _ { r } = \mathop { \mathrm { K e r } } ( T - \lambda I ) ^ { r }$，此处 r 取遍所有非负整数。习题 4.5.14 断言：

$$
\{ \pmb { \theta } \} = \mathcal { S } _ { \pmb { \theta } } \subset \mathcal { S } _ { 1 } \subset \mathcal { S } _ { 2 } \subset \cdots \subset \mathcal { S } _ { p } = \mathcal { S } _ { p + 1 } = \cdots \subset \mathcal { S }\tag{1}
$$

对某个正整数 $p .$ 成立。注意，$\mathcal { S } _ { 1 }$ 是 T 关于特征值 $\lambda ;$ 的特征子空间；严格包含关系 $\{ \pmb { \theta } \} \subset \mathcal { S } _ { 1 }$ 源于假设 $\lambda \in \sigma ( T )$。  

习题 1．验证：$\mathbf { \boldsymbol { x } } \in \mathcal { S } _ { r }$ 当且仅当 $( T - \lambda I ) ( { \pmb x } ) \in \mathcal { S } _ { r - 1 }$。□

式 (1) 中的子空间 $\mathcal { S } _ { r } ( 1 \leq r \leq p )$ 称为线性变换 $T$ 关于特征值 λ 的 r 阶广义特征子空间。此外，若非零向量 x 满足 $\mathbf { \boldsymbol { x } } \in \mathcal { S } _ { r }$ 但 $x \notin \mathcal { S } _ { r - 1 }$，则称 x 为线性变换 $T$ 关于特征值 $\lambda ,$ 的 r 阶广义特征向量，即  

$$
\pmb { x } \in \mathrm { K e r } ( T - \lambda I ) ^ { r } , \qquad \mathsf { b u t } \qquad \pmb { x } \notin \mathrm { K e r } ( T - \lambda I ) ^ { r - 1 } .
$$  

特别地，T 的通常意义下的特征向量可视为 T 关于同一特征值的 1 阶广义特征向量；同理，T 的特征子空间亦可视为其关于该特征值的 1 阶广义特征子空间。需注意：本节中，除非另有说明，所有广义特征向量与广义特征子空间均默认与线性变换 $T .$ 的某个固定特征值 λ 相关联。

需要强调的是，方程 (6.2.4) 中的子空间 $\mathscr { G } _ { i }$ 均为广义特征子空间；而定理 6.2.3 所给出的基本分解，依赖于全空间 $\mathcal { S }$ 按照式 (6.2.5) 分解为若干广义特征子空间的直和。
