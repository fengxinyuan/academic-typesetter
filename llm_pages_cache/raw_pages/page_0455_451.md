## 13.2 关于单位圆的稳定性

我们已知：具常系数的线性微分方程的稳定性问题，与某矩阵的特征值相对于虚轴的位置密切相关。类似地，在线性差分方程中，特征值相对于单位圆的位置起着相应的作用。

为阐明这些思想，设给定 $A \in \mathbb { C } ^ { n \times n }$ 及非零向量 $\pmb { x _ { 0 } } \in \mathbb { C } ^ { n }$，并考虑最简单的差分方程：

$$
\pmb { x } _ { j } = A \pmb { x } _ { j - 1 } , \qquad \pmb { x } _ { j } \in \mathbb { C } ^ { n } , \qquad j = 1 , 2 , \ldots .\tag{1}
$$

该方程是微分方程（13.1.1）的一个差分对应形式，但其解要简单得多：  
$\pmb { x } _ { j } = A ^ { j } \pmb { x } _ { 0 }$，其中 $j = 0 , 1 , \ldots$。  

我们称方程（1）中的矩阵 $ A $ 是**稳定的（关于单位圆）**，若对任一初始向量 $\pmb { x _ { 0 } }$，方程（1）的解序列 $\pmb { x } _ { 0 } , \pmb { x } _ { 1 } , \ldots , \pmb { x } _ { j } , \ldots$ 均收敛于零。容易看出，这一性质成立当且仅当 $A ^ { j }  0$（当 $j \to \infty$ 时），而由习题 11.1.8 可知，这又等价于矩阵 $ A $ 的谱半径小于 1。因此，矩阵 $ A $ 关于单位圆稳定，当且仅当其所有特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ 均位于单位圆内部，即满足 $i s , | \lambda _ { i } | < 1$，其中 $i = 1 , 2 , \ldots , n .$。

本节中，我们将发展一种类似于李雅普诺夫（Lyapunov）方法的技术，用于判定一个矩阵（按重数计）有多少个特征值位于单位圆内、单位圆外以及单位圆周上。结果表明，该问题与如下 Stein 方程  
$H - A ^ { * } H A = V$  
是否存在正定解 $ H $（对某个给定的正定矩阵 $ V $）密切相关。

**定理 1**．设 $ A $、$V \in \mathbb { C } ^ { n \times n }$，且 $ V $ 为正定矩阵。

（a）若 $ A $ 关于单位圆稳定，则方程  

$$
H - A ^ { * } H A = V\tag{2}
$$  

存在唯一解 $ H $，且 $ H $ 为正定矩阵。

（b）若存在正定矩阵 $ H $ 满足方程（2），则 $ A $ 关于单位圆稳定。

**证明**．首先假设 $ A $ 是稳定的，并令 $ \text{$\lambda _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { n }$} $ 表示 $ A $ 的特征值，因此对所有 $ \text{$i  $= 1 , 2 , \ldots , n . } $，均有 $ \text{$| $\lambda$ _ { i } | < 1$} $。于是（参见习题 9.4.3），矩阵 $ \text{$A ^ { * } + I$} $ 是非奇异的，从而我们可以定义矩阵  

$$
\text{$$
C = ( A ^ { * } + I ) ^ { - 1 } ( A ^ { * } $- I ) .\tag{3}$ 
$$}
$$
