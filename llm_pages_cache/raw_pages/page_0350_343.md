引理 2．定义如下的矩阵值函数 $W ( t )$：

$$
W ( t ) = \int _ { 0 } ^ { t } e ^ { A s } B B ^ { * } e ^ { A ^ { * } s } d s\tag{7}
$$

具有如下性质：对任意 $t > 0 ,$，有 $ \operatorname{Im}  W ( t ) = { \mathcal { C } } _ { A , B }$。

$\mathbb { C } ^ { n } \mathbb { C } ^ { n } .$



**证明**．显然，对每个 $t > 0$，$W ( t )$ 均为埃尔米特矩阵，因此［参见式 (5.8.5)］  

$$
\operatorname { I m } W ( t ) = ( \operatorname { K e r } W ( t ) ) ^ { \perp } .
$$  

此外［参见式 (5.13.5)］，若 $\mathcal { K } _ { A , B }$ 表示 $( B ^ { * } , A ^ { * } )$ 的不可观子空间，则  

$$
\mathcal { C } _ { A , B } = ( \mathcal { K } _ { A , B } ) ^ { \perp } .
$$  

于是，本引理的结论等价于如下命题：$\operatorname{Ker} W(t) = \text{$= $\mathcal { K }$ _ { A , B }$}$，我们将以此形式予以证明。  

若 $\mathbf { \boldsymbol { x } } \in \mathbf { \mathbb { K } } \in \operatorname{Ker} W(t)$，则  

$$
x ^ { * } W ( t ) x = \int _ { 0 } ^ { t } \lVert B ^ { * } e ^ { A ^ { * } s } x \rVert ^ { 2 } d s = 0 ;
$$  

此处采用欧几里得向量范数。因此，对所有 $s \in [ 0 , t ]$，有  

$$
B ^ { * } e ^ { A ^ { * } s } x = 0 .
$$  

对此关系式关于 $s$ 反复求导，并令 $s \to 0 _ { + }$，可得  

$$
B ^ { * } ( A ^ { * } ) ^ { j - 1 } x = 0 \qquad \mathrm { f o r } \quad j = 1 , 2 , \ldots , n .
$$  

换言之，  

$$
\pmb { x } \in \bigcap _ { j = 1 } ^ { n } \operatorname { K e r } ( B ^ { * } ( A ^ { * } ) ^ { j - 1 } ) = \pmb { \mathcal { M } } _ { A , B } .
$$  

从而 $\operatorname{Ker} \text{$W  $( t ) \subset \mathcal { K }$ _ { A , B }$}$。容易验证：将上述推理过程逆向进行，并利用引理 1，即可得到反向包含关系。故 $\operatorname{Ker} \text{$W  $( t ) = \mathcal { K }$ _ { A , B }$}$，引理得证。■  

该引理给出了矩阵对 $( A , B )$ 可控性的一个新判据。  

**推论 1**．矩阵对 $( A , B )$ 可控当且仅当式 (7) 所定义的矩阵 $W(t)$ 对所有 $t > 0$ 均为正定矩阵。

**证明**．由定义 (7) 显然可知，$W ( t )$ 至少是半正定的。然而，$( A , B )$ 的能控性意味着 $\mathcal { C } _ { A , B } = \mathbb { C } ^ { n } ;$，因此引理 2 推出 $\operatorname{Im} \, \text{$W  $( t ) = \mathbb { C } ^ { n } }$。于是 $W ( t )$ 的秩为 $n$，从而是正定的。■
