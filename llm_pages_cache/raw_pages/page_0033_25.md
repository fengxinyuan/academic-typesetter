为了对任意 $ n \times n $ 阶方阵定义行列式，使得克莱姆法则（Cramer’s rule）仍然成立，我们首先观察：对于一个 $3 \times 3$ 矩阵，其行列式由形如 $a _ { 1 j _ { 1 } } a _ { 2 j _ { 2 } } a _ { 3 j _ { 3 } } .$ 的项之和组成，其中 $j _ { 1 } , j _ { 2 } , j _ { 3 }$ 是数字 $ 1,2,3 $ 的某种排列，即 $( j _ { 1 } , j _ { 2 } , j _ { 3 } )$ 是 $ 1,2,3 $ 的一个排列。一般地，若 $j _ { 1 } , j _ { 2 } , \ldots , j _ { n }$ 是数字 $1 , 2 , \ldots , n$ 的某种重排，则称 $( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } )$ 是 $1 , 2 , \ldots , n$ 的一个排列。

设 $\begin{array} { r } { A = [ a _ { i j } ] _ { i , j = 1 } ^ { n } } \end{array}$ 表示任一阶方阵。考虑到低阶矩阵行列式的结构，我们将 $ A $ 的一条对角线定义为：由 $ A $ 中 $ n $ 个元素构成的一个序列，该序列恰好包含 $ A $ 的每一行中的一个元素，且恰好包含 $ A $ 的每一列中的一个元素。$ A $ 的对角线总是按照行指标的顺序加以排序；因此它可写成如下形式：

$$
a _ { 1 j _ { 1 } } , a _ { 2 j _ { 2 } } , \ldots , a _ { n j _ { n } } ,\tag{7}
$$

其中，$( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } )$ 是数字 $1 , 2 , \ldots , n .$ 的一个排列。特别地，若 $( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } ) = ( 1 , 2 , \ldots , n )$，则得到矩阵 $ A $ 的主对角线；当 $( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } ) = ( n , n - 1 , \ldots , 1 )$ 时，则得到矩阵 $ A $ 的次对角线（参见第 1.1 节）。显然，一个 $n \times n$ 矩阵恰好具有 $ n! $ 条互不相同的对角线。

**习题 1.** 验证：$2 \times 2$ 矩阵与 $3 \times 3$ 矩阵的行列式均为各条对角线上元素乘积所构成的代数和。

为确定这些乘积（例如式 (6) 中）的符号，我们需要一些关于排列的基本事实。我们称排列 $( j _ { 1 } , j _ { 2 } , \ldots , j _ { n } )$ 中的一对数 $j _ { k }$ 与 $j _ { p }$ 构成一个**逆序**（inversion），如果 $j _ { k } > j _ { p }$ 而 $k < p ,$，即：在该排列中，较大的数出现在较小的数之前。每个排列 $j = ( j _ { 1 } , j _ { 2 } , \dots , j _ { n } )$ 均对应一个确定的逆序数，简记为 $t ( j )$。只要按如下例所示的方式依次计数，该逆序数即被唯一确定。若 $t ( j )$ 为奇数，则称该排列为**奇排列**；若为偶数，则称其为**偶排列**。这一性质称为该排列的**奇偶性**（parity）。

**习题 2.** 求 $t ( j )$，其中 $j = ( 2 , 4 , 3 , 1 , 5 )$。

**解**：数 2 出现在 1 之前，因此构成一个逆序；数 4 分别与 3 和 1 构成逆序；而 3 又与 1 构成逆序。于是，给定排列中的逆序总数 $t ( j )$ 为 $^ { 4 , }$，故该排列 $ j $ 是一个偶排列。
