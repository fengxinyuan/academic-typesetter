## 11.4 分量矩阵的摄动

假设一个未受摄动的特征值 λ 在由 $A ( \zeta )$ 所确定的摄动作用下“分裂”为互异的特征值 $\lambda _ { 1 } ( \zeta ) , \ldots , \lambda _ { p } ( \zeta )$。我们可以证明：对应于这些特征值的各首个分量矩阵之和，在 $\zeta = 0 .$ 附近是解析的。该定理是我们后续整个摄动问题分析所赖以展开的基石。

定理 1．设  A  $( \zeta$ )在 $\zeta = 0$ 的某个邻域内解析，且  A ( 0 ) = A 。假设 $\lambda$ _ { 1 } $( \zeta ) , \ldots , \lambda$ _ { p } $( \zeta$ )是 $A ( \zeta$ )的互异特征值，满足 $\lambda$ _ { k } $( \zeta ) \to \lambda a s \zeta \to 0 , k = 1 , 2 , \ldots , p .$ ；并设  Z _ { k 0 } $( \zeta$ )是 $A ( \zeta$ )关于 $\lambda$ _ { k } $( \zeta$ )的幂等分量矩阵。若 $ Z $ 是 $ A $ 关于特征值 $ \lambda $ 的幂等分量矩阵，并定义  

$$

Y ( \zeta ) = \sum _ { k = 1 } ^ { p } Z _ { k 0 } ( \zeta ) ,
$$
  

则存在一个邻域  o  $f \zeta = 0  $，使得下列展开式在其中成立：  

$$

Y ( \zeta ) = Z + \zeta C _ { 1 } + \zeta ^ { 2 } C _ { 2 } + \cdots ,
$$
  

$$
