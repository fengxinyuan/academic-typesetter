## 14.3 若尔当三元组的结构

根据定义，对于首项系数非奇异的矩阵多项式 $L ( \lambda )$，其所有标准三元组在式 (14.2.4) 所定义的相似意义下彼此相似。因此，总存在某些标准三元组，使其第二项（即 $ L(\lambda) $ 的线性化）为若尔当标准形 $ J $。此时，该标准三元组 $L ( \lambda ) .  (X, J, Y) $ 称为 $ L(\lambda) $ 的一个**若尔当三元组**（Jordan triple）。类似地，若尔当三元组中的矩阵对 $ (X, J) $ 称为 $ L(\lambda) $ 的一个**若尔当对**（Jordan pair）。接下来我们将证明：一个若尔当三元组显式地给出了 $ L(\lambda) $ 的全部谱信息。

我们首先作一个简化假设，该假设将在后续被取消。假设  L  $( \lambda$ )是一个次数为 $ l $ 的 $n \times n$ 矩阵多项式，且满足 $ \det $L _ { l } $\neq 0$ ，并具有全部一次初等因子。这意味着：对 $L ( \lambda$ )的任一线性化所对应的若尔当矩阵 $ J $，必为对角矩阵。特别地，若 $L ( \lambda$ )  的所有特征根互异，则此情形必然成立。记  
$$
$J = \mathrm { d i a g } [ \lambda _ { 1 } , \lambda _ { 2 } , . . . , \lambda _ { \iota n } ]$
$$

设  ( X , J )  是 $L ( \lambda$ )的一个若尔当对（Jordan pair），并令 $\pmb { x }$ _ { j } $\in \mathbb { C } ^ { n }$ 为矩阵 $ X $ 的第 $ j $ 列，其中 $j = 1 , 2 , \dots , l r$ ，$ n $。由于若尔当对亦为标准对（standard pair），由定理 14.2.3 可知，$ ln \times ln $ 矩阵

$$
  

是非奇异的。此外，
