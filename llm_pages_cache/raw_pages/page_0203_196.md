正交投影子的作用可通过其特征向量来刻画。为阐明这一点，我们选取 $ P $ 的一组标准正交（右）特征向量 $ \text{$\{ $\pmb { x }$ _ { 1 } $, \pmb { x }$ _ { 2 } $, \ldots , \pmb { x }$ _ { n } \}$} $。此时，对应的左特征向量恰为这些（右）特征向量的共轭转置（即埃尔米特伴随），于是表示式 (1) 化为（参见习题 5.2.5）

$$
P = \sum _ { j = 1 } ^ { r } x _ { j } x _ { j } ^ { * } ,
$$

且对任意向量 $ \text{$x  $\in \mathcal { F } ^ { n } } $，有

$$
P x = \sum _ { j = 1 } ^ { r } x _ { j } x _ { j } ^ { * } x = \sum _ { j = 1 } ^ { r } ( x , x _ { j } ) x _ { j } .
$$

现在可见，该求和式的每一项均为 $ \mathbf{x} $ 到某个（右）特征向量 $ \mathbf{x}_j $ 所张成的一维子空间上的正交投影。因此，$ P $ 是到由 $ \text{$x _ { 1 } , x _ { 2 } $, \ldots , x$ _ { r } ,$} $ 所张成的子空间（即 $ \operatorname{Im} P $）上的正交 $ \text{$\mathbf { $\boldsymbol { x } }$ _ { j }$}   \text{$P$} $ 投影子。

为进一步深入理解正交投影子，我们还可采用如下更直接的途径。设给定一个子空间 $ \text{${ $\mathcal { S } } \subset { \mathcal { F } } ^ { n } } $，其一组基为 $ \text{$\{ $\pmb { u }$ _ { 1 } $, \pmb { u }$ _ { 2 } $, \dots , \pmb { u }$ _ { k } \}$} $，我们希望构造一个到 $ S $ 上的正交投影子。令 $ \text{$\mathcal { S }$} $ 为 $ \text{$n  $\times k } $ 矩阵 $ \text{$A  $= \left[ \pmb { u }$ _ { 1 } $, \pmb { u }$ _ { 2 } $, \ldots , \pmb { u }$ _ { k } $\right$ ]$} $，则 $ \text{$\mathcal { S }$} $ 中的任一典型元素均可表为 $ A\mathbf{x} $，其中 $ \mathbf{x} \in \text{$\ b { x } $\in \mathcal { F } ^ { k } } $。对任意给定的 $ \text{$\pmb { a } $\in \mathcal { F } ^ { n } } $，我们希望找到一个向量 $ \text{$A  $x \in { \mathcal { S } } } $，它可恰当地称为 $ \mathbf{a} $ 到 $ \text{$\mathcal { S } .$} $ 上的投影。

我们通过要求 $ \mathbf{Ax} $ 满足 $ \mathbf{Ax} - \mathbf{b} $ 与 $ \mathcal{S} $ 中每个向量正交，来确定 $ \mathbf{x} $。这一条件成立当且仅当 $ \mathbf{Ax} - \mathbf{b} $ 与 $ \mathcal{S} $ 的每一组基向量均正交。因此，在标准内积下，

$$
( \pmb { a } - \pmb { A } \pmb { x } , \pmb { u } _ { j } ) = \pmb { u } _ { j } ^ { * } ( \pmb { a } - \pmb { A } \pmb { x } ) = 0 , \qquad j = 1 , 2 , \ldots , k ,
$$

这等价于矩阵方程

$$
A ^ { * } ( a - A x ) = 0 .
$$

解出 $ \mathbf{x} $，得  
$\pmb { x } = ( A ^ { * } A ) ^ { - 1 } A ^ { * } \pmb { a }$  
其中逆矩阵存在，是因为 $A ^ { * } A$ 是线性无关向量组的格拉姆矩阵（定理 3.12.2）。于是，若 $ P $ 是 $ \mathcal{S} $ 上的正交投影算子，则必有

$$
\begin{array} { r } { P { \pmb { a } } = A { \pmb { x } } = A ( A ^ { * } A ) ^ { - 1 } A ^ { * } { \pmb { a } } , \qquad { \pmb { a } } \in { \mathscr F } ^ { n } , } \end{array}
$$

即

$$
P = A ( A ^ { * } A ) ^ { - 1 } A ^ { * } .\tag{2}
$$

事实上，容易验证 $ P $ 是幂等的且为埃尔米特矩阵。因此，我们已由 $ \mathcal{S} $ 的任意一组基唯一确定了其上的正交投影算子 $P$。
