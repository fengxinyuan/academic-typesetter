习题 3．证明：一个方阵 A 是对称矩阵，当且仅当  

$$
A ^ { \mathsf { T } } = A . \quad \bigsqcup\tag{1}
$$  

一些关于对称矩阵的附加性质可直接由式 (1) 推出。  

习题 4．证明：若 A 与 B 均为对称矩阵，则 $A + B$ 也是对称矩阵。  

习题 5．证明：对任一方阵 A，矩阵 $A A ^ { \boldsymbol { \mathsf { T } } } , A ^ { \boldsymbol { \mathsf { T } } } A ,$ 与 $A ^ { \boldsymbol { \mathsf { T } } } + A$ 均为对称矩阵。□  

若矩阵 A 满足  

$$
A ^ { \mathsf { T } } = - A .\tag{2}
$$  

则称 A 为斜对称矩阵（或反对称矩阵）。

习题 6．验证矩阵  

$$
A = \left[ { \begin{array} { r r r } { 0 } & { - 2 } & { - 3 } \\ { 2 } & { 0 } & { - 2 } \\ { 3 } & { 2 } & { 0 } \end{array} } \right]
$$  

是斜对称矩阵。□  

显然，一个 $ n \times n $ 斜对称矩阵 $A = [ a _ { i j } ]$ 的元素满足下列条件：  

$$
a _ { i j } = - a _ { j i } , \qquad 1 \leq i , j \leq n ,
$$  

特别地，矩阵 $ A $ 主对角线上的元素均为零。  

习题 7．验证：对任意方阵 $ A $，矩阵 $A - A ^ { \boldsymbol { \mathsf { T } } }$ 是斜对称矩阵。□

习题 8．证明：任一方阵 $ A $ 均可表示为  

$$
A = A _ { 1 } + A _ { 2 } ,
$$  

其中 $\pmb { A _ { 1 } }$ 是对称矩阵，$A _ { 2 }$ 是斜对称矩阵。□  

考虑一个元素属于复数域 $ \mathbb{C} $ 的矩阵 $A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n }$。其复共轭矩阵 $ \overline{A} $ 定义为将 $ A $ 的每个元素替换为其复共轭所得到的矩阵。† 换言之，$\overline { { A } } \triangleq [ \overline { { a } } _ { i j } ] _ { i , j = 1 } ^ { m , n }$。显然，矩阵 $ A $ 是实矩阵当且仅当 ${ \bar { A } } = A .$。  

† 回忆：若 $a = c + d i , c , d \in \mathbb { R } ,$，则其复共轭为 $ \overline{a}  \triangleq c - d i .$。
