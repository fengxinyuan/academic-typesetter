# 标量多项式综述

表达式  

$$
p ( \lambda ) = p _ { 0 } + p _ { 1 } \lambda + p _ { 2 } \lambda ^ { 2 } + \cdot \cdot \cdot + p _ { l } \lambda ^ { l } ,\tag{1}
$$

$i = 1 , 2 , \ldots , n$



其系数为  p _ { 0 } , p _ { 1 } $, \ldots , p$ _ { l } 、定义在域 $\mathcal { F }$ 上的表达式  p _ { l } $\neq 0 ,$ ，称为关于 $\mathcal { F } .$ 的 $ l $ 次多项式。来自 $\mathcal { F }$ 的非零标量被视为零次多项式；而所有系数均为零的多项式则记作 $p ( \lambda ) \equiv 0  $。

本附录简要概述此类多项式的一些基本性质。关于该主题更易读且完整的论述，可参见 Sam Perlis 所著《矩阵论》（Addison-Wesley 出版社，1958 年）第 6 章。

**定理 1.** 对任意两个定义在  \mathcal { F }  上的多项式 $p ( \lambda$ )与 $q ( \lambda ) （$ 其中 $q ( \lambda ) \not \equiv 0 )$ ），存在唯一确定的、定义在 $\mathcal { F }$ 上的多项式 $d ( \lambda$ )与 $r ( \lambda$ ) ，使得

$$

\begin{array} { r } { p ( \lambda ) = q ( \lambda ) d ( \lambda ) + r ( \lambda ) , } \end{array}\tag{2}
$$


且满足 $ \deg $r  $( \lambda ) < \deg { q ( \lambda ) } o r r ( \lambda ) \equiv 0$ 。满足式 (2) 的多项式 $d ( \lambda$ )与 $r ( \lambda$ )  是唯一确定的。

式 (2) 中的多项式  d  $( \lambda$ )称为 $p ( \lambda$ )除以 $q ( \lambda$ )所得的**商式**，而 $r ( \lambda$ )则称为该除法的**余式**。若式 (2) 中的余式 $r ( \lambda$ )为零多项式，则称 $d ( \lambda ) （$ 或 $q ( \lambda ) )$ ）为 $p ( \lambda$ )的一个**因式**（divisor）。此时，我们也说 $d ( \lambda ) （$ 或 $q ( \lambda ) ) ）**$ 整除 $**  p ( \lambda$ )，或 $p ( \lambda )  **$ 可被 $**  d ( \lambda$ )  **整除**。次数为 1 的因式称为**线性因式**。
