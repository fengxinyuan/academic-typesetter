习题 8．验证：$e _ { i }$ 与 $\begin{array} { r } { e _ { j } ( 1 \leq i < j \leq n ) } \end{array}$ 是 $\mathbb { C } ^ { n }$（或 ℝⁿ）中任意两个单位向量，则它们在标准内积下正交。

习题 9．（勾股定理）证明：若 x 与 y 是某酉空间中的正交元素，则  

$$
\| { \pmb x } \pm { \pmb y } \| ^ { 2 } = \| { \pmb x } \| ^ { 2 } + \| { \pmb y } \| ^ { 2 } . \quad \bigtriangledown\tag{7}
$$

注意：若 $ \mathbf{x}, \mathbf{y} $ 表示 $ \mathbb{R}^n $ 中的位置向量，则 $ \|\mathbf{x} - \mathbf{y}\| $ 是由 $ \mathbf{x} $ 与 $ \mathbf{y} $ 所确定的三角形之第三边的长度。因此，通常所说的毕达哥拉斯定理可由式 (7) 推出。下一个结论有时被称为阿波罗尼奥斯定理（Apollonius’s theorem），或称平行四边形定理。

## 3.12 正交系

单位酉空间中任意一组非零元素，若其中任意两个元素彼此正交，或该集合仅含一个元素，则称其为一个**正交集**（或**正交系**）。
