**推论 1.** 矩阵 $A \in \mathbb { C } ^ { n \times n }$ 是可对角化的（即“单”的），当且仅当它的极小多项式仅有单重零点。

**证明**．由推论 7.8.1 可知，矩阵 $ A $ 是单矩阵（simple）当且仅当 $ \text{$\lambda I - A$} $ 的所有初等因子均为一次式，即当且仅当其不变因子为  
$$
\text{$\begin{array} { r } { i _ { n } ( \lambda ) = \prod _ { i = 1 } ^ { s } { ( \lambda - \lambda _ { i } ) } . } \end{array}$},
$$  
其中 $ \text{$\lambda _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { s }$} $ 是 $ A $ 的互异特征值。该结论可直接由定理 2 推出。

**推论 2**．矩阵 $ \text{$A  $\in { \mathcal { F } } ^ { n \times n } } $ 是非减次的（nonderogatory）当且仅当 $ \text{$\lambda I - A$} $ 的前 $ \text{$n - 1$} $ 个不变多项式次数为零，即它们恒等于 1。

**证明**．设 $ A $ 是非减次矩阵，并令 $ \text{$i _ { 1 } $( \lambda ) , i$ _ { 2 } $( \lambda ) , . . . , i$ _ { n } $( \lambda$ )$} $ 表示 $ \text{$\lambda I - A . \  $\mathrm { I f } \ c ( \lambda$ )$} $ 的不变多项式。若 $ \text{$\begin{array} { r } { $c ( \lambda ) = \prod$ _ { k = 1 } ^ { n } i _ { k } $( \lambda ) } \end{array} } $ 是 $ A $ 的特征多项式，则由假设，$ \text{$c  $( \lambda$ )$} $ 与 $ A $ 的极小多项式 $ \text{$m  $( \lambda$ )$} $ 相重合。但根据定理 2，有  
$$
\text{$m ( \lambda ) = i _ { n } ( \lambda )$},
$$  
因此比较两端可得  
$$
\text{$i _ { 1 } ( \lambda ) = \cdot \cdot \cdot = i _ { n - 1 } ( \lambda ) = 1$}.
$$  
注意：由于 $ \lambda I - A $ 是一个正则矩阵多项式，故其不变多项式中不存在零多项式。

现在我们证明：定理 7.8.1 中所述的第二种自然标准形（以及由此导出的若尔当标准形）在如下意义上是最优的，即式 (7.8.1) 中的任一子块 $C _ { l _ { k } } , k = 1 , 2 , \ldots , p ,$ 均不能再分解为更小的子块。更准确地说，我们将证明：$C _ { l _ { k } }$ 不可能相似于一个含有多于一个子块的分块对角矩阵。为此，我们首先定义：若矩阵 $A \in { \mathcal { F } } ^ { n \times n }$ 相似于一个分块对角矩阵 $\operatorname{diag}($[ A _ { 1 } , A _ { 2 } ]$)$，其中 $$\ b { A _ { 1 } } \in \mathbb { C } ^ { n _ { 1 } \times n _ { 1 } } , \ b { A _ { 2 } } \in \mathbb { C } ^ { n _ { 2 } \times n _ { 2 } }$$，且 $$n _ { 1 } , n _ { 2 } > 0 , n _ { 1 } + n _ { 2 } = n .$$，则称该矩阵是可分解的；否则，称其为不可分解的（indecomposable）。

**命题 1**．矩阵 $A \in \mathbb { C } ^ { n \times n }$ 是不可分解的，当且仅当它是非减次的（nonderogatory），且其特征多项式 $c ( \lambda )$ 具有形式 $( \lambda - \lambda _ { 0 } ) ^ { p }$，其中 $\lambda _ { 0 } \in \mathbb { C }$，$p$ 为正整数。

**证明**．设 $A$ 是不可分解的。若 $A$ 是减次的（derogatory），则由推论 2 可知，矩阵多项式 $\lambda I - A$ 至少有两个非常数的不变因子。而由定理 7.6.2 可知，此时 $A$ 是可分解的，矛盾。若其特征多项式 $c ( \lambda )$ 具有两个或两个以上互异的零点，则 $\lambda I - A$ 至少有两个初等因子。于是由定理 7.8.1 可知，$A$ 再次是可分解的，亦矛盾。
