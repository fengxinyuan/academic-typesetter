**证明．** 首先注意到，定理的条件蕴含 A 与 −B 没有公共特征值，因此方程 (3) 存在唯一解 X。  

考虑一个取值于矩阵空间的函数 Z(t)，定义为其满足如下初值问题的解：  

$$
d Z / d t = A Z + Z B , \qquad Z ( 0 ) = C .\tag{5}
$$  

如习题 9.12.14 所指出，方程 (5) 的解为  

$$
Z ( t ) = e ^ { A t } C e ^ { B t } .
$$  

现观察到，在假设矩阵 (4) 存在的前提下，将方程 (5) 中的微分方程从 $t = 0$ 积分至 $t = \infty$，可得  

$$
Z ( \infty ) - Z ( 0 ) = A \int _ { 0 } ^ { \infty } Z ( t ) d t + \left( \int _ { 0 } ^ { \infty } Z ( t ) d t \right) B .
$$  

因此，若进一步假设  

$$
Z ( \infty ) = \operatorname* { l i m } _ { t ^ {  } \infty } e ^ { A t } C e ^ { B t } = 0 ,\tag{6}
$$  

则可知由方程 (4) 给出的矩阵即为方程 (3) 的（唯一）解。于是，只需验证：当 A 与 B 稳定时，我们所作的各项假设均成立。为此，对函数 $e ^ { A t } \left( 0 < t < \infty \right)$ 写出其谱分解式（即式 (9.5.1)）：  

$$
e ^ { \boldsymbol { A } t } = \sum _ { \boldsymbol { k } = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { \boldsymbol { k } } - 1 } t ^ { j } e ^ { \lambda _ { \boldsymbol { k } } t } Z _ { \boldsymbol { k } j } ,\tag{7}
$$

其中，$\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 是矩阵 $ A $ 的互异特征值，其指标分别为 $m _ { 1 } , m _ { 2 } , \ldots , m _ { s }$。考虑这些特征值的笛卡尔分解：$\lambda _ { k } = \alpha _ { k } + i \beta _ { k }$，并对每个 $k = 1 , 2 , \ldots , s .$ 写出  

$$
e ^ { \lambda _ { k } t } = e ^ { \alpha _ { k } t } e ^ { i \beta _ { k } t } = e ^ { \alpha _ { k } t } ( \cos \beta _ { k } t + i \sin \beta _ { k } t ) ,
$$  

由于 $\alpha _ { k } < 0 \ ( k = 1 , 2 , \ldots , s ) _ { }$，故对每个 $ k $，均有 $\mathrm { e x p } ( \lambda _ { k } t ) \to 0$ 当 $t  \infty$ 时成立。因此（参见式 (7)），有 $\begin{array} { r } { \operatorname* { l i m } _ { t \to \infty } e ^ { A t } = O } \end{array}$；类似地，亦有 $\quad \operatorname* { l i m } _ { t \to \infty } e ^ { B t } = O$。于是，关系式 (6) 成立，且式 (4) 中的积分亦存在。

接下来考虑 $ A $ 与 $ -B $ 具有公共特征值的情形。此时矩阵 $G = ( I _ { n } \otimes A ) + ( B ^ { \boldsymbol { \mathsf { T } } } \otimes I _ { m } )$ 是奇异的；当且仅当 $ \operatorname{rank}[G\ \mathbf{c}] = \operatorname{rank}\,G $ 时，方程组存在解（推论 1）。此时线性无关解的个数由 $ G $ 的核空间维数 $ \dim(\operatorname{Ker}\,G) $ 所决定。直接计算 $ \dim(\operatorname{Ker}\,G) $ 是一个相对困难的问题，其解答可参见 MacDuffee（1946）所著标准参考文献，其中给出了 Frobenius 的证明；该证明最早可追溯至 1910 年。
