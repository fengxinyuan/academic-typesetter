## 4.1 线性变换

设 $ S_1 $ 与 $ S_2 $ 是域 $ F $ 上的线性空间。映射  
$\mathcal { S } _ { 1 } \mathcal { S } _ { 2 } \mathcal { F } . T \colon { \mathcal { S } } _ { 1 } \to { \mathcal { S } } _ { 2 }$  
称为**线性变换**，若对任意两个元素  
$\mathbf { x _ { 1 } }$  与  $\pmb { x } _ { 2 }$  
属于  $\mathcal { S } _ { 1 }$ ，以及任意标量  
$\alpha \in \mathcal { F }$ ，均有  

$$
\begin{array} { c } { { T ( { \pmb x } _ { 1 } + { \pmb x } _ { 2 } ) = T ( { \pmb x } _ { 1 } ) + T ( { \pmb x } _ { 2 } ) , } } \\ { { { } } } \\ { { T ( \alpha { \pmb x } _ { 1 } ) = \alpha T ( { \pmb x } _ { 1 } ) , } } \end{array}\tag{1}
$$  

即：$ T $ 既是可加的（additive），又是齐次的（homogeneous）。

需注意，由于我们假定 $ S_1 $ 是域 $ F $ 上的线性空间，从而保证了元素  
$\mathcal { S } _ { 1 } \mathcal { F }$  
以及 $ \alpha x $ 同样属于 $ T $ 所定义其上的空间  
$\mathcal { S } _ { 1 }$ 。此外，由于  
$\mathcal { S } _ { 2 }$  
是域  
${ \mathcal F } ,$  
上的线性空间，故只要  
$T ( \pmb { x } _ { 1 } )$  与  $T ( \pmb { x } _ { 2 } )$  
成立，则像  
$T ( \pmb { x } _ { 1 } + \pmb { x } _ { 2 } )$  与  $T ( \alpha \mathbf { x } _ { 1 } )$  
必为  
$\mathcal { S } _ { 2 }$  
中的元素。两个同维数线性空间之间的同构（参见习题 3.14.4）即为一类特殊的线性变换。下文还将给出其他若干例子。

${ \pmb x } _ { 1 } + { \pmb x } _ { 2 } T$



例 1．考虑位置向量构成的二维空间 $ \mathbb{R}^2 $，其元素为 $\mathbb { R } _ { 2 }$，令 $\mathcal { S } _ { 1 } = \mathcal { S } _ { 2 } = \mathbb { R } _ { 2 }$。若 $ T $ 表示该空间到自身的变换，使得每个向量 $ \mathbf{x} $ 均被映射（参见图 4.1）为一个与之共线的向量 ${ \mathfrak { X } } _ { 0 } { \mathfrak { X } } _ { : }$，其中标量 $\alpha _ { 0 } \in \mathcal { F }$ 是固定的 $( \alpha _ { 0 } \neq 0 )$  

$$
T ( { \pmb x } ) = { \pmb \alpha } _ { 0 } { \pmb x } ,
$$  

则易见，$ T $ 是 $ \mathbb{R}^2 $ 到其自身的线性变换。$\mathbb { R } _ { 2 }$ 实际上，  

$$
T ( { \pmb x } _ { 1 } + { \pmb x } _ { 2 } ) = \alpha _ { 0 } ( { \pmb x } _ { 1 } + { \pmb x } _ { 2 } ) = \alpha _ { 0 } { \pmb x } _ { 1 } + \alpha _ { 0 } { \pmb x } _ { 2 } = T ( { \pmb x } _ { 1 } ) + T ( { \pmb x } _ { 2 } ) ,
$$  

且对所有 $\alpha \in \mathbb { R }$，均有  

$$
T ( \alpha \mathbf { x } ) = \alpha _ { 0 } \alpha \mathbf { x } = \alpha ( \alpha _ { 0 } \mathbf { x } ) = \alpha T ( \mathbf { x } ) .
$$  

显然，对任意 $\boldsymbol { y } \in \mathbb { R } _ { 2 }$，均存在某个 $\mathbf { \delta x } ,$，即 $\pmb { x } = ( 1 / \alpha _ { 0 } ) \pmb { y }$，使得 $T ( { \pmb x } ) = { \pmb y }$，从而 $T : \mathbb { R } _ { 2 } \xrightarrow { \mathrm { o n t o } } \mathbb { R } _ { 2 }$。
