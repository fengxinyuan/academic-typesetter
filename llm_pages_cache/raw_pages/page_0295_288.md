习题1的结果与定理1的结果一样，存在一个缺陷：即特征值 $\lambda _ { j } \ ( j > 1 )$ 是借助其对应的特征向量 $\pmb { x } _ { n - j + 1 } , \ldots , \pmb { x } _ { n }$ 来刻画的。因此，在应用定理1时，我们必须将特征值按非降序排列，并同时计算出各特征值对应特征子空间的一组标准正交基。下一个定理则是一个非凡的结果，它允许我们对每一个特征值进行独立刻画，而无需涉及其他特征值或特征向量。这便是著名的柯朗–费希尔（Courant–Fischer）定理：该定理最早由E. 费希尔†于1905年提出，后于1920年由R. 柯朗重新发现。正是柯朗首先认识到、并清晰阐明了该结果在数学物理问题中的重大意义。我们先从一个预备命题开始。

命题1．设 $\mathcal { S } _ { j } \ ( 1 \leq j \leq n )$ 表示 ℂⁿ 中任意一个 $( n - j + 1 ) – d i m e n .$ 维子空间，H 为一埃尔米特矩阵，其特征值为 $\lambda _ { 1 } \leq$ 与 $\lambda _ { 2 } \leq \cdots \leq \lambda _ { n }$ ，R(x) 为其瑞利商（Rayleigh quotient）。则  

$$
\operatorname* { m i n } _ { \pmb { 0 } \neq \pmb { x } \in \mathcal { S } _ { j } } R ( \pmb { x } ) \le \lambda _ { j } , \qquad \operatorname* { m a x } _ { \pmb { 0 } \neq \pmb { x } \in \mathcal { S } _ { j } } R ( \pmb { x } ) \ge \lambda _ { n - j + 1 } .\tag{6}
$$

**证明**．设  { $\mathfrak { x } }$ _ { 1 } , { $\mathfrak { x } }$ _ { 2 } $, \ldots , { \mathfrak { x } }$ _ { n }  是 $ H $ 的一组标准正交特征向量系，对应于 $ H $ 的特征值 $\lambda$ _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n } ；并设 $\hat { \mathcal { S } }$ _ { j } =  张成子空间  \{ $\pmb { x }$ _ { 1 } $, \pmb { x }$ _ { 2 } $, \ldots , \pmb { x }$ _ { j } \} ，其中 $j = 1 , 2 , \dots , n .  $。  
固定指标 $ j $，注意到由于 $ \dim $\mathcal { S } _ { j } +$ = \dim $\begin{array} { r } { $\hat { \mathcal { S } }$ _ { j } = ( n ^ { ' } - j + 1 ) + j > n , } $\end{array}$ ，故这两个子空间必有非零交集（参见习题 3.14.3），即存在非零向量 $\pmb { x }$ _ { 0 } $\in \mathbb { C } ^ { n }$ 同时属于这两个子空间。特别地，由于 $\pmb { x }$ _ { 0 } $\in \hat { \mathcal { S } }$ _ { j } ，可得 $\begin{array} { r } { \pmb { x }$ _ { 0 } $= \sum$ _ { k = 1 } ^ { j } $\pmb { \alpha }$ _ { k } $\pmb { x }$ _ { k } } $\end{array}  $，从而  

$$

( H x _ { 0 } , x _ { 0 } ) = \left( \sum _ { k = 1 } ^ { j } \lambda _ { k } \alpha _ { k } x _ { k } , \sum _ { k = 1 } ^ { j } \alpha _ { k } x _ { k } \right) = \sum _ { k = 1 } ^ { j } \lambda _ { k } | \alpha _ { k } | ^ { 2 } .
$$
  

因此显然有  

$$

\lambda _ { 1 } \sum _ { k = 1 } ^ { j } | \alpha _ { k } | ^ { 2 } \leq ( H \mathbf { x } _ { 0 } , \pmb { x } _ { 0 } ) \leq \lambda _ { j } \sum _ { k = 1 } ^ { j } | \alpha _ { k } | ^ { 2 }
$$
  

两边同除以  \sum _ { k = 1 } ^ { j } | { $\alpha$ _ { k } } | ^ { 2 } = ( { $\pmb x }$ _ { 0 } , { $\pmb x }$ _ { 0 } ) ，即得  

$$

\lambda _ { 1 } \leq R ( \mathbf { x } _ { 0 } ) \leq \lambda _ { j } .\tag{7}
$$


现在回顾一下，$ x_0 $ 也属于 $ S $；而我们当前的直接目标是建立式 (6) 中的第一个关系。但该关系可直接由式 (7) 推出，因为  

$$
\operatorname* { m i n } _ { \theta \neq \pmb { x } \in \mathcal { S } _ { j } } R ( \pmb { x } ) \leq R ( \pmb { x } _ { 0 } ) \leq \lambda _ { j } .
$$  

命题的第二个断言可用类似方法证明，只需将 $\hat { \mathcal { S } } _ { j }$ 替换为 $\mathcal { C } _ { n - j + 1 }$ 即可。
