## 4.4 相似矩阵的若干性质

本节中，所有矩阵均假定为方阵。

**习题 1.** 设 $A \approx B$；即设 A 与 B 为相似矩阵。证明：

(a) 秩 $A = \operatorname { r a n k } B$；

(b) 行列式 $A = \operatorname* { d e t } B$；

(c) $A - \lambda I \approx B - \lambda I$（对每个 i）；

(d) $A ^ { k } \approx B ^ { k } \operatorname { f o r } k = 0 , 1 , 2 , . . . ;$；

(e) $\dot { p } ( A ) \approx p ( B )$，其中 $p ( \lambda )$ 为任意标量多项式；

(f) $A ^ { \boldsymbol { \mathsf { T } } } \approx B ^ { \boldsymbol { \mathsf { T } } }$。

**解答**  
(b) 若 $A = P B P ^ { - 1 }$，则 det A = (det P)(det B)(det $P ^ { - 1 } )$)，结论即由习题 2.6.11 推出。

(e) 对于 $\begin{array} { r } { p ( \lambda ) = \sum _ { i = 0 } ^ { l } p _ { i } \lambda ^ { i } } \end{array}$，我们有  

$$
\begin{array} { l } { { \displaystyle p ( A ) = \sum _ { i = 0 } ^ { l } p _ { i } ( P B P ^ { - 1 } ) ^ { i } } } \\ { { \displaystyle \phantom { \sum _ { i = 0 } ^ { l } p _ { i } B ^ { i } \bigg \rangle } = P \bigg ( \sum _ { i = 0 } ^ { l } p _ { i } B ^ { i } \bigg ) P ^ { - 1 } = P p ( B ) P ^ { - 1 } . ~ \bigtriangledown } } \end{array}
$$  

当 A 与 B 相似时，关系式 $A = P B P ^ { - 1 }$ 中的矩阵 P 称为将 B 变换为 A 的**变换矩阵**（transforming matrix）。需指出的是，该变换矩阵 P 并不唯一。例如，P 可被替换为 $P P _ { 1 }$，其中 $P _ { 1 }$ 为任意一个与 B 可交换的非奇异矩阵。

**习题 2.** 证明  

$$
\left[ A _ { 1 } \quad 0 \right] \approx { \left[ \begin{array} { l l } { A _ { 2 } } & { 0 } \\ { 0 } & { A _ { 1 } } \end{array} \right] } , \qquad A _ { 1 } \in \mathcal { F } ^ { k \times k } , \quad A _ { 2 } \in \mathcal { F } ^ { m \times m } ,
$$  

且形如……的非奇异矩阵

$$
\begin{array} { r } { \bigg [ \theta \quad P _ { 1 } \bigg ] , \qquad P _ { 1 } \in \mathcal { F } ^ { k \times k } , \quad P _ { 2 } \in \mathcal { F } ^ { m \times m } , } \end{array}
$$  

其中，$P _ { 1 }$ 与 $A _ { 1 }$ 可交换，$P _ { 2 }$ 与 $A _ { 2 }$ 可交换，这些矩阵均为若干相似变换矩阵。

习题 3．验证如下前述结论的推广：任一 n 阶方阵 A 均相似于将 A 关于次对角线（即从右上至左下的对角线）作反射所得之矩阵。
