## 3.4 线性相关性与线性无关性

设线性空间 $\mathcal { S }$ 上的元素 ${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { n }$ 张成子空间 $\mathcal { S } _ { 0 } = \operatorname { s p a n } \{ \pmb { a } _ { 1 } , \pmb { a } _ { 2 } , \dots , \pmb { a } _ { n } \}$，且假设 $\mathcal { S } _ { 0 }$ 可由给定元素的一个真子集张成。例如，假设 $\mathcal { S } _ { 0 } = \operatorname { s p a n } \{ a _ { 2 } , a _ { 3 } , \dotsc , a _ { n } \}$。这意味着：由全部 $ n $ 个元素 ${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { n }$ 所生成的线性组合空间，与由其中后 $n - 1$ 个元素 ${ \pmb a } _ { 2 }$、${ \pmb a } _ { 3 } , \ldots , { \pmb a } _ { n }$ 所生成的线性组合空间完全相同。换言之，对任意给定的 ${ \mathfrak { a } } _ { 1 } , { \mathfrak { a } } _ { 2 } , \ldots , { \mathfrak { a } } _ { n }$ 的线性组合，均存在后 $n - 1$ 个元素的一个线性组合，使得二者相等。
