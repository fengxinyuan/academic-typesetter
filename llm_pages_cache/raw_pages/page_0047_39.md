习题 3．证明：若方阵 A 具有分块三角形式，且主（分块）对角线上的各分块均为方阵 $A _ { i } ( i = 1 , 2 , \ldots , k )$，则

$$
\operatorname* { d e t } A = \prod _ { i = 1 } ^ { k } \operatorname* { d e t } A _ { i } .
$$

习题 4．证明：若 $n \times n$ 阶矩阵 A 具有如下形式

$$
A = { \left[ \begin{array} { l l } { A _ { 1 } } & { A _ { 2 } } \\ { A _ { 3 } } & { 0 } \end{array} \right] } ,
$$

其中 $A _ { 2 }$ 与 $A _ { 3 }$ 分别为 $p \times p$ 阶与 $( n - p ) \times ( n - p )$ 阶矩阵，且 $p < n ,$，则

$$
\operatorname* { d e t } A = ( - 1 ) ^ { ( n + 1 ) p } ( \operatorname* { d e t } A _ { 2 } ) ( \operatorname* { d e t } A _ { 3 } ) .
$$

习题 5．计算  n  $\times n$ 阶矩阵  [ - D \_ B ] .  的行列式，其中 $ B $ 是一个 $n \times m$ 阶矩阵  ( m < n ) ，而 $ D $ 是由 $n \times n$ 阶单位矩阵  I _ { n }  删去下列各列后所得的矩阵：  

$$
j _ { 1 } , j _ { 2 } , . . . , j _ { m } \quad ( 1 \leq j _ { 1 } < j _ { 2 } < \cdot \cdot \cdot < j _ { m } \leq n ) .
$$  

答案：  

$$
\operatorname* { d e t } [ - D \quad B ] = ( - 1 ) ^ { t } B { \binom { j _ { 1 } } { 1 } } \quad { \dot { j } } _ { 2 } \quad \cdots \quad { \dot { j } } _ { m } \rangle ,
$$  

其中  

$$
t = ( n - m ) + \left( \sum _ { k = 1 } ^ { n } k + \sum _ { k = 1 } ^ { m } j _ { k } \right) - \sum _ { k = 1 } ^ { n - m } k .\tag{6}
$$  

提示：注意到子矩阵 $-D$ 仅有一个非零的  n - m ,  阶子式，并利用公式 (4)。  

习题 6．证明：若 $ m \times n $ 矩阵 $ A $ 的所有 $ k $ 阶子式（ $( 1 \leq k < \operatorname* { m i n } ( m , n ) )$ ）均为零，则 $ A $ 的任意阶数大于 $ k $ 的子式也必为零。  

提示：对任意 $ k $ 行（或 $ k $ 列）应用拉普拉斯定理，将高阶子式展开为若干 $ k $ 阶子式与相应代数余子式的乘积之和。
