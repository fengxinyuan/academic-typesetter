**习题 3**：向量 $\mathbf { x } _ { 0 } = [ - 1 \quad 1 \quad 1 ] ^ { \mathbf { I } }$ 是习题 2 中所考虑的线性方程组的一个解向量；该方程组对应的齐次方程的一个解向量为 ${ \pmb x } ^ { \prime } = [ 2 - 1 - 1 ] ^ { \pmb { \tau } }$。由此易见，非齐次方程组的任一解均可表示为 $\mathbf { x } _ { 0 } + \alpha \mathbf { x } ^ { \prime } \left( \alpha \in \mathbb { R } \right)$ 的形式。

**推论 1**：若 $ A $ 是一个方阵，则矩阵方程 $A \mathbf { x } = \mathbf { \delta } \mathbf { b }$ 有唯一解当且仅当 $ A $ 是非奇异矩阵。

证明．若方程 (1) 有唯一解，则由定理 2 可知，$\mathbf { x } ^ { \prime } = \pmb { \theta }$，且 $A \mathbf { x } = \pmb { \theta }$ 仅有零解。因此，根据推论 3.7.1，矩阵 $ A $ 是非奇异的。其逆命题则由定理 2.9.2 直接得出。

定理 2 还有一些其他重要推论。当解存在时，非齐次线性方程组 $A \mathbf { x } = \mathbf { b }$ 的解的个数，与对应的齐次方程组的解的个数相同；且在这两种情形下，解的个数要么为 1，要么为无穷多。由于 $A \mathbf { x } = \pmb { \theta }$ 的任一解向量均属于 $ \operatorname{Ker} A $，故 $ \operatorname{Ker} A $ 的维数即为该齐次方程的线性无关解（作为 $\mathcal { F } ^ { n } )$ 中的向量）的最大个数。而非齐次方程的解集本身并不构成一个线性空间。下一个定理指出：该解集应被理解为子空间 $ \operatorname{Ker} A $ 沿向量 $\mathbf { \delta x } _ { 0 }$（即一个特解）作整体平移所得的仿射子集。

**定理 3．** 设 $A \in \mathcal { F } ^ { m \times n }$ 的秩为 $r < n .$，则为完整描述可解矩阵方程 $A x = b$ 的解集所需独立参数的个数等于 $n \mathrm { ~ - ~ } r .$。

该定理的证明直接由定理 2 与命题 3.8.1 得出。

定理 3 实质上重述了如下事实：方程 (1) 的任一解均可表示为 $n \mathrm { ~ - ~ } r$ 个 $A \mathbf { x } = \pmb { \theta }$ 的线性无关解（因而对应 $n - r$ 个参数）的线性组合，再加上一个特解。

**习题 4．** 验证定理 3 对习题 2 和习题 3 中所考虑的方程组成立。
