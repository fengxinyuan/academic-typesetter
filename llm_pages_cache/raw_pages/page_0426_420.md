**命题 2**．简单矩阵 $ A $ 与 $\pmb { X } \in \mathbb { C } ^ { n \times n }$ 可交换，当且仅当它们具有一组由 $ n $ 个线性无关的公共特征向量构成的集合。  

换言之，若 $ A $ 与 $ X $ 均为简单矩阵，且  A X = X A . ，则在 $\mathbb { C } ^ { n }$ 中存在一组基，该基完全由 $ A $ 与 $ X $ 的公共特征向量组成。

**证明**．设  \lambda _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { s }  为矩阵 $ A $ 的互异特征值，其对应的指标分别为  m _ { 1 } , m _ { 2 } $, \ldots , m$ _ { s } . ；并设  A = P J P ^ { - 1 } ，其中对角块矩阵 $ J $ 是 $ A $ 的一个若尔当标准形．根据定理 1，与 $ A $ 可交换的所有矩阵的一般形式为  

$$

X = P Y P ^ { - 1 } = P \mathrm { d i a g } [ Y _ { 1 } , Y _ { 2 } , . . . , Y _ { s } ] P ^ { - 1 }
$$
  

其中  Y _ { j } $\in \mathbb { C } ^ { m$ _ { j } $\times m$ _ { j } } $, j = 1 , 2 , \ldots , s ．$ 将每个  Y _ { j }  分别化为若尔当标准形  Y _ { j } ^ { ' } = Q _ { j } J _ { j } Q _ { j } ^ { - 1 } ，我们得到  

$$

X = ( P Q ) \mathrm { d i a g } [ J _ { 1 } , J _ { 2 } , . . . , J _ { s } ] ( P Q ) ^ { - 1 } ,
$$
  

其中  Q  $= \mathrm { d i a g } [ Q$ _ { 1 } , Q _ { 2 } $, \dots , Q$ _ { s } ] . ．  

由于 $ X $ 是单矩阵（simple matrix），故 $ \operatorname{diag}[$\cdot J _ { 1 } , J _ { 2 } $, \ldots , J$ _ { s } ]$] $ 也是单矩阵，因此乘积矩阵 $ PQ $ 的列向量构成 $ X $ 的 $ n $ 个线性无关的特征向量．对 $ A $ 同样成立，这是因为  

$$

$$
