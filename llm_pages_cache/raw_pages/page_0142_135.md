## 定理 2．在前述记号下，  

$$
\operatorname { r a n k } T = \operatorname { r a n k } A
$$  

对任意 $A \in \mathcal { A } _ { T }$

**证明**．设 $ A $ 是线性映射 $ \text{$T  $\in { \mathcal { L } } ( { \mathcal { S } }$ _ { 1 } , { $\mathcal { S } }$ _ { 2 } )$} $ 关于空间 $ \text{$\mathcal { S } _ { 1 }$} $ 与 $ \text{$\mathcal { S } _ { 2 }$} $ 的基 $ \text{$\mathcal { E } = \{ $\mathbf { y }$ _ { j } \} _ { j = 1 } ^ { n }$} $ 和 $ \text{$\mathcal { G } = \{ y _ { i } \} _ { i = 1 } ^ { m }$} $ 所对应的矩阵表示。由于 $ \operatorname{rank} \text{$T  $= \mathrm { d i m } ( \operatorname { s p a n } \{ T ( \pmb { x }$ _ { j } ) _ { j = 1 } ^ { n } ) ,$} $，由命题 3.7.1 可知 $ \operatorname{rank} \text{$T  $= \mathrm { d i m } ( \operatorname { s p a n } \{ \boldsymbol { \mathfrak { p } }$ _ { j } \} _ { j = 1 } ^ { n } )$} $，其中 $ \text{$\beta _ { j } \  $( 1 \leq j \leq n$ )$} $ 是元素 $ \text{$T  $( \mathbf { x }$ _ { j } )$} $ 关于基 $ G $ 的矩阵表示。再结合恒等式 $ \text{$A =$} = \text{$[ { $\pmb { \beta } }$ _ { 1 } $\quad { \pmb { \beta } }$ _ { 2 } $\quad \cdots \quad { \pmb { \beta } }$ _ { n } ]$} $，并应用定理 3.7.2 的结论，即得证。

将第 3.2 节中引入的矩阵核（kernel）概念加以推广，我们现对任一线性变换 $ \text{$T  $\in { \mathcal { L } } ( { \mathcal { S } }$ _ { 1 } , { $\mathcal { S } }$ _ { 2 } )$} $ 定义其核如下：

$$
\text{$$
 $\operatorname { K e r } T \triangleq \{ \pmb { x } \in \mathcal { S }$ _ { 1 } : $T ( \pmb { x } ) = \pmb { \theta } \} .$ 
$$}
$$

在习题 4.1.3 的记号下，我们看到：对任意矩阵 $ A $，有 $ \operatorname{Ker} \text{$A =$} = \operatorname{Ker} \text{$T _ { A }$} $。

**定理 3**．设 $ \text{$T  $\in \mathcal { L } ( \mathcal { S }$ _ { 1 } $, \mathcal { S }$ _ { 2 } )$} $，则集合 $ \operatorname{Ker} T $ 是 $ \text{$\mathcal { S } _ { 1 }$} $ 中的一个线性子空间。

**证明**．对任意 $ \text{${ $\pmb x }$ _ { 1 } , { $\pmb x }$ _ { 2 } $\in { \bf K } } \in \operatorname{Ker} T $ 及任意标量 $ \alpha $、$ \text{$\beta  $\in { \mathcal { F } } , } $，元素 $ \text{$\alpha { $\pmb x }$ _ { 1 } $+ \beta { \pmb x }$ _ { 2 }$} $ 也属于 $ \text{$T$} $ 的核。

$$
T ( \alpha { \pmb x } _ { 1 } + \beta { \pmb x } _ { 2 } ) = \alpha T ( { \pmb x } _ { 1 } ) + \beta T ( { \pmb x } _ { 2 } ) = \alpha { \pmb \theta } + \beta { \pmb \theta } = { \pmb \theta } .
$$  

至此，证明完成。

子空间 $\operatorname{Ker} $T$$ 的维数称为该线性变换的**亏度**（defect），记作 $\operatorname{def} T$。

$$

 } $= \mathbf { 0 } ,$ 
$$  

解得 $$x _ { 1 } = x _ { 2 } = x _ { 3 } = 0$$，故 $\operatorname{Ker} ${ \pmb T } = \{ { \pmb \theta } \}$$。因此，$\operatorname{def} $T = 0$$。
