**命题 1.** 若 $ \lambda $ 是矩阵 $ A $ 的指数为 1 的特征值，则方程 (1) 与 (3) 具有相同的解集 $\mathcal { S }$；进一步地，${ \pmb x } = E { \pmb b }$ 是二者的一个公共解（当 ${ \mathcal { S } } \neq { \mathcal { O } } )$ 时）。

**证明.** 鉴于前述论证，我们只需证明这两个方程的解集重合即可。但 $I - Z = E ( \lambda I - A )$，因此，依据习题 3.10.8，我们只需验证 $ \operatorname{rank} \, \text{$( $I - Z ) = \mathrm { r a n k } ( \lambda I - A$ )$} $。为此，注意到 ${ I - Z }$ 与 $\lambda I - A$ 具有相同的核，即 $ A $ 关于特征值 $ \lambda $ 的特征子空间。

现设定理 11.5.1 的全部条件均被满足。则 $ \lambda $ 的代数重数为 1，且对足够小的 $| \zeta | ,$，我们可利用该定理的结果将下式展开为：

$$
\begin{array} { c } { { ( A + \zeta A ^ { ( 1 ) } + \zeta ^ { 2 } A ^ { ( 2 ) } + \cdots ) ( x + \zeta x ^ { ( 1 ) } + \zeta ^ { 2 } x ^ { ( 2 ) } + \cdots ) } } \\ { { { } } } \\ { { = ( \lambda + \zeta \lambda ^ { ( 1 ) } + \cdots ) ( x + \zeta x ^ { ( 1 ) } + \cdots ) . } } \end{array}\tag{4}
$$

我们将上述关于 $\pmb { n = 0 } , 1 , 2 , \ldots$ 的幂级数相乘，并比较 $\zeta ^ { n }$ 的系数。其中，$\zeta ^ { 0 }$ 的系数给出未受扰动特征值所满足的方程：$A \pmb { x } = \lambda \pmb { x }$；而 $\zeta$ 的系数给出……

$$
( \lambda I - A ) { \bf x } ^ { ( 1 ) } = ( A ^ { ( 1 ) } - \lambda ^ { ( 1 ) } I ) { \bf x } .\tag{5}
$$  

由于 $ y $（见式 (11.5.4)）是矩阵 $\lambda ,$ 的左特征向量，我们可推出  
${ \bf y } ^ { \tt T } ( A ^ { ( 1 ) } - \lambda ^ { ( 1 ) } I ) \mathbf { x } = 0 .$  
又因 $\mathbf { y } ^ { \mathsf { T } } \mathbf { x } = 1$，该条件导出  

$$
\lambda ^ { ( 1 ) } = { \bf y } ^ { \mathsf { T } } A ^ { ( 1 ) } x .\tag{6}
$$  

此外，依据我们对 $\pmb { x } ( \zeta )$ 的定义，关系式 (11.5.5) 给出  

$$
y ^ { \operatorname { T } } ( x + \zeta x ^ { ( 1 ) } + \zeta ^ { 2 } x ^ { ( 2 ) } + \cdot \cdot \cdot ) = 1 ,
$$  

由此可得  

$$
y ^ { \mathrm { T } } x ^ { ( r ) } = 0 , \qquad r = 1 , 2 , \ldots { } .\tag{7}
$$  

为从式 (5) 中导出 $\mathbf { x } ^ { ( 1 ) }$ 的表达式，我们应用命题 1。由此可知，$\begin{array} { r } { \hat { \mathbf { x } } ^ { ( 1 ) } = E ( A ^ { ( 1 ) } - \lambda ^ { ( 1 ) } I ) \mathbf { x } } \end{array}$ 是一个解。由于 $\boldsymbol { Z } = \mathbf { x } \mathbf { y } ^ { \boldsymbol { \mathsf { T } } }$ 且 $E Z = O ;$，故有 $E { \pmb x } = E Z { \pmb x } = { \pmb 0 }$，因此 $\mathbf { x } ^ { ( 1 ) }$ 的表达式简化为 $\mathbf { x } ^ { ( 1 ) } = E A ^ { ( 1 ) } \mathbf { x }$。  

我们应验证：上述所选解与式 (7) 相容，即需验证 $\begin{array} { r } { \mathbf { y ^ { \mathsf { T } } } \mathbf { x ^ { ( 1 ) } } = 0 } \end{array}$。由于 $\mathbf { y } ^ { \mathsf { T } } Z = \mathbf { y } ^ { \mathsf { T } }$，我们得到  

$$
\mathbf { y } ^ { \mathrm { T } } \mathbf { x } ^ { ( 1 ) } = \mathbf { y } ^ { \mathrm { T } } Z E A ^ { ( 1 ) } \mathbf { x } .
$$

但此时有 $\begin{array} { r } { Z E = E Z = 0 . } \end{array}$，故 $\mathbf { y } ^ { \mathsf { T } } \mathbf { x } ^ { ( 1 ) } = 0$，符合要求。
