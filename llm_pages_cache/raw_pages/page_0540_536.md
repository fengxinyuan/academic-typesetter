设 $ z $ 是一个极值向量，并令  w = ( I + A ) ^ { n - 1 } z 。不失一般性，可假设 $z \in \mathcal { M }$ 。命题 1 表明  w > 0 , ，且显然有 $w \in { \mathcal { N } } .$ 。我们还有 $A z - r z \geq 0$ ；而若 $A z - r z \neq 0  $，则

$$
( I + A ) ^ { n - 1 } ( A z - r z ) > 0 .
$$

故有  A  $w \mathrm { ~ - ~ } r w > 0 ,$ 或  r w < A w _ { : } ，从而推出  r < r ( w ) 。但这与 $ r $ 的定义（5）相矛盾，因此必有  A z = r z 。于是，任一极值向量 $ z $ 均为 $ A $ 关于特征值 $ r $ 的右特征向量。

最后，由于  A z = r z ，我们得到

$$
w = ( I + A ) ^ { n - 1 } z = ( 1 + r ) ^ { n - 1 } z ,
$$

并且由于 $w > 0$ 与 $r > 0 ,$，我们必须有 $z > \theta .$。

现在我们可以陈述并证明不可约矩阵的 Perron–Frobenius 定理的第一部分。

**定理 1.** 若矩阵 $A \in \mathbb { R } ^ { n \times n }$ 是非负且不可约的，则  

（a）矩阵 $ A $ 具有一个正的特征值 $ r $，且该特征值等于 $ A $ 的谱半径；  

（b）存在一个与特征值 $ r $ 相关联的正（右）特征向量；  

（c）特征值 $ r $ 的代数重数为 1。

**证明.** 在命题 2 中，我们已确立了存在一个正特征值及其对应的正特征向量。为完成本定理中（a）与（b）两部分，只需证明：$ A $ 的其余特征值的模均不超过 $ r $。

事实上，若我们有 $\alpha \mathbf { y } = A \mathbf { y }$ 与 $\mathbf { \boldsymbol { y } } \neq \mathbf { \boldsymbol { \theta } } _ { : }$，则由于 $A \geq 0 ,$，易见  

$$
| \alpha | | { \mathbf { y } } | = | A { \mathbf { y } } | \leq A | { \mathbf { y } } | ,
$$  

其中，若 $z \in \mathbb { R } ^ { n } , | z |$ 表示由向量 $ z $ 的各分量取绝对值后所得的向量。因此有 $| \alpha | \leq r ( | \mathbf { y } | ) \leq r ,$，这正是我们所要证明的结论。

现设 $ z $ 是任一与特征值 $ r $ 相关联的右特征向量。于是有 $A z = r z$ 与 $z \neq \theta ,$；而如前所证，  

$$
r | z | \leq A | z | .
$$

这意味着  | z |  是一个极值向量，且由命题 $2 , | z | > \pmb { \theta } .$ 可知， z _ { i } $\neq 0 , i = 1 , 2 , \ldots , n .$ 。因此，$ r $ 的右特征子空间的维数为 1。否则，我们将能找出两个线性无关的右特征向量  { $\tt z }$ _ { 1 } , { $\tt z }$ _ { 2 } ，并进而确定若干数 $\alpha , \beta$ ，使得 $\alpha z$ _ { 1 } $+ \beta z$ _ { 2 }  具有一个零元。这就证明了 $ r $ 的几何重数为 1。
