命题 1．若矩阵  
$A \in \mathbb { R } ^ { n \times n }$  
是非负且不可约的，则  

$$
( I + A ) ^ { n - 1 } > 0 .
$$

**证明**．考虑一个向量 $\boldsymbol { \mathsf { y } } \in \mathbb { R } ^ { n }$，使得 $\pmb { y } \geq \pmb { \theta }$ 且 $y \neq \theta$，并令  

$$
z = ( I + A ) { \bf y } = { \bf y } + A { \bf y } .\tag{1}
$$  

由于 $A \geq 0 ,$，乘积 $A { \bf y } \geq \theta$，因此 z 的非零（从而为正）元素个数至少与 y 相同。若 y 尚非正向量，则我们将证明：z 的非零元素个数至少比 y 多一个。事实上，若 P 是一个置换矩阵，满足 $\begin{array} { r } { P \mathbf { y } = [ \pmb { u } ^ { \mathrm { T } } \quad \pmb { \theta } ^ { \mathrm { T } } ] ^ { \mathbf { T } } } \end{array}$ 且 $u > \theta$，则由式 (1) 及关系式 $P P ^ { \mathrm { T } } = I$ 可得  

$$
P z = { \binom { u } { \theta } } + P A P ^ { \operatorname { T } } { \left[ \begin{array} { l } { u } \\ { \theta } \end{array} \right] } .\tag{2}
$$  

于是，若我们按 ${ \mathfrak { p } } ,$ 的分块方式对 z 和 $P A P ^ { \mathbf { T } }$ 作一致分块，即  

$$
z = { \binom { v } { w } } , \qquad P A P ^ { \operatorname { T } } = { \binom { A _ { 1 1 } \quad A _ { 1 2 } } { A _ { 2 1 } \quad A _ { 2 2 } } } ,
$$  

则式 (2) 蕴含  

$$
v = \pmb { u } + A _ { 1 1 } \pmb { u } \qquad \mathrm { a n d } \qquad \pmb { w } = A _ { 2 1 } \pmb { u } .\tag{3}
$$  

现注意到，矩阵 $P A P ^ { \mathrm { \bf T } }$ 是非负且不可约的。因此，特别地，$A _ { 1 1 } \geq 0 , A _ { 2 1 } \geq 0 , A _ { 2 1 } \neq 0 .$；从而由 (3) 式可得 ${ \mathfrak { v } } > { \pmb { \theta } } , { \pmb { w } } \geq { \pmb { \theta } } .$。但 $u > \theta$，故必有 $w \neq \theta .$。于是，z 的正元素个数至少比 y 多一个。

若  ( I + A ) y  尚非正，则从元素  ( I + A ) z = ( I + A ) ^ { 2 } y  出发，重复上述论证，可知其正元素个数至少比 $ y $ 多两个。继续这一过程，至多经过  n - 1  步后，我们得到  

$$

( I + A ) ^ { n - 1 } y > 0
$$
  

对任意  \mathbf { y } $\geq \mathbf { 0 } , \mathbf { y } \neq \mathbf { 0 }$ 成立。令  y = e _ { j } $\operatorname { f o r } j = 1 , 2 , \ldots , n .  $，即得所求结论。

注意：反向亦存在一个简单结果。若对任意  A  $\in \mathbb { R } ^ { n \times n }$ 及任意正整数  j , ，均有 $\operatorname { I f } \left( I + A \right) ^ { j } > 0$ ，则 $ A $ 必为不可约矩阵。否则，假设 $ A $ 具有习题 15.1.4 中所述的分块形式，我们可轻易导出与假设矛盾的结果。
