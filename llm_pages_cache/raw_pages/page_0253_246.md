# 矩阵多项式与标准形

本章所发展的不变多项式与 λ-矩阵的重要理论，使我们得以独立地证明：任意矩阵均可化为 Jordan 标准形；同时，还提供了一种直接由矩阵元素构造该标准形的方法。此外，本章还导出了矩阵的其他若干标准形。这种处理 Jordan 标准形的方式可视为一种代数方法，与第 6 章所发展的几何方法形成对照。相较于几何方法，该代数方法所需的数学抽象程度较低，因而对部分读者而言可能更易理解。此外，矩阵多项式的分析本身即具有重要价值。本章进一步发展了其在微分方程与差分方程中的直接应用，并为第 14 章将要研究的矩阵多项式的谱理论奠定了基础。

## 7.1 矩阵多项式的概念

考虑一个 $n \times n$ 阶矩阵 $A ( \lambda )$，其元素均为关于 $\lambda$ 的多项式：  

$$
A ( \lambda ) = { \begin{array} { r c c c } { \left[ a _ { 1 1 } ( \lambda ) } & { a _ { 1 2 } ( \lambda ) } & { \cdots } & { a _ { 1 n } ( \lambda ) \right] } \\ { a _ { 2 1 } ( \lambda ) } & { a _ { 2 2 } ( \lambda ) } & { \cdots } & { a _ { 2 n } ( \lambda ) } \\ { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { a _ { n 1 } ( \lambda ) } & { a _ { n 2 } ( \lambda ) } & { \cdots } & { a _ { n n } ( \lambda ) } \end{array} } ,\tag{1}
$$
