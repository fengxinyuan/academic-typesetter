例 2．设 $ T $ 是向量的逆时针旋转变换（参见图 4.2），将 $ \mathbb{R}^2 $ 中的向量绕原点旋转一个固定角度 $ \theta $。若原向量为 $ 

$$
\begin{bmatrix} x \\ y \end{bmatrix}
$$

 $，则易见所得向量为 $ 

$$
\begin{bmatrix} x\cos\theta - y\sin\theta \\ x\sin\theta + y\cos\theta \end{bmatrix}
$$

 $，其中  

$$
\begin{array} { r } { x _ { 1 } ^ { \prime } = ( \cos \gamma ) x _ { 1 } - ( \sin \gamma ) x _ { 2 } , } \\ { x _ { 2 } ^ { \prime } = ( \sin \gamma ) x _ { 1 } + ( \cos \gamma ) x _ { 2 } . } \end{array}
$$  

利用矩阵记号，可将该变换写作  

$$
{ \bf \xi } \left[ { \pmb x } _ { 1 } ^ { \prime } \right] = { \bf \zeta } \left[ { \cos { \gamma } \mathrm { \bf \beta } } - \sin { \gamma } \right] \left[ { \pmb x } _ { 1 } \right] ,
$$  

此处 $ \mathbf{x} $ 与 $ \mathbf{y} $ 分别表示为列向量，即  

$$
T ( \mathbf { x } ) = \mathbf { x } ^ { \prime } = A \mathbf { x } ,
$$  

其中  

$$
A = { \left[ \begin{array} { l l } { \cos \gamma } & { - \sin \gamma } \\ { \sin \gamma } & { \cos \gamma } \end{array} \right] } .
$$  

此时，变换 $ T $ 的线性性可直接由矩阵的相应性质推出（参见第 1.2 节）：  

$$
\begin{array} { c } { { T ( { \bf x } _ { 1 } + { \bf x } _ { 2 } ) = A ( { \bf x } _ { 1 } + { \bf x } _ { 2 } ) = A { \bf x } _ { 1 } + A { \bf x } _ { 2 } = T ( { \bf x } _ { 1 } ) + T ( { \bf x } _ { 2 } ) , } } \\ { { T ( \alpha { \bf x } ) = A ( \alpha { \bf x } ) = \alpha ( A { \bf x } ) = \alpha T ( { \bf x } ) . } } \end{array}
$$  

例 3．设 $ T $ 表示从 $ n $ 维空间 $ \mathbb{R}^n $ 到 $ m $ 维空间 $ \mathbb{R}^m $ 的一个变换，其定义规则为

$\mathbb { R } _ { 2 } \gamma \left( 0 < \gamma < 2 \pi \right) \pmb { x } = ( \pmb { x } _ { 1 } , \pmb { x } _ { 2 } ) \pmb { x } ^ { \prime } = ( \pmb { x } _ { 1 } ^ { \prime } , \pmb { x } _ { 2 } ^ { \prime } ) \mathbf { o r } , \mathbf { \Delta } \mathbf { x ^ { \prime } } T _ { A } { \mathcal { F } } ^ { n } { \mathcal { F } } ^ { m }$



$$
T _ { A } ( { \pmb x } ) = A { \pmb x } , \qquad { \pmb x } \in \mathcal { F } ^ { n } ,
$$  

其中 $ A $ 是一个给定的 $ m \times n $ 矩阵。显然，$T _ { A }$ 是线性的（参见第 1.2 节及例 2）。□  

因此，任何由 $ m \times n $ 矩阵 $m \times n$ 与矩阵–向量乘法所确定的、从 ${ \mathcal { F } } ^ { n }$ 到 ${ \mathcal { F } } ^ { m }$ 的变换都是线性的。值得注意的是，在适当的意义下，**任一线性变换均可由此类方式描述**。后文将证明：任意两个有限维线性空间之间的线性变换，均可通过某个矩阵与矩阵–向量乘法来表示。在给出下一个例子之前，请注意：例 1 中的变换，正是按例 3 所述意义，由标量矩阵 $A = \alpha _ { 0 } I$ 所确定的。
