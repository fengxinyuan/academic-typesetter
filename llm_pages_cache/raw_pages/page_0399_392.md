证明：在 $\zeta = 0$ 处与在 $\zeta = 1 0 ^ { - 1 0 }$ 处的特征值之差的绝对值为 0.1。  

注意：$A ( 0 )$ 与 $A ( 1 0 ^ { - 1 0 } )$ 之间的差值极小，以至于在字长过短的计算机上可能无法将二者区分。  

对于充分小的 $| \zeta | 2$，函数 $\lambda _ { j } ( \zeta )$ 具有怎样的性质？我们将看到，在若干重要的特殊情形下，函数 $\lambda _ { j } ( \zeta )$ 在 $\zeta = 0$ 的某个邻域内也是解析的。而下一例表明，这一性质并非普遍成立。

例 2．矩阵  

$$
A ( \zeta ) = { \left[ \begin{array} { l l } { 0 } & { \zeta } \\ { \zeta ^ { 2 } } & { 0 } \end{array} \right] }
$$  

的特征值，即为多项式  

$$
\operatorname* { d e t } ( \lambda I - A ( \zeta ) ) = \lambda ^ { 2 } - \zeta ^ { 3 } ,
$$  

的零点。

即，$\lambda _ { 1 } ( \zeta ) = \zeta ^ { 3 / 2 }$（由函数 $\zeta ^ { 1 / 2 } )$ 的某一特定单值解析分支及 $\lambda _ { 2 } ( \zeta ) = - \lambda _ { 1 } ( \zeta )$ 所定义）。因此，我们看到：特征值在 $\zeta = 0 . \ \bigcirc$ 的邻域内未必是解析函数。

需注意，det $( \lambda I - A ( \zeta ) )$ 是关于 λ 的一个多项式，其系数均为 ζ 的解析函数。于是，依据代数函数理论可得：

（a）若 $\lambda _ { j }$ 是矩阵 A 的一个单重特征值，则 $\lambda _ { j } ( \zeta )$ 在 $\zeta = 0$ 的某个邻域内是解析函数；

（b）若 $\lambda _ { j }$ 具有代数重数 m，且 $\lambda _ { k } ( \zeta ) \to \lambda _ { j }$（对 $k = \mathfrak { x } _ { 1 } , \ldots , \mathfrak { x } _ { m } .$ 成立），则 $\lambda _ { k } ( \zeta )$ 是 $\dot { \zeta } ^ { 1 / l }$ 的解析函数，在 $\zeta = 0 _ { : }$ 的某个邻域内成立，其中 $l \leq m$，而 $\zeta ^ { 1 / l }$ 是函数 $\zeta ^ { 1 / l }$ 的 l 个单值解析分支之一。因此，$\lambda _ { k } ( \zeta )$ 关于 $\zeta ^ { 1 / l }$ 具有幂级数展开式。

我们将一并证明结论（a）以及一个关于相应特征向量的结论。需指出，在结论（b）中，可能出现 $l = 1$ 与 $m > 1$ 的情形，此时 $\lambda _ { k } ( \zeta )$ 仍可能是解析的。正如预期，真正导致分析困难的情形是（b）中 $m > 1$ 的情况。结论（b）中所述、关于 $\zeta$ 的分数幂的展开式称为皮塞克斯（Puiseux）级数；在第 11.7 节的讨论中，我们将直接假定此类级数的有效性。

当我们试图追踪特征向量的行为时，问题便变得更为复杂。该矩阵

$$
A ( \zeta ) = { \left[ \begin{array} { l l } { 0 } & { \zeta } \\ { 0 } & { 0 } \end{array} \right] }
$$  

用以说明：即使特征值可能是解析的，特征向量在 $\zeta = 0$ 处也未必连续。
