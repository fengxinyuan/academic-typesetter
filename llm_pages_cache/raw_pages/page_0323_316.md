证明．关系式 (a) 已在习题 1 中建立。然而，该式及其他各条性质均可直接由分量 $Z _ { k j }$ 的结构导出——我们将在下文讨论该结构。

首先注意到：若 $A = P J P ^ { - 1 }$，其中 $\boldsymbol { J } = \operatorname { d i a g } [ J _ { 1 } , J _ { 2 } , \dots , J _ { t } ]$ 是 $ A $ 的一个若尔当标准形（Jordan form），则根据命题 9.4.5，

$$
Z _ { k j } = \varphi _ { k j } ( A ) = { \cal P } \mathrm { d i a g } [ \varphi _ { k j } ( J _ { 1 } ) , \dots , \varphi _ { k j } ( J _ { t } ) ] { \cal P } ^ { - 1 } ,\tag{2}
$$  

其中，$\varphi _ { k j } ( J _ { i } ) ( 1 \leq i \leq t , 1 \leq k \leq s , 0 \leq j \leq m _ { k } - 1 )$ 是形如 (9.4.4) 式的矩阵。接下来通过考察两种情形来研究 $\varphi _ { k j } ( J _ { i } )$ 的结构。

**情形 1**．Jordan 块 $J _ { i }$（阶数为 $n _ { i } )$）对应于特征值 $\lambda _ { k }$。由于（参见式 (9.2.6)）$\varphi _ { k j } ^ { ( r ) } ( \lambda _ { k } ) = \delta _ { j r } ~ ( r , j = 0 , 1 , \ldots , m _ { k } - 1 )$，故由式 (9.4.4) 可得  

$$
\varphi _ { k j } ( J _ { i } ) = \frac { 1 } { j ! } N _ { n _ { i } } ^ { j } ,\tag{3}
$$  

其中，$N _ { n _ { i } }$ 是对应于零特征值的 $n _ { i } \times n _ { i }$ 阶 Jordan 块；并假定当 $j = 0$ 时，式 (3) 右端为 $n _ { i } \times n _ { i }$ 阶单位矩阵。还需注意，$n _ { i } \le m _ { k }$（参见习题 7.7.4 与 7.7.9）。

**情形 2**．Jordan 块 $J _ { i }$（阶数为 $n _ { i } )$）对应于某个特征值 $\lambda _ { 1 } \neq \lambda _ { k }$。此时仍有 $n _ { i } \le m _ { l }$，且[如式 (9.2.7) 所示]，函数 $\varphi _ { k j } ( \lambda )$ 及其在 $\lambda = \lambda _ { l }$ 处的前 $m _ { l } - 1$ 阶导数均为零。再次利用式 (9.4.4)，可得  

$$
\varphi _ { k j } ( J _ { i } ) = 0 .\tag{4}
$$  

为简化记号，考虑 $k = 1$ 的情形。将式 (3) 与式 (4) 代入式 (2)，易见

$$
Z _ { 1 j } = \frac { 1 } { j ! } P \mathrm { d i a g } [ N _ { n _ { 1 } } ^ { j } , N _ { n _ { 2 } } ^ { j } , . . . , N _ { n _ { q } } ^ { j } , 0 , . . . , 0 ] P ^ { - 1 }\tag{5}
$$  

对任意  j = 0 , 1 , . . . , m _ { 1 } - 1  成立，前提是  J _ { 1 } , J _ { 2 } $, \ldots , J$ _ { q }  是 Jordan 标准形 $ J $ 中仅有的、对应于特征值 $\lambda$ _ { 1 }  的 Jordan 块。更确切地说，式 (5) 蕴含  

$$
Z _ { 1 0 } = { \cal P } \mathrm { d i a g } [ I _ { r } , { \cal O } ] { \cal P } ^ { - 1 } ,\tag{6}
$$  

其中  r = n _ { 1 } + n _ { 2 } $+ \cdot \cdot \cdot + n$ _ { q } 。  

对于一般的  \lambda _ { k } ，上述结果的本质现已十分清晰，所需结论亦可由此直接推出。  

定理 1 与定理 2 的结论应视为习题 4.14.3 的推广。它们有助于计算  f ( A ) ，尤其适用于同时求取同一矩阵的多个函数的情形。在后一情形中，每个函数均可按式 (1) 表示；仅系数  f _ { k , j }  随函数不同而异。
