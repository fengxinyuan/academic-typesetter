## 10.7 盖尔什戈林圆盘与不可约矩阵

本节介绍两个有用的结果，可视作盖尔什戈林定理（Geršgorin’s theorem）的精化形式。然而，这两个结果均需额外假设所涉矩阵为“不可约矩阵”（irreducible matrix）。该性质在许多实际问题中易于验证。我们在此给出正式定义，并将于第15章中进一步讨论这一概念。

若 $ A \in \mathbb{C}^{n \times n} $，则称矩阵 $ A $ 是**可约的**（reducible），如果存在一个 $ n $ 阶置换矩阵 $ P $，使得  

$$
P ^ { \mathrm { T } } A P = { \left[ \begin{array} { l l } { A _ { 1 1 } } & { A _ { 1 2 } } \\ { 0 } & { A _ { 2 2 } } \end{array} \right] } ,\tag{1}
$$  

其中 $ A_{11} $ 和 $ A_{22} $ 均为阶数小于 $ n $ 的方阵。若不存在这样的 $ P $，则称 $ A $ 是**不可约的**（irreducible）。

若将 $ A $ 视为 $ n $ 维空间 $ \mathcal{V} $ 上的一个线性变换 $ \mathcal{A} \colon \mathcal{V} \to \mathcal{V} $ 的矩阵表示，则 $ A $ 的不可约性仅意味着：在为此表示所选取的 $ \mathcal{V} $ 的一组基向量中，不存在任何真子集，其张成的空间是 $ A $ 的一个不变子空间（参见第4.8节，尤其是式(4.8.3)）。

**习题 1.** 若 $ A \in \mathbb{C}^{n \times n} $ 是可约的，证明：对任意正整数 $ k $，矩阵 $ A^k $ 也是可约的；并进一步证明：$ A $ 的任意多项式均为可约矩阵。
