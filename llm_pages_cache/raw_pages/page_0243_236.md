## 6.5 若尔当定理

考虑一个在有限维空间 $\mathcal { S }$ 上作用的线性变换 $ T $。根据定理 6.2.4 的推论 1，求 $T$ 的规范表示问题可归约为：对一个作用于典型广义特征子空间 $\mathsf { K e r } ( T - \lambda _ { i } I ) ^ { m _ { i } }$ 上的变换 $T _ { i }$（即 $( 1 \leq i \leq s )$）求其规范表示，其中 $( m _ { i }$ 是 $\lambda _ { i } )$ 的指数。此时，定理 6.4.2 指出：为达此目的，只需找出作用于循环若尔当子空间上的变换 $T _ { i } ^ { ( j ) } ( 1 \leq j \leq t ^ { ( i ) } )$ 的简单表示即可。

设 $\mathcal { J }$ 表示 $ T $ 的一个循环若尔当子空间，它由如下向量组张成：

$$
( T - \lambda _ { i } I ) ^ { r - 1 } ( { \pmb x } ) , \ldots , ( T - \lambda _ { i } I ) ( { \pmb x } ) , { \pmb x } ,\tag{1}
$$

其中 $\lambda _ { i } \in \sigma ( T )$，且 $ x $ 是 $ T $ 关于特征值 $\lambda _ { i }$ 的 $ r $ 阶广义特征向量。记 $\pmb { x } _ { i } = ( T - \lambda _ { i } I ) ^ { r - j } ( \pmb { x } ) ~ ( j = 1 , 2 , \dots , r )$，并注意到［参见习题 6.3.2 及公式 (6.3.3)］有 $T ( { \pmb x } _ { 1 } ) = \lambda _ { i } { \pmb x } _ { 1 }$，且

$$
T ( \pmb { x } _ { j } ) = \lambda _ { i } \pmb { x } _ { j } + \pmb { x } _ { j - 1 } , \qquad j = 2 , 3 , \ldots , r .\tag{2}
$$

因此，将式 (2) 与线性变换  T | _ { $\mathcal { J } }$ 关于基 (1) 的表示  J _ { i } $= [ \alpha$ _ { i j } ] _ { i , j = 1 } ^ { r } $\in \mathbb { C } ^ { r \times r }  $ 的定义进行比较，即



$$
T ( \boldsymbol { x } _ { j } ) = \sum _ { i = 1 } ^ { r } \alpha _ { i j } \boldsymbol { x } _ { i } , \qquad j = 1 , 2 , \ldots , r ,
$$



可得



$$
J _ { i } = { \left[ \begin{array} { l l l l l } { \lambda _ { i } } & { 1 } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { \lambda _ { i } } & { 1 } & { \ddots } & { \vdots } \\ { \vdots } & { \ddots } & { \ddots } & { \ddots } & { 0 } \\ { 0 } & { \ldots } & { 0 } & { \lambda _ { i } } \end{array} \right] } ,\tag{3}
$$



其中所有超对角线元素均为 1，所有未特别标出的元素均为 0。式 (3) 中的矩阵称为对应于特征值  \lambda _ { i }  的 r 阶若尔当块（或若尔当子块）。
