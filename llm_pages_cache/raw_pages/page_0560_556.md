习题 9．证明：若 $\tilde { p } ( \lambda )$ 是 $p _ { 1 } ( \lambda ) _ { : }$ 与 $p _ { 2 } ( \lambda ) , \ldots , p _ { k - 1 } ( \lambda )$ 的最小公倍式，则 $p _ { 1 } ( \lambda ) , p _ { 2 } ( \lambda ) , \ldots , p _ { k } ( \lambda )$ 的最小公倍式与 $\tilde { p } ( \lambda )$ 和 $p _ { \pmb { k } } ( \lambda )$ 的最小公倍式重合。□

一个域 $\mathcal { F }$，若它包含每个定义在域 $\mathcal { F }$ 上的多项式的全部零点，则称该域为代数闭域。因此，定理 4 特别指出：复数域 C 是代数闭域。注意，多项式 $p ( \lambda ) = \lambda ^ { 2 } + 1$ 若视为定义在实数域 R 上的多项式，则表明 R 不是代数闭域。

若  p  $( \lambda$ )是域 $\mathcal { F }$ 上次数为 $ l $ 的多项式，且 $ 1 $ 是 $\mathcal { F }$ 上唯一一个次数小于 $ l $ 的首一多项式，并整除 $p ( \lambda$ )，则称 $p ( \lambda$ )在 $\mathcal { F } .$ 上不可约；否则，称 $p ( \lambda$ )在 $\mathcal { F } .$ 上可约。显然，由习题  { $\mathfrak { s } } ,$ 可知，代数闭域上任一次数大于 $ 1 $ 的多项式均为可约的。事实上，若 $p ( \lambda$ )是代数闭域 $\mathcal { F }$ 上的首一多项式，且 $p ( \lambda$ )的次数为  l , ，则 $p ( \lambda$ )  可分解为线性因子之积：  
$$
$p ( \lambda ) = \prod _ { j = 1 } ^ { l } ( \lambda - \lambda _ { j } )$,
$$  
其中  \lambda _ { 1 } $, \lambda$ _ { 2 } $, \ldots , \lambda$ _ { l } $\in \mathcal { F }$ ，且这些根未必互异。若该域不是代数闭域，则次数高于 $ 1 $ 的多项式可能不可约。
