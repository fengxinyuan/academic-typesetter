## 7.5 不变因子多项式与史密斯标准型

本节首先构造一个多项式系，该多项式系由给定的矩阵多项式唯一确定，且在矩阵的等价变换下保持不变。为此，我们首先定义矩阵多项式的秩为：其所有不恒等于零多项式的子式中阶数最大的那个子式的阶数。例如，习题 7.3.5 中定义的矩阵多项式 $A ( \lambda )$ 的秩等于 1，而典范矩阵多项式 $A _ { 0 } ( \lambda ) = \mathrm { d i a g } [ a _ { 1 } ( \lambda ) , \ldots , a _ { r } ( \lambda ) , 0 , \ldots , 0 ]$ 的秩等于 $ r $。还需注意：若 $A ( \lambda )$ 是一个 $ n \times n $ 矩阵多项式，则它正则当且仅当其秩为 $ n $。

命题 1．矩阵多项式的秩在等价变换下保持不变。

证明．设矩阵多项式 $A ( \lambda )$ 与 $B ( \lambda )$ 等价。则由命题 7.3.1 可知，存在幺模矩阵 $P ( \lambda )$ 与 $Q ( \lambda )$，使得  
$$
\text{$B ( \lambda ) = P ( \lambda ) A ( \lambda ) Q ( \lambda )$}.
$$  
对此等式两次应用比内–柯西公式（Binet–Cauchy formula），可将 $B ( \lambda )$ 的任意一个 $ j $ 阶子式 $b ( \lambda )$ 表示为 $A ( \lambda )$ 的同阶子式 $a _ { s } ( \lambda )$ 的线性组合（经适当重排后）：  

$$
b ( \lambda ) = \sum _ { s } p _ { s } ( \lambda ) a _ { s } ( \lambda ) q _ { s } ( \lambda ) ,\tag{1}
