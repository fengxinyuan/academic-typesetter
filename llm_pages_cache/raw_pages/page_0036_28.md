一个函数 $ f $ 称为**可加的**（additive），若对 $ f $ 定义域中的任意 $ a, b $，均有  
$f ( a + b ) = f ( a ) + f ( b )$。  
如下命题表明：$ \det A $ 关于矩阵 $ A $ 的某一行（或某一列）是可加函数。

**习题 2.** 设 $ n \times n $ 矩阵 $ A $ 的第 $ i $ 行中每个元素均可表示为  
$n \times n$  
的形式，则有  
$$
a _ { i j } = b _ { j } + c _ { j } , \qquad j = 1 , 2 , \ldots , n ,
$$  
⇒  
$$
\operatorname* { d e t } A = \operatorname* { d e t } B + \operatorname* { d e t } C ,
$$，  
其中矩阵 $ B $ 与 $ C $ 除第 $ i $ 行外，其余各行均与 $ A $ 相同；而它们的第 $ i $ 行分别为  
$$
B _ { i } = [ b _ { 1 } \quad b _ { 2 } \quad \cdots \quad b _ { n } ] , \qquad C _ { i } = [ c _ { 1 } \quad c _ { 2 } \quad \cdots \quad c _ { n } ] .
$$。  
注意：关于矩阵 $ A $ 的列，存在类似结论。

将习题 1 与习题 2 的结果结合起来，即得如下性质：

**性质 1.** 方阵 $ A $ 的行列式关于其第 $ i $ 行（或第 $ i $ 列）是可加的且齐次的函数，即对任意标量 $ \alpha, \beta $ 及任意向量 $ \mathbf{u}, \mathbf{v} \in \mathbb{F}^n $，有  
$1 \leq i \leq n .$。

我们接下来继续建立行列式函数的若干其他重要性质。

**性质 2.** 矩阵 $ A $ 的行列式等于其转置矩阵的行列式：  
$$
\operatorname* { d e t } A = \operatorname* { d e t } A ^ { \boldsymbol { \mathsf { T } } } .
$$。

**证明.** 回顾转置矩阵的定义，不难看出：$ A $ 的一个形如  
$$
a _ { 1 j _ { 1 } } , a _ { 2 j _ { 2 } } , \ldots , a _ { n j _ { n } }\tag{2}
$$  
的主对角线项（按行指标顺序排列），对应于置换  
$$
j = ( j _ { 1 } , j _ { 2 } , \dots , j _ { n } )\tag{3}
$$。

 1  $, 2 , \ldots , n ,$ 的一条对角线同时也是  A ^ { $\boldsymbol { \mathsf { T } } } .$ 的一条对角线。由于矩阵 $ A $ 中的元素  a _ { i j } $( 1 \leq i , j \leq n$ )在  A ^ { $\boldsymbol { \mathsf { T } } } ,$ 中位于第 $( j , i ) \mathrm { t h }$ 个位置，因此式 (2) 中各元素的第二个下标决定了它们在  A ^ { $\mathrm { T } }$ 中所在的行。为得到 $ \det $A ^ { $\boldsymbol { \mathsf { T } } } ,  $ 的一个项，必须对这些元素进行重排，使得其第二个下标按自然顺序排列。假设对式 (2) 中元素的这种重排产生如下对角线：

$$
a _ { k _ { 1 } 1 } , a _ { k _ { 2 } 2 } , \ldots , a _ { k _ { n } n } .\tag{4}
