我们首先考虑线性变换 $T \colon { \mathcal { S } }  { \mathcal { S } } .$ 的零化多项式概念。上述几何方法中引入该概念的意义并非一目了然，但我们将看到：本节的核心结果——定理 4——确实给出了 $\mathcal { S }$ 的一种直和分解，即将其表为若干子空间的直和。这一结论在本章后续内容中至关重要。

设 $\mathcal { S }$ 是域 ${ \mathcal F } ,$ 上的一个线性空间，$T \in { \mathcal { L } } ( { \mathcal { S } } )$，且 $\begin{array} { r } { p ( \lambda ) = \sum _ { i = 0 } ^ { l } p _ { i } \lambda ^ { i } } \end{array}$，$( p _ { l } \neq 0 )$ 是域 ${ \mathcal { F } } .$ 上的一个多项式。与矩阵情形类似（参见第 1.7 节），线性变换 $p ( T )$ 由如下等式定义：$\begin{array} { r } { p ( T ) \triangleq \sum _ { i = 0 } ^ { l } p _ { i } T ^ { i } } \end{array}$。
