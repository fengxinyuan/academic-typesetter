## 7.5 不变多项式

现在考虑如下商式：

$$
i _ { 1 } ( \lambda ) = \frac { d _ { 1 } ( \lambda ) } { d _ { 0 } ( \lambda ) } , \qquad i _ { 2 } ( \lambda ) = \frac { d _ { 2 } ( \lambda ) } { d _ { 1 } ( \lambda ) } , \ldots , \qquad i _ { r } = \frac { d _ { r } ( \lambda ) } { d _ { r - 1 } ( \lambda ) } .
$$

鉴于 $d _ { j } ( \lambda )$ 可被 $d _ { j - 1 } ( \lambda )$ 整除，这些商式 $i _ { j } ( \lambda ) ( j = 1 , 2 , . . . , r )$ 均为多项式。它们被称为矩阵 $A ( \lambda )$ 的**不变多项式**；此处的“不变性”是指在等价变换下的不变性。注意：当 $j = 1 , 2 , \dots , r ,$ 时，

$$
d _ { j } ( \lambda ) = i _ { 1 } ( \lambda ) i _ { 2 } ( \lambda ) \cdot \cdot \cdot i _ { j } ( \lambda ) ,\tag{3}
$$

而当 $j = 2 , 3 , \dots , r , i _ { j } ( \lambda )$ 时，$i _ { j - 1 } ( \lambda )$ 整除 $j = 2 , 3 , \dots , r , i _ { j } ( \lambda )$。

**习题 2**．根据定义，求下列矩阵多项式的不变多项式：

$$
{ \left[ \begin{array} { l l l l } { ~ 0 } & { 1 } & { ~ \lambda } \\ { ~ \lambda } & { ~ \lambda } & { ~ 1 } \\ { ~ \lambda ^ { 2 } ~ - ~ \lambda } & { \lambda ^ { 2 } ~ - ~ 1 } & { ~ \lambda ^ { 2 } ~ - ~ 1 } \end{array} \right] } ; \qquad ( \mathbf { b } ) ~ { \left[ \begin{array} { l l l } { ~ \lambda } & { \lambda ^ { 2 } } & { ~ 0 } \\ { ~ \lambda ^ { 3 } } & { \lambda ^ { 5 } } & { ~ 0 } \\ { ~ 0 } & { 0 } & { 2 \lambda } \end{array} \right] } .\tag{a}
$$

**解答**．

$$
i _ { 1 } ( \lambda ) = 1 , i _ { 2 } ( \lambda ) = 1 ;\tag{a}
$$

i _ { 1 } $( \lambda ) = \lambda , i$ _ { 2 } $( \lambda ) = \lambda , i$ _ { 3 } $( \lambda ) = \lambda ^ { 5 } - \lambda ^ { 4 } .$ 
$$
$$


回顾习题1的结果，并注意到标准矩阵多项式的不变因子仅为 $a _ { j } \{ \lambda \}$，我们现在利用命题2得出本节的主要结论。

定理1．秩为 $ r $ 的矩阵多项式 $ A(\lambda) $ 等价于标准矩阵多项式 $\mathrm { d i a g } [ i _ { 1 } ( \lambda ) , \dots , i _ { r } ( \lambda ) , 0 , \dots , 0 ]$，其中 $i _ { 1 } ( \lambda ) , i _ { 2 } ( \lambda ) , : \dots , i _ { r } ( \lambda )$ 是 $ A(\lambda) $ 的不变因子。

该标准形  

$$
\mathrm { d i a g } [ i _ { 1 } ( \lambda ) , \dots , i _ { r } ( \lambda ) , 0 , \dots , 0 ]
$$  

称为史密斯标准形（Smith canonical form）。H. J. S. 史密斯† 于1861年对整数矩阵（其代数结构与矩阵多项式极为相似）导出了这一形式。弗罗贝尼乌斯（Frobenius）则于1878年将该结果推广至矩阵多项式情形。矩阵多项式 $A ( \lambda )$ 及其标准形自然均定义在同一个数域 ${ \mathcal { F } } .$ 上。

推论1．两个矩阵多项式等价当且仅当它们具有相同的不变因子。

证明．“仅当”部分即为命题2的直接结论。若两个矩阵多项式具有相同的不变因子，则由定理1可知，它们具有相同的史密斯标准形；再依据等价关系的传递性（习题7.3.2），即可推出二者等价。■
