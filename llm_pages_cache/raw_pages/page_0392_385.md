我们现在假设 $\delta = \lVert A ^ { - 1 } \rVert \ \lVert F \rVert < 1$，且 $\| I \| = 1$。于是，由于 $\| A ^ { - 1 } F \| \le \| A ^ { - 1 } \| \| F \| < 1$，定理 1 表明 $( \dot { I } + A ^ { - 1 } F ) ^ { - 1 }$ 存在，且满足 $\lVert ( I + A ^ { - 1 } F ) ^ { - 1 } \rVert < ( 1 - \delta ) ^ { - 1 }$。因此，

$$
\pmb { y } = ( \pmb { I } + \pmb { A } ^ { - 1 } \pmb { F } ) ^ { - 1 } \pmb { A } ^ { - 1 } \pmb { k } - ( \pmb { I } + \pmb { A } ^ { - 1 } \pmb { F } ) ^ { - 1 } \pmb { A } ^ { - 1 } \pmb { F } \pmb { x } ,
$$

且 ${ \dot { \mathbf { i f } } } \parallel \mathbf { \nabla } \parallel _ { \mathbf { v } }$ 是任一与 $\parallel \parallel$ 相容的向量范数，

$$
\left\| \mathbf { y } \right\| _ { \mathbf { v } } \leq { \frac { \left\| A ^ { - 1 } \right\| } { 1 - \delta } } \left\| \pmb { k } \right\| _ { \mathbf { v } } + { \frac { \delta } { 1 - \delta } } \left\| \pmb { x } \right\| _ { \mathbf { v } } .
$$

为获得我们所定义的扰动大小度量 $\| { \bf y } \| _ { \bf v } / \| { \bf x } \| ,$ 的一个便于使用的表达式，我们利用如下事实：$A \mathbf { x } = \mathbf { b }$ 蕴含 $\| \pmb { b _ { \mathrm { \pmb { v } } } } \| \leq \| A \| \ \| \mathbf { x } \| _ { \cdot }$，从而有 $1 / \| \mathbf { x } \| _ { \mathbf { v } } \leq \| A \| / \| \pmb { \mathit { b } } \| _ { \mathbf { v } } , \pmb { \mathit { b } } \neq \pmb { \mathit { 0 } } .$。

$$
\frac { \left\| \pmb { y } \right\| _ { \mathbf { v } } } { \left\| \pmb { x } \right\| _ { \mathbf { v } } } \leq \frac { \left\| \pmb { A } \right\| \left\| \pmb { A } ^ { - 1 } \right\| } { 1 - \delta } \frac { \left\| \pmb { k } \right\| _ { \mathbf { v } } } { \left\| \pmb { b } \right\| _ { \mathbf { v } } } + \frac { \delta } { 1 - \delta } .
$$  

等式右侧的第一项包含了  \mathbf { $\delta }$ _ { $\mathbf { \delta } }$ 的相对摄动，而最后一项则与原方程右端向量无关。我们现在将 $\kappa ( A ) = \| A \| \ \| A ^ { - 1 } \|$ 定义为矩阵 $ A $ 关于范数 $ \|\cdot\| $ 的条件数，并注意到  

$$
\delta = \| A ^ { - 1 } \| \ \| F \| = { \frac { \kappa ( A ) \left\| F \right\| } { \left\| A \right\| } } .
$$  

于是我们最终得到  

$$
\frac { \Vert \pmb { y } \Vert _ { \mathbf { v } } } { \Vert \pmb { x } \Vert _ { \mathbf { v } } } \leq \frac { \kappa ( A ) } { 1 - ( \kappa ( A ) \Vert \boldsymbol { F } \Vert / \Vert A \Vert ) } \left( \frac { \Vert \pmb { k } \Vert _ { \mathbf { v } } } { \Vert \pmb { b } \Vert _ { \mathbf { v } } } + \frac { \Vert \boldsymbol { F } \Vert } { \Vert A \Vert } \right) .\tag{2}
$$  

该式给出了未知向量 $ x $ 的相对摄动的一个上界，其表达式由右端向量 $ b $ 与系数矩阵 $ A $ 的相对摄动以及条件数 $\kappa ( A$ )共同决定。尤其应当指出的是，条件数在此处起着决定性作用——无论摄动仅出现在 $ b $ 中、仅出现在 $ A $ 中，还是 $ b $ 与 $ A $ 同时发生摄动，这一结论均成立。此外，条件数在特征值摄动的分析中亦将扮演重要角色（见第 2 节）。
