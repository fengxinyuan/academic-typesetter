# 线性变换与矩阵

${ \mathcal { F } } ^ { n }$



将实变量函数视为从一个实数集到另一个实数集的映射这一概念，可自然地推广至定义在任意集合上的函数。于是，若 $\boldsymbol { F } _ { 1 }$ 与 $\boldsymbol { F } _ { 2 }$ 表示任意两个非空元素集合，则对每个元素 $\pmb { x } \in { \pmb { F } } _ { 1 }$ 指定唯一元素 $\boldsymbol { y } \in F _ { 2 }$ 的规则 T，称为从 $F _ { 1 }$ 到 $F _ { 2 }$ 的一个变换（或算子，或映射），并记作 $T \colon F _ { 1 } \ { \stackrel { \mathrm { i n t o } } { \longrightarrow } } \ F _ { 2 }$，或简记为 T: $F _ { 1 } \to F _ { 2 }$。集合 $F _ { 1 }$ 称为 T 的定义域。若 $T$ 将 $\pmb { x } \in F _ { 1 }$ 映为 $\boldsymbol { y } \in F _ { 2 }$，则称 y 是 x 在 T 下的像，并记作 $y = T ( x )$。所有 $\pmb { F } _ { 1 }$ 中元素在 $T$ 下的像所构成的全体记为  

$$
T ( F _ { 1 } ) = \{ y \in F _ { 2 } : y = T ( x ) { \mathrm { f o r ~ s o m e ~ } } x \in F _ { 1 } \}
$$  

并称为集合 $\boldsymbol { F } _ { 1 }$ 在变换 ${ \pmb T }$ 下的像，或称为 T 的值域。

一般地，$T ( F _ { 1 } )$ 是 $F _ { 2 }$ 的一个子集。当 $T ( F _ { 1 } ) = F _ { 2 }$ 时，称 T 将 $F _ { 1 }$ 映满（或映上）$F _ { 2 } ;$，此时我们写作 $T \colon F _ { 1 } \ { \stackrel { \mathrm { o n t o } } { \longrightarrow } } \ F _ { 2 }$。显然，${ \bar { T } } \colon F _ { 1 } \ { \stackrel { \mathrm { o n t } \circ } { \longrightarrow } } \ T ( F _ { 1 } )$。在重要情形 $F _ { 1 } =$ = $\boldsymbol { F _ { 2 } } = \boldsymbol { F }$ 下，我们也称变换 $T$ 作用于集合 $F .$ 上。

本书中，我们主要关注具有“线性性”这一性质的变换，该性质将在下一节中予以讨论。若从线性变换的观点出发来考察矩阵的诸多性质，则这些性质往往变得鲜明而清晰。
