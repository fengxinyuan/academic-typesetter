**定理 1.** 对应于互异特征值的特征向量必线性无关。

**证明.** 设 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 是线性变换 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 的互异特征值，${ \bf x } _ { 1 } , { \bf x } _ { 2 } , \ldots , { \bf x } _ { s }$ 为其对应的特征向量。

假设存在数 $\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { s }$，使得  

$$
\sum _ { i = 1 } ^ { s } \alpha _ { i } \pmb { x } _ { i } = \pmb { \theta } .\tag{3}
$$  

为证 $\alpha _ { i } = 0 ( i = 1 , 2 , \ldots , s )$，我们首先在等式 (3) 两端左乘 $T - \lambda _ { 1 } I ,$，并注意到 $( T - \lambda _ { 1 } I ) \pmb { x } _ { 1 } = \pmb { \mathscr { 0 } }$ 且 $T ( { \pmb x } _ { i } ) = \lambda _ { i } { \pmb x } _ { i } i = 1 , 2 , \ldots , s .$。于是有  

$$
\sum _ { i = 2 } ^ { s } ( \lambda _ { 1 } - \lambda _ { i } ) \alpha _ { i } \pmb { x } _ { i } = \pmb { 0 } .\tag{4}
$$  

再对等式 (4) 左乘 $T \mathrm { ~ - ~ } \lambda _ { 2 } I ,$，得  

$$
\sum _ { i = 3 } ^ { s } ( \lambda _ { 1 } - \lambda _ { i } ) ( \lambda _ { 2 } - \lambda _ { i } ) \alpha _ { i } x _ { i } = \pmb { \mathscr { 0 } } .
$$  

经过 $s - 1$ 次此类运算后，最终得到  

$$
( \lambda _ { 1 } - \lambda _ { s } ) ( \lambda _ { 2 } - \lambda _ { s } ) \cdot \cdot \cdot ( \lambda _ { s - 1 } - \lambda _ { s } ) \alpha _ { s } { \bf x } _ { s } = \pmb { 0 } .
$$

这说明了 $\alpha _ { s } = 0$。但特征值与特征向量的排序是任意的，因此我们同样可以证明 $\alpha _ { 1 } = \alpha _ { 2 } = \cdot \cdot \cdot = \alpha _ { s - 1 } = 0$。于是，元素 ${ \pmb x } _ { 1 } , { \pmb x } _ { 2 } , \dots , { \pmb x } _ { s }$ 线性无关。

线性变换 $T \in { \mathcal { L } } ( { \mathcal { S } } ) _ { : }$ 的谱（spectrum），记作 $\sigma ( T )$，定义为 T 的所有互异特征值构成的集合。注意：命题 2 在此术语下可重述如下：任何作用于代数闭域上有限维空间的线性变换，其谱非空。而定理 1 进一步对谱的大小施加了限制。

推论 1．作用于 n 维空间上的线性变换的谱至多包含 n 个互异的特征值。

证明：若 $T \in { \mathcal { L } } ( { \mathcal { S } } )$，且 $T$ 具有 k 个互异的特征值 $k > n =$，dim ${ \mathcal { S } } ,$，则 n 维空间 $\mathcal { S }$ 将含有超过 n 个线性无关的元素（此处即为 $T ,$ 的特征向量）。这是矛盾的。
