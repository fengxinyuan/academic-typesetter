（b）

$$
{ \left[ \begin{array} { l l l } { a } & { b } & { c } \\ { 0 } & { a } & { b } \\ { 0 } & { 0 } & { a } \end{array} \right] } ,
$$

其中 $a , b , c ,$、$ d $ 表示任意标量。 □

由习题 1.3.4 可知，单位矩阵与任意同阶方阵可交换。事实上，还存在其他具有这一性质的矩阵。下一习题将给出这类矩阵的一般刻画；随后，还将列举若干其他可交换矩阵的特殊情形。

习题 2．证明：一个矩阵与所有与其同阶的方阵均可交换，当且仅当该矩阵为数量矩阵。

习题 3．证明：同阶对角矩阵彼此可交换。

习题 4．证明：同一个方阵的（非负整数）幂彼此可交换。

习题 5．证明：若矩阵 $ A $ 与对角矩阵 $ \operatorname{diag} $[ $\overline { { \ b { a } } }$ _ { 1 } , \ b { a } _ { 2 } $, \dotsc , \ b { a }$ _ { n } ]  可交换，其中  a _ { i } $\neq a$ _ { j } $, i \neq j$ ，则 $ A $ 必为对角矩阵。□

另一类重要的矩阵是满足如下方程的矩阵：

$$
A ^ { 2 } = A .\tag{1}
$$

满足该方程的矩阵 $ A $ 称为幂等矩阵。

习题 6．验证下列矩阵：

$$
A _ { 1 } = { \left[ \begin{array} { l l } { 1 } & { 0 } \\ { 0 } & { 0 } \end{array} \right] } \qquad { \mathrm { a n d } } \qquad A _ { 2 } = { \left[ \begin{array} { l l l } { 1 } & { 2 } & { 2 } \\ { 0 } & { 0 } & { - 1 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] }
$$

均为幂等矩阵。

习题 7．证明：若 $ A $ 是幂等矩阵，且  p  为正整数，则  A ^ { p } = A . 。

习题 8．刻画所有  2  $\times 2  $ 阶幂等矩阵的集合。□

若存在正整数 $ p $，使得

$$
A ^ { p } = 0 .\tag{2}
$$

则称方阵 $ A $ 为幂零矩阵。
