一个矩阵 $A \in \mathbb { R } ^ { n \times n }$ 称为单调矩阵（monotone matrix），若其非奇异，且 $A ^ { - 1 } \geq 0 .$。单调矩阵常具有特定的符号模式：例如，主对角线元素为正，而非主对角线元素为非正。此类矩阵被赋予专门的名称：若一单调矩阵的所有非主对角线元素均非正，则称其为 M-矩阵（M-matrix）。习题 2.11.17 中的矩阵 A 和 B 均为单调矩阵，而 B 是一个 M-矩阵。

**习题 1.** 利用习题 1.8.5 证明：若 $0 \leq A \leq B _ { \cdot }$，则对所有 $k = 1 , 2 , \ldots$，有 $A ^ { k } \leq B ^ { k }$。

**习题 2.** 证明：若 A 是一个 M-矩阵，则 A 的每个主对角线元素均为正。

**提示.** 注意：若不然，则 A 存在一列（设为第 j 列）完全非正，从而有 $A e _ { j } \leq 0 , \bigstar \bigstar$。

下面我们讨论若干可确保矩阵 $A \in \mathbb { R } ^ { n \times n }$ 为 M-矩阵的判别准则。这些准则均给出易于验证的充分条件。

**定理 2.** 设 $\pmb { { \cal B } } \in \mathbb { R } ^ { n \times n }$，且 $B \geq \theta$。则矩阵 $I - B$ 是一个 M-矩阵，当且仅当 $j f \mu _ { B } < 1$。

**证明.** 若 $\mu _ { B } < 1$，则由定理 10.3.1 与定理 11.1.1 可知，${ \pmb I } - { \pmb B }$ 非奇异，且

$$
( I - B ) ^ { - 1 } = I + B + B ^ { 2 } + \cdots .
$$

由于 $B \geq 0$，显然有 $\left( I - B \right) ^ { - 1 } \geq 0 .$。显然，$I \sim B$ 的非主对角线元素均非正，故 $I - B$ 是一个 M-矩阵。

反之，若 $I - B$ 是一个 M-矩阵，则 $\left( I - B \right) ^ { - 1 } \geq 0 .$。令 $\lambda \in \sigma ( B )$ 且 $\lambda { \mathbf { x } } = B { \mathbf { x } }$，其中 $\mathbf { x } \neq \mathbf { 0 } .$。于是，由于 $B \geq 0 ,$，易见有  

$$
| \lambda | | x | \leq B | x | ,
$$  

这蕴含 $( I - B ) | { \boldsymbol { x } } | \leq ( 1 - | \lambda | ) | { \boldsymbol { x } } |$，从而  

$$
| x | \leq ( 1 - | \lambda | ) ( I - B ) ^ { - 1 } | x | .
$$  

又因 $| { \pmb x } | \geq \pmb 0$ 且 $( I - B ) ^ { - 1 } \geq 0$，故得 $| \lambda | < 1$。但此结论对任意 $\lambda \in \sigma ( B )$ 均成立，因此有 $\mu _ { B } < 1$。■
