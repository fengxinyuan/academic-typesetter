## 7.8 第二标准形与若尔当标准形  

设 $A \in \mathbb { C } ^ { n \times n }$，且令 $l _ { 1 } ( \lambda ) , l _ { 2 } ( \lambda ) , \dots , l _ { p } ( \lambda )$ 表示矩阵 $\lambda I - A$ 的初等因子。  

定理 1（第二自然标准形）．在上一段所引入的记号下，矩阵 A 相似于如下分块对角矩阵：  

$$
C _ { 2 } = \mathrm { d i a g } [ C _ { l _ { 1 } } , C _ { l _ { 2 } } , . . . , C _ { l _ { p } } ] ,\tag{1}
$$  

其中 $C _ { l _ { k } } \ ( 1 \le k \le p )$ 表示与多项式 $l _ { k } ( \lambda )$ 相关联的友矩阵。

**证明**．由习题 7.5.4 可知，矩阵 $\mathcal { U } \sim C _ { \iota _ { k } }$ 的唯一非常数不变多项式为 $l _ { k } ( \lambda )$。由于 $l _ { k } ( \lambda )$ 是矩阵 $\lambda I - A$ 在域 $\mathbb { C } ,$ 上的一个初等因子，故其为 $\lambda ,$ 中某个一次多项式的幂，因而也是 $\lambda I - C _ { l _ { k } }$ 的唯一初等因子。应用定理 7.7.2 可知：矩阵 $\lambda I - C _ { 2 }$（其中 $C _ { 2 }$ 由式 (1) 定义）与 $\lambda I - A$ 具有相同的初等因子。再由命题 7.7.1 即得矩阵 $ A $ 与 $C _ { 2 }$ 相似。
