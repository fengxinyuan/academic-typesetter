习题 9．验证：若  

$$
A = { \left[ \begin{array} { l l l } { 0 } & { 0 } & { 1 } \\ { 0 } & { 0 } & { 0 } \\ { 0 } & { 0 } & { 0 } \end{array} \right] } ,
$$  

则不存在 $3 \times 3$ 矩阵 B，使得  

$$
A B = I , \ \bigcirc
$$  

应当强调的是，鉴于矩阵乘法不满足交换律，若 B 是 A 的逆矩阵，则根据定义，B 必须同时是 A 的左逆，即满足 $( B A = I )$，又必须是 A 的右逆，即满足 $r i g h t ( A B = I )$。不过，我们很快将看到：对任一 n 阶方阵而言，只要它存在单侧逆（左逆或右逆），该单侧逆必自动成为双侧逆。

此外还须指出，定义 (4) 平凡地给出了矩阵可逆的一个必要条件：即若一方阵 A 至少存在一个单侧逆，则 A 必为非奇异矩阵，亦即其行列式 det $A \neq 0 .$。事实上，若例如 $A B = I ,$，则  

$$
\operatorname* { d e t } A B = ( \operatorname* { d e t } A ) ( \operatorname* { d e t } B ) = 1
$$

并且显然，det $A \neq 0 .$。事实上，条件 det $A \neq 0$ 对于矩阵 $ A $ 存在逆矩阵而言也是充分的。

**定理 2.** 一个方阵可逆当且仅当它是非奇异的。

**证明.** 若 det $A \neq 0 ,$，则公式 (1) 和 (2) 表明，矩阵  

$$
B = { \frac { 1 } { \operatorname* { d e t } A } } \operatorname { a d j } A\tag{5}
$$  

满足条件 (4)，因此即为 $ A $ 的逆矩阵。■  

在 det $A \neq 0$ 的情形下，逆矩阵的存在性可直接推出其唯一性。为说明这一点，首先验证右逆的唯一性：即若 $A B _ { 1 } = I$ 且 $A B _ { 2 } = I ,$，则必有 ${ \pmb { { \cal B } } } _ { 1 } = { \pmb { { \cal B } } } _ { 2 }$。事实上，由 $A B _ { 1 } = A B _ { 2 }$ 可得 $A ( B _ { 1 } - B _ { 2 } ) = 0 ,$；又因 $ A $ 存在右逆，故 det $A \neq 0$。应用定理 $^ { 2 , }$，我们可推出 $A ^ { - 1 }$ 的存在性。在等式两端左乘 $A ^ { - 1 }$，即得  

$$
A ^ { - 1 } A ( B _ { 1 } - B _ { 2 } ) = 0 ,
$$  

从而得到所要求的等式 $B _ { 1 } = B _ { 2 }$。

类似地，可证非奇异矩阵的左逆亦唯一。因此，若 det $A \neq 0 ,$，则其左、右单侧逆均唯一；而且由于二者均由公式 (5) 给出，故彼此相等。
