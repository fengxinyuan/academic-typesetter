## 引理 1. 方程 (14.4.1) 的每一个解均具有形式 (5)，其中 $z \in \mathbb { C } ^ { t n } .$ ∈ L。  

需指出，该引理已初步达成目标：将方程 (14.4.1) 的所有解统一表示为标准三元组 $( P _ { 1 } , C _ { L } , R _ { 1 } )$ 的函数。此外，方程 (14.4.2) 的通解可通过在方程 (4) 中令 $\pmb { f } ( t ) \equiv \pmb { \theta } .$ 而得到。  

从该引理过渡到我们的主要结果仅需一步简短推演。  

**定理 1.** 设 $( U , T , V )$ 是 $L ( \lambda )$ 的一个标准三元组，则方程 (14.4.1) 的每一个解均具有如下形式：  

$$
{ \boldsymbol { x } } ( t ) = U e ^ { T t } { \boldsymbol { z } } + U \int _ { 0 } ^ { t } e ^ { T ( t - \tau ) } V f ( \tau ) d \tau ,\tag{6}
$$  

其中 $z \in \mathbb { C } ^ { l n }$ 为某个向量。

**证明**． 回忆标准三元组（standard triple）的定义（参见定理 14.2.2 的证明），可知存在一个非奇异矩阵 $\pmb { S } \in \mathbb { C } ^ { i n \times i n }$，使得  

$$
P _ { 1 } = U S , \qquad C _ { L } = S ^ { - 1 } T S , \qquad R _ { 1 } = S ^ { - 1 } V
$$  

此外，由定理 9.4.2 可知，对任意 $\alpha \in \mathbb { R }$，均有 $e ^ { C _ { L } \alpha } = S ^ { - 1 } e ^ { T \alpha } S$。因此，  

$$
P _ { 1 } e ^ { C _ { L } \alpha } = U e ^ { T \alpha } S , ~ P _ { 1 } e ^ { C _ { L } \alpha } R _ { 1 } = U e ^ { T \alpha } V .
$$  

将上述表达式代入式 (5)，并取 $\alpha = t$，即得证。

在实际应用中，定理中所涉三元组 $( U , T , V )$ 有两个重要候选。其一是三元组 $( P _ { 1 } , C _ { L } , R _ { 1 } )$，这正是引理中用于将微分方程通解表示为该方程系数函数之形式时所采用的三元组。其二是若取若尔当三元组（Jordan triple）$( X , J , Y )$，则解可表为 $L ( \lambda )$ 的谱性质之函数。后一种三元组的选择，显然与前一节所阐述的思想密切相关。
