**定理 2**．在定理 1 的假设条件下，右商、右余式、左商与左余式各自唯一。

**证明**．假设有矩阵多项式 $ Q(\lambda),\, R(\lambda) $ 以及 $Q _ { 1 } ( \lambda )$ 和 $R _ { 1 } ( \lambda )$，使得  

$$
A ( \lambda ) = Q ( \lambda ) B ( \lambda ) + R ( \lambda )
$$  

且  

$$
A ( \lambda ) = Q _ { 1 } ( \lambda ) B ( \lambda ) + R _ { 1 } ( \lambda )
$$  

其中 $R ( \lambda ) , R _ { 1 } ( \lambda )$ 的次数均小于 $ m $。于是  

$$
( Q ( \lambda ) - Q _ { 1 } ( \lambda ) ) B ( \lambda ) = R _ { 1 } ( \lambda ) - R ( \lambda ) .
$$  

若 $Q ( \lambda ) \neq Q _ { 1 } ( \lambda )$，则该等式左端为一个次数至少为 $ m $ 的矩阵多项式；然而右端却是一个次数小于 $ m $ 的矩阵多项式。故必有 $Q _ { 1 } ( \lambda ) = Q ( \lambda )$，从而亦得 $R _ { 1 } ( \lambda ) = R ( \lambda )$。

类似论证亦可用来确立左商与左余式的唯一性。
