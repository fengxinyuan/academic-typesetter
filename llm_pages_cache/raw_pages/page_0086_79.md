回到上文提出的那个问题，并运用新引入的术语，我们得出结论：任何包含给定元素 ${ \pmb a } _ { 1 } , \ldots , { \pmb a } _ { n } ,$ 的子空间，都必须包含这些元素的所有线性组合。

容易验证，对属于线性空间 $\mathcal { S }$ 的元素 ${ a } _ { 1 } , { a } _ { 2 } , \ldots , { a } _ { n }$，在数域 $\mathcal { F } )$ 上取的一切线性组合所构成的集合，生成了 $\mathcal { S }$ 的一个子空间 $\mathcal { S } _ { 0 }$。显然，该子空间恰好解决了前述问题：它既包含给定的元素本身，又包含于 $\mathcal { S }$ 的任意其他满足条件 ${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , \dots , { \pmb a } _ { n } \in \mathcal { S } _ { 1 }$ 的子空间 $\mathcal { S } _ { 1 }$ 之中。

由元素 ${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , . . . , { \pmb a } _ { n } \in \mathcal { S }$ 所生成的极小（即包含关系下最小的）子空间 $\mathcal { S } _ { 0 }$，称为这些元素 $a _ { i } ( i = 1 , 2 , \dots , n )$ 在 $\mathcal { F }$ 上的线性包（或称张成空间），记作 span $\{ a _ { 1 } , a _ { 2 } , \ldots , a _ { n } \}$。因此，依定义有：

$$
\operatorname { s p a n } \{ a _ { 1 } , a _ { 2 } , \dotsc , a _ { n } \} \triangleq \left\{ a \in { \mathcal { S } } \colon a = \sum _ { i = 1 } ^ { n } \alpha _ { i } a _ { i } , \alpha _ { 1 } , \alpha _ { 2 } , \dotsc , \alpha _ { n } \in { \mathcal { F } } \right\} .
$$
