**定理 1.** 一个 $ n \times n $ 矩阵 $ A $ 是正规矩阵，当且仅当 $i f$ 它酉相似于由其特征值构成的对角矩阵：

$$
A = U D U ^ { * } ,\tag{1}
$$

其中 $D = \mathrm { d i a g } [ \lambda _ { i } ] _ { i = 1 } ^ { n } , \lambda _ { i } \in \sigma ( A ) , i = 1 , 2 , \ldots , n ,$，且 $ U $ 是酉矩阵。

注意（参见定理 4.10.2）：将 $ U $ 的列视作来自 ${ \mathcal { F } } ^ { n }$ 的向量，它们恰好给出 $ A $ 的（标准正交）特征向量；而式 (1) 中的 $ D $ 是 $\mathcal { A } _ { T } ^ { 0 }$ 中矩阵关于酉相似的典范形式。

回顾：在 $\mathbb { R } ^ { n \times n }$ 中，酉矩阵被称为正交矩阵（参见习题 2.6.16），并满足条件 $U ^ { \boldsymbol { \mathsf { T } } } U = I .$。自然地，对于实矩阵 $A$ 和 $ B $（均属于 $\mathbb { R } ^ { n \times n }$），若存在某个正交矩阵 $U \in \mathbb { R } ^ { n \times n }$，使得 $B = U A U ^ { \boldsymbol { \mathsf { T } } }$，则称它们正交相似。
