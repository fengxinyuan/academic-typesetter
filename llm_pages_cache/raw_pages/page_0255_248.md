幺模 λ-矩阵在将任意 λ-矩阵化为更简单形式的过程中起着重要作用。在接下来的两节中，我们将进一步展开这一思想；但在那之前，我们希望指出关于 λ-矩阵的一种不同视角。

设 $A ( \lambda )$ 表示一个次数为 $ l $ 的 $n \times n \lambda – \mathrm { m a t r i x }$。$A ( \lambda )$ 的第 $ (i,j) $ 个元素可写成如下形式：



$$
a _ { i j } ( \lambda ) = a _ { i j } ^ { ( 0 ) } + a _ { i j } ^ { ( 1 ) } \lambda + \cdots + a _ { i j } ^ { ( l ) } \lambda ^ { l } ,
$$



且至少存在一个元素满足 $a _ { i j } ^ { ( l ) } \neq 0 ( 1 \leq i , j \leq n )$。若令 $A _ { r }$ 为这样一个矩阵，其第 $ i,j $ 个元素对每个 $i , j )$ 均为 $a _ { i j } ^ { ( r ) } ( r \dot { = } 0 , 1 , \dots , l$，则有 $A _ { l } \neq O$，且



$$
A ( \lambda ) = A _ { 0 } + \lambda A _ { 1 } + \cdots + \lambda ^ { l - 1 } A _ { l - 1 } + \lambda ^ { l } A _ { l } .
$$



这种表述方式启发我们将“矩阵多项式”作为“λ-矩阵”的另一种称谓。

习题 2．验证上述结论。

$$
\begin{array} { r } { \left[ \lambda ^ { 2 } + \lambda + 1 \lambda ^ { 2 } - \lambda + 2 \atop 2 \lambda \lambda \right]} \lambda ^ { 2 } - 3 \lambda - 1  = \left[ \begin{array} { l l } { 1 } & { 2 } \\ { 0 } & { - 1 } \end{array} \right] + \lambda \left[ \begin{array} { l l } { 1 } & { - 1 } \\ { 2 } & { - 3 } \end{array} \right] + \lambda ^ { 2 } \left[ \begin{array} { l l } { 1 } & { 1 } \\ { 0 } & { 1 } \end{array} \right] . \bigsqcup \lambda  \end{array}
$$  

将 λ-矩阵视为矩阵多项式，自然引出关于整除性、多项式方程求解以及其他标量多项式理论之推广的一系列问题。当然，矩阵多项式系数之间缺乏交换性，为此类问题的展开带来若干困难，并要求对原有理论框架作相应修正。然而，近年来已发展出一套重要且实用的矩阵多项式理论；本书第14章即对此理论作一简要介绍。

在下一节中，我们将陈述若干关于矩阵多项式整除性的基本事实，这些结果将在本章及后续各章中反复使用。

## 7.2 矩阵多项式的除法  

设 $\begin{array} { r } { A ( \lambda ) = \sum _ { i = 0 } ^ { l } \lambda ^ { i } A _ { i } } \end{array}$ 是一个 $n \times n$ 阶矩阵多项式 $( \mathrm { i . e . , ~ } A _ { i } \in \mathcal { F } ^ { n \times n } i = 0 , 1 , \ldots , l )$，其次数为 $ l $。若 $A _ { l } = I ,$，则称该矩阵多项式 $A ( \lambda )$ 为**首一的**（monic）。若 $\begin{array} { r } { B ( \lambda ) = \sum _ { i = 0 } ^ { m } \lambda ^ { i } B _ { i } } \end{array}$ 表示一个 $n \times n$ 阶矩阵多项式，其次数为 $m ,$，则显然有  

$$
A ( \lambda ) + B ( \lambda ) = \sum _ { i = 0 } ^ { k } \lambda ^ { i } ( A _ { i } + B _ { i } ) ,
$$

其中，$k = \operatorname* { m a x } ( l , m )$。因此，$A ( \lambda ) + B ( \lambda )$ 的次数不超过 $ k $。
