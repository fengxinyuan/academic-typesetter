## 6.8 杂项习题

1. 证明：两个单矩阵相似当且仅当它们具有相同的特征多项式。

2. 证明：任一 n 阶方阵均与其转置矩阵相似。

3. 验证：幂等矩阵（即投影矩阵）的若尔当标准形是一个对角矩阵，其对角元仅为 0 或 1。

4. 证明：

　(a) 一个 r 阶若尔当块的极小多项式与特征多项式均为 $( \lambda - \lambda _ { 0 } ) ^ { r }$；

　(b) 一个若尔当矩阵的极小多项式等于其各个若尔当块之极小多项式的最小公倍式。

5. 证明：任一若尔当块均与其特征多项式（或极小多项式）所对应的友矩阵相似。

　提示（几何方法）：设 $\mathscr { J }$ 是一个若尔当子空间，取基 $\{ \pmb { x } , T ( \pmb { x } ) , \hdots , T ^ { r ^ { - 1 } } ( \pmb { x } ) \}$，证明线性变换 $T | _ { \mathcal { g } }$ 关于该基的矩阵表示即为一个友矩阵。

6. 证明：任一矩阵 $A \in \mathbb { C } ^ { n \times n }$ 均可表为一个单矩阵与一个幂零矩阵之和。

　提示：将一个 $r \times r$ 阶若尔当块写成 $\lambda _ { i } I + N$ 的形式，其中 $N = [ \delta _ { j + 1 , k } ] _ { j , k = 1 } ^ { r }$，并注意到 $N ^ { r } = O$。

7. 验证下列矩阵

$$
\left[ { \begin{array} { c c c c } { a _ { 0 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 r } } \\ { 0 } & { \ddots } & { \vdots } \\ { \vdots } & { \ddots } & { a _ { r - 1 , r } } \\ { 0 } & { \cdots } & { 0 } & { a _ { 0 } } \end{array} } \right] \qquad { \mathrm { a n d } } \qquad \left[ { \begin{array} { c c c c } { a _ { 0 } } & { 1 } & { 0 } & { \cdots } & { 0 } \\ { 0 } & & { \ddots } & { \vdots } \\ { \vdots } & { \ddots } & { \ddots } & { 0 } \\ { 0 } & { \cdots } & { 0 } & { a _ { 0 } } \end{array} } \right]
$$  

彼此相似，前提是 $a _ { i , i + 1 } \neq 0 , i = 1 , 2 , \ldots , r - 1$。  

8. 验证：设 $ J $ 是对应于特征值 $\lambda _ { 0 }$ 的一个 $r \times r$ 阶若尔当块，且 $ f(\lambda) $ 是任意多项式 $p ( \lambda )$，则  

$$
p ( J ) = \left[ \begin{array} { l l l l l } { p ( \lambda _ { 0 } ) } & { p ^ { \prime } ( \lambda _ { 0 } ) / 1 ! } & { \cdots } & { p ^ { ( r - 1 ) } ( \lambda _ { 0 } ) / ( r - 1 ) ! } \\ { 0 } & { } & { \ddots } & { \ddots } & { \vdots } \\ { \vdots } & { } & { \ddots } & { } & { p ^ { \prime } ( \lambda _ { 0 } ) / 1 ! } \\ { 0 } & { \cdots } & { } & { 0 } & { p ( \lambda _ { 0 } ) } \end{array} \right] .
$$
