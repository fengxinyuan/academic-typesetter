## 习题 6．证明：

(a) 矩阵  

$$
\left[ { \begin{array} { l l } { A _ { 1 } } & { A _ { 3 } } \\ { 0 } & { A _ { 2 } } \end{array} } \right]
$$  

的特征多项式等于 $A _ { 1 }$ 与 $A _ { 2 }$ 的特征多项式的乘积；  

(b) 若子空间 $\mathcal { S } _ { 0 }$ 是 T-不变的，则 $T \vert _ { \mathcal { S } _ { 0 } }$ 的特征多项式整除 T 的特征多项式。

接下来考虑矩阵 A 与其函数 $p ( A )$（其中 $p ( \lambda )$ 是一个标量多项式）的特征值之间的一个重要关系。

**定理 3．** 设 $\lambda _ { 0 }$ 是 $A \in { \mathcal { F } } ^ { n \times n }$ 的一个特征值，$p ( \lambda )$ 是任意一个标量多项式，则 $p ( \lambda _ { 0 } )$ 是 $p ( A )$ 的一个特征值。

**证明．** 读者可利用 A 的各次幂之间的可交换性，轻易验证存在某个多项式 $q ( \lambda )$，使得  

$$
p ( A ) - p ( \lambda _ { 0 } ) I = ( A - \lambda _ { 0 } I ) q ( A )
$$  

成立。于是，det $( A - \lambda _ { 0 } I ) = 0$ 给出 det $( p ( A ) - p ( \lambda _ { 0 } ) I ) = 0$，所要求的结果即由定理 1 推出。

习题 7．证明：幂等矩阵的所有特征值均等于 0 或 1。并利用定理 4.5.6 与定理 4.9.2，证明幂等矩阵是单纯矩阵。

习题 8．证明：幂零矩阵的所有特征值均为 0，且非零的幂零矩阵不可能是单纯矩阵。
