本节最后给出若干补充习题。第一题提供了一种利用初等行变换求可逆矩阵之逆的方法。

**习题 4.** 设 $ A $ 是一个 $ \text{$n  $\times n } $ 矩阵，则同阶矩阵  

$$
\text{$$
 $[ A \quad I$ _ { n } $] \qquad \mathrm { a n d } \qquad [ I$ _ { n } $\quad B ]\tag{12}$ 
$$}
$$  

当且仅当 $ A $ 可逆且 $ \text{$B =$} = \text{$A ^ { - 1 }$} $ 时，彼此行等价（即：二者可通过初等行变换相互化简得到）。

**提示.** 若式 (12) 中的两个矩阵行等价，则必有 $ \text{$\begin{array} { r l } { [ A } & { { } I _ { n } ] = P [ I _ { n } $\quad B ] = } \end{array} } = \text{$\begin{array} { r l } { [ P } & { { } P B ] } $\end{array} } $。因此，若对 $ \text{$[ $A \quad I$ _ { n } ]$} $ 实施高斯消元法所得结果为 $ \text{$[ I _ { n } $\quad B$ ]$} $，则必有 $ \text{$B = A ^ { - 1 }$} $。若此类消元过程无法完成，则 $ A $ 不可逆。

**习题 5.** 证明：若两个方阵等价，则它们要么均非奇异（即可逆），要么均奇异（即不可逆）。

**习题 6.** 验证：一个 $ \text{$n  $\times n } $ 矩阵是非奇异的，当且仅当它与单位矩阵 $ \text{$I _ { n }$} $ 行等价（或列等价）。因此，包含单位矩阵的互等价矩阵类，恰好由所有适当阶数的非奇异矩阵构成。

**习题 7.** 证明：任一非奇异矩阵均可分解为若干初等矩阵的乘积。

习题 8．证明：给定矩阵的行最简形（简化行阶梯形）是唯一的。□

## 2.8 矩阵的秩

设 $ A $ 是一个 $m \times n$ 矩阵。定理 2.7.2 中所述矩阵 $ A $ 的简化（标准）形中单位矩阵的阶数 $r \left( 1 \leq r \leq \operatorname* { m i n } ( m , n ) \right)$，称为 $ A $ 的秩，记作 $r = \operatorname { r a n k } A$。回顾由式 (2.7.8) 给出的 $ A $ 的所有可能的标准形，我们有  

$$
\mathrm { r a n k } [ I _ { m } \quad 0 ] = m , \qquad \mathrm { r a n k } \biggl \lbrack I _ { n } \biggr \rbrack = n ,
$$
 $\mathrm { r a n k } \left[$ 

$$
\begin{array} { l l } { I _ { r } } & { 0 } \\ { 0 } & { 0 } \end{array}
$$
 $\right] = r , \qquad \mathrm { r a n k } \ I$ _ { n } = n .
