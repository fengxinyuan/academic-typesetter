还需注意：若 $\boldsymbol { x } _ { j }$ 是 $B ,$ 的一个特征向量，则 $\pmb q _ { j } = A ^ { - 1 / 2 } \pmb x _ { j }$ 即为该振动问题的一个模态向量（normal-mode vector），且如式 (5.12.5) 所示，

$$
\begin{array} { r } { \pmb q _ { j } ^ { \operatorname { T } } A \pmb q _ { k } = \delta _ { j k } , \qquad \pmb q _ { j } ^ { \operatorname { T } } C \pmb q _ { k } = \omega _ { j } ^ { 2 } \delta _ { j k } . } \end{array}
$$

将本章中每一项定理应用于 $B ,$，可立即看出，由此得到的推广结论适用于 det $( A \lambda - C )$ 的零点。作为示例，我们仅陈述第 8.2 节中柯朗–费希尔（Courant–Fischer）定理的推广形式。

**定理 1.** 设 ${ \pmb a } _ { 1 } , { \pmb a } _ { 2 } , \dots , { \pmb a } _ { i - 1 }$ 是 $\mathbb { R } ^ { n } ;$ 中任意一组线性无关向量，令 $\mathcal { S } _ { i }$ 表示 $\mathbb { R } ^ { n }$ 中所有与 ${ \pmb a } _ { 1 } , \ldots , { \pmb a } _ { i - 1 }$ 正交的向量所构成的子空间。则

$$
\lambda _ { i } = \operatorname* { m a x } _ { \stackrel { } { \mathcal { S } _ { i } } } \operatorname* { m i n } _ { { \pmb x } \in { \mathcal { S } _ { i } } } \left( \frac { { \pmb x } ^ { \operatorname { T } } C { \pmb x } } { { \pmb x } ^ { \operatorname { T } } A { \pmb x } } \right) .
$$

该最小值在 $a _ { j } = q _ { j } , j = 1 , 2 , \ldots , i - 1$ 处达到。

定理 8.4.1 与定理 8.7.1 的物理意义在此设定下更为直观。添加一个约束条件可对应于将系统中的某一点固定，从而使其在该点处不发生振动；而定理 8.7.1 中所考虑的摄动则对应于系统刚度的增强。该定理告诉我们：这种刚度增强只会导致系统的固有频率升高。
