习题 2．证明：$\mathbf { \delta } _ { \mathbf { \lambda } ^ { \mathbf { X } } \mathbf { \lambda } ^ { \mathbf { \alpha } } }$ 是线性变换 $T$ 的 $r \geq 2$ 阶广义特征向量（对应特征值 $\lambda )$），当且仅当元素 $x _ { r - 1 } = ( T - \lambda I ) ( x _ { r } )$ 是线性变换 $T$ 的 $r - 1$ 阶广义特征向量；等价地，

$$
T ( { \boldsymbol { \mathbf { x } } } _ { r } ) = \lambda { \boldsymbol { \mathbf { \mathit { x } } } } _ { r } + { \boldsymbol { \mathbf { \mathit { x } } } } _ { r - 1 } ,\tag{2}
$$  

其中  ${ \pmb x } _ { r - 1 } \in \mathcal { S } _ { r - 1 } , { \pmb x } _ { r - 1 } \notin \mathcal { S } _ { r - 2 }$。  

习题 3．验证：向量  $\mathbf { \delta x } _ { r }$  是矩阵  $T$  的阶为  $r \geq 1$  的广义特征向量，当且仅当向量  $( T - \lambda I ) ^ { r - 1 } ( { \bf x } _ { r } )$  是矩阵  $T$  的特征向量，等价地，当且仅当  $( T - \lambda I ) ^ { k } ( \mathbf { x } _ { r } ) = 0$  对某个  $k \geq r$  成立。 □  

利用习题  $^ { 2 , }$  可知：若  $\scriptstyle \mathbf { \pmb { x } } _ { r }$  是矩阵  $T$  的阶为  $r ,$  的广义特征向量，则存在向量  $\pmb { x } _ { r - 1 } , \ldots , \pmb { x } _ { 2 } , \pmb { x } _ { 1 }$，使得  

$$
\begin{array} { c } { T ( { \boldsymbol x } _ { 1 } ) = \lambda { \boldsymbol x } _ { 1 } } \\ { T ( { \boldsymbol x } _ { 2 } ) = \lambda { \boldsymbol x } _ { 2 } + { \boldsymbol x } _ { 1 } , } \\ { \vdots } \\ { T ( { \boldsymbol x } _ { r } ) = \lambda { \boldsymbol x } _ { r } + { \boldsymbol x } _ { r - 1 } , } \end{array}\tag{3}
$$

其中，$\boldsymbol { x } _ { j } \in \mathcal { S } _ { j }$ 对应于 $j = 1 , 2 , \dots , r .$。这样的序列 $\pmb { x } _ { 1 } , \pmb { x } _ { 2 } , \dots , \pmb { x } _ { r }$ 称为与特征值 $\lambda .$ 相关联的长度为 $ r $ 的若尔当链（Jordan chain）。该链亦可视为与 $\pmb { x } _ { 1 }$ 相关联。从这一观点出发，首先选取一个特征向量 $\mathbf { x _ { 1 } }$，然后通过依次求解方程组 (3) 来生成向量 $x _ { 2 } , \ldots , x ,$，只要非齐次方程 $( T - \lambda I ) x _ { j } = x _ { j - 1 }$ 对 $j = 2 , 3 , \dots .$ 仍有解，此过程便持续进行。显然，$ T $ 的任意若尔当链之长度必为有限，这是因为对长度为 $ r $ 的链，恒有 $r \leq$ ≤ dim $\mathcal { S } _ { p } \leq$ ≤ dim $\mathcal { S }$。此外，若尔当链中的各元素线性无关，如下一习题所示。

习题 4．证明：任意若尔当链均由线性无关的元素构成。

解．令 $\begin{array} { r } { \sum _ { i = 1 } ^ { r } \pmb { x } _ { i } \pmb { x } _ { i } = \pmb { \theta } . } \end{array}$。对上述方程两端同时应用变换 $( T - \lambda I ) ^ { r - 1 }$，并注意到当 $1 \leq i \leq r - 1$ 时有 $( T - \lambda I ) ^ { r - 1 } ( { \bf x } _ { i } ) = \pmb { \theta }$（习题 3），我们得到 $\alpha _ { r } ( T - \lambda I ) ^ { r - 1 } ( x _ { r } ) = 0 .$。由习题 3 可知，元素 $( T - \lambda I ) ^ { r - 1 } ( \pmb { x } _ { r } )$ 是线性算子 $T$ 的一个特征向量，因而非零，故 $\mathfrak { X } _ { r } = 0$。再对方程 $\begin{array} { r } { \sum _ { i = 1 } ^ { r - 1 } \pmb { \alpha } _ { i } \pmb { x } _ { i } = \pmb { \theta } _ { 2 } } \end{array}$ 应用变换 $( T - \lambda I ) ^ { r - 2 }$，类似地可推出 $\pmb { \alpha _ { r - 1 } } = 0$。重复此过程，即可证得 Jordan 链中广义特征向量所构成的集合是线性无关的。

特别地，习题 4 表明：由 $T$ 的一条长度为 $r$ 的 Jordan 链所生成、对应于 $T ,$ 的 Jordan 子空间具有维数 $r$。
