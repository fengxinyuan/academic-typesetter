更一般地，我们寻求方程 (1) 的如下形式的解：  

$$
\begin{array} { r } { \pmb { x } ( t ) = \pmb { x } _ { 0 } ( t ) e ^ { \lambda _ { 0 } t } , \qquad \lambda _ { 0 } \in \mathbb { C } , } \end{array}\tag{3}
$$  

其中 ${ \pmb x } _ { 0 } ( t )$ 是一个 n 阶向量，其各分量均为关于 t 的多项式。为方便起见，我们将 ${ \pmb x } _ { 0 } ( t )$ 写成如下形式：  

$$
\pmb { x } _ { 0 } ( t ) = \frac { t ^ { k - 1 } } { ( k - 1 ) ! } \pmb { x } _ { 1 } + \cdots + \frac { t } { 1 ! } \pmb { x } _ { k - 1 } + \pmb { x } _ { k } ,\tag{4}
$$  

其中 $\pmb { x } _ { i } \in \mathbb { C } ^ { n } , i = 1 , 2 , \ldots , k _ { 2 }$，且 $\mathbf { x _ { 1 } }$ 被假定为非零向量。  

容易看出，形如 (3) 的 x(t) 是方程 (1) 的解，当且仅当  

$$
\dot { { \mathbf x } } _ { 0 } ( t ) = ( A - \lambda _ { 0 } I ) { \mathbf x } _ { 0 } ( t ) ,
$$  

其中 ${ \bf { x } } _ { 0 } ( t )$ 由方程 (4) 给出。对其求导，可得  

$$
\begin{array} { r } { { \pmb x } _ { 0 } ^ { ( i ) } ( t ) = ( A - \lambda _ { 0 } I ) ^ { i } { \pmb x } _ { 0 } ( t ) , \qquad i = 1 , 2 , \ldots , } \end{array}\tag{5}
$$  

又因 ${ \bf { x } } _ { 0 } ( t )$ 是一个次数为 $k \mathrm { ~ - ~ } 1$ 的向量值多项式，故有 $\pmb { \theta } = ( A - \lambda _ { 0 } I ) ^ { k } \pmb { x } _ { 0 } ( t )$

现在由式 (4) 可得 $x _ { 0 } ^ { ( k - 1 ) } ( t ) = x _ { 1 }$，将其与式 (5) 比较，得 $x _ { 1 } = ( A - \lambda _ { 0 } I ) ^ { k - 1 } x _ { 0 } ( t )$。在左边同乘以 $( A - \lambda _ { 0 } I )$，得到 $( A - \lambda _ { 0 } I ) { \pmb x } _ { 1 } = { \pmb \theta } ,$；又由假设知 $\pmb { x } _ { 1 } \neq \pmb { \theta }$，故 $\bf { x _ { 1 } }$ 是矩阵 A 关于特征值 $\lambda _ { 0 }$ 的一个特征向量。

接下来，将式 (4) 与式 (5) 分别给出的 ${ \pmb x } _ { 0 } ( t )$ 的第 (k − 2) 阶导数进行比较，可得  

$$
t x _ { 1 } + x _ { 2 } = ( A - \lambda _ { 0 } I ) ^ { k - 2 } x _ { 0 } ( t ) .
$$  

在左边同乘以 $( A - \lambda _ { 0 } I )$，并利用前一段所得结果，即得 $( A - \lambda _ { 0 } I ) \mathbf { x } _ { 2 } = \mathbf { x } _ { 1 }$。因此（参见式 (6.3.3)），$\mathbf { \delta x } _ { 1 } , \mathbf { \delta x } _ { 2 }$ 构成一个长度为 2 的若尔当链。

以同样方式继续推导，可得 $\mathbf { x } _ { 1 } , \mathbf { x } _ { 2 } , \ldots , \mathbf { x } _ { k }$ 构成矩阵 A 关于特征值 $\lambda _ { 0 }$ 的一个若尔当链。类似地可证：若 $\mathbf { x } _ { 1 } , \mathbf { x } _ { 2 } , \ldots , \mathbf { x } _ { k }$ 生成矩阵 A 关于特征值 $\lambda _ { 0 }$ 的一个若尔当链，则式 (3) 联合式 (4) 给出式 (1) 的一个解。于是我们证明了如下命题。

**命题 1**．由式 (3) 和式 (4) 所定义的函数 x(t) 是式 (1) 的解，当且仅当 $\mathbf { x } _ { 1 } , \mathbf { x } _ { 2 } , \ldots , \mathbf { x } _ { k }$ 构成矩阵 A 关于其特征值 $\lambda _ { 0 }$ 的一个若尔当链。

现在回顾定理 7.10.1：方程 (1) 的解空间 $\mathcal { f }$ 的维数为 $ n $；又由若尔当定理可知，$\mathbb { C } ^ { n }$ 中存在一组基，该基完全由 $ A $ 的特征向量与广义特征向量构成。因此，以下结论显然成立。
