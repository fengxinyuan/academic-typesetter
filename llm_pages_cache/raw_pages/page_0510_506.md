## 14.4 微分方程中的应用

考虑如下阶数为 $ l $ 的常系数矩阵微分方程：



$$
L _ { l } { \pmb x } ^ { ( l ) } ( t ) + L _ { l - 1 } { \pmb x } ^ { ( l - 1 ) } ( t ) + \dots + L _ { 1 } { \pmb x } ^ { ( 1 ) } ( t ) + L _ { 0 } { \pmb x } ( t ) = { \pmb f } ( t ) ,\tag{1}
$$

其中，$L _ { 0 } , L _ { 1 } , \dots , L _ { l } \in \mathbb { C } ^ { n \times n }$，det $L _ { l } \neq 0 ;$，且 $ x $ 上的下标表示对自变量 $ t $ 的导数。向量函数 $f ( t )$ 取值于 $\mathbb { C } ^ { n } .$，分段连续，且视为给定；待求的是 $\mathbf { \boldsymbol { x } } ( t )$。当 $\begin{array} { r } { f ( t ) \neq \pmb { \theta } , } \end{array}$ 时，该方程为非齐次方程；而方程  

$$
L _ { l } { \mathbf { } x } ^ { ( l ) } ( t ) + \cdots + L _ { 1 } { \mathbf { } x } ^ { ( 1 ) } ( t ) + L _ { 0 } { \mathbf { } x } ( t ) = { \boldsymbol { 0 } }\tag{2}
$$  

称为齐次方程，已在第 7.10 节中引入。请回顾该节关于函数空间 ${ \mathcal { C } } ( \mathbb { C } ^ { n } )$ 的讨论：${ \mathcal { C } } ( \mathbb { C } ^ { n } )$ 表示所有定义在实数 $ t $ 上、取值于 $\mathbb { C } ^ { n }$ 的连续向量值函数 $\pmb { x } ( t )$ 所构成的线性空间。本节将进一步探讨 $L ( \lambda )$ 的若尔当链与齐次方程 (2) 在 ${ \mathcal { C } } ( \mathbb { C } ^ { n } )$ 中的本原解之间的关系。

首先注意到：若 $\lambda _ { 0 }$ 是 $L ( \lambda )$ 的一个特征根（即“隐根”，latent root），且 $\mathbf { x _ { 0 } }$ 是其对应的特征向量（即“隐向量”，latent vector），即满足 $L ( \lambda _ { 0 } ) { \bf x } _ { 0 } = { \bf \nabla } \theta ,$，则方程 (2) 存在一个解 $\pmb { x } _ { 0 } e ^ { \lambda _ { 0 } t }$；反之亦然。这是因为  

$$
\cdot \qquad { \biggl ( } { \frac { d } { d t } } { \biggr ) } ^ { j } ( x _ { 0 } e ^ { \lambda _ { 0 } t } ) = \lambda _ { 0 } ^ { j } x _ { 0 } e ^ { \lambda _ { 0 } t } ,
$$  

从而有

$$
L \left( { \frac { d } { d t } } \right) \left( x _ { 0 } e ^ { \lambda _ { 0 } t } \right) = \sum _ { j = 0 } ^ { l } L _ { j } \left( { \frac { d } { d t } } \right) ^ { j } ( x _ { 0 } e ^ { \lambda _ { 0 } t } ) = L ( \lambda _ { 0 } ) x _ { 0 } = \theta .
$$  

现在假设 $ \mathbf{x}_0, \mathbf{x}_1 $ 是矩阵 $L ( \lambda$ )关于其一个特征值（即隐含根） $\lambda$ _ { 0 }  的若尔当链中的两个首项。我们断言  

$$
u _ { 0 } ( t ) = x _ { 0 } e ^ { \lambda _ { 0 } t } \qquad \mathrm { a n d } \qquad u _ { 1 } ( t ) = ( t x _ { 0 } + x _ { 1 } ) e ^ { \lambda _ { 0 } t }
$$  

是方程 (2) 的一组线性无关解。我们已知第一个函数是该方程的解；此外，第一个函数显然满足  

$$
\bigg ( \frac { d } { d t } - \lambda _ { 0 } I \bigg ) u _ { 0 } ( t ) = 0 .\tag{3}
$$  

再考察第二个函数：  

$$
\left( { \frac { d } { d t } } - \lambda _ { 0 } I \right) ( t x _ { 0 } + x _ { 1 } ) e ^ { \lambda _ { 0 } t } = x _ { 0 } e ^ { \lambda _ { 0 } t } .
$$
