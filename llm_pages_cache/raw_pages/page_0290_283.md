## 8.1 数值域与埃尔米特矩阵的极值特征值

矩阵 $A \in \mathbb { C } ^ { n \times n }$ 的特征值构成复平面上 $ n $ 个点（未必互异）。关于这些点的分布，一些有用的思想可由 $A ,$ 的数值域（field of values）这一概念引出：数值域定义为复数集合 $F ( A )$，其中每个复数形如 $( A { \bf { x } } , { \bf { x } } )$，而 $ \mathbf{x} $ 取遍所有满足归一化条件 $( x , x ) = x ^ { * } x = 1 . ^ { \dagger }$ 的 $\mathbb { C } ^ { n }$ 中的向量。

注意，二次型  

$$
f ( { \pmb x } ) = ( { \pmb A } { \pmb x } , { \pmb x } ) = \sum _ { i , j = 1 } ^ { n } a _ { i j } x _ { i } \bar { x } _ { j } , \qquad { \pmb x } = [ { \pmb x } _ { 1 } \quad x _ { 2 } \quad \cdots \quad x _ { n } ] ^ { \mathrm { T } } ,
$$  

是定义在 $\mathbb { C } ^ { n } ,$ 中单位球面上的 $ n $ 元连续函数，即定义在满足  

$$
( \mathbf { x } , \mathbf { x } ) = \sum _ { i = 1 } ^ { n } | x _ { i } | ^ { 2 } = 1 .
$$  

的所有向量所构成的集合上。因此，由附录 2 中的定理 2 可知，$F ( A )$ 是复平面上的一个闭集且有界集。还可进一步证明：$F ( A )$ 是一个凸集（凸集的定义见附录 2），但此处略去该证明。

定理 1．矩阵 $A \in \mathbb { C } ^ { n \times n }$ 的数值域在酉相似变换下保持不变。因此，若 $U \in \mathbb { C } ^ { n \times n }$ 是酉矩阵，则有  

$$
F ( A ) = F ( U A U ^ { * } ) .
$$  

**证明．** 我们有  

$$
( U A U ^ { * } x , \pmb { x } ) = ( A U ^ { * } x , U ^ { * } \pmb { x } ) = ( A y , \pmb { y } ) ,
$$  

其中 $y = U ^ { * } x$。若 $( { \pmb x } , { \pmb x } ) = 1$，则 $( y , y ) = ( U U ^ { * } x , \pmb { x } ) = ( \pmb { x } , \pmb { x } ) = 1$。因此，一个数 α 等于 $( U A U ^ { * } { \pmb x } , { \pmb x } )$（对某个满足 $\mathbf { x } \in \mathbb { C } ^ { n }$ 且 $( { \pmb x } , { \pmb x } ) = 1$ 的向量 x）当且仅当 α = $\alpha = ( A \mathbf { y } , \mathbf { y } )$（对某个单位化向量 $\ b { y } \in \mathbb { C } ^ { n }$）；即，α 属于 $F ( U A U ^ { * } )$ 当且仅当 $\alpha \in F ( A )$。  

该结果为正规矩阵的数值域提供了一种优美的几何刻画——其数值域恰为其特征值的凸包。首先注意到：对任一矩阵 $A \in \mathbb { C } ^ { n \times n }$，其所有特征值均属于 $F ( A )$。事实上，若 $\lambda \in \sigma ( A )$，则存在 A 关于该特征值的一个特征向量 x，使得 $A { \boldsymbol { x } } = \lambda { \boldsymbol { x } }$ 且 $( { \pmb x } , { \pmb x } ) = 1$。于是  

$$
( A x , x ) = ( \lambda \mathbf { x } , \mathbf { x } ) = \lambda ( x , x ) = \lambda ,
$$  

从而 $\lambda \in F ( A )$，故 $\sigma ( A ) \subset F ( A )$。
