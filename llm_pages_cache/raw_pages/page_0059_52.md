又因初等矩阵的逆矩阵仍是同类型的初等矩阵（参见习题 2），故可推出  

$$
\begin{array} { r } { A = ( E _ { 1 } ^ { - 1 } E _ { 2 } ^ { - 1 } \cdot \cdot \cdot E _ { k } ^ { - 1 } \widetilde { E } _ { l } \cdot \cdot \cdot \widetilde { E } _ { 1 } ) B ( \widetilde { E } _ { l + 1 } \cdot \cdot \cdot \widetilde { E } _ { l + t } E _ { k + s } ^ { - 1 } \cdot \cdot \cdot E _ { k + 1 } ^ { - 1 } ) . } \end{array}
$$

因此，矩阵 $ A $ 可通过对 $ B $ 施行若干次初等变换而得到。

用推论 1 的语言来表述，我们已证明存在适当阶数的非奇异矩阵 $ P $ 与  Q ，使得  

$$
A = P B Q\tag{10}
$$  

下一个定理将上述结果加以总结。

**定理 4.** 若 $ A $ 与 $ B $ 是同型矩阵（即均为 $ m \times n $ 矩阵），则下列命题彼此等价：

(1) $ A $ 与 $ B $ 具有相同的行最简形（即形式 (8)）；  
(2) 其中任一矩阵均可通过对另一矩阵施行初等行变换与初等列变换而得到；  
(3) 存在非奇异矩阵 $ P $ 与 $ Q $，使得  A = P B Q 。

上述任一命题均可作为如下“矩阵等价”概念的定义。例如，若命题 (3) 成立，则称矩阵 $ A $ 与 $ B $ 等价，记作 $A \sim B ,  $。

显然，关系  A  $\sim B  $ 是一个等价关系，即它满足：

(1)  A  $\sim A  $（任一矩阵与其自身等价），此为自反性；  
(2) 若  A  $\sim B ,$ ，则 $B \sim A  $（对称性）；  
(3) 若  A  $\sim B$ 且 $B \sim C ,$ ，则 $A \sim C  $（传递性）。

于是，所有固定阶数 $ m \times n $ 的矩阵构成的集合被划分为互不相交的、彼此等价的矩阵类（即等价类）。每个 $ m \times n $ 矩阵 $ A $ 恰属于且仅属于其中一类；该类可描述为全体形如  P A Q  的矩阵之集合，其中 $ P $ 与  Q  分别取遍所有 $ m \times m $ 阶与 $n \times n  $ 阶非奇异矩阵。

每一等价类均由且仅由一个形如 (8) 的矩阵唯一代表并确定；该矩阵称为该类中所有矩阵的**标准形**（亦称**最简形**）。例如，若  r < m < n , ，则矩阵  

$$
\begin{array} { r } { \left[ \begin{array} { l l } { I _ { r } } & { 0 } \\ { 0 } & { 0 } \end{array} \right] } \end{array}\tag{11}
$$

是某一等价类的代表元；它是该等价类中所有矩阵的标准型（典范形式）。显然，只要知道式 (11) 中的数 $ r $，即可唯一确定一个等价类。这一事实为下一节对数 $ \text{$r ,$} $ 的深入研究提供了依据。
