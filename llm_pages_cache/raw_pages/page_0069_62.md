此外，由于 L 是下三角矩阵，若依次求出分量 $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$，则 y 可被便捷地计算出来。

接着求解方程 $U { \pmb x } = { \pmb y }$，从而得到方程组 $\pmb { A } \pmb { x } = \pmb { b } .$ 的解（或解集）。事实上，$U { \pmb x } = { \pmb y }$ 与 $L y = b$ 显然蕴含 $L U x = A x = b$。但再次强调，U 的三角形式使得由 y 推导出 x 尤为简便。此时，x 的各分量按顺序 $x _ { n } , x _ { n - 1 } , \ldots , x _ { 2 } , x _ { 1 }$ 求得。

线性方程组消元算法的实际实现与分析，在很大程度上依赖于三角分解的存在性；而我们接下来给出的结果，正是此类理论中的基本定理。至此为止的讨论中，我们不得不引入一个不尽人意的假设：即在将矩阵 A 化为标准形的过程中无需进行行交换或列交换。本定理则以 A 的各阶顺序主子式所满足的条件取代了该假设（顺序主子式的定义见第 2.4 节）。

定理 1．设 $A \in \mathbb { C } ^ { n \times n }$，并假定其各阶顺序主子式

$$
A { \binom { 1 } { 1 } } , A { \binom { 1 } { 1 } } , 2 \rangle , \dots , A { \binom { 1 } { 1 } } , 2 \dots n - 1 )\tag{2}
$$

所有主子式均非零。于是存在唯一的单位下三角矩阵 $ L $（即对角元全为 1 的下三角矩阵）和唯一的上三角矩阵 $ U_1 $，使得  
$A = L U$  

此外，  
$$ \det A = \prod_{i=1}^n u_{ii}, $$  
即 $ A $ 的行列式等于 $ U_1 $ 对角元的乘积。  

**证明**． 对矩阵 $ A $ 的阶数 $ n $ 作数学归纳法。显然，当 $ n = 1 $ 时，设 $ A = [a_{11}] $，且 $ a_{11} \ne 0 $，则取 $ L = [1] $、$ U_1 = [a_{11}] $，即得定理所要求的唯一分解：  
$a _ { 1 1 } = 1 \cdot a _ { 1 1 }$  

现假设该定理对一切 $ (n-1) \times (n-1) $ 阶方阵成立，并将 $ A $ 分块为  

$$
A = \left[ { \begin{array} { l l } { A _ { n - 1 } } & { a _ { 1 } } \\ { a _ { 2 } ^ { \mathrm { T } } } & { a _ { n n } } \end{array} } \right] ,\tag{3}
$$  

其中  \ b { a } _ { 1 } , \ b { a } _ { 2 } $\in \mathbb { C } ^ { n - 1 }$ 。于是可将该定理应用于 $ (n-1) \times (n-1) $ 阶子矩阵  A _ { n - 1 } ，得到其唯一的三角分解  

$$
A _ { n - 1 } = L _ { n - 1 } U _ { n - 1 } ,
$$  

其中  L _ { n - 1 }  是对角元全为 1 的下三角矩阵。由于  

$$
\operatorname* { d e t } A _ { n - 1 } = A { \binom { 1 } { 1 } } \quad 2 \quad \cdots \quad n - 1 { \bmod { 2 } } \quad 0 ,
$$  

可知  L _ { n - 1 }  与  U _ { n - 1 }  均为非奇异矩阵。

$$
L = { \left[ \begin{array} { l l } { L _ { n - 1 } } & { \theta } \\ { d ^ { \mathrm { T } } } & { 1 } \end{array} \right] } \quad \quad { \mathrm { a n d } } \quad \quad U = { \left[ \begin{array} { l l } { U _ { n - 1 } } & { c } \\ { \theta ^ { \mathrm { T } } } & { a _ { n n } - d ^ { \mathrm { T } } c } \end{array} \right] } ,\tag{4}
