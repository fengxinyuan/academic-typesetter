**定理 1.** 系统 (1) 是可观测的，当且仅当 $\operatorname{Ker} \, \text{$Q ( C , A ) = \{ $\pmb { 0 } \} } = \{0\}$，即当且仅当数对 $( C , A )$ 是可观测的。  

在证明该定理之前，我们先建立一个技术性引理，它将简化后续涉及极限过程的论证。所谓整函数（entire function），是指在整个复平面上解析的函数；其唯一的可能奇点位于无穷远点。  

**引理 1.** 对任意矩阵 $A \in \mathbb { C } ^ { n \times n }$，存在整函数 $\psi _ { 1 } ( t )$ 与 $\ldots , \psi _ { n } ( t )$，使得  

$$
e ^ { A t } = \sum _ { j = 1 } ^ { n } \psi _ { j } ( t ) A ^ { j - 1 } .\tag{2}
$$  

**证明.** 令 $f ( \lambda ) = e ^ { \lambda t }$；则 $f$ 是关于 $\lambda$ 的整函数，且在任一 $n \times n$ 矩阵 $A$ 的谱上均有定义。由于 $f ^ { ( j ) } ( \lambda ) = t ^ { j } e ^ { \lambda t }$，根据定理 9.5.1 可得  

$$
f ( A ) = e ^ { A t } = \sum _ { k = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } t ^ { j } e ^ { \lambda _ { k } t } Z _ { k j } .\tag{3}
$$

由于对每个  k , j  和 $\varphi$ _ { k j } ， Z _ { k j } $= \varphi$ _ { k j } ( A )  均为次数不超过 $ n $ 的多项式［参见式 (9.2.6) 与 (9.2.7) 前的讨论］，且因函数 $ \varphi_i $ 仅依赖于矩阵 $ A $，故式 (3) 右端项可被重排为 $\varphi$ _ { k j } ，其形式恰如式 (2) 所示。此外，每个系数 $ \psi_j(t) $ 均仅为形如  t ^ { j } e ^ { $\lambda$ _ { k } t }  的函数的线性组合（其组合系数为 $\psi$ _ { j } ( t ) ），因而 $ \psi_j(t) $ 是整函数。■

**定理 1 的证明**：若 $ \operatorname{Ker} $Q  $( C , A ) \neq \{ \pmb { 0 } \}$ ，则存在非零向量 $\mathbf { \boldsymbol { x } }$ _ { 0 } ，使得对所有 $j = 0 , 1 , \ldots , n - 1$ ，均有  C A ^ { j } $\mathbf { x }$ _ { 0 } $= \pmb { 0 }$ 。由引理 1 可知，对任意实数 $ t $，恒有  C e ^ { 4 t } $\pmb { x }$ _ { 0 } $= \pmb { 0 }  $。但此时，依据定理 9.10.3 及式 (1)，可得  

$$

\mathbf { y } ( t ) = C e ^ { A t } \mathbf { x } _ { 0 } \equiv \pmb { \theta }
$$
  

从而该系统不可观。因此，若系统可观，则矩阵对  ( C , A )  必须可观。

反之，若系统不可观，则存在某个非零向量  \mathbf { $\boldsymbol { x } }$ _ { 0 } $\neq \mathbf { \boldsymbol { \theta } }$ ，使得 $\mathbf { y } ( t ) = C e ^ { A t } \mathbf { x }$ _ { 0 } $\equiv \pmb { \theta }$ 。对该等式关于 $ t $ 逐次求导，可得  

$$

Q ( C , A ) e ^ { A t } x _ { 0 } \equiv \pmb { \theta }
$$
  

于是 $ \operatorname{Ker} $Q  $( C , A ) \neq \{ \pmb { 0 } \}$ 。由此可知，矩阵对  ( C , A )  的可观性必然蕴含该系统的可观性。
