子空间 $ \mathcal{M} $（记为 $\mathcal { S } _ { \mathfrak { d } }$）与它在 $ \mathcal{V} $（记为 $\pmb { \mathcal U }$）中的正交补子空间 $ \mathcal{M}^\perp $（记为 $\mathcal { S } _ { \mathfrak { d } } ^ { \perp }$）的和具有特殊意义。首先注意到，该和是直和：$ \mathcal{M} \cap \mathcal{M}^\perp = \{0\} $（即 $\mathcal { S } _ { 0 } \cap \mathcal { S } _ { 0 } ^ { \bot } = \{ \pmb { \theta } \} _ { 1 }$），因此 $ \mathcal{V} = \mathcal{M} \oplus \mathcal{M}^\perp $（即 $\mathcal { S } _ { 0 } \dot { + } \mathcal { S } _ { 0 } ^ { \perp }$）是两个彼此正交的子空间的直和，亦即正交直和（orthogonal sum）。更一般地，设 $ \mathcal{U}_1, \mathcal{U}_2, \dots, \mathcal{U}_k $（即 $\mathcal { S } _ { i } \left( i = 1 , 2 , \ldots , k \right)$）是 $ \mathcal{V} $（即 $\pmb { \mathcal U }$）的 $ k $ 个线性子空间；若对任意 $ i \ne j $，均有 $ \mathcal{U}_i \perp \mathcal{U}_j $（即 $\mathcal { S } _ { i } \perp \mathcal { S } _ { j }$），其中 $ i,j = 1,2,\dots,k $（即 $i \neq j ( 1 \leq i , j \leq k )$），则称其直和为这些子空间的正交直和，记作 $ \mathcal{U}_1 \overset{\perp}{\oplus} \mathcal{U}_2 \overset{\perp}{\oplus} \cdots \overset{\perp}{\oplus} \mathcal{U}_k $（即 ${ \mathcal { S } } _ { 1 } \oplus { \mathcal { S } } _ { 2 } \oplus \cdots \oplus { \mathcal { S } } _ { k }$），或简记为 $ \bigoplus_{i=1}^k \mathcal{U}_i $（即 $\sum _ { i = 1 } ^ { k } \oplus \mathcal { S } _ { i }$）。注意，这与通常意义下（未必正交）的直和所用符号 $ \bigoplus_{i=1}^k \mathcal{U}_i $（即 $\mathcal { S } _ { 1 } + \mathcal { S } _ { 2 } + \cdots + \mathcal { S } _ { k }$）形成对比。

习题 5．设 $ \mathcal{V} $（即 $\pmb { \mathcal U }$）是一个 $ n $ 维酉空间。证明：对 $ \mathcal{V} $（即 ${ \pmb u } ,$）的任一子空间 $ \mathcal{M} $（即 $\mathcal { S } _ { \mathfrak { d } }$），有  

$$
\pmb { \mathscr { U } } = \mathcal { S } _ { 0 } \oplus \mathcal { S } _ { 0 } ^ { \bot }\tag{1}
$$  

特别地，$ \dim \mathcal{M}^\perp = n - \dim \mathcal{M} $（即 dim $\mathcal { S } _ { 0 } + \mathrm { d i m } \mathcal { S } _ { 0 } ^ { \perp } = n . \quad \bigsqcup$）。

由式 (1) 可知，$ \mathcal{V} $ 中每个元素 $ x $ 均可唯一地表为  

$$
{ \pmb x } = { \pmb x } _ { 1 } + { \pmb x } _ { 2 } ,\tag{2}
$$

其中  \pmb { x } _ { 1 } $\in \mathcal { S }$ _ { 0 }  且  { $\pmb x }$ _ { 1 } $\perp { \pmb x }$ _ { 2 } 。表示式 (2) 使人联想到向量在 $\mathbb { R } ^ { 3 }$ 中分解为两个互相正交的向量之和的情形。因此，式 (2) 中的元素 $\pmb { x$ _ { 1 } }  称为 $ \mathbf{x} $ 在 $\mathcal { S }$ _ { $\mathfrak { d } }  $ 上的正交投影。
