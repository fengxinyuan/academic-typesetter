若能证明存在某个 $\pmb { x } _ { 0 } \in \mathbb { C } ^ { n }$，使得 $\| D \pmb { x } _ { 0 } \| _ { \mathbf { v } } / \| \pmb { x } _ { 0 } \| _ { \mathbf { v } } = d _ { 2 }$，则证明即告完成。设 $ m $ 为满足 $d = | d _ { m } |$ 的整数。于是  

$$
{ \frac { \| D e _ { m } \| _ { \mathrm { v } } } { \| e _ { m } \| _ { \mathrm { v } } } } = { \frac { \| d _ { m } e _ { m } \| _ { \mathrm { v } } } { \| e _ { m } \| _ { \mathrm { v } } } } = | d _ { m } | = d ,
$$  

其中 $e _ { m }$ 是 $ \mathbb{C}^n $ 中第 $ m $ 个单位向量（即第 $ m $ 个标准基向量），故  

$$
\left\| D \right\| = \operatorname* { m a x } _ { \mathbf { x } \neq \mathbf { 0 } } { \frac { \| D \mathbf { x } \| _ { \mathbf { v } } } { \| \mathbf { x } \| _ { \mathbf { v } } } } = d ,
$$  

且 (c) 式由 (b) 式推出。  

$( c ) \Rightarrow ( a )$  
假设条件 (c) 成立；令 $\mathbf { x } = [ x _ { 1 } \quad x _ { 2 } \quad \cdots \quad x _ { n } ] ^ { \mathrm { T } }$。取 $d _ { j } = 1 \mathrm { i f } x _ { j } = 0$ 与 $d _ { j } = | x _ { j } | / x _ { j } \mathrm { i f } x _ { j } \neq 0 .$，则对任意 $\boldsymbol { x } \in \mathbb { C } ^ { n }$，均存在一对角矩阵 $D = \dot { \mathrm { d i a g } } [ d _ { 1 } , d _ { 2 } , \dots , d _ { n } ]$，使得 $| { \pmb x } | = D { \pmb x }$。因此，由性质 (c) 可得 $\| D \| = \| D ^ { - 1 } \| = 1$。于是我们有  

$$
\left\| ~ | ~ \mathbf { x } | ~ \right\| _ { \mathbf { v } } = ~ \left\| D \mathbf { x } \right\| _ { \mathbf { v } } \leq ~ \left\| D \right\| ~ \left\| \mathbf { x } \right\| _ { \mathbf { v } } = ~ \left\| \mathbf { x } \right\| _ { \mathbf { v } }
$$  

又因 ${ \pmb x } = D ^ { - 1 } | { \pmb x } |$，故可得

$\mathbb { C } ^ { n } .$



$$
\| { \boldsymbol { \mathbf { x } } } \| _ { \mathbf { \check { v } } } \leq \| { \boldsymbol { D } } ^ { - 1 } \| \mathbf { \check { \phi } } \| | { \boldsymbol { \mathbf { \mathit { x } } } } | \| _ { \mathbf { \check { v } } } = \| \mathbf { \phi } | { \boldsymbol { \mathbf { \mathit { x } } } } | \| _ { \mathbf { \check { v } } }
$$  

因此，对任意 $\pmb { x } \in \mathbb { C } ^ { n }$，均有 $\| { \pmb x } \| _ { \mathbf { v } } = \| { \mathbf \alpha } \| { \pmb x } \| \| ,$，故 (c) 蕴含 (a)。证明完毕。

习题 1．设 $\mathbf { I f } \parallel \parallel$ 是由某绝对向量范数所诱导的矩阵范数，$\left| A \right|$ 是元素为 $| a _ { i j } | ,$ 的矩阵，试证：$\| A \| < \| \left| A \right| \|$。  

提示：利用公式 (10.4.2)。

接下来讨论本节的第二个主题。回顾前文，我们引入范数的初衷是寻求一种“大小”的度量，或更一般地，寻求一种刻画某个元素偏离零元素程度的度量。若将注意力限定于矩阵范数，则除偏离零矩阵外，另一种同样有用的度量是刻画矩阵偏离奇异性的程度（即偏离奇异矩阵的程度，而非零矩阵）。因此，我们希望构造一个定义在所有方阵 A 上的非负函数，且该函数为零当且仅当 det $A = 0$。初看之下，令人惊讶的是：这样一种度量竟可由式 (10.4.1) 中所给出的诱导范数定义之“互补定义”导出；但再细思之，便不觉意外了——因为我们熟知：存在一个 $\pmb { x } \neq \pmb { \theta }$ 满足 $A \pmb { x } = \pmb { \theta }$ 当且仅当 det $A = 0$。我们依向量范数 $\Vert \bigstar \bigstar \Vert _ { \mathbf { v } } .$ 定义矩阵 A 的下界（lower bound），记作 l(A)，如下：

$$
l ( A ) = \operatorname* { i n f } _ { \mathbf { x } \in \mathbb { C } ^ { n } , \mathbf { x } \neq \mathbf { 0 } } \frac { \| A \mathbf { x } \| _ { \mathrm { v } } } { \| \mathbf { x } \| _ { \mathrm { v } } } .\tag{1}
$$  

如果我们接受如下观点：当矩阵 $ A $ 趋近于奇异矩阵时，量 $ \mathrm{$\| A ^ { - 1 } \|$} $ 的模长无限增大，则下一个定理将证实我们的论断——该下界确实可作为衡量矩阵偏离奇异程度的一种度量。
