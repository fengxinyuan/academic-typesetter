且子空间  \mathscr { C } _ { p }  与由 $\pmb { x }$ _ { 1 } $, \pmb { x }$ _ { 2 } $, \ldots , \pmb { x }$ _ { p ^ { - 1 } }  所生成的空间正交。此前已证得：  

$$
\lambda _ { 1 } = \operatorname* { m i n } _ { \pmb { \theta } \neq \pmb { x } \in \mathcal { C } _ { 1 } } R ( \pmb { x } ) ,\tag{1}
$$  

接下来将证明：$ H $ 的其余特征值亦可被刻画，其刻画方式是对命题 (1) 的推广。

定理 1．设  R ( x )  是由埃尔米特矩阵 $ H $ 定义的瑞利商，且子空间 $\mathcal { C }$ _ { 1 } $, \ldots , \mathcal { C }$ _ { n } （与 $ H $ 相关联）如前一段所述予以定义。则对 $i = 1 , 2 , \dots , n .  $，下列各数  

$$

\lambda _ { i } = \operatorname* { m i n } _ { \pmb { \theta } \neq \pmb { x } \in \mathscr { C } _ { i } } R ( \pmb { x } )\tag{2}
$$
  

即为 $ H $ 的特征值。此外，式 (2) 中的极小值在特征向量  x _ { i } o f H  上达到。  

**证明．** 首先注意到， i = 1  的情形即为定理 8.1.4 以形式 (1) 表达的情形。令  U = [ { $\pmb x }$ _ { 1 } $\quad { \pmb x }$ _ { 2 } $\quad \cdots \quad { \pmb x }$ _ { n } ]  是由 $ H $ 的一组标准正交特征向量构成的矩阵（如定理 5.2.1 所述），并回顾 $\mathscr { C }$ _ { i }  由 $\pmb { x }$ _ { i } $, \pmb { x }$ _ { i + 1 } $, \ldots , \pmb { x }$ _ { n }  张成。于是，对任一 $\pmb { x } \in \mathcal { C }$ _ { i } ，存在数 $\alpha$ _ { i } $, \alpha$ _ { i + 1 } $, \ldots , \alpha$ _ { n } ，使得 $\begin{array} { r } { \pmb { x } = \sum$ _ { j = i } ^ { n } $\pmb { \alpha }$ _ { j } $\pmb { x }$ _ { j } } $\end{array}$ 。引入由下式定义的向量 $\pmb { \mathscr { a } } \in \mathbb { C } ^ { n }  $：  

$$

\pmb { \alpha } = [ 0 \quad \ldots \quad 0 \quad \alpha _ { i } \quad \alpha _ { i + 1 } \quad \cdots \quad \alpha _ { n } ] ^ { \mathrm { T } } ,\tag{3}
$$
  

从而有  \begin{array} { r } { $\pmb { x } = U \pmb { \alpha } , } \end{array}  $，并注意到，利用定理 5.2.1 可得……

$$
( H \pmb { x } , \pmb { x } ) = \pmb { x } ^ { * } H \pmb { x } = \pmb { \alpha } ^ { * } U ^ { * } H U \pmb { \alpha } = \pmb { \alpha } ^ { * } D \pmb { \alpha } = \sum _ { j = i } ^ { n } \lambda _ { j } | \alpha _ { j } | ^ { 2 } .\tag{4}
$$  

此外，我们还有 $\textstyle ( { \pmb x } , { \pmb x } ) = \sum _ { j = 1 } ^ { n } | { \boldsymbol \alpha } _ { j } | ^ { 2 }$，因此  

$$
R ( \pmb { x } ) = \bigg ( \sum _ { j = i } ^ { n } \lambda _ { j } | \alpha _ { j } | ^ { 2 } \bigg ) \bigg / \bigg ( \sum _ { j = 1 } ^ { n } | \alpha _ { j } | ^ { 2 } \bigg ) .\tag{5}
$$  

由于 $\lambda _ { i } \leq \lambda _ { i + 1 } \leq \cdots \leq \lambda _ { n }$，显然对所有 $\alpha _ { i } , \alpha _ { i + 1 } , \ldots , \alpha _ { n }$（并非全为零），从而对所有非零的 $\pmb { x } \in \mathcal { C } _ { i } )$，均有 $R ( { \pmb x } ) \geq \lambda _ { i }$；且当 $\alpha _ { i } \neq 0$ 与 $\alpha _ { i + 1 } = \alpha _ { i + 2 } = \cdot \cdot \cdot = \alpha _ { n } = 0$ 时，有 $R ( \mathbf { x } ) = \lambda _ { i }$。于是关系式 (2) 得证。注意，$\mathscr { C } _ { i }$ 的极小化向量恰为 $\alpha _ { i } { \pmb x } _ { i }$，即对应于 $\lambda _ { i }$ 的一个特征向量。  

以下对偶结果可类似地证明。  

习题 1．在定理 1 的记号下，证明  

$$
\lambda _ { i } = \operatorname* { m a x } _ { \substack { 0 \neq x \in \mathcal { C } _ { n - i + 1 } } } R ( { \pmb x } ) , \qquad i = 1 , 2 , \ldots , n ,
$$  

其中最大值在 $ H $ 的特征向量上达到。 □
