**定理 3**．设函数 $ f(\lambda) $ 在点 $\lambda _ { 0 } \in \mathbb { C }$ 处具有泰勒级数展开  

$$
f ( \lambda ) = \sum _ { p = 0 } ^ { \infty } \alpha _ { p } ( \lambda - \lambda _ { 0 } ) ^ { p } ,\tag{5}
$$  

其收敛半径为 $ r $。若 $\ b { A } \in \mathbb { C } ^ { n \times n }$，则 $ f(A) $ 有定义，且由下式给出：  

$$
f ( A ) = \sum _ { p = 0 } ^ { \infty } \alpha _ { p } ( A - \lambda _ { 0 } I ) ^ { p }\tag{6}
$$  

当且仅当矩阵 $ A $ 的每个互异特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { s }$ 满足下列条件之一：  

(a) $| \lambda _ { k } - \lambda _ { 0 } | < r ;$；  

(b) $| \lambda _ { k } - \lambda _ { 0 } | = r$，且函数 $f ^ { ( m _ { k } - 1 ) } ( \lambda )$ 的级数（其中 $m _ { k }$ 是 $\lambda _ { k } )$ 的指数）在点 $\lambda = \lambda _ { k } , 1 \leq k \leq s$ 处收敛。

**证明**．首先我们回顾：$f ( A )$ 存在当且仅当 $f ^ { ( j ) } ( \lambda _ { k } )$ 对于 $j = 0 , 1 , \ldots , m _ { k } - 1$ 和 $k = 1 , 2 , \ldots , s .$ 存在。此外，由式 (5) 所定义的函数 $f ( \lambda )$ 在其收敛圆内部任意一点处具有任意阶导数，且这些导数可通过逐项微分 $f ( \lambda )$ 的幂级数而得到。因此，若对所有 $k = 1 , 2 , \ldots , s .$ 均有 $| \lambda _ { k } - \lambda _ { 0 } | < r$，则 $f ( \lambda )$ 显然在矩阵 $ A $ 的谱上被定义。再者，若对某个正整数 $ k $ 有 $\vert \lambda _ { k } - \lambda _ { 0 } \vert = r$，且将式 (5) 中的级数作 $m _ { k } \mathrm { ~ - ~ } 1$ 次逐项微分后所得级数在点 $\lambda = \lambda _ { k }$ 处收敛，则 $f ( \lambda _ { k } ) , f ^ { \prime } ( \lambda _ { k } ) , \ldots , f ^ { ( m _ { k } - 1 ) } ( \lambda _ { k } )$ 存在，从而 $f ( A )$ 被定义。注意，上述论证可从 $f ( A )$ 的存在性出发逆向进行。

若现在令 $u _ { p } ( \lambda ) = \alpha _ { p } ( \lambda - \lambda _ { 0 } ) ^ { p }$ 表示 $\begin{array} { r } { p = 0 , 1 , 2 , \ldots } \end{array}$，则 $u _ { p } ( \lambda )$ 必然在 $ A $ 的谱上被定义；并且在假设条件 (a) 或 (b) 下，级数 $\begin{array} { r } { \sum _ { p = 1 } ^ { \infty } u _ { p } ^ { ( j ) } ( \lambda _ { k } ) , k = 1 , 2 , \ldots , s , j = 0 , 1 , \ldots , \ldots 1 } \end{array}$ 均收敛。由此根据定理 2 可知：$\sum _ { p = 0 } ^ { \infty } u _ { p } ( A )$ 收敛，且其和为 $f ( A )$；反之亦然。
