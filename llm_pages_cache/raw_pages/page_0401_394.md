我们注意到，矩阵  R _ { z } $( \zeta$ )的元素是关于 $\zeta$ 的函数的有理表达式，而这些函数在 contour $ L $ 上的每一点 $ z $ 的某个邻域内关于 $ z $ 解析。因此，存在与 $\zeta$ 无关的矩阵  R _ { z } ^ { ( r ) } $, r = 1 , 2 , \ldots  $，使得  

$$

R _ { z } ( \zeta ) = R _ { z } + \zeta R _ { z } ^ { ( 1 ) } + \zeta ^ { 2 } R _ { z } ^ { ( 2 ) } + \cdots .\tag{2}
$$
  

利用 (1)，我们只需将该级数沿 contour $ L $ 逐项积分，即可得到本定理的第一个结论。只要每个系数  R _ { z } ^ { ( r ) } ~ ( r = 0 , 1 , 2 , . . . )  在 $ L $ 上可积，此项操作即为合法。由习题 9.9.3 可知，对固定的  z , ，有  

$$

R _ { z } ^ { ( 1 ) } ( \zeta ) = R _ { z } ( \zeta ) A ^ { ( 1 ) } ( \zeta ) R _ { z } ( \zeta ) ,\tag{3}
$$
  

从而对每个 $ r $，矩阵  R _ { z } ^ { ( r ) }  是形如  R _ { z } ( A ^ { ( p ) } R _ { z } ) ^ { s }  的矩阵的线性组合，其中整数  p ,  满足 $p \leq r$ 。由于  A ^ { ( p ) } ( 0 )  与 $ z $ 无关，且  R _ { z }  在  L  上关于  z  必然连续，故  R _ { z } ^ { ( r ) }  在 $ L $ 上连续。现在将  R _ { z } $( \zeta$ )的级数沿  L ,  积分，可得  

$$

{ \cal { Y } } ( \zeta ) = Z + \zeta C _ { 1 } + \zeta ^ { 2 } C _ { 2 } + \cdots ,
$$
  

其中  

$$

C _ { r } = \frac { 1 } { 2 \pi i } \int _ { L } R _ { z } ^ { ( r ) } d z , \qquad r = 1 , 2 , \ldots { . }
$$
  

现在， Y  $( \zeta$ )与 $A ( \zeta$ )均在 $\zeta = 0$ 的某个邻域内解析。因此，它们的乘积 $A ( \zeta ) Y ( \zeta$ )在该邻域内亦解析，且其泰勒展开式恰为 $A ( \zeta$ )与 $Y ( \zeta$ )_ { : }  各自泰勒展开式的乘积，定理得证。

一个类似的定理可以证明：若  A  $( \zeta$ )在 $\zeta = 0$ 处连续，则 $Y ( \zeta$ )与 $\zeta = 0$ 在 $ B $ 处也连续。
