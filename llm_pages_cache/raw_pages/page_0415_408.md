(a) $I f \mu \in { \mathcal { F } } , ( \mu A ) \otimes B = A \otimes ( \mu B ) = \mu ( A \otimes B )$；  
(b) $( A + B ) \otimes C = ( A \otimes C ) + ( B \otimes C )$；  
(c) $A \otimes ( B + C ) = ( A \otimes B ) + ( A \otimes C )$；  
(d) $A \otimes ( B \otimes C ) = ( A \otimes B ) \otimes C ;$。

**命题 2.** 若 $ A $、$ B $、$ C $、$ D $ 为适当维数的矩阵，则  

$$
( A \otimes B ) ( C \otimes D ) = A C \otimes B D .\tag{1}
$$  

**证明.** 记 $ A \otimes B = $B = [ a _ { i j } B ] _ { i , j = 1 } ^ { m } $, C \otimes D = [ c$ _ { i j } D ] _ { i , j = 1 } ^ { m } 。则 $( A \otimes B ) ( C \otimes D$ )的第 $ i,j $ 块为  

$$
F _ { i j } = \sum _ { k = 1 } ^ { m } ( a _ { i k } B ) ( c _ { k j } D ) = \sum _ { k = 1 } ^ { m } a _ { i k } c _ { k j } B D , \qquad { \mathrm { f o r } } \quad 1 \leq i , j \leq m .
$$  

另一方面，由克罗内克积（Kronecker product）的定义，有  A  $C \otimes B D =   [ \gamma$ _ { i j } B D ] _ { i , j = 1 } ^ { m } ，其中 $\gamma$ _ { i j }  是  A C  的第 $i , j \mathbf { t }$ 个元素，且由公式 $\begin{array} { r } { \gamma$ _ { i j } $= \sum$ _ { k = 1 } ^ { m } a _ { i k } c _ { k j } } $\end{array}$ 给出。因此，对所有可能的下标对  ( i , j ) , ，均有  F _ { i j } $= \gamma$ _ { i j } B D ，结论得证。

**系理 1.** 若 $ A $、$ B $、$ C $、$ D $ 为适当维数的矩阵，则
