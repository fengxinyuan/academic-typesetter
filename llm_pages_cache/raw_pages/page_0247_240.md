**证明**．一个矩阵是简单矩阵（simple matrix），当且仅当它相似于一个对角矩阵（参见定理 4.8.2′）。因此，结合习题 6.5.1 与定理 6.5.1 可知，其对应的若尔当（Jordan）矩阵必为对角矩阵，从而仅由 $1 \times 1$ 个若尔当块构成。于是，回溯命题 1 及前述讨论，该矩阵的各重数彼此一致。

接下来证明第二部分：一个特征值作为极小多项式之零点的重数（即该特征值的指数，index）等于与之关联的若尔当块的最大阶数（请回顾 (6.4.1) 式中 $ p $ 的含义）。这一观察即完成本定理的证明。

注意，在此情形下，该矩阵不具有任何非平凡的广义特征向量（proper generalized eigenvectors）。

**习题 1**．试证：若特征值 $\lambda _ { i }$ 的几何重数等于 1，则其若尔当矩阵中仅含一个与 $\lambda _ { i }$ 关联的若尔当块；且该块的阶数恰等于该特征值的代数重数。□

当习题 1 对矩阵的所有特征值均成立时，其极小多项式与特征多项式相等；反之亦然。

**习题 2**．验证：一个矩阵的极小多项式与特征多项式相等，当且仅当其若尔当矩阵中，每个互异特征值仅对应一个若尔当块。

**提示**：参见命题 2 的证明。□

若矩阵 $\pmb { A } \in \mathcal { F } ^ { { n } \times { n } }$ 的特征多项式与极小多项式相等，则称其为**非减次矩阵**（nonderogatory matrix）；否则称为**减次矩阵**（derogatory matrix）。因此，习题 2 揭示了非减次矩阵的结构特征。

**习题 3**．验证：任一友矩阵（companion matrix）均为非减次矩阵。
