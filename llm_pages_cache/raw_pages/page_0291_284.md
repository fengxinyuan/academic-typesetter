对于正规矩阵，其数值域的几何结构现可被简洁地刻画。下一命题中出现的“凸包”概念在附录 2 中定义并予以讨论。

定理 2．正规矩阵 $\ b { A } \in \mathbb { C } ^ { n \times n }$ 的数值域与其特征值的凸包重合。

证明．若 A 是正规矩阵，且其特征值为 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n } ,$，则由定理 5.2.1 可知，存在一个酉矩阵 $n \times n$ U，使得 $A = U D U ^ { * }$，其中 $D = \mathrm { d i a g } [ \lambda _ { 1 } , \lambda _ { 2 } , . . . , \lambda _ { n } ]$。此时，定理 1 断言 $F ( A ) = F ( D )$；因此，只需证明对角矩阵 D 的数值域与其主对角线上元素的凸包重合即可。

事实上，$F ( D )$ 是如下形式的数所构成的集合：  

$$
\alpha = ( D \mathbf { x } , \mathbf { x } ) = \sum _ { i = 1 } ^ { n } \lambda _ { i } | x _ { i } | ^ { 2 } ,
$$  

其中 $\begin{array} { r } { ( { \bf x } , { \bf x } ) = \sum _ { i = 1 } ^ { n } | x _ { i } | ^ { 2 } = 1 . } \end{array}$。

另一方面，根据附录 2 中习题 2，点集 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ 的凸包恰为如下集合：  

$$
\left\{ \sum _ { i = 1 } ^ { n } \theta _ { i } \lambda _ { i } \colon \theta _ { i } \geq 0 , \quad \sum _ { i = 1 } ^ { n } \theta _ { i } = 1 \right\} .
$$  

令 $\theta _ { i } = | x _ { i } | ^ { 2 } ( i = 1 , 2 , \dots , n )$，并注意到：当 x 取遍所有满足 $( { \pmb x } , { \pmb x } ) = { \ o 1 } ,$ 的向量时，$\theta _ { i }$ 取遍所有可能的取值，使得 $\theta _ { i } \geq 0 ,$ 且 $\sum _ { i } ^ { n } { \theta _ { i } } = 1$，由此即得所求结论。

对于一般的 $ n \times n $ 矩阵 $ A $，其谱中各点的凸包是 $ \text{$F ( A )$} $ 的一个子集（参见附录 2）。但对于埃尔米特矩阵这一特殊情形，其几何结构则呈现出优美的简化。

**定理 3.** 矩阵 $ \text{$\ b { A } $\in \mathbb { C } ^ { n \times n } } $ 的数值域是一条实轴上的区间，当且仅当 $ A $ 是埃尔米特矩阵。

**证明.** 首先，若 $ A $ 是埃尔米特矩阵，则 $ A $ 是正规矩阵；由定理 2 可知，$ F(A) $ 是 $ A $ 的特征值的凸包，而这些特征值全为实数（参见定理 5.3.1）。由于实轴上唯一的凸集即为区间，故所证结论成立。

反之，若 $ \text{$\ b { A } $\in \mathbb { C } ^ { n \times n } } $ 且 $ \text{$F ( A )$} $ 是实轴上的一个区间，则将

$$
\text{$$
 $B = \mathcal { H }  A = \frac 1 2 ( A + A ^ { * } ) , \ ~ C = \mathcal { I }$ _ { m } \  $A = \frac 1 { 2 i } ( A - A ^ { * } ) ,$ 
$$}
$$

代入，可得

$$
\text{$$
( A { $\pmb x } , { \pmb x } ) = ( ( B + i C ) { \pmb x } , { \pmb x } ) = ( B { \pmb x } , { \pmb x } ) + i ( C { \pmb x } , { \pmb x } ) ,$ 
$$}
$$

其中 $ \text{$( B { $\pmb x } , { \pmb x }$ )$} $ 与 $ \text{$( C { $\pmb x } , { \pmb x }$ )$} $ 均为实数，这是因为 $ B $ 与 $ C $ 均为埃尔米特矩阵（参见第 5.10 节）。但 $ \text{$F ( A )$} $ 仅包含实数，因此对所有满足 $ \text{$( { $\pmb x } , { \pmb x } ) = 1 } $ 的 $ x $，均有 $ \text{$( $C \pmb { x } , \pmb { x } ) = 0 } $。于是可得 $ \text{$C = O$} $（参见习题 3.13.2），进而 $ \text{$A = A ^ { * }$} $，从而 $ \text{$\mathbf { i s } , A$} $ 是埃尔米特矩阵。■
