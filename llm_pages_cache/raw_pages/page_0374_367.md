在结束从向量范数诱导矩阵范数这一思路之前，我们提出一个逆问题：给定一个矩阵范数 $\parallel \parallel .$，能否利用它来诱导出一个与之相容的向量范数？答案是肯定的；可通过如下方式定义 ∥·∥ₗ：

$$
\| \pmb { x } \| _ { \mathbf { v } } = \| \pmb { x } \pmb { a } ^ { \top } \|\tag{4}
$$  

其中 a 是某个固定的非零向量。

习题 12．设  

$$
A = \left[ { 3 / 2 \ - 1 / 2 } \atop { - 1 / 2 \ } \right] .
$$

利用习题11证明 $\left\| A \right\| _ { s } \leq 2$，并利用习题8证明 $\| A \| _ { s } = ( 5 + { \sqrt { 5 } } ) / 4 \simeq 1 . 8$。

习题13．考虑一个形如分块对角形式的 $n \times n$ 矩阵：$A = \mathrm { d i a g } [ A _ { 1 } \quad A _ { 2 } ]$，其中 $A _ { 1 }$ 和 $A _ { 2 }$ 均为方阵。证明：在谱范数意义下，

$$
\| A \| = \operatorname* { m a x } ( \| A _ { 1 } \| , \| A _ { 2 } \| ) .
$$

习题14．设 $A \in \mathbb { C } ^ { n \times n }$，并考虑如下形式的埃尔米特矩阵：

$$
H = \biggl [ \begin{array} { c c } { { 0 } } & { { i A \biggr ] } } \\ { { - i A ^ { * } } } & { { \theta \biggr ] . } } \end{array}
$$

证明：在谱范数意义下，$\| H \| = \| A \|$。□

## 10.5 绝对向量范数与矩阵的下界

我们在习题中所引入的几乎所有向量范数，都仅依赖于向量自变量各分量的绝对值。这类范数称为**绝对向量范数**（absolute vector norms）。迄今为止我们所发展的范数一般理论，并未假定这一性质必然成立。本节第一部分将专门用于证明绝对向量范数的两条基本性质。

我们将要建立的绝对向量范数的一个性质称为**单调性**。记 $ \mathbf{|x|} $ 为向量，其各分量是向量 $ \mathbf{x} $ 对应分量的绝对值；若 $ \mathbf{x}, \mathbf{y} \in \mathbb{C}^n $，我们称 $ \mathbf{x} \le \mathbf{y} $，当且仅当该不等式对 $ \mathbf{x} $ 与 $ \mathbf{y} $ 的对应分量均成立。定义在 $ \mathbb{C}^n $ 上的向量范数 $ \|\cdot\| $ 称为**单调的**，若对任意向量 $ \mathbf{x}, \mathbf{y} \in \mathbb{C}^n $，只要 $ |\mathbf{x}| \le |\mathbf{y}| $，就有 $ \|\mathbf{x}\| \le \|\mathbf{y}\| $。
