习题 5．对下列每个标量多项式：$L _ { 1 } ( \lambda ) =$、$( \lambda - \lambda _ { 0 } ) ^ { l }$ 和 $L _ { 2 } ( \lambda ) = ( \lambda - \lambda _ { 1 } ) ^ { p } ( \lambda - \lambda _ { 2 } ) ^ { q }$，分别求其若尔当对，其中 $\lambda _ { 1 } \neq \lambda _ { 2 }$ 与 $p , q$ 均为正整数。

现在假设  ( X , J , Y )  是 $ L(\lambda) $ 的一个若尔当三元组（Jordan triple）。其中 $ X $ 与 $ J $ 的角色是明确的，但矩阵 $ Y $ 又作何解释？它在谱数据意义上的含义可由推论 14.2.1 得出：该推论指出， ( Y ^ { $\mathsf { T } } , J ^ { \mathsf { T } } , X ^ { \mathsf { T } }$ )是  L ^ { $\operatorname { T } } ( \lambda$ )的一个标准三元组（standard triple）。注意，这并非一个若尔当三元组，因为线性化  J ^ { $\boldsymbol { \mathsf { T } } }  $ 是若尔当形的转置，因而一般而言其自身并不处于若尔当形。为将其化为若尔当形，我们引入矩阵  

$$
P = \mathrm { d i a g } [ P _ { 1 } , P _ { 2 } , . . . , P _ { s } ] ,
$$  

其中  P _ { j }  是  n _ { j } $\times n$ _ { j }  阶旋转矩阵（rotation matrix）：  

$$
P _ { j } = { \left[ \begin{array} { l l l l } { 0 } & { \cdots } & { 0 } & { 1 } \\ { \vdots } & { \cdots } & { \cdot } & { 1 } & { 0 } \\ { 0 } & { 1 } & { \cdot } & { \cdot } & { \vdots } \\ { 1 } & { 0 } & { \cdots } & { 0 } \end{array} \right] } .
$$  

（回顾一下， J  $= \mathrm { d i a g } [ J$ _ { 1 } $, \dots , J$ _ { s } ] ，其中  J _ { j }  的阶数为  n _ { j } . ) 。注意  P ^ { 2 } = I （从而  P ^ { - 1 } = P )  且  P ^ { * } = P ）。容易验证：对每个 $ j $，均有  P _ { j } J _ { j } ^ { $\mathrm { T } } P$ _ { j } = J _ { j } ，因此  P J ^ { $\boldsymbol { \mathsf { T } } } P = J  $。现考虑如下相似变换：  

$$
Y ^ { \mathrm { T } } P , \qquad J = P J ^ { \mathrm { T } } P , \qquad P X ^ { \mathrm { T } }
$$

对 $( Y ^ { \boldsymbol { \mathsf { T } } } , J ^ { \boldsymbol { \mathsf { T } } } , X ^ { \boldsymbol { \mathsf { T } } } )$ 进行化简，可得到 $L ^ { \operatorname { T } } ( \lambda )$ 的一个标准三元组，其中中间项为若尔当（Jordan）型。因此，$( Y ^ { \mathsf { T } } P , J , P X ^ { \mathsf { T } } )$ 是 $L ^ { \operatorname { T } } ( \lambda )$ 的一个若尔当三元组，而我们关于若尔当对（Jordan pairs）的讨论可用于刻画矩阵 $ Y $。于是，将 $ Y $ 按如下形式分块：

$$
Y = { \left[ \begin{array} { l } { Y _ { 1 } } \\ { Y _ { 2 } } \\ { \vdots } \\ { Y _ { s } } \end{array} \right] } ,
$$

其中 $Y _ { j }$ 是 $n _ { j } \times n$ 阶的，对应于 $j = 1 , 2 , \dots , s .$。则有 $\boldsymbol { Y } ^ { \mathrm { T } } \boldsymbol { P } = [ Y _ { 1 } ^ { \mathrm { T } } \boldsymbol { P } _ { 1 } \quad \cdot \cdot \cdot \quad Y _ { s } ^ { \mathrm { T } } \boldsymbol { P } _ { s } ]$，且由此可知：对每个 $j ,$，将 $Y _ { j }$ 的转置行向量按逆序排列，即构成 $L ^ { \mathbb { T } } ( \lambda )$ 的一个长度为 $n _ { j }$ 的左若尔当链（left Jordan chain），该链对应于特征值 $\lambda _ { j }$。

这类若尔当链称为 $L ( \lambda ) ,$ 的左若尔当链；而 $L ( \lambda )$ 的左隐向量（left latent vectors）是指属于 $ \operatorname{Ker} \, \text{$L ^ { $\mathsf { T } } ( \lambda$ _ { j } $) , j = 1 , 2 , \ldots , \bar { s } . } $ 的非零向量。因此，左若尔当链的首项（即链中第一个向量）恰为左隐向量。
