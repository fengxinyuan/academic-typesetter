## 15.1 不可约矩阵

可约性（reducibility）这一概念在本章中占据重要地位。该概念最早在第10.7节中引入；建议读者再次回顾该节中的相关讨论。本节将着重强调可约性概念的组合结构方面。

值得注意的是，可约性这一概念与矩阵元素的大小或符号毫无关联，而仅取决于零元素与非零元素在矩阵中的分布位置。这一思想在“矩阵所对应的有向图”（directed graph associated with a matrix）这一概念中得到系统发展；我们仅需迈出该理论的第一步，即可在定理1中获得不可约矩阵的第二种刻画。

设 $P _ { 1 } , P _ { 2 } , \ldots , P _ { n }$ 为复平面上互异的点，且令 $A \in \mathbb { C } ^ { n \times n }$。对矩阵 A 的每一个非零元素 $a _ { i j }$，连接点 $P _ { i }$ 到点 $P _ { j }$，并作一条有向线段 $\overline { { \boldsymbol { P } _ { i } \boldsymbol { P } _ { j } } }$。由此在复平面上所得的图形即为矩阵 A 的一个有向图。我们在图15.1中以一个 $3 \times 3$ 矩阵及其对应的有向图为例予以说明。

$$
\begin{array} { r } { \left[ 1 - 2 0 \right] } \\ { 0 4 2 } \\ { 1 - 1 0 } \end{array}
$$

若对有向图中任意两个节点 $P _ { i } , P _ { j }$（其中 $i \neq j ,$），均存在一条从 $P _ { i }$ 指向 $P _ { j }$ 的有向路径  

$$
\overrightarrow { P _ { i } P _ { k _ { 1 } } } , \overrightarrow { P _ { k _ { 1 } } P _ { k _ { 2 } } } , \dotsc , \overrightarrow { P _ { k _ { r - 1 } } P _ { j } }
$$  

则称该有向图为强连通的（strongly connected）。此处，该路径由 r 条有向线段组成。

注意：节点 i 与 j 之间可能存在一条有向路径，但 j 与 i 之间却未必存在。
