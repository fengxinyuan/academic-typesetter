最后，我们来证明矩阵范数的次乘性性质（10.3.1）。由习题 1(b) 可知：对给定矩阵 $ A $，存在一个向量 $ \mathbf{x} $ 满足 $ \|\mathbf{x}\| = 1 $，使得  
$$
\|A\mathbf{x}\| = \|A\|.
$$  
于是  

$$
f ( A B ) = \| A B \mathbf { x } _ { 0 } \| _ { \mathbf { v } } = \| A ( B \mathbf { x } _ { 0 } ) \| _ { \mathbf { v } } \leq f ( A ) \| B \mathbf { x } _ { 0 } \| _ { \mathbf { v } } ,
$$  

这是因为，由式 (1) 可得  

$$
\| A x \| _ { \mathbf { v } } \leq f ( A ) \| x \| _ { \mathbf { v } }\tag{3}
$$  

对所有非零向量 $ \mathbf{x} $ 及任意矩阵 $ A $ 均成立。再次利用式 (3)（此处应用于矩阵 $ B $），我们有  

$$
f ( A B ) \leq f ( A ) \| B \mathbf { x } _ { 0 } \| _ { \mathbf { v } } \leq f ( A ) f ( B ) \| \mathbf { x } _ { 0 } \| _ { \mathbf { v } } = f ( A ) f ( B ) ,
$$  

从而性质 (10.3.1) 得证。定理的第 (a) 部分因而成立，故可记为  
$f ( A ) = \left\| A \right\|$  

注意，定理的第 (b) 部分即为关系式 (3) 本身。对于第 (c) 部分，设元素 $ \mathbf{x} $ 如习题 1(b) 中所定义，则对任一与向量范数 $ \|\cdot\| $ 相容的矩阵范数，均有  

$$
\| A \| = f ( A ) = \| A \pmb { x } _ { 0 } \| _ { \mathbf { v } } \leq \| A \| _ { 1 } \| \pmb { x } _ { 0 } \| _ { \mathbf { v } } = \| A \| _ { 1 } ,
$$  

其中 $ \|\cdot\| $ 为给定的向量范数。

习题 3．令 $N _ { n } \in \mathbb { C } ^ { n \times n }$ 表示一个矩阵，其在第 $i$ 行、第 $i+1$ 列的位置（即 $(i,i+1)$ 位置）上为 1，其余位置均为 0。验证存在相应的诱导矩阵范数，使得  

$$
\mathrm { ( a ) } \quad \| N _ { n } \| = n ; \qquad \mathrm { ( b ) } \quad \| N _ { n } \| = 1 ; \qquad \mathrm { ( c ) } \quad \| N _ { n } \| < 1 .
$$  

提示：对第 (a) 小题，考虑习题 10.2.1 中定义的向量范数；对第 (b) 和 (c) 小题，则分别考虑如下范数  

$$
\| { \pmb x } \| _ { \mathfrak { v } } = \biggl ( \frac { 1 } { k } \biggr ) ^ { n - 1 } | x _ { 1 } | + \biggl ( \frac { 1 } { k } \biggr ) ^ { n - 2 } | x _ { 2 } | + \cdots + \frac { 1 } { k } | x _ { n - 1 } | + | x _ { n } |
$$  

其中 $k = 1$，$k > 1$。□  

在接下来的习题中所讨论的诱导矩阵范数，是矩阵范数中最重要且最有用的一类。特别地，由欧几里得向量范数所诱导的矩阵范数称为**谱范数**（spectral norm），它很可能是矩阵分析中应用最广泛的范数。
