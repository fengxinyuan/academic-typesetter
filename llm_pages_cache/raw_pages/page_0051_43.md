习题 2．验证：对任意 $ n \times n $ 矩阵 $ A $ 以及任意 $k \in \mathcal { F }$

$$
\begin{array} { r l } & { \mathrm { { a d j } } ( A ^ { \mathrm { T } } ) = ( \mathrm { a d j } A ) ^ { \mathrm { T } } , } \\ & { { \mathrm { a d j } } ( A ^ { * } ) = ( \mathrm { a d j } A ) ^ { * } , } \\ & { \quad \mathrm { { a d j } } I = I , } \\ & { \mathrm { { a d j } } ( k A ) = k ^ { n - 1 } \mathrm { a d j } A . \quad \bigtriangledown } \end{array}
$$  

以下这一引人注目的结论及其推论，正是人们关注矩阵伴随矩阵（adjoint）的主要原因。  

**定理 1.** 对任意 $n \times n$ 阶矩阵 $ A $，有  

$$
A ( \operatorname { a d j } A ) = ( \operatorname* { d e t } A ) I .\tag{1}
$$  

**证明.** 利用行展开公式（2.3.1）及习题 2.3.3 的结果计算左边的乘积，可得一个矩阵：其主对角线上每个位置的元素均为 $ \det A $，其余位置均为零，即该乘积等于 $ (\det A)I $。  

**习题 3.** 证明：  

$$
( \operatorname { a d j } A ) A = ( \operatorname* { d e t } A ) I . \quad \varsquare\tag{2}
$$  

**定理 1** 具有一些重要推论。例如，若 $ A $ 是 $n \times n$ 阶矩阵且 $ \det\, \text{$A  $\neq 0 , } $，则  

$$
\operatorname* { d e t } ( \operatorname { a d j } A ) = ( \operatorname* { d e t } A ) ^ { n - 1 } .\tag{3}
$$  

事实上，利用行列式性质 $ \det\, \text{$A  $B = ( \operatorname* { d e t } A ) ( \operatorname* { d e t } B$ )$} $、式 (1) 以及对角矩阵行列式的已知结果，即可推出该结论。  

$ \det A $ 是否为零，是方阵的一项极为关键的性质，因而值得专门定义：一个方阵 $ A $ 称为**奇异的**（singular）或**非奇异的**（nonsingular），当且仅当 $ \det A = 0 $ 或 $ \det A \neq 0 $。
