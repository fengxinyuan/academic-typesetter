**证明**．设 $ \lambda $ 是 $ A $ 的一个特征值，且满足 $\mu _ { A } = | \lambda |$．则存在非零向量 $\pmb { x } \neq \pmb { \theta }$，使得 $A { \boldsymbol { \mathbf { x } } } = \lambda { \boldsymbol { \mathbf { x } } }$．定义 $n \times n$ 矩阵  

$$
A _ { x } = [ { \pmb x } \quad { \pmb \theta } \quad { \pmb \theta } \quad \cdots \quad { \pmb \theta } ]
$$  

并注意到  

$$
A A _ { x } = \lambda A _ { x } .
$$

$A \in \mathbb { C } ^ { n \times n } \mu _ { A }$



利用范数的第二条公理及矩阵范数的性质 (1)，我们可推出  

$$
| \lambda | \ \| A _ { x } \| \leq \| A \| \ \| A _ { x } \| ,
$$  

由于 $A _ { x } \neq \theta ,$，故有 $\| A _ { x } \| \neq 0$，从而  

$$
| \lambda | = \mu _ { A } \leq \| A \| . \quad \overline { { \mathbb { I } } }
$$  

我们常常需要求解如下形式向量的范数：$A { \boldsymbol { \mathbf { \mathit { x } } } } ,$，其中 $A \in \mathbb { C } ^ { n \times n }$ 且 $\boldsymbol { x } \in \mathbb { C } ^ { n }$。借鉴矩阵范数性质 (1) 的经验，我们自然会猜测：存在某些矩阵范数 $\parallel \parallel$ 与向量范数 ∥·∥（即定义在 $\mathbb { C } ^ { n } )$ 上的范数），使得  

$$
\left\| A \pmb { x } \right\| _ { \mathbf { v } } \leq \left\| A \right\| \left\| \pmb { x } \right\| _ { \mathbf { v } } .\tag{4}
$$  

当式 (4) 对所有 $\boldsymbol { x } \in \mathbb { C } ^ { n }$ 及所有 $A \in \mathbb { C } ^ { n \times n }$ 均成立时，则称该向量范数 ∥·∥ 与矩阵范数  相容（compatible）。  

习题 9．证明欧几里得矩阵范数与欧几里得向量范数是相容的。  

解．对任意 $\pmb { x } = [ { \alpha } _ { 1 } \quad { \alpha } _ { 2 } \quad \cdots \quad { \alpha } _ { n } ] ^ { \mathsf { T } } \in \mathbb { C } ^ { n }$ 及  

$$
\begin{array} { r } { A = [ \boldsymbol { a } _ { i j } ] _ { i , j = 1 } ^ { n } \in \mathbb { C } ^ { n \times n } , } \end{array}
$$

计算 $A { \bf x } = [ \beta _ { 1 } \mathrm { ~  ~ \nabla ~ } \beta _ { 2 } \mathrm { ~  ~ \cdot ~ } \cdot \mathrm { ~  ~ \nabla ~ } \beta _ { n } ] ^ { \bf T }$，其中 $\begin{array} { r } { \beta _ { i } = \sum _ { j = 1 } ^ { n } a _ { i j } \alpha _ { j } , i = 1 , 2 , . . . , n . } \end{array}$。因此，由式 (3) 对于 $p = 2 , q = 2 ,$ 可得  

$$
\| A \pmb { x } \| _ { \mathbb { V } } ^ { 2 } = \sum _ { i = 1 } ^ { n } | \beta _ { i } | ^ { 2 } = \sum _ { i = 1 } ^ { n } \bigg | \sum _ { j = 1 } ^ { n } a _ { i j } \alpha _ { j } \bigg | ^ { 2 } \leq \sum _ { i = 1 } ^ { n } \bigg ( \sum _ { j = 1 } ^ { n } | a _ { i j } | ^ { 2 } \bigg ) \bigg ( \sum _ { j = 1 } ^ { n } | \alpha _ { j } | ^ { 2 } \bigg ) .
$$  

最后，由于 $\textstyle \| A \| _ { \mathrm { E } } ^ { 2 } = \sum _ { i , j = 1 } ^ { n } | a _ { i j } | ^ { 2 }$ 且 $\begin{array} { r } { \| \mathbf { x } \| _ { \mathrm { v } } ^ { 2 } = \sum _ { j = 1 } ^ { n } | \alpha _ { j } | ^ { 2 } } \end{array}$，我们有  

$$
\begin{array} { r } { \| A { \mathbf { x } } \| ^ { 2 } \leq \| A \| _ { \mathrm { E } } ^ { 2 } \| { \mathbf { x } } \| ^ { 2 } , } \end{array}
$$  

该式等价于式 (4)。
