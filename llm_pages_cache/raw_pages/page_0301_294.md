## 8.5 瑞利定理与定正矩阵

设 $ H $ 是一个 $n \times n$ 阶埃尔米特矩阵， H _ { n - r }  是 $ H $ 的一个 $( n - r ) \times ( n - r )$ 阶主子矩阵，且 $1 \leq r < n  $。以下结果可视作定理 8.4.1 的一个特例。

**定理 1（瑞利）**：若  \lambda _ { 1 } $\leq \lambda$ _ { 2 } $\leq \cdots \leq \lambda$ _ { n }$ - r $ 是  H _ { n - r }  的特征值，而 $\mu$ _ { 1 } $\leq \mu$ _ { 2 } $\leq \cdot \cdot \cdot \leq \mu$ _ { n }  是 $ H $ 的特征值，则对  i = ，有  
$1 , 2 , \ldots , n - r ,$  

$$
\mu _ { i } \leq \lambda _ { i } \leq \mu _ { i + r } .\tag{1}
$$  

**证明**：若  H _ { n - r }  并非 $ H $ 的第 $( n - r ) \times ( n - r$ )个顺序主子矩阵，则我们可选取一个置换矩阵 $ P $，使得在变换后的矩阵  P ^ { $\boldsymbol { \mathsf { T } } } H P$ 中，它处于该位置。由于  P ^ { - 1 } = P ^ { $\mathsf { T } }$ ，矩阵  P ^ { $\boldsymbol { \mathsf { T } } } H P$ 与 $ H $ 具有相同的谱，因此不失一般性，可假设  H _ { n - r }  即为 $ H $ 的第 $( n - r ) \times ( n - r$ )  个顺序主子矩阵。

根据前一节末尾的评注， H _ { n - r }  的特征值对应于一个带有 $ r $ 个约束条件的  C H C ^ { * }  的特征值问题，其中 $ C $ 为某个酉矩阵。这一结论亦可直接由易验证的关系式  B ^ { * } ( C H C ^ { * } ) ~ B = H _ { n - r }  推出。应用定理 8.4.1，即得所求结论。

$$
\tilde { \mu } _ { i } \leq \lambda _ { i } \leq \tilde { \mu } _ { i + r } , \qquad i = 1 , 2 , \ldots , n - r ,
$$  

其中，$\tilde { \mu } _ { 1 } , \tilde { \mu } _ { 2 } , \ldots , \tilde { \mu } _ { n }$ 是 $C H C ^ { * }$ 的特征值。现只需注意到：由于 $ C $ 是酉矩阵，故有 $\tilde { \mu } _ { j } = \mu _ { j } \mathrm { f o r } j = 1 , 2 , \ldots , n$，从而证毕。
