**定理 4.** 方程 (1) 的任一解 $ x(t) $ 均可表示为形式 ${ \bf \boldsymbol { x } } ( t ) = e ^ { \boldsymbol { A } t } { \bf \boldsymbol { z } }$，其中 $z \in \mathbb { C } ^ { n }$ 为某个适当选取的向量（或矩阵，依上下文而定）。

值得注意且意义深远的是：定理 1 中所有繁复的技术细节，均可被简化并统摄于定理 4 这一简洁陈述之中。这充分彰显了本章所发展的“函数演算”（functional calculus）的强大威力。

另一类关于方程 (1) 解的表示式，可通过在定理 9.5.1 中取 $f ( \lambda ) = e ^ { \lambda }$，并结合 $e ^ { A t }$ 的谱分解（spectral resolution）而导出。因此，记 ${ \bf { x } } ( 0 ) = { \bf { x } } _ { 0 }$，我们利用定理 3 推得  

$$
\qquad \mathbf { x } ( t ) = \sum _ { k = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } Z _ { k j } t ^ { j } e ^ { \lambda _ { k } t } \pmb { x } _ { 0 } = \sum _ { k = 1 } ^ { s } ( z _ { k 0 } + z _ { k 1 } t + \cdot \cdot \cdot + z _ { k , m _ { k } - 1 } t ^ { m _ { k } - 1 } ) e ^ { \lambda _ { k } t } ,
$$

其中，$z _ { k j } = Z _ { k j } \mathbf { x } _ { 0 }$ 且与 $ t $ 无关。因此，我们再次看到：解是关于 $ t $ 的多项式与指数函数的线性组合。若 $ A $ 是一个可对角化矩阵（即单矩阵），则解简化为  

$$
{ \bf { x } } ( t ) = \sum _ { k = 1 } ^ { s } z _ { k 0 } e ^ { \lambda _ { k } t } ,
$$  

此时可见，$x ( t )$ 的每个元素均为指数函数的线性组合，不含任何多项式项（参见第 4.13 节）。
