定理 2．对任意 $b _ { 1 } , b _ { 2 } , \ldots , b _ { n } \in { \mathcal { S } } ,$，

$$
\dim ( \operatorname { s p a n } \{ b _ { 1 } , b _ { 2 } , \dotsc , b _ { n } \} ) = \operatorname { r a n k } A ,\tag{8}
$$

其中 A 是线性变换 $\mathbf { b } _ { 1 } , \mathbf { b } _ { 2 } , \ldots , \mathbf { b } _ { n }$ 关于 $\mathcal { S }$ 中某组基的矩阵表示。

习题 2．证明：任取 m 维空间中一组 m 个线性无关的元素，其关于该空间另一组基 $\mathcal { S }$ 的矩阵表示是一个 m × m 非奇异矩阵。

提示：利用习题 2.8.2 的结论。

由式 (8) 可知，对固定集合 $\{ \mathbf { b } _ { 1 } , . . . , \mathbf { b } _ { n } \}$ 的所有不同基下的矩阵表示，其秩均相等。因此（参见第 2.8 节），所有这些矩阵彼此等价。这一结论将在第 3.9 节中详加讨论——但需先作若干必要准备；而定理 1 的若干重要推论则将在下一节中先行指出。

## 3.8 与秩相关的一些矩阵性质

设 A 是 ${ \mathcal { F } } ^ { m \times n }$ 中的一个矩阵。由习题 2.8.2 及推论 3.7.1 可知，若 $m = n$ 且 A 是非奇异矩阵，则  
rank $A = n ,$，  
Ker $A = \{ \pmb { \theta } \}$，  
从而当 det $A \neq 0 ,$ 时……

$$
\operatorname { r a n k } A + \dim ( \operatorname { K e r } A ) = n .
$$  

该关系事实上对任意 $ m \times n $ 矩阵均成立。  

**命题 1.** 对任意  A  $\in F ^ { m \times n }  $，有  

$$
\operatorname { r a n k } A + \dim ( \operatorname { K e r } A ) = n .\tag{1}
$$  

**证明.** 设 $ \operatorname{rank} $A = r ，且不失一般性，假设 $ A $ 左上角的 $r \times r$ 阶子矩阵 $\pmb { A }$ _ { 1 1 }  是非奇异的：†  

$$
A = { \left[ \begin{array} { l l } { A _ { 1 1 } } & { A _ { 1 2 } } \\ { A _ { 2 1 } } & { A _ { 2 2 } } \end{array} \right] } ,
$$  

其中  A _ { 1 1 } $\in { \mathcal { F } } ^ { r \times r }$ ，且 $ \det $A _ { 1 1 } $\neq 0 .$ 。根据定理 2.7.4，给定矩阵 $ A $ 可经初等变换化为如下形式：  

$$
\begin{array} { r } { \widetilde { A } = \left[ \begin{array} { l l } { I _ { r } } & { { \cal O } } \\ { { \cal O } } & { { \cal O } } \end{array} \right] = { \cal P } ^ { - 1 } A { \cal Q } ^ { - 1 } , } \end{array}\tag{2}
$$  

其中 $ P $ 与 $\pmb { Q }$ 分别为 $ m \times m $ 与 $\textbf { \em n } \times \textbf { \em n }  $ 阶可逆矩阵。
