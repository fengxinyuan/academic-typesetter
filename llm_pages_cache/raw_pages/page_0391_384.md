**证明**．定理 10.3.1 表明，对矩阵 $ A $ 的任一特征值 $ \lambda $，均有  
$\lambda _ { 0 }$  是 $ A $ 的特征值，且满足  
$M , \vert \lambda _ { 0 } \vert \leq \| M \| < 1$．  
此外，由  
$f ( \lambda ) = ( 1 + \lambda ) ^ { - 1 }$  
所定义的函数 $ f $ 在点  
$\lambda = 0$  
处具有幂级数展开式，其收敛半径等于 1．因此（参见定理 9.8.3），极限  
$f ( M ) = ( I + M ) ^ { - 1 }$  
存在，且  

$$
( I + M ) ^ { - 1 } = I - M + M ^ { 2 } - \cdots .
$$  

若记  
$S _ { v } = I - M + M ^ { 2 } - \cdot \cdot \cdot \pm M ^ { p - 1 }$

$\| M ^ { r } \| \leq \| M \| ^ { r }$，  
则可得  

$$
\| S _ { p } \| \leq \sum _ { k = 1 } ^ { p - 1 } \| M ^ { k } \| \leq \sum _ { k = 1 } ^ { p - 1 } \| M \| ^ { k } = \frac { 1 - \| M \| ^ { p } } { 1 - \| M \| } \leq \frac { 1 } { 1 - \| M \| } .
$$

$p ,$  
无关，故令  
$p  \infty$
