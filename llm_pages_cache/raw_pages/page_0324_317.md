当面临求解矩阵  Z _ { k j }  的问题时，最直接的方法是：首先构造插值多项式 $\varphi$ _ { k j } $( \lambda$ )，再令  Z _ { k j } $= \varphi$ _ { k j } ( A ) 。然而，多项式 $\varphi$ _ { k j } $( \lambda$ )  的具体计算可能极为繁复；以下习题则提示了一种规避该计算的途径。  

例 3（参见习题 6.2.4、6.5.2 与 9.4.1）：我们希望求出矩阵  

$$
A = { \left[ \begin{array} { l l l } { 6 } & { 2 } & { 2 } \\ { - 2 } & { 2 } & { 0 } \\ { 0 } & { 0 } & { 2 } \end{array} \right] } .
$$  

的分量矩阵。

我们还希望利用定理 1 来计算 $\ln A$。我们已知矩阵 $A$ 的极小多项式为 $( \lambda - 2 ) ( \lambda - 4 ) ^ { 2 }$，因此，对任意在 $A$ 的谱上定义的函数 $f$，定理 1 给出  

$$
f ( A ) = f ( 2 ) Z _ { 1 0 } + f ( 4 ) Z _ { 2 0 } + f ^ { ( 1 ) } ( 4 ) Z _ { 2 1 } .\tag{7}
$$  

我们代入三个精心选取的线性无关多项式作为 $f(\lambda)$，并求解由此得到的联立方程组，以确定 $Z _ { 1 0 } , Z _ { 2 0 }$、2 和 $Z _ { 2 1 }$。具体地，依次取 $f ( \lambda ) = 1 , f ( \lambda ) = \lambda - 4$ 和 $f ( \lambda ) = ( \lambda - 4 ) ^ { 2 }$，可得  

$$
Z _ { 1 0 } + Z _ { 2 0 } = I ,
$$

- 2 Z _ { 1 0 } + Z _ { 2 1 } = A - 4 I = { $\left[$ 

$$
\begin{array} { r r r } { 2 } & { 2 } & { 2 } \\ { - 2 } & { - 2 } & { 0 } \\ { 0 } & { 0 } & { - 2 } \end{array}
$$
 $\right] } ,$ 
$$

4 Z _ { 1 0 } = ( A - 4 I ) ^ { 2 } = { \left[ 0 \begin{array} { l l l } { 0 } & { 0 } & { 0 } \\ { 0 } & { 0 } & { - 4 } \\ { 0 } & { 0 } & { 4 } \end{array} \right] } .
$$  

这些方程易于求解，解得  

$$
Z _ { 1 0 } = { \left[ \begin{array} { l l l } { 0 } & { 0 } & { 0 } \\ { 0 } & { 0 } & { - 1 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } , \qquad Z _ { 2 0 } = { \left[ \begin{array} { l l l } { 1 } & { 0 } & { 0 } \\ { 0 } & { 1 } & { 1 } \\ { 0 } & { 0 } & { 0 } \end{array} \right] } , \qquad Z _ { 2 1 } = { \left[ \begin{array} { l l l } { 2 } & { 2 } & { 2 } \\ { - 2 } & { - 2 } & { - 2 } \\ { 0 } & { 0 } & { 0 } \end{array} \right] } .
$$  

相比之下，直接依据定义 $$Z _ { 2 0 } = \varphi _ { 2 0 } ( A )$$ 计算某个分量矩阵（例如 $$Z _ { 2 0 }$$）则更为繁琐。若尝试寻求一个次数不超过 2 的多项式 $$\varphi _ { 2 0 } ( \lambda )$$，使其满足……

$$
\varphi _ { 2 0 } ( 2 ) = 0 , \qquad \varphi _ { 2 0 } ( 4 ) = 1 , \qquad \varphi _ { 2 0 } ^ { \prime } ( 4 ) = 0 ,\tag{8}
$$
