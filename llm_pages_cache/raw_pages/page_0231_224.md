## 6.2 极小多项式

显然，一个固定的线性变换 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 具有多个零化多项式。同样显然的是，对于一个固定的 $ T $，其所有零化多项式的次数存在一个下界。自然地，我们希望寻求一个首一的、次数尽可能小的零化多项式，称之为 $ T $ 的**极小多项式**（minimal polynomial），记作 $m _ { T } ( \lambda )$，或简记为 $ m(\lambda) $。接下来将证明：$ T $ 的所有零化多项式之集按其次数构成一个“良序集”（well ordered），因此极小多项式是唯一的。

**定理 1.** $ T $ 的极小多项式 $T \in { \mathcal { L } } ( { \mathcal { S } } )$ 整除 $ T $ 的任意其他零化多项式。
