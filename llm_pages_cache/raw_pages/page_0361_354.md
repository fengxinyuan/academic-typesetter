## 10.2 向量范数作为度量：收敛性

在第 10.1 节中，我们强调范数的重要性，首先在于它作为赋范线性空间中元素“大小”的度量工具；其次，范数同样极为重要地充当一种“距离”的度量。因此，若 $\mathcal { S } , \Vert \mathbf { \Sigma } \Vert$ 是一个赋范线性空间，则对任意 $\mathbf { \Delta } _ { \mathbf { { x } } , \mathbf { \Delta } \mathbf { { y } } \in \mathcal { S } }$，量 $\| { \pmb x } - { \pmb y } \|$ 被视为点 $x$ 与 $y$ 之间的距离度量。特别地，当取 $$\mathbb { R } _ { 3 } \left( \mathrm { o r } \mathbb { R } _ { 2 } \right)$$ 并赋予欧几里得范数时，便得到最常见、最直观的物理意义下的距离度量。

(a) $\| { \pmb x } - { \pmb y } \| \geq 0$，且等号成立当且仅当 ${ \bf y } = { \bf x }$；

(b) $\| { \pmb x } - { \pmb y } \| = \| { \pmb y } - { \pmb x } \| ;$。
