## 11.2 简单矩阵特征值的扰动

我们现在研究简单矩阵 $ A $ 的特征值关于其元素的依赖性问题。本节的结果本质上归功于 F. L. 巴尔（F. L. Bauer）与 A. S. 豪斯霍尔德（A. S. Householder）。†

设 $ A $ 是一个单矩阵（即其最小多项式无重因式），其特征值为 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$。若 $D =$ 与对角矩阵 $[ \lambda _ { 1 } , . . . , \lambda _ { n } ]$ 相似，即 $D =  \sim \operatorname{diag}  [ \lambda _ { 1 } , . . . , \lambda _ { n } ]$，则存在一个非奇异矩阵 $ P $，使得 $A = P D P ^ { - 1 }$。在定理 10.5.1 中，我们已能刻画一类在应用于对角矩阵时具有良好性质的矩阵范数；因此，自然引出利用 $\| D \|$ 来估计 $\| A \|$ 的思想（针对此类范数）。于是，若 $ \|\cdot\| $ 是由某个绝对向量范数所诱导的矩阵范数，则等式 $A =$ 与 $P D P ^ { - 1 }$，以及定理 10.5.1 推出：

$$
\| A \| \leq \kappa ( P ) \operatorname* { m a x } _ { 1 \leq j \leq n } | \lambda _ { j } | ,
$$

其中 $\kappa ( P ) = \| P \| \ \| P ^ { - 1 } \|$ 是矩阵 $ P $ 关于范数 $\parallel \parallel .$ 的条件数，其定义见第 1 节。然而，如习题 6.5.4 所示，满足方程 $A = P D P ^ { - 1 }$ 的矩阵 $ P $ 并非唯一确定。特别地，对任意矩阵 $Q = P D _ { 1 }$，只要 $A = Q D Q ^ { - 1 }$，其中 $D _ { 1 }$ 是任一非奇异对角矩阵，该关系即成立。因此，若我们定义 $\begin{array} { r } { \nu ( A ) = \operatorname* { i n f } _ { P } \kappa ( P ) } \end{array}$，且该下确界取遍所有使 $P ^ { - 1 } A P$ 为对角矩阵的非奇异矩阵 $ P $，则可得到最优可能的上界：

$$
\| A \| \leq \nu ( A ) \operatorname* { m a x } _ { 1 \leq j \leq n } | \lambda _ { j } | ,
$$

这一结果可视作矩阵 $A$ 的谱半径的一个下界；结合定理 10.3.1，便得出如下结论的前半部分。

定理 1．若 $ A $ 是一个可对角化矩阵（即单矩阵），$ \|\cdot\| $ 是由某个绝对向量范数所诱导的矩阵范数，且 $\begin{array} { r } { \nu ( A ) = \operatorname* { i n f }$ _ { P } $\kappa ( P ) } \end{array}$ ，其中  P ^ { - 1 } A P  为对角矩阵，则

$$

{ \frac { \| A \| } { \nu ( A ) } } \leq \operatorname* { m a x } _ { 1 \leq j \leq n } | \lambda _ { j } | \leq \| A \| ,
