雅可比方法的一个缺点在于其强假设：所有顺序主子式均非零。这一条件在贡德尔芬格（Gundelfinger）与弗罗贝尼乌斯（Frobenius）所提出的推广中得到了放宽。

定理 2（S. 贡德尔芬格†）：沿用定理 1 的记号，设序列 (1) 中不出现两个相邻的零。若 det $H _ { r } \neq 0 ;$，则雅可比定理的结论依然成立，只要对序列 (1) 中每一个（孤立的）零 $d _ { i } = 0$ 任意指定一个符号（正或负）即可。

换言之，在计算 v(H) 时，序列 (1) 中的孤立零可以忽略不计。

**证明**． 假设归纳地，该假设对  H _ { 1 } , H _ { 2 } $, \dots , H$ _ { k }  成立。若 $ \det $H _ { k + 1 } $\neq 0 ;$ ，则雅可比定理（Jacobi’s theorem）证明中相应部分可被重复使用，从而表明：从 $ 1, $d _ { 1 } $, \ldots , d$ _ { k } （其中以符号代替零元）到  1 , d _ { 1 } $, \dotsc , d$ _ { k + 1 }  的过渡，将在  d _ { k }  与  d _ { k + 1 } )  之间引入一次符号的改变或保持符号不变；这一结果取决于  H _ { k + }  相较于  H _ { k }  是否多出一个负特征值或正特征值。

设 $ d_{k+1} = \det $H _ { k + 1 } = 0 。则 $\lambda$ _ { i } ^ { ( k + 1 ) }  的至少一个特征值 $( 1 \leq i \leq k + 1$ )必为零。由于  d _ { k } $\neq 0$ 且  d _ { k + 2 } $\neq 0$ ，故  H _ { k + 1 }  恰好有一个零特征值。事实上，若 $\lambda$ _ { i } ^ { ( k + 1 ) } $= \lambda$ _ { s } ^ { ( k + 1 ) } = 0 ( i < s ) , ，则根据定理 8.5.1， H _ { k }  与  H _ { k + 2 }  均具有零特征值，从而导致  d _ { k } = d _ { k + 2 } = 0 。

令  \lambda _ { m + 1 } ^ { ( k + 1 ) } $= 0 \left( 1 \leq m \leq k - 1 \right$ ) 。于是由

$$

\lambda _ { m } ^ { ( k ) } < \lambda _ { m + 1 } ^ { ( k + 1 ) } = 0 < \lambda _ { m + 1 } ^ { ( k ) }
$$


以及

$$

\lambda _ { m + 1 } ^ { ( k + 2 ) } < \lambda _ { m + 1 } ^ { ( k + 1 ) } = 0 < \lambda _ { m + 2 } ^ { ( k + 2 ) }\tag{2}
$$


可知， H _ { k }  的负特征值个数为 $ m $，而  H _ { k + 2 }  的负特征值个数为 $ m + 1 $。因此，$ \operatorname{sign} $d _ { k } = ( - 1 ) ^ { m } 、$ \operatorname{sign} $d _ { k + 2 } = ( - 1 ) ^ { m + 1 } ，进而有  d _ { k } d _ { k + 2 } < 0 。

若 $\lambda _ { 1 } ^ { ( k + 1 ) } = 0$，则 $H _ { k }$ 的所有特征值均为正数，因而 sign $d _ { k } = 1$。此外，我们可在式 (2) 中取 $ m = 0 $，从而得出 sign $d _ { k + 2 } = - 1$。因此，$d _ { k } d _ { k + 2 } < 0$ 再次成立。类似地，当 $\lambda _ { k + 1 } ^ { ( k + 1 } = 0$ 时，亦可得到同一不等式。

由此可知：无论赋予 $d _ { k + 1 } = 0$ 正号、负号，抑或将其省略，均将在 $d _ { k }$ 与 $d _ { k + 2 }$ 之间引入一次符号改变。这便证明了该定理。
