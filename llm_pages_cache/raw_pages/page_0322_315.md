回顾定义可知，$Z _ { k 0 } = \varphi _ { k 0 } ( A )$。若将习题 4.14.3 的结论应用于多项式 $\varphi _ { k 0 } ( \lambda ) , k = 1 , 2 , \ldots , s ,$，则可见 $Z _ { k 0 }$ 是与特征值 $\lambda _ { k }$ 相关联的各成分矩阵之和。由此易见，$Z _ { k 0 }$ 是幂等矩阵，且 $Z _ { k 0 }$ 的值域即为与 $\lambda _ { k }$ 相关联的（右）特征子空间（亦即 $\lambda _ { k } I - A )$ 的核）。因此，习题 4.14.3 的结论可视作定理 1 的一个特例。由此我们推出：对任一可对角化矩阵 A，有  

$$
\sum _ { k = 1 } ^ { s } Z _ { k 0 } = I { \qquad \mathrm { a n d } \qquad } Z _ { k 0 } Z _ { j 0 } = \delta _ { k j } Z _ { k 0 } ,
$$  

尽管其中第一个等式对所有矩阵 $A \in \mathbb { C } ^ { n \times n }$ 均成立（参见习题 1），这一点可直接验证。我们将在定理 2 中证明：第二个等式也普遍成立。

最后，根据习题 9.2.4，可知  

$$
Z _ { k 0 } = \varphi _ { k 0 } ( A ) = \prod _ { j = 1 , j \neq k } ^ { s } ( A - \lambda _ { j } I ) \Bigg / \prod _ { j = 1 , j \neq k } ^ { s } ( \lambda _ { k } - \lambda _ { j } ) .
$$  

习题 1．若 $A \in \mathbb { C } ^ { n \times n }$，证明：在前述记号下，有  

$$
( \mathfrak { a } ) \ I = \sum _ { k = 1 } ^ { s } Z _ { k 0 } \qquad \mathrm { a n d } \qquad ( \mathfrak { b } ) \ A = \sum _ { k = 1 } ^ { s } ( \lambda _ { k } Z _ { k 0 } + Z _ { k 1 } ) .
$$  

提示：对 (a) 部分，在式 (1) 中令 $f ( \lambda ) = 1$；对 (b) 部分，令 $f ( \lambda ) = \lambda$。

习题 2．若 $A \in \mathbb { C } ^ { n \times n }$ 且 $\lambda \not \in \sigma ( A )$，则证明：

$$
R _ { \lambda } ( { \cal A } ) \triangleq ( \lambda I - { \cal A } ) ^ { - 1 } = \sum _ { k = 1 } ^ { s } \sum _ { j = 0 } ^ { m _ { k } - 1 } \frac { j ! } { ( \lambda - \lambda _ { k } ) ^ { j + 1 } } Z _ { k j } .
$$

提示：利用习题 9.3.5。
