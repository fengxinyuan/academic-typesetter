**定理 1**．任意含 $ m $ 个方程、$ n $ 个未知量的线性方程组，均存在一个等价方程组，其增广矩阵具有行最简形。  

在实际计算中，将方程组化为行最简形的过程通常采用高斯消元法（Gauss elimination process），如例 2.7.3 所示。  

**习题 1**．求解下列方程组：  

$$
\begin{array} { c } { { x _ { 2 } + 2 x _ { 3 } = - 1 , } } \\ { { - 2 x _ { 1 } = 6 , } } \\ { { 4 x _ { 1 } - 2 x _ { 2 } - 4 x _ { 3 } = - 1 0 , } } \end{array}
$$  

其增广矩阵为：  

$$
\left[ { \begin{array} { r r r r } { 0 } & { 1 } & { 2 } & { - 1 } \\ { - 2 } & { 0 } & { 0 } & { 6 } \\ { 4 } & { - 2 } & { - 4 } & { - 1 0 } \end{array} } \right]
$$  

（见例 2.7.3）。该例中已证得其行最简形为：  

$$
{ \left[ \begin{array} { l l l l } { 1 } & { 0 } & { 0 } & { - 3 } \\ { 0 } & { 1 } & { 2 } & { - 1 } \\ { 0 } & { 0 } & { 0 } & { 0 } \end{array} \right] } ,
$$  

（参见式 (2.7.5)），这意味着该方程组

$$
\begin{array} { c } { 1 \cdot x _ { 1 } + 0 \cdot x _ { 2 } + 0 \cdot x _ { 3 } = - 3 , } \\ { 0 \cdot x _ { 1 } + 1 \cdot x _ { 2 } + 2 x _ { 3 } = - 1 } \end{array}
$$  

等价于原方程组。因此，关系式  

$$
x _ { 1 } = - 3 , ~ x _ { 2 } = - 1 - 2 t , ~ x _ { 3 } = t ,
$$  

中参数 $ t $ 可取任意值，由此描述了该方程组的所有（无穷多个）解。□  

接下来考虑含 $ n $ 个未知量的 $ n $ 元线性方程组。我们回顾：若该方程组的系数矩阵 $ A $ 是非奇异的，则 $ A $ 行等价于 $n \times n$ 单位矩阵（习题 2.7.6）。因此，存在一个非奇异矩阵 $ B $，使得 $B A = I _ { n }$，且方程 (4) 可改写为如下等价形式：  

$$
\begin{array} { r } { { \bf { x } } = B A { \bf { x } } = B { \bf { b } } . } \end{array}
$$  

显然，$B = A ^ { - 1 }$，于是方程 (4) 的解为 ${ \pmb x } = { \pmb A } ^ { - 1 } { \pmb b }$，且该解唯一，因为逆矩阵是唯一的。
