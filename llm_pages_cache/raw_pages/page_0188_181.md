**定理 1.** 矩阵 $ H $ 是正定的（或正半定的），当且仅当它具有一个正定的（相应地，正半定的）平方根 $ H_0 $。此外，$ \text{$H _ { 0 }$} $，且 $ \operatorname{rank} \, \text{$H _ { 0 } $= \mathrm { r a n k } } = \operatorname{rank} \, H $。

**证明.** 若 $ \text{$H  $\geq 0 } $，则由定义知，其特征值 $ \text{$\{ $\lambda$ _ { i } \} _ { i = 1 } ^ { n }$} $ 非负；于是可定义一个实矩阵 $ \text{$D _ { 0 } $= \mathrm { d i a g } [ \sqrt { \lambda$ _ { 1 } } $, \sqrt { \lambda$ _ { 2 } } $, \dots , \sqrt { \lambda$ _ { n } } ]$} $。矩阵 $ H $ 是正规矩阵，故存在一个酉矩阵 $ U $，使得 $ \text{$H =$} \, \text{$U D U ^ { * }$} $，其中 $ \text{$D = D _ { 0 } ^ { 2 }$} $。所求的 $ H $ 的平方根即为矩阵  

$$
\text{$$
H _ { 0 } = U D _ { 0 } U ^ { * } $,\tag{1}$ 
$$}
$$  

因为 $ \text{$H _ { 0 } ^ { 2 } = U D _ { 0 } U ^ { * } U D _ { 0 } U ^ { * } $\approx U D$ _ { 0 } ^ { 2 } U ^ { * } = H$} $。注意，表示式 (1) 表明：$ H_0 $ 的特征值恰为 $ H $ 的特征值 $ \text{$H _ { 0 }$} $ 的（算术）平方根。由此即得 $ \operatorname{rank} \, \text{$H _ { 0 } $= \mathrm { r a n k } \ H } = \operatorname{rank} \, H $（参见习题 5.3.9），而 $ \text{$H  $\geq 0 } $ 又推出 $ \text{$H _ { 0 } $\geq 0 . } $。

反之，若 $ \text{$H = H _ { 0 } ^ { 2 }$} $ 且 $ \text{$H _ { 0 } $\geq 0 , } $，则 $ H $ 的特征值作为 $ H_0 $ 的特征值的平方，必为非负数。因此 $ \text{$H _ { 0 }$} \, \text{$H  $\geq 0 . } $。该事实亦蕴含秩的相等性。
