## 2.10 LU 分解

再次考虑定理 2.7.3，并设矩阵 $ A $ 是 $ \text{$n  $\times n } $ 阶方阵，且进一步满足：将其化为标准形（canonical form）的过程中，无需施行第一类初等变换（即不需交换任意两行或两列）。此时，其标准形为  

$$
\bar { D _ { 0 } } = \left[ \begin{array} { l l } { { I _ { r } } } & { { 0 } } \\ { { 0 } } & { { 0 } } \end{array} \right]
$$  

当 $ \text{$r < n ,$} $ 时成立；我们约定将 $ \text{$D _ { $\pmb { 0 } } } $ 解释为 $ \text{$I _ { n } $\operatorname { i f } r = n . } $。于是，由定理 2.7.3 可得  

$$
( E _ { k } E _ { k - 1 } \cdot \cdot \cdot E _ { 1 } ) A ( E _ { k + 1 } E _ { k + 2 } \cdot \cdot \cdot E _ { k + s } ) = D _ { 0 }
$$  

其中，$ \text{$E _ { 1 } , E _ { 2 } $, \ldots , E$ _ { k }$} $ 和 $ \text{$E _ { k + 1 } ,$} $ 均为下三角初等矩阵，而 $ \text{$E _ { k + 2 } $, \ldots , E$ _ { k + s }$} $ 为上三角初等矩阵。由于初等矩阵的逆矩阵仍是同类型的初等矩阵，因此可将上式改写为  

$$
A = L U ,\tag{1}
$$  

其中，$ \text{$L = E _ { 1 } ^ { - 1 } E _ { 2 } ^ { - 1 } $\cdot \cdot \cdot E$ _ { k } ^ { - 1 }$} $ 是一个非奇异的下三角矩阵；又令 $ \text{$U = D _ { 0 } E _ { k + s } ^ { - 1 } $\cdot \cdot \cdot E$ _ { k + 2 } ^ { - 1 } E _ { k + 1 } ^ { - 1 }$} $，它是一个上三角矩阵；若 $ \text{$D _ { 0 }$} $（从而 $ A $）是非奇异的，则 $ U $ 亦为非奇异矩阵。形如式 (1) 的、将 $ A $ 分解为两个三角矩阵乘积的形式，称为 $ A $ 的 **LU 分解**（LU decomposition）。

当这种因式分解已知时，求解线性方程组 $\pmb { A } \pmb { x } = \pmb { b }$ 相对快速且简单。首先求解方程组 $L y = b$。回顾可知，$L$ 是非奇异矩阵，因此由定理 2.9.2，存在唯一的解向量 y。
