反之，若 $F ( A ) = \left[ \lambda _ { 1 } , \lambda _ { n } \right]$，则 $ A $ 是埃尔米特矩阵，且 $\lambda _ { 1 } , \lambda _ { n }$ 分别为 $ A $ 的最小与最大特征值。

该结果可直接由定理 2 与定理 3 推出。

回顾 $F ( H )$ 的定义，并结合式 (1)，可知存在单位球面上的向量 $\mathbf { x } _ { 1 }$ 与 ${ \pmb x } _ { n }$，使得 $( H \pmb { x } _ { 1 } , \pmb { x } _ { 1 } ) = \lambda _ { 1 }$ 且 $( H \pmb { x } _ { n } , \pmb { x } _ { n } ) =$ = $\lambda _ { n }$。显然，

$$
\lambda _ { 1 } = ( H x _ { 1 } , x _ { 1 } ) = \operatorname* { m i n } _ { ( \pmb { x } , \pmb { x } ) = 1 } ( H \pmb { x } , \pmb { x } ) ,\tag{2}
$$

以及

$$
\lambda _ { n } = ( H \mathbf { x } _ { n } , \mathbf { x } _ { n } ) = \operatorname* { m a x } _ { ( \pmb { x } , \pmb { x } ) = 1 } ( H \pmb { x } , \pmb { x } ) .\tag{3}
$$

此外，向量 $\mathbf { x } _ { 1 }$ 与 $\mathbf { x } _ { n }$ 分别是 $ H $ 关于特征值 $\lambda _ { 1 }$ 与 $\lambda _ { n }$ 的特征向量。事实上，由式 (2) 可知：若 $ x $ 是任一满足 $( { \pmb x } , { \pmb x } ) = 1$ 的向量，则

$$
( H \mathbf { x } , \mathbf { x } ) \geq \lambda _ { 1 } = \lambda _ { 1 } ( \mathbf { x } , \mathbf { x } ) .
$$

因此

$$
( ( H - \lambda _ { 1 } I ) \mathbf { x } , \mathbf { x } ) \geq 0 ,
$$

这表明 $H - \lambda _ { 1 } I$ 是半正定矩阵。但式 (2) 同时也蕴含

$$
( ( H - \lambda _ { 1 } I ) x _ { 1 } , x _ { 1 } ) = 0 ,
$$

并且由此（如习题 5.4.1 中所示）可得 $( H - \lambda _ { 1 } I ) \pmb { x } _ { 1 } = \pmb { \mathscr { 0 } } .$。由于 $( { \pmb x } _ { 1 } , { \pmb x } _ { 1 } ) = 1$，故有 $\ b x _ { 1 } \neq \ b \theta$，因此 $\mathbf { x } _ { 1 }$ 是埃尔米特矩阵 $ H $ 关于特征值 $\lambda _ { 1 }$ 的一个特征向量。

类似地，$x _ { n }$ 是 $ H $ 关于其最大特征值 $\lambda _ { n }$ 的一个特征向量。于是，我们证明了如下结论：

**定理 4**．设 $\lambda _ { 1 }$ 与 $\lambda _ { n }$ 分别表示埃尔米特矩阵 $H \in \mathbb { C } ^ { n \times n }$ 的最小与最大特征值，则

$$
\lambda _ { 1 } = \operatorname* { m i n } _ { ( \mathbf { x } , \mathbf { x } ) = 1 } ( H \mathbf { x } , \mathbf { x } ) , \qquad \lambda _ { n } = \operatorname* { m a x } _ { ( \mathbf { x } , \mathbf { x } ) = 1 } ( H \pmb { x } , \pmb { x } ) .
$$

此外，二次型 $ (Hx, x) $ 的极值在 $ H $ 的相应特征向量处达到。

该结果是埃尔米特矩阵特征值的极小-极大理论（min-max theory）发展的第一步，而这一理论正是本章的主要课题之一。
