对于以行矩阵或列矩阵形式表示的有序 n 元组，该运算自然推广为  

$$
\begin{array} { r l } { [ x _ { 1 } } & { x _ { 2 } \quad \cdots \quad x _ { n } ] + [ y _ { 1 } \quad y _ { 2 } \quad \cdots \quad y _ { n } ] } \\ & { \triangleq [ x _ { 1 } + y _ { 1 } \quad x _ { 2 } + y _ { 2 } \quad \cdots \quad x _ { n } + y _ { n } ] } \end{array}
$$  

或  

$$
{ \left[ \begin{array} { l } { x _ { 1 } } \\ { x _ { 2 } } \\ { \vdots } \\ { x _ { n } } \end{array} \right] } + { \left[ \begin{array} { l } { y _ { 1 } } \\ { y _ { 2 } } \\ { \vdots } \\ { y _ { n } } \end{array} \right] } \triangleq { \left[ \begin{array} { l } { x _ { 1 } + y _ { 1 } } \\ { x _ { 2 } + y _ { 2 } } \\ { \vdots } \\ { x _ { n } + y _ { n } } \end{array} \right] } .
$$

也就是说，所得向量的各元素（或称分量、坐标）仅仅是相应位置上两个向量对应元素的和。注意：仅当两个向量维数相同时，它们才可相加。

现在，对同型矩阵  \begin{array} { r } { A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } } $\end{array}$ 与  B = [ b _ { i j } ] _ { i , j = 1 } ^ { m , n } ，如下定义其和是自然的：

$$

A + B \triangleq [ a _ { i j } + b _ { i j } ] _ { i , j = 1 } ^ { m , n } .
$$


实数与复数（我们统称为标量）所具有的性质，显然可推出矩阵加法满足交换律与结合律。

习题 1．证明：对同型矩阵，有

$$

\begin{array} { c } { A + B = B + A , } \\ { ( A + B ) + C = A + ( B + C ) . } \end{array}
$$


这些运算法则使得若干同型矩阵之和的定义与计算变得简便。特别地，显然任意多个 $ n \times n $ 上三角矩阵（相应地，下三角矩阵）之和仍为上三角矩阵（相应地，下三角矩阵）。还需注意：同阶的若干个对角矩阵之和仍为对角矩阵。

矩阵的减法运算按数的减法方式来定义。即，对同型矩阵 $ A $ 与 $ B $，其差记作  A \ : - \ : B , ，是指满足下式的矩阵 $ X $：

$$

X \cdot + B = A .
$$


显然，

$$

A - B = [ a _ { i j } - b _ { i j } ] _ { i , j = 1 } ^ { m , n } ,
$$


其中

$$

A = [ a _ { i j } ] _ { i , j = 1 } ^ { m , n } , \qquad B = [ b _ { i j } ] _ { i , j = 1 } ^ { m , n } .
$$


显然，零矩阵在矩阵运算中扮演着数系中“零”的角色：将零矩阵加到任一矩阵上，或从该矩阵中减去零矩阵，均不改变该矩阵。

在引入矩阵与标量相乘这一运算之前，先回顾三维欧几里得空间中（位置）向量的相应定义：若 $\mathbf { \sigma } _ { \pmb { a } } ^ { \mathbf { \hat { r } } } = [ \pmb { a } _ { 1 } \quad \pmb { a } _ { 2 } \quad \pmb { a } _ { 3 } ]$，且 α 表示一个实数，则向量 $\alpha a ^ { \mathbf { T } }$ 定义为  

$$
\alpha { \pmb a } ^ { \dag } \triangleq [ \alpha { \pmb a } _ { 1 } \quad \alpha { \pmb a } _ { 2 } \quad \alpha { \pmb a } _ { 3 } ] .
$$  

因此，在向量与标量的乘积中，向量的每个分量均乘以该标量。

此运算对实向量与实标量具有直观的几何意义（参见图 1.3）：向量 ${ \pmb { \alpha } } { \pmb { a } } ^ { \dagger }$ 的长度等于 $| \alpha |$ 倍的向量 ${ \pmb a } ^ { \dagger }$ 的长度；当 $\alpha > 0$ 时，其方向保持不变；当 ${ \pmb { \alpha } } < { \bf 0 }$ 时，其方向则恰好相反。
