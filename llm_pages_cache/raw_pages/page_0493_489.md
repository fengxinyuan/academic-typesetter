## 矩阵多项式

在 §4.13 与 §9.10 中已指出：常系数（即时不变）微分方程组  
${ \dot { \mathbf { x } } } ( t ) - A { \mathbf { x } } ( t ) \mathbf { \mu } = f ( t ) .$  
的解——其中  $A \in \mathbb { C } ^ { n \times n }$ ，且初始条件  ${ \pmb x } ( 0 )$  给定——完全由矩阵值函数  $\lambda I - A$  的性质所决定。更具体地说，该解由行列式 $ \det $( $\lambda I - A$ )的零点，以及子空间  $\boldsymbol { \mathrm { K e r } } ( \lambda I - A ) ^ { j }$  在  $\mathbb { C } ^ { n } , \ j = 0 , 1 , 2 , \ldots , n .$  中的一组基所确定。这些谱性质又可进一步归结为矩阵 $ A $ 的若尔当标准形；或者，如我们接下来将表述的那样，归结为  $\lambda I - A$  的若尔当标准形。

本章†的分析将允许我们描述高阶系统初值问题的解：  

$$
L _ { l } \mathbf { \boldsymbol { x } } ^ { ( l ) } ( t ) + L _ { l - 1 } \mathbf { \boldsymbol { x } } ^ { ( l - 1 ) } ( t ) + \cdot \cdot \cdot + L _ { 1 } \mathbf { \boldsymbol { x } } ^ { ( 1 ) } ( t ) + L _ { 0 } \mathbf { \boldsymbol { x } } ( t ) = f ( t ) ,\tag{1}
$$  

其中 $L _ { 0 } , L _ { 1 } , \dots , L _ { l } \in \mathbb { C } ^ { n \times n } ,$，det $L _ { l } \neq 0 ,$，且下标表示关于独立变量 $ t $ 的导数。当前所涉及的基本代数问题，是与之关联的 $ m $ 次矩阵多项式 $\begin{array} { r } { L ( \lambda ) = \sum _ { j = 0 } ^ { l } \lambda ^ { j } L _ { j } } \end{array}$，该多项式已在第 7.1 节中引入。我们将注意力限定于 det $L _ { l } \neq 0$ 成立的情形。由于多项式 det $L ( \lambda )$ 中 $ \lambda^m $ 项的系数恰好为 det $L _ { t }$，因此可知 $L ( \lambda )$ 是正则的；换言之，依第 7.5 节的术语，其秩为 $ n $。

与一阶微分方程组类似，即使系数矩阵为埃尔米特矩阵，要构造方程 (1) 的通解，仍需建立 $L ( \lambda )$ 的“若尔当结构”，而本章即致力于此项工作。朝此方向迈出的重要初步步骤已在第 7 章完成；我们尤其回顾史密斯标准型（Smith normal form）与初等因子（elementary divisors），二者在 $L ( \lambda )$ 的相抵变换下均保持不变。在第 7 章中，这些概念被用于构建 $\lambda I - A$（或矩阵 $ A $）的若尔当结构；而今，它们将被应用于更一般矩阵多项式谱性质的分析之中。
