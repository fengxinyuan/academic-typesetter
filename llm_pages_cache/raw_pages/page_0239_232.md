## 6.4 广义特征子空间的结构

在前一节中，我们已引入了广义特征子空间与若尔当链的一些基本概念。本节将运用这些概念，证明式 (6.2.4) 所定义的每一个广义特征子空间  \mathscr { G } _ { i }  均存在一组基，该基由一个或若干个若尔当链构成。

设  T  $\in { \mathcal { L } } ( { \mathcal { S } }$ )，其中 $\mathcal F = \mathbb C$ ，并设 $\mathcal { S }$ _ { p } $= \mathop { \bf K e r } ( T - \lambda I ) ^ { p }$ 为线性算子 $ T $ 关于特征值 $\lambda ,$ 的最大阶数为 $ p $ 的广义特征子空间，即  
$$
$\mathcal { S } _ { p - 1 } \neq \mathcal { S } _ { p } = \mathcal { S } _ { p + 1 }$.
$$  
满足该条件的子空间  \mathcal { S } _ { p }  称为 $ T $ 关于 $ \lambda $ 的广义特征子空间。因此，若仅称某特征值“对应的广义特征子空间”而未指明阶数，则隐含所指为**最大阶数**的广义特征子空间；事实上，此处的阶数 $\mathbf { i s } ,  $ 即为最大可能的阶数。

**定理 1.** 存在唯一的直和分解  

$$

\mathcal { S } _ { p } = \sum _ { i = 1 } ^ { t _ { p } } \cdot \mathcal { J } _ { p } ^ { ( i ) } \dot { + } \sum _ { i = 1 } ^ { t _ { p - i } } \cdot \mathcal { J } _ { p - 1 } ^ { ( i ) } \dot { + } \cdots \dot { + } \sum _ { i = 1 } ^ { t _ { 1 } } \cdot \mathcal { J } _ { 1 } ^ { ( i ) } ,
$$
  

其中每个  \mathcal { J } _ { j } ^ { ( i ) } $\left( 1 \leq j \leq p , 1 \leq i \leq t$ _ { j } $\right$ )是一个维数为 $ j $ 的循环若尔当子空间。

在此  \mathcal { S } _ { p } ,  的分解中，可能出现  t _ { j } = 0  的情形；此时，右侧对应项之和被理解为平凡子空间  \{ $\pmb { \theta } \}  $。

定理 1 表明：在  \mathsf { K e r } $( T - \lambda I ) ^ { p }$ 中存在一组由若尔当链构成的基；每条若尔当链构成某个循环若尔当子空间 $\mathcal { J }$ _ { j } ^ { ( i ) }  的一组基，且 $( 1 \leq j \leq p , 1 \leq i \leq t$ _ { j } ) 。具体而言，从  j = p ,  出发，我们得到如下基：

$$
\begin{array} { l l l l l } { x _ { 1 } ^ { ( 1 ) } , } & { x _ { 2 } ^ { ( 2 ) } , } & { \cdots , } & { x _ { 0 } ^ { ( n _ { 2 } ) } , } & { x _ { 0 } ^ { ( n ) } , } \\ { \vdots } & { \vdots } & { \vdots } & { \vdots } & { \vdots } \\ { x _ { 1 } ^ { ( n _ { p } ) } , } & { x _ { 2 } ^ { ( n _ { p } ) } , } & { \cdots , } & { x _ { p - \cdot } ^ { ( n _ { p } ) } , } & { x _ { p } ^ { ( n _ { p } ) } , } \\ { x _ { 1 } ^ { ( t _ { p } + 1 ) } , } & { x _ { 2 } ^ { ( t _ { p } + 1 ) } , } & { \cdots , } & { x _ { p - \cdot } ^ { ( t _ { p } + 1 ) } , } \\ { \vdots } & { \vdots } & { \ddots } & { \vdots } \\ { x _ { 1 } ^ { ( t _ { p } + t _ { p - 1 } ) } , } & { x _ { 2 } ^ { ( t _ { p } + t _ { p - 1 } ) } , } & { \cdots , } & { x _ { p - 1 } ^ { ( t _ { p } + t _ { p - 1 } ) } , } \\ { \vdots } & { \vdots } & \\ { x _ { 1 } ^ { ( t _ { - 1 } + 1 ) } , } & { } & { } & { } & { } \\ { \vdots } & { } & { } & { } & { } \\ { x _ { 2 } ^ { ( t ) } } & { } & { } & { } & { } \end{array}\tag{1}
$$  

其中，$\begin{array} { r } { t = \sum _ { j = 1 } ^ { p } t _ { j } } \end{array}$，且每一行的元素构成关于 λ 的最长可能长度的若尔当链。此外，(1) 中第 r 列的元素是 T 关于特征值 λ 的 r 阶广义特征向量。上述 (1) 所给出的 $\mathrm { K e r } ( T - \lambda I ) ^ { p }$ 的基称为该广义特征子空间的一个若尔当基。
