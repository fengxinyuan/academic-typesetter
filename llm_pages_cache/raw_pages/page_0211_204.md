其中 $\gamma _ { i j } = \bar { \gamma } _ { j i } \left( i , j = 1 , 2 , \ldots , n \right)$，且 $\alpha _ { i } ( i = 1 , 2 , \ldots , n )$ 是向量 x 关于 ℂⁿ 中某组基的坐标。根据定理 1，由式 (7) 所定义的埃尔米特矩阵 $\mathbb { C } ^ { n } .$ 与 $\pmb { \tilde { A } } = [ \gamma _ { i j } ] _ { i , j = 1 } ^ { n }$ 是合同的。因此，定理 5.5.1 断言：在 $\mathbb { C } ^ { n }$ 中存在一组基，使得该埃尔米特型在此基下的矩阵为 $\tilde { A } _ { 0 } = \mathrm { d i a g } [ I _ { s } , - I _ { r - s } , 0 ]$ 形式。在此（规范）基下，埃尔米特型被化为若干（代数）平方项之和：

$$
( \widetilde { A } _ { 0 } x , x ) = \sum _ { i , j = 1 } ^ { n } \gamma _ { i j } ^ { ( 0 ) } \alpha _ { j } \bar { \alpha } _ { j } = \sum _ { i = 1 } ^ { s } | \alpha _ { i } | ^ { 2 } - \sum _ { j = s + 1 } ^ { r } | \alpha _ { j } | ^ { 2 } ,\tag{8}
$$  

其中，$[ { \alpha } _ { 1 } \quad { \alpha } _ { 2 } \quad \cdots \quad { \alpha } _ { n } ] ^ { \mathrm { T } }$ 是向量 $ x $ 关于标准基的坐标表示。

**定理 2.** 对任意埃尔米特型 $( A x , x )$，存在空间 $\mathbb { C } ^ { n }$ 中的一组基，使得该型在此基下的矩阵表示为式 (8) 所示的平方和形式，其中 $s = \pi ( A )$，且 $ r = \operatorname{rank} A $。

**推论 1（西尔维斯特惯性定律）†**：式 (8) 中正平方项与负平方项的个数是埃尔米特型 $ f_A $ 的不变量，分别记为 $f _ { A }$ 和 $s = \pi ( A ) , r - s = \nu ( A )$。

注意，式 (8) 所给出的表示称为 $( A x , x )$ 的**第一标准型**，以区别于其**第二标准型**：

$$
( A x , x ) = \sum _ { i = 1 } ^ { r } \lambda _ { i } | \alpha _ { i } | ^ { 2 } ,\tag{9}
$$  

其中，$\{ \lambda _ { i } \} _ { i = 1 } ^ { r }$ 是矩阵 $ A $ 的所有非零特征值，而 $[ { \alpha } _ { 1 } \quad { \alpha } _ { 2 } \quad \cdots \quad { \alpha } _ { n } ] ^ { \mathrm { { T } } }$ 是向量 $ x $ 关于相应的一组标准正交特征向量基的坐标表示。式 (9) 可直接由定理 5.2.1 推出。此外，由于 $A = U D U ^ { * }$，其中 $D = \mathrm { d i a g } [ \lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { r } , 0 , \ldots , 0 ]$，且 $ U $ 是酉矩阵，故第二标准型 (9) 可通过基的酉合同变换得到。这正是该标准型的一个优势。（参见下一节。）

考虑埃尔米特型的一些特殊情形。类比于矩阵，我们称埃尔米特型 $f ( x )$ 为正定的（相应地，负定的），若对所有非零向量 $\boldsymbol { x } \in \mathbb { C } ^ { n }$，均有 $f ( { \pmb x } ) > 0$（相应地，$f ( x ) < 0 )$）。这一类比亦可自然延拓至半正定与半负定埃尔米特型的定义。

**习题 4.** 验证：一个埃尔米特型是定号的（即正定或负定）或半定号的（即半正定或半负定），当且仅当其生成矩阵（或该型的任一表示矩阵）是同类型的定号或半定号矩阵。

还须指出，埃尔米特矩阵与埃尔米特型之间存在平行对应关系：一个矩阵的秩及其惯性特征（即正、负、零特征值的个数）可直接归于它所生成的埃尔米特型。此外，第 5.5 节中讨论的“通过同一合同变换将两个埃尔米特矩阵同时化为对角矩阵”，等价于将对应的两个埃尔米特型同时化为平方和的形式。
